# Semantic model

The authoritative contract is [SQLSEM-DESIGN-001: read-only semantic model](read-only-design.md).
It supersedes the earlier persistent-update and assertion-only design. The public
model structures meaning and exposes immutable operations, relationships,
references, types, and diagnostics. New requests are constructed from explicit
new input or analyzed from SQL; existing models cannot be edited or rebound.

The [migration inventory](read-only-migration.md) records removed APIs and
outstanding implementation obligations. This branch is not complete until every
SQL form generated by every supported SQL Faker grammar is structured and
reconstructed, rule contracts and correspondence boundaries have been reviewed,
and the full PR CI passes. Current test success is not a claim of that coverage.
