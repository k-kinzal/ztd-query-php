# table yields, which the layout of the file changes. A multi-start grammar
# whose start symbol is a token gets a switching token YY_PARSE_<token> with

# come out one way or the other. Such a file counts as a known tie, not a
# failure. Each is a calc.y of Bison 3.8.2's test suite (calc.at, %start
# input exp NUM).
