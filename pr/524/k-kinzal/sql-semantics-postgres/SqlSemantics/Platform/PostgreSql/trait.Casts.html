trait Casts
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Spells the targets of PostgreSQL's CAST, which names any type.

A builtin type is spelled by its SQL name with the modifiers it declares: a length, a precision and scale, the precision of a time or timestamp, the fields and precision of an interval, and array dimensions. A named type is spelled by its qualified name. A fact PostgreSQL does not have, such as a sign or a character set, is an error.
