Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

What the PHP functions that shape query text do to the values they are given.

Queries are assembled with a small, stable set of string functions. Modelling those keeps a statement resolved that would otherwise become a gap the moment it passed through sprintf() or implode().

public function sprintf(list<Domain> $arguments, Domain $format): Domain
source§

The result of sprintf(), resolved as far as the format and the arguments allow.

A format the analyzer knows only in part — "SELECT * FROM $table WHERE id IN (%s)" — still has conversions in the parts it knows, so those are filled in and the gaps are carried through, rather than the whole result becoming one gap because one piece of the format was not fixed.
