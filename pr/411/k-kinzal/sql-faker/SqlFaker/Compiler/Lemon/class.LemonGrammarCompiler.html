final class LemonGrammarCompiler
Public API: explicitly declared with @visibility public.

Turns a Lemon grammar file into the grammar the generators walk.

The file is read with lemon-parser after its %ifdef regions are settled; this class keeps what generation needs. A position shared by several terminals, A|B, is spelled out into one alternative per terminal, a %token_class becomes a rule with one alternative per member, and the first rule is the start symbol. A name written in capitals, digits and underscores is a terminal, as is the %wildcard token whatever its spelling; every other name is a nonterminal.
