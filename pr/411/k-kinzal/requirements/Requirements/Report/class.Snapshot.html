final class Snapshot

A coverage snapshot lists every source unit in scope with the semantic fingerprint of the records claiming it, and nothing else: no source text. Comparing the current analysis with the snapshot of a trusted base revision yields the new or changed units, which form the differential denominator, and the units the snapshot lists but the scope no longer contains.
