final class MissingResultColumnTypeResolver
    implements ResultColumnTypeResolver

The resolver a session has when no platform gave it one.

It answers nothing, on purpose. A session that can read rows but cannot say what any column is has been built without a platform, and refusing at the first question is what makes that visible.
