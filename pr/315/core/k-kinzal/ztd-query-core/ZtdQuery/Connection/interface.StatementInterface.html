interface StatementInterface

Minimal statement interface for ZTD layer.

This interface defines the contract that all statement adapters must implement to work with the ZTD session. It provides a driver-agnostic API for executing prepared statements and fetching results.

A column of a row is a scalar or null, which is what every driver behind this interface hands back and what every driver will take on the way in. The row itself is a row of a table, so its shape is stated with the table definition and imported here rather than the other way round.
