final class EntryPoint
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

A declared application entry and its explicitly supplied initial inputs.

Properties give the receiver object its initial state. Each key names a declared instance property as seen from the entry method's class; unspecified properties stay symbolic values of their declared types, and a supplied value must satisfy the declared type.
