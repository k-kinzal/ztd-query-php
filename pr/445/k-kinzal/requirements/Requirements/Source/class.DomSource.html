final class DomSource
    implements SourceExtension

Selects elements of HTML, XML, IETF XML and Markdown sources with CSS selectors.

Markdown is rendered to HTML first. XML may not declare a DTD or entities. An evidence selector may also be an exact Text Fragment within an HTML scope. A selection may not contain both an element and one of its descendants.
