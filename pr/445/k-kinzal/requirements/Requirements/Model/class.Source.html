final class Source
Public API: explicitly declared with @visibility public.

A source document a definition quotes, and the scope of units that coverage counts.

The URI is an HTTP(S) URL or a path relative to the configuration; a pinned snapshot is a local copy verified by its SHA-256 digest. The format names the source extension and the selector declares the coverage scope in that extension's syntax.
