AnalysisThe result of analyzing a project's sources: units, scopes, errors and resolved evidence.
AnalyzerSelects every declared scope, resolves every evidence entry and records which units the specifications claim.
ClaimsRecords which specifications account for each source unit.
CoverageBuilds the coverage report and applies the overall, per-source and differential gates.
EvidenceMatcherResolves an evidence entry to the one unit of its item's scope that it quotes completely.
SnapshotA coverage snapshot lists every source unit in scope with the semantic fingerprint of the records claiming it, and nothing else: no source text. Comparing the current analysis with the snapshot of a trusted base revision yields the new or changed units, which form the differential denominator, and the units the snapshot lists but the scope no longer contains.
SourceUnitA unit in scope together with the specifications that claim it.
UnitCollectorGathers the units selected by each declared scope and rejects inconsistent selections.
