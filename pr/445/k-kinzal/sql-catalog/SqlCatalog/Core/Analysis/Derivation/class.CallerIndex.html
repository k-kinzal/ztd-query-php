final class CallerIndex
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Every call in the source, by the name it is written with.

Going from a parameter to the arguments passed for it means finding the calls that reach the function. The calls are gathered once, by name, so that finding them is a lookup; deciding which of them really reach the function is left to whoever asks, because that can need their receivers.
