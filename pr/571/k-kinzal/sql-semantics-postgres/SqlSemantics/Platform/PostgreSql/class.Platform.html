public function relations(): RelationRules
source§

Names the positions where the grammar writes table names, and the forms that declare, drop, or merely name tables.

The body of a common table expression names the ones written before it in a plain WITH clause, and every one of a recursive clause, itself and later ones included. The table INSERT, UPDATE, DELETE, or MERGE writes to is always a table, never a common table expression.
