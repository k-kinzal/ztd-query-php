final class ObjectSpelling
Restricted visibility: declared "@visibility SqlSemantics\Platform\PostgreSql". Code outside that scope must not name this declaration.

Writes the keywords of an object kind in a generic object command.

Rule: PG-OBJECT-SPELLING-001. Each kind is written with its keywords; a domain constraint is written CONSTRAINT and its object adds ON DOMAIN. The optional PROCEDURAL before LANGUAGE is a noise word and not written. Source: https://www.postgresql.org/docs/17/sql-comment.html. Status: Implemented.
