final class CaseTyping
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Types a CASE expression.

Rule: PG-CASE-TYPING-001. The operand, then each branch's condition and result, then the ELSE result are derived in order. In a searched CASE each condition must be boolean (PG-OPERAND-CHECK-001); with an operand each condition is a value compared with it by =. The result is of the common type of the results and the ELSE result (PG-UNIFICATION-001); a conflict is reported. The result can be NULL when a result can, and when no ELSE is written. Termination: one pass over the branches. Source: https://www.postgresql.org/docs/17/functions-conditional.html#FUNCTIONS-CASE, https://www.postgresql.org/docs/17/typeconv-union-case.html. Status: Implemented.
