final class Catalogs
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

The entry point of the catalog family: schemas, databases, tablespaces, extensions, foreign data, languages, access methods, publications, subscriptions, text search, collations, conversions, domains, types, casts and transforms.

Rule: PG-CATALOG-001. Scope: the statement nonterminals of the family (php .agent/pg-families.php Catalog), each handed to the rule of its group, and opt_enum_val_list, enum_val_list. Termination: each statement is lowered by one rule; lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-commands.html. Status: Implemented.
