final class SequenceRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers sequence options.

Rule: PG-SEQUENCE-OPTION-LOWER-001. Scope: OptSeqOptList, OptParenthesizedSeqOptList, SeqOptList, SeqOptElem, opt_by. The optional BY of INCREMENT and WITH of START and RESTART are noise (TableNoise, LeafNoise). Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-createsequence.html. Status: Implemented.
