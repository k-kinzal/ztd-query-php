final class WithRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers WITH clauses and their common table expressions.

Rule: PG-WITH-LOWER-001. Scope: opt_with_clause, with_clause, cte_list, common_table_expr, opt_materialized, opt_search_clause, opt_cycle_clause. Constructors: WithClause, CommonTableExpression, SearchClause, CycleClause. The statement of a common table is lowered by the manipulation family (PreparableStmt). Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/queries-with.html. Status: Implemented.
