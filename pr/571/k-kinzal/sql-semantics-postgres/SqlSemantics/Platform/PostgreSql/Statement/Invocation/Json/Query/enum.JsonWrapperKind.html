enum JsonWrapperKind: string
Public API: explicitly declared with @visibility public.

Whether JSON_QUERY wraps the items found in an array.

UNCONDITIONAL is the default after WITH and, like the optional ARRAY word, noise: WITH WRAPPER is the unconditional wrapper. Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-SQLJSON-QUERYING.
