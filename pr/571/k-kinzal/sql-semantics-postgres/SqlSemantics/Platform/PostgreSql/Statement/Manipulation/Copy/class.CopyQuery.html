Public API: explicitly declared with @visibility public.

COPY of the rows of a query to a file, a program or the client.

Mirrors PostgreSQL's CopyStmt with a query. The query is a query statement or a data-modifying statement with RETURNING. The facts follow PG-COPY-001. Source: https://www.postgresql.org/docs/17/sql-copy.html. Status: Implemented.
