final class NumericConstant
    implements Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

The exact value of a numeric constant written with a decimal point or an exponent.

The value is the integer digits, the fraction digits and the power of ten; no floating-point number is involved. The fraction digits are kept as written because their count is the display scale of the numeric value, so 1.0 and 1.00 are different constants. Source: https://www.postgresql.org/docs/17/sql-syntax-lexical.html#SQL-SYNTAX-CONSTANTS-NUMERIC.
