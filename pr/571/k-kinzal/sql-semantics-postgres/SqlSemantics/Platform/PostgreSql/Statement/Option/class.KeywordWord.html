    implements OptionArgument

Public API: explicitly declared with @visibility public.

A reserved keyword, or NONE, written as the value of a definition option.

A definition accepts any reserved keyword as a value and passes its lower-case text to the command, as in CREATE OPERATOR ... (commutator = none) or (analyze = true). Source: https://www.postgresql.org/docs/17/sql-createoperator.html.
