final class CreateForeignTable
    implements Relation, Statement
    uses Snapshot
Public API: explicitly declared with @visibility public.

A request to create a foreign table: a table whose rows a foreign server provides.

Mirrors PostgreSQL's CreateForeignTableStmt (a CreateStmt with servername and options). Like CREATE TABLE it provides a declaration (PG-TABLE-DECLARATION-001); its relation fact resolves to it. Source: https://www.postgresql.org/docs/17/sql-createforeigntable.html.
