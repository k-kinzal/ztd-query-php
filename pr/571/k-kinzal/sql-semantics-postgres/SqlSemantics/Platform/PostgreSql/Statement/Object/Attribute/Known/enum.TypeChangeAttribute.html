enum TypeChangeAttribute: string
    implements KnownAttribute
Public API: explicitly declared with @visibility public.

A property ALTER TYPE ... SET recognizes.

AlterType reads storage as one of the storage words and receive, send, typmod_in, typmod_out, analyze and subscript as functions (without a value, or with NONE, the function is removed). The other attributes of CREATE TYPE are recognized only to be refused: they cannot be changed. Any other property, analyse included, is an error. Source: https://www.postgresql.org/docs/17/sql-altertype.html, AlterType in src/backend/commands/typecmds.c of PostgreSQL 16 and 17.
