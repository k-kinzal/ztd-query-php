ALTER [ COLUMN ] ... ADD GENERATED ... AS IDENTITY: makes a column an identity column.

Mirrors AT_AddIdentity with the sequence options. The column must exist, and its declared type is checked by PG-IDENTITY-TYPE-001. Source: https://www.postgresql.org/docs/17/sql-altertable.html.
