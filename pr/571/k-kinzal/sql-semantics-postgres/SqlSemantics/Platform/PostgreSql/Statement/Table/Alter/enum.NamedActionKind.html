enum NamedActionKind: string
Public API: explicitly declared with @visibility public.

The relation actions on one named object: an index, a constraint, a tablespace, a trigger or a rule.

Mirrors AT_ClusterOn, AT_ValidateConstraint, AT_SetTableSpace and the trigger and rule firing actions. Source: https://www.postgresql.org/docs/17/sql-altertable.html.
