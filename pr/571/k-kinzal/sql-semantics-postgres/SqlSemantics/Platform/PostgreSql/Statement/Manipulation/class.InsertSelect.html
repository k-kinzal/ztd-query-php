final class InsertSelect
    implements Modification
    uses Snapshot
Public API: explicitly declared with @visibility public.

An INSERT of the rows of a query.

Mirrors PostgreSQL's InsertStmt whose selectStmt is a query other than a bare VALUES list (a VALUES list with WITH, ORDER BY, LIMIT or locking clauses is such a query). The query does not see the target table; its output columns are assigned to the target columns in order. The facts follow PG-INSERT-001. Source: https://www.postgresql.org/docs/17/sql-insert.html. Status: Implemented.
