final class Grouped
    implements Scalar, OutputNaming
    uses Snapshot
Public API: explicitly declared with @visibility public.

An expression written in parentheses: ( a_expr ).

The raw parser of PostgreSQL keeps no node for the parentheses, but they fix the evaluation structure of what they enclose, so the model keeps them as written; rendering never adds or removes a grouping.

Rule: PG-GROUPED-001. The type, the NULL fact and the output name are those of the operand; the name resolution stays with the operand. A query in parentheses is a scalar subquery, and more parentheses around it belong to the query, so a grouping never encloses a scalar subquery. Source: https://www.postgresql.org/docs/17/sql-expressions.html. Status: Implemented.
