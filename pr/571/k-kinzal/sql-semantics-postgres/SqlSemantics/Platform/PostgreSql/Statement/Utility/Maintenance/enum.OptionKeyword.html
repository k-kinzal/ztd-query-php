enum OptionKeyword: string
Public API: explicitly declared with @visibility public.

The option names the grammar reads as keywords of their own.

ANALYZE is a reserved word with the British spelling ANALYSE; both name the option analyze. FORMAT directly before the word JSON is read as a keyword of its own and names the option format. Every other option name is an ordinary word. The value is the keyword. Source: https://www.postgresql.org/docs/17/sql-explain.html, https://www.postgresql.org/docs/17/sql-analyze.html.
