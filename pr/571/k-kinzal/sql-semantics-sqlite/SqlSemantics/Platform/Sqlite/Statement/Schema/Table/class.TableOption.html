final class TableOption
    implements Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

One option written after the closing parenthesis of a table definition.

Rule: SQLITE-TABLE-OPTION-001. The grammar accepts WITHOUT name and name for any name. SQLite compares the written text of the name, without regard to ASCII case, with rowid after WITHOUT and with strict otherwise; every other word, and either word in quotes, is the error "unknown table option". The word is therefore kept with its quoting. Source: https://sqlite.org/syntax/table-options.html. Status: Implemented.
