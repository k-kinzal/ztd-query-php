final class ColumnUse
    implements Scalar
    uses Snapshot
Public API: explicitly declared with @visibility public.

A name used as a value: a request to resolve it as a column at its position.

The node holds the decoded name and qualifier only. Which occurrence and declaration it denotes is a fact of the operation that contains it. A name written bare, in brackets or in backticks is always this request; a word in double quotes and the bare words TRUE and FALSE are other requests.

Rule: SQLITE-COLUMN-USE-001. Facts: the resolution of SQLITE-COLUMN-LOOKUP-001 and the facts of SQLITE-COLUMN-FACT-001. Source: https://sqlite.org/lang_expr.html#column_names. Status: Implemented.
