Public API: explicitly declared with @visibility public.

Composes SQLite values under stable names.

A name that spells a keyword is always quoted, even one the parser would fall back to reading as an identifier, because the fallback depends on the position the name is written in. Double quotes delimit names; strings double their quotes and know no escapes.
