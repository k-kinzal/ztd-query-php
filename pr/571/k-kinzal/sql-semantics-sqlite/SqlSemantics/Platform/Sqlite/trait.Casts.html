Spells the targets of SQLite's CAST, a type name whose affinity the value takes.

A builtin type is spelled by its name and a named type by its words, with the length, or precision and scale, it declares. SQLite converts to the affinity of the name, so a type whose affinity differs from the one its spelling has, such as ANY in a STRICT table, is an error, and so is a column without a declared type.
