final class TokenCorrespondence
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Compares the significant tokens of the analyzed SQL with those of the rendered SQL.

Both parse trees are reduced to the ordered comparison keys of their tokens. Equal sequences establish that rendering the model reproduces every significant token of the input in order; whitespace, comments, letter case of keywords, equivalent spellings of one name or literal, and the positions a database package declares as noise are not significant.
