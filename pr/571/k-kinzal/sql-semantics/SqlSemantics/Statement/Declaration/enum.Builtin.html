enum Builtin: string
Public API: explicitly declared with @visibility public.

A built-in database type the binder models, named after its canonical SQL spelling.

Each dialect maps its own spellings and synonyms onto these cases and reports which cases it supports. Three cases are not declared types: Unknown is the type of a value the binder has not resolved, such as NULL or a parameter; Dynamic is a value whose storage class is decided at run time; Any is a declared type that accepts every storage class.
