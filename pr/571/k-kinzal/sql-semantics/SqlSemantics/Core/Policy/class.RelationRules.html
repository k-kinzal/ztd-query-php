Where a grammar writes table names, and which of those positions declare, drop, or merely name a table.

A database package describes its grammar with symbols rather than with generated classes: the symbols whose values are table names, and the forms whose names are declarations, drops, common table expressions, or names of other objects that are not tables. Every other table name is a reference.

It also describes where common table expressions are visible: the symbols at which a form writes its WITH clause, the fixed word that makes the clause recursive, which expressions of its own clause the body of an expression can name, and the positions, such as the target of a DML statement, whose names never refer to a common table expression.
