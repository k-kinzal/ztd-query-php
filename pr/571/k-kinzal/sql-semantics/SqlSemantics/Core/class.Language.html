final class Language
Public API: explicitly declared with @visibility public.

The language SQL is read and written in: a dialect, a grammar release, a mode, and a parameter syntax.

Every entry point resolves its language once, so the parser, the statement vocabulary of the release, and the settings the text is read under are the same for analysis, splitting, and composition.
