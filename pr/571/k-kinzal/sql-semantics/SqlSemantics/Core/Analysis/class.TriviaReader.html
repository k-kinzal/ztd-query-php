final class TriviaReader
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Reads the comments out of the whitespace and comments a lexer skipped.

Languages differ in how a block comment ends. Some nest block comments. Some have executable comments: a block comment opened by ! and a version number whose body the lexer reads as SQL when the number does not exceed the parsed release, so its opening and closing delimiters are found apart from each other; an ordinary block comment in such a language steps over /* pairs and nests only an executable comment. The rest end at the first * /. Whether the reader is inside an executable comment carries from one run of trivia to the next until a tree has been read.
