Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Resolves the table names of a statement against the declarations of its dependencies.

Dependencies supply declarations independently of statement order. No DDL effects are evaluated. A statement's own declaration is visible inside that statement; other names resolve in the explicit declaration context or the locally visible common table expressions.
