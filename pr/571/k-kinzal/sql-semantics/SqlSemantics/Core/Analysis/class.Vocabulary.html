The generated construction vocabulary of one grammar release.

A recipe describes one alternative of one grammar rule: the value class and the positions of its fields, a finite choice, or a forwarding to the single value it is made of. Every recipe names the symbols of its form, so a form can be found by the symbols it is written with, and a name or literal role can be followed through forwarding rules to the class that holds one terminal.
