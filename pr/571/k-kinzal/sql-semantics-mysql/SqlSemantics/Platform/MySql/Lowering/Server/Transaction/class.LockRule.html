final class LockRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Lowering\Server". Code outside that scope must not name this declaration.

Lowers LOCK TABLES, UNLOCK TABLES and the backup lock statements.

Rule: MYSQL-LOCK-001. Scope: lock, unlock, table_lock_list, table_lock, lock_option. TABLE and TABLES are synonyms (LeafNoise); the alias goes through the query family's alias rule. Constructs: LockTables, TableLock, UnlockTables, LockInstance, UnlockInstance. Terminates: the lock list is flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/lock-tables.html, https://dev.mysql.com/doc/refman/8.4/en/lock-instance-for-backup.html. Status: Implemented.
