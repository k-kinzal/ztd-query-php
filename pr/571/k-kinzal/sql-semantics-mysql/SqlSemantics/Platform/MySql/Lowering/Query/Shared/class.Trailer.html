final class Trailer
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Lowering\Query". Code outside that scope must not name this declaration.

The clauses written after a query during lowering: ORDER BY, LIMIT, PROCEDURE ANALYSE, a trailing INTO and the locking clauses.

A lowering-time value: it collects the clauses until the query they belong to is known (MYSQL-SELECT-001) and is never part of a model.
