The ODBC escape { OJ table_reference } of the 8.0 and later grammars.

Rule: MYSQL-ODBC-JOIN-001. The braces group the reference like parentheses and change no name. Source: https://dev.mysql.com/doc/refman/8.4/en/join.html ("The { OJ ... } syntax ... exists only for compatibility with ODBC"). Status: Implemented.
