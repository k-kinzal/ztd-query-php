One assignment of INSTALL COMPONENT … SET: [GLOBAL | PERSIST] [component.]variable = value.

Mirrors PT_install_component_set_element. The scope is the variable's scope: GLOBAL, PERSIST, or none, which the server takes as GLOBAL. The variable is written without at signs. The value is an expression or the word ON. Source: https://dev.mysql.com/doc/refman/8.4/en/install-component.html.
