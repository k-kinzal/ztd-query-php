RELEASE SAVEPOINT name: a request to remove a savepoint of the current transaction.

Mirrors SQLCOM_RELEASE_SAVEPOINT. Rule: MYSQL-RELEASE-SAVEPOINT-001. The savepoint is a name of the session's current transaction, which no declaration context holds; the server compares savepoint names case-insensitively. The statement names no relation and has no facts. Source: https://dev.mysql.com/doc/refman/8.4/en/savepoint.html. Status: Implemented.
