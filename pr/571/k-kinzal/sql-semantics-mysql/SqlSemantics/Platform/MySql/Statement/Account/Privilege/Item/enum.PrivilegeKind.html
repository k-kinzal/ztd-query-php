enum PrivilegeKind: string
Public API: explicitly declared with @visibility public.

The static privileges, by the words GRANT and REVOKE write them with.

Mirrors the ACL bits of sql/auth/auth_acls.h. The levels a privilege can be granted at follow the masks there: TABLE_ACLS for a table, PROC_ACLS for a routine, DB_ACLS for a database; every privilege can be granted globally. USAGE is no privilege and fits every level. Source: https://dev.mysql.com/doc/refman/8.4/en/privileges-provided.html, https://dev.mysql.com/doc/refman/8.4/en/grant.html#grant-privileges.
