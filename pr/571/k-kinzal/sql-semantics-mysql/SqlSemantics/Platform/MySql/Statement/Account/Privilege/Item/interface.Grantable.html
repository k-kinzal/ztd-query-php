interface Grantable
    extends Node
Public API: explicitly declared with @visibility public.

One item of the privilege or role list of GRANT and REVOKE.

The server parses GRANT a, b … items as PT_role_or_privilege nodes and reads them as roles when no ON clause follows and as privileges when one does; the model holds each item as what the statement reads it as. Source: https://dev.mysql.com/doc/refman/8.4/en/grant.html.
