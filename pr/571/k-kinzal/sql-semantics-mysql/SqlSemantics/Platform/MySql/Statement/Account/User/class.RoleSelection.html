final class RoleSelection
    implements Node

Public API: explicitly declared with @visibility public.

The roles SET ROLE, a DEFAULT ROLE clause or GRANT … AS … WITH ROLE select: role, …, NONE, DEFAULT or ALL [EXCEPT role, …].

The roles are the named ones for Named and the excepted ones for All. Source: https://dev.mysql.com/doc/refman/8.4/en/set-role.html, https://dev.mysql.com/doc/refman/8.4/en/set-default-role.html.
