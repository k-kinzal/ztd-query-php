final class DollarQuotedText
    implements Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

A dollar-quoted string: $tag$ text $tag$ (MySQL 8.1 and later).

The text between the delimiters is taken as it is, without escapes; the server treats it as the opaque code of an external language. The tag is part of the spelling the text needs: the text cannot hold its own closing delimiter. Source: https://dev.mysql.com/doc/refman/9.1/en/create-procedure.html.
