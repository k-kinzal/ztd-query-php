enum FullTextMode
Public API: explicitly declared with @visibility public.

The search mode of MATCH … AGAINST.

The natural language mode is the default; IN NATURAL LANGUAGE MODE names it explicitly and is not written. Query expansion is a natural language search followed by a second search. Source: https://dev.mysql.com/doc/refman/8.4/en/fulltext-search.html.
