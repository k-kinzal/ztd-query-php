UPDATE HISTOGRAM ON column USING DATA 'json': a request to store a histogram given as its JSON form (MySQL 8.0.31 and later).

The columns are those of the one table ANALYZE TABLE names; the statement checks them (MYSQL-HISTOGRAM-001). Source: https://dev.mysql.com/doc/refman/8.4/en/analyze-table.html.
