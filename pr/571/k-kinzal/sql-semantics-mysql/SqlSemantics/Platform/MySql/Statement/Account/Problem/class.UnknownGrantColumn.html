Public API: explicitly declared with @visibility public.

A column of a column privilege that the completely declared table of GRANT does not have.

The server rejects the statement with ER_BAD_FIELD_ERROR (mysql_table_grant). REVOKE does not check the columns. Source: https://dev.mysql.com/doc/refman/8.4/en/grant.html#grant-column-privileges.
