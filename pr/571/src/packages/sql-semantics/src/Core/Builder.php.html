10/**
11 * Composes the values every dialect has, under stable names, from PHP data and other values.
12 *
13 * A database package implements this for its own generated model and narrows
14 * the return types to its roles. Names and literals are spelled as the
15 * release and mode read them: a name is quoted when the release would read
16 * it as a keyword or fold or reject its characters, and a string is escaped
17 * as the session reads escapes. An operand that binds more weakly than the
18 * position it is placed in is parenthesized.
19 *
20 * @visibility public
21 * @example Composing a comparison with the builder of any database
22 *     $condition = static fn (\SqlSemantics\Core\Builder $builder): string => \SqlSemantics\Statement\Writer::render($builder->compare($builder->column('select'), '=', $builder->string("it's")));
23 *     $condition instanceof \Closure // => true
24 */
