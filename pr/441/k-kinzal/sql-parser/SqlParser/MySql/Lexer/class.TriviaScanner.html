Skips the whitespace and comments between MySQL tokens.

A /*! comment is versioned: when the release it names is not newer than the release being read for, its body is SQL and only the markers are skipped, with the closing marker recognised later at a token boundary. Any other block comment, a # comment, and a -- comment followed by a space are skipped whole.
