Reads the rules section of a Bison grammar into a builder.

An action written before the end of an alternative is a mid-rule action. Bison stands a nonterminal named $@n in for it, deriving the empty string, and numbers that nonterminal's rule before the rule it appears in. The same is done here so the automaton and its conflicts come out alike.
