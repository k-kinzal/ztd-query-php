final class BisonDeclarations
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads the declarations section of a Bison grammar into a builder.

Only the declarations that shape the parse table are interpreted: the tokens, the precedence groups, the start symbol and the expected conflict count. Everything else, from type tags to parser parameters, is skipped together with its arguments.
