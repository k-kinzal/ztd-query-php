final class BisonScanner
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Splits a Bison grammar file into tokens, up to the end of the rules section.

The prologue between %{ and %}, comments, and the epilogue after the second %% are not grammar and are dropped. Host code in braces is kept as a single token so that the rules reader can tell a mid-rule action from a final one.
