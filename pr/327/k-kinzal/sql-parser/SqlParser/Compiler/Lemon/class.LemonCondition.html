final class LemonCondition
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Evaluates the condition of a Lemon %if against the names defined for a build.

Lemon's evaluator reads && and || from left to right without giving either priority, negates with !, and groups with parentheses; a bare name is true when it is defined.
