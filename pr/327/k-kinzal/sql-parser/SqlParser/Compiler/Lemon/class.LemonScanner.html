final class LemonScanner
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Splits a Lemon grammar file into tokens.

Comments are dropped and host code in braces is kept as one token. An alias in parentheses and a precedence mark in brackets are tokens of their own, as they attach to the symbol or rule before them.
