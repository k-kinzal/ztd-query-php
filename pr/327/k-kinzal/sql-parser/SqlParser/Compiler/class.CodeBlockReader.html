final class CodeBlockReader
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads a brace-delimited block of host code as one opaque unit.

Braces inside string literals, character literals and comments do not count, which is what lets an action such as { if (c == '{') ... } be skipped without being understood.
