enum PrecedencePolicy
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Which terminal lends a rule its precedence when the rule names none itself.

Bison takes the last terminal of the rule whether or not it has a declared rank, so a rule ending in an unranked keyword has no precedence. Lemon takes the first terminal that has a declared rank.
