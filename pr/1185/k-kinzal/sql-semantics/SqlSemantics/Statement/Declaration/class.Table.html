final class Table
    uses Snapshot
Public API: explicitly declared with @visibility public.

A relation declaration supplied to an analysis context: a table or a view with its columns.

The object is the identity of the declaration. Two equal-looking tables are two declarations, and a context that holds both keeps the conflict.
