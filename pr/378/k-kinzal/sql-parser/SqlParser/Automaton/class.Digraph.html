final class Digraph
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Closes sets over a relation: each node ends with the union of every node it reaches.

This is the traversal of DeRemer and Pennello, which finds the strongly connected components of the relation and gives every member of a component the same set. It runs on an explicit stack, as the relations of a large grammar chain deeper than the call stack should be asked to go.
