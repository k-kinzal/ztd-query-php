Reads PostgreSQL's operators and punctuation.

A user-defined operator is the longest run of operator characters that does not start a comment. A run that ends in + or - gives those up unless it also holds a character that only user-defined operators use, so that a<-1 reads as a < -1. A single character that stands for itself and the few two-character comparisons have terminals of their own.
