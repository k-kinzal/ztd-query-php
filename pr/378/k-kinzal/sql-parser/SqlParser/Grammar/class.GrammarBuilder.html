final class GrammarBuilder
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Collects the declarations of a grammar source and numbers them into a grammar.

Readers meet symbols in whatever order the source spells them, so names are gathered first and numbered only when the grammar is built: terminals in declaration order after the end marker, then the accept symbol and the nonterminals in the order their rules appear.
