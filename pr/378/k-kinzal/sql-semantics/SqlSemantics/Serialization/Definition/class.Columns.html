public static function write(
    ColumnDefinition $column,
    Dialect $dialect,
    ConstraintResponse $keyConflict = ConstraintResponse::Default,
    bool $serialKey = true,
): Tree
source§

Writes declaration-level nullability and generation behavior; a MySQL generated column writes its expression before the other attributes, as its grammar requires, and a nullable MySQL AUTO_INCREMENT column writes NULL after AUTO_INCREMENT, because the later of the two decides. A column MySQL SERIAL DEFAULT VALUE declared writes that attribute, which stands for NOT NULL, AUTO_INCREMENT and the unique key its caller leaves out, and writes AUTO_INCREMENT once that key is gone.

$dialectDialect
$keyConflictConstraintResponseON CONFLICT resolution of the SQLite primary key an AUTOINCREMENT column declares
$serialKeyboolWhether the unique key SERIAL DEFAULT VALUE declares is still present
