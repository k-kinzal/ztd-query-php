public static function setOperationLock(Node $source, Node $body): ?Node
source§

Finds a PostgreSQL row-locking clause attached to a set operation or to one of its operands.

PostgreSQL rejects FOR UPDATE/SHARE on a UNION/INTERSECT/EXCEPT and on each of its leaf SELECTs, including a parenthesized operand; subqueries inside an operand keep their own locking clauses. The search follows the nodes from the query source down to the set-operation body, then the operands.
