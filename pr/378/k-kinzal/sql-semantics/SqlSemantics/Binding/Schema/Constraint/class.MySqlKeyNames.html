final class MySqlKeyNames
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Gives unnamed MySQL keys the names the server chooses when it creates them, so that later DROP INDEX statements find them: a key is named after its first column, or functional_index for an expression, and a name that PRIMARY or a key created before it already uses, compared without case, takes the first free suffix of _2 to _99.
