final class MySqlCounterKeys
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Checks the MySQL rule for AUTO_INCREMENT columns (error 1075): a table has at most one, and a key of the table must begin with it; MyISAM, MERGE and BLACKHOLE tables also accept it at a later position of a key. A primary key, a unique key, an index, and the index a foreign key creates all count; an expression key does not.
