final class KeyChanges
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Applies the table-level key, constraint, and index actions of ALTER TABLE to a table snapshot: MySQL ADD and DROP of PRIMARY KEY, UNIQUE, FOREIGN KEY, CHECK, and indexes, and PostgreSQL ADD and DROP CONSTRAINT. Both servers drop before they add within one statement, so a drop applies where it is written and an addition waits for {@see self::add()}.
