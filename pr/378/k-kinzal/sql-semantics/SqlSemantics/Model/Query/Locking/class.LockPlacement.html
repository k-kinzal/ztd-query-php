public static function repeated(list<RowLock> $locks, list<TableUse> $relations): bool

Reports whether some table would be locked by more than one clause, which MySQL rejects (error 3569): a named target repeated in the OF lists, or a clause without OF next to another clause when the block reads a stored table. PostgreSQL merges such clauses instead, keeping the strongest lock.
