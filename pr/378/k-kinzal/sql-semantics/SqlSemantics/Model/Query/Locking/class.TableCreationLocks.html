final class TableCreationLocks
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Finds the row locks that MySQL refuses in the input query of a table being created.

MySQL fails CREATE TABLE ... SELECT when any query block of the input, including subqueries, derived tables, common table expressions and set-operation operands, takes an exclusive (FOR UPDATE) lock on a stored table or view (error 1746); a shared lock, or an exclusive lock over derived rows only, is accepted.
