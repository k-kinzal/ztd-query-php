final class JsonArrayConstructor

Public API: explicitly declared with @visibility public.

PostgreSQL SQL/JSON JSON_ARRAY over a list of values: builds an array of the elements in order, without evaluating them. The result is json unless RETURNING says otherwise, and is never NULL. Without elements there is no NULL clause.
