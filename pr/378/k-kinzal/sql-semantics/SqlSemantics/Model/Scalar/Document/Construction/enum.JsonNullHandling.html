enum JsonNullHandling: string

What a SQL/JSON constructor does with a NULL value: write a JSON null, or leave the member or element out. JSON_OBJECT and JSON_OBJECTAGG default to NULL ON NULL; JSON_ARRAY and JSON_ARRAYAGG default to ABSENT ON NULL.
