final class JsonObjectAggregate
    extends Expression
Public API: explicitly declared with @visibility public.

PostgreSQL JSON_OBJECTAGG: aggregates one key/value member per row into an object, without evaluating it. The result is json unless RETURNING says otherwise; a group without rows yields NULL. OVER makes it a WindowCall.
