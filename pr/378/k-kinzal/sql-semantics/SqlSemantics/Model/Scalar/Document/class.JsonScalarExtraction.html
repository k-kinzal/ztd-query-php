final class JsonScalarExtraction
    extends Expression
Public API: explicitly declared with @visibility public.

JSON_VALUE: extracts the scalar at a path of a JSON document as the returned type, without evaluating it. MySQL takes a string-literal path; PostgreSQL takes any path expression, an optional document FORMAT and PASSING variables. Without RETURNING the result is a MySQL string or PostgreSQL text; without an ON EMPTY or ON ERROR response the database returns NULL.
