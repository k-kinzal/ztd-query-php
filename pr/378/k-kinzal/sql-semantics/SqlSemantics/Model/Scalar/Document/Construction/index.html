JsonArrayAggregate public APIPostgreSQL JSON_ARRAYAGG: aggregates one element per row into an array in the given order, without evaluating it. The result is json unless RETURNING says otherwise; a group without rows yields NULL. OVER makes it a WindowCall.
JsonArrayConstructor public APIPostgreSQL SQL/JSON JSON_ARRAY over a list of values: builds an array of the elements in order, without evaluating them. The result is json unless RETURNING says otherwise, and is never NULL. Without elements there is no NULL clause.
JsonArrayQuery public APIPostgreSQL SQL/JSON JSON_ARRAY over a query: builds an array of the only result column of every row, without running the query. The result is json unless RETURNING says otherwise; a query without rows yields NULL.
JsonMember public APIOne key and value of JSON_OBJECT or JSON_OBJECTAGG; KEY k VALUE v, k VALUE v and k : v are the same member.
JsonObjectAggregate public APIPostgreSQL JSON_OBJECTAGG: aggregates one key/value member per row into an object, without evaluating it. The result is json unless RETURNING says otherwise; a group without rows yields NULL. OVER makes it a WindowCall.
JsonObjectConstructor public APIPostgreSQL SQL/JSON JSON_OBJECT: builds an object from ordered key/value members, without evaluating them. The result is json unless RETURNING says otherwise, and is never NULL. Without members there is no NULL or key-uniqueness clause.
