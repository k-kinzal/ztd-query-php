AlterTableStatement public APIApplies an ordered list of typed alterations to one MySQL table under the requested algorithm, lock level, and validation. Partition and tablespace commands stand alone, a partitioning change comes last, and an empty list requests no change. WITH or WITHOUT VALIDATION exists from MySQL 5.7, INSTANT from MySQL 8.0, and IGNORE only in MySQL 5.6.
