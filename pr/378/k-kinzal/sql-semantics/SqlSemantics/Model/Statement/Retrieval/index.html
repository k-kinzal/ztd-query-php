RetrievedQuery @visibility SqlSemanticsChecks the query whose rows a SELECT ... INTO statement stores instead of returning.
SelectIntoDumpfileStatement public APIMySQL SELECT ... INTO DUMPFILE 'file': the query's single row is written to a new server file without separators or escaping.
SelectIntoOutfileStatement public APIMySQL SELECT ... INTO OUTFILE 'file': the query's rows are written to a new server file as delimited text instead of being returned.
SelectIntoTableStatement public APIPostgreSQL SELECT ... INTO [TEMPORARY | UNLOGGED] [TABLE] name: a new table is created from the query's columns and filled with its rows. A temporary table lives in the session's temporary schema, so it is named without a schema or with pg_temp.
SelectIntoVariablesStatement public APIMySQL SELECT ... INTO @a, @b: the query's single row is stored in user variables, one per selected column, instead of being returned.
