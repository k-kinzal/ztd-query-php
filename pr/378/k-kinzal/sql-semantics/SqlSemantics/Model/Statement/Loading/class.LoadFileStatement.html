final class LoadFileStatement
    extends BoundStatement
Public API: explicitly declared with @visibility public.

Inserts the rows of a text or XML file into a table (LOAD DATA or LOAD XML without ALGORITHM = BULK). Without BULK the server ignores IN PRIMARY KEY ORDER, PARALLEL and MEMORY, so they are not retained.
