final class BulkLoadStatement
    extends BoundStatement
Public API: explicitly declared with @visibility public.

Loads delimited text into a table with the bulk loader (LOAD DATA ... ALGORITHM = BULK). The bulk loader reads server, URL or S3 sources, maps fields to every column in order, and takes an exclusive table lock, so LOCAL, column lists, SET, IGNORE, LINES STARTING BY and lock scheduling do not apply.
