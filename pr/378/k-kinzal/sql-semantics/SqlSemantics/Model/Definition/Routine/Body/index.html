AssignmentStatement public APIA SET statement in a stored program that assigns at least one local variable or NEW trigger column, in written order. Other items of the same SET keep their ordinary setting and user-variable forms.
BlockStatement public APIA BEGIN ... END compound statement: local declarations visible to its ordered statements.
ConditionalBranch public APIA guarded statement list: an IF or ELSEIF condition, a searched CASE condition, or a simple CASE comparison value.
EmbeddedStatement public APIAn ordinary MySQL statement run from a stored program body, bound with the same semantic forms as direct SQL.
IfStatement public APIIF ... ELSEIF ... ELSE ... END IF: runs the statements of the first branch whose condition is true, otherwise the ELSE statements.
IterateStatement public APIITERATE label: starts the next pass of the enclosing loop with that label.
LeaveStatement public APILEAVE label: exits the enclosing block or loop with that label.
LoopStatement public APILOOP ... END LOOP: repeats its statements until LEAVE or RETURN exits.
RepeatStatement public APIREPEAT ... UNTIL condition END REPEAT: runs its statements, then stops once the condition is true.
ReturnStatement public APIRETURN expression: ends a stored function with its result.
SearchedCaseStatement public APICASE WHEN condition THEN ... END CASE: runs the statements of the first true WHEN condition. Without ELSE, no true condition raises the case-not-found condition when the program runs.
SelectIntoStatement public APISELECT ... INTO targets in a stored program, storing the single result row in local and user variables, one per column.
SimpleCaseStatement public APICASE operand WHEN value THEN ... END CASE: runs the statements of the first WHEN value equal to the operand. Without ELSE, no match raises the case-not-found condition when the program runs.
WhileStatement public APIWHILE condition DO ... END WHILE: runs its statements while the condition, tested before each pass, is true.
