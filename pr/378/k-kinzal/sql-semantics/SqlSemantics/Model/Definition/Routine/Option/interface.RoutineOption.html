interface RoutineOption
Public API: explicitly declared with @visibility public.

One PostgreSQL routine attribute that CREATE and ALTER FUNCTION, PROCEDURE, or ROUTINE can set. The security context is the shared RoutineSecurity; every other attribute implements this interface.
