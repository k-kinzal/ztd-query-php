ColumnsPartitioning public APIAssigns rows by comparing column tuples with RANGE COLUMNS or LIST COLUMNS partition values.
ExpressionPartitioning public APIAssigns rows by comparing one integer expression with RANGE or LIST partition values.
HashPartitioning public APIAssigns rows by the value of an integer expression, optionally with linear powers-of-two hashing.
KeyPartitioning public APIAssigns rows by the server hash of columns; an empty column list uses the primary key, and ALGORITHM selects hashing 1 or 2.
ListBound public APIThe value tuples a LIST partition accepts; a tuple has one value per partitioning column.
PartitionDefinition public APIOne named partition: its RANGE or LIST values (none for HASH and KEY), storage options, and subpartitions.
PartitionProperties public APIStorage options of one partition or subpartition.
PartitioningRules @visibility SqlSemanticsChecks the consistency MySQL requires between a partitioning function, its counts, and its partitions.
RangeBound public APIThe exclusive upper bound of a RANGE partition; MAXVALUE stands for a bound above every value.
SubpartitionDefinition public APIOne named subpartition of a partition, with its storage options.
TablePartitioning public APIA complete MySQL PARTITION BY clause: the function, partition and subpartition counts, and explicit partitions. RANGE and LIST require explicit partitions with matching values, HASH and KEY take no values, and only RANGE and LIST subpartition.
