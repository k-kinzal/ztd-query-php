SQL Semantics

License: MIT Docs PHP Version Ask DeepWiki

SQL Semantics converts SQL strings into structured declarations and bound statements for MySQL, PostgreSQL, and SQLite. It uses sql-parser to preserve the original SQL and exposes table and column definitions, types, nullability, query inputs, write destinations, conditions, and configuration effects. No database connection is required. See the schema API, binder API, and limitations.

Requirements

  • PHP 8.1 or higher
  • k-kinzal/sql-parser

Support Syntax

The following grammar versions are available through sql-parser, matching sql-faker. Pass grammarVersion to SchemaBuilder to select a grammar; omitting it uses the default for that database. The database release is the only language support boundary. Every SQL construct in that release is in scope; missing semantic behavior is a defect.

Installation

composer require k-kinzal/sql-semantics

Usage

use SqlSemantics\Binder;
use SqlSemantics\Dialect;
use SqlSemantics\SchemaBuilder;

$schema = (new SchemaBuilder(Dialect::PostgreSql))->build(
    'CREATE TABLE users (id INTEGER PRIMARY KEY, score INTEGER DEFAULT 0)',
);
$schema->tables[0]->columns[0]->type->name; // integer

$binder = new Binder($schema);
$statement = $binder->bind('SELECT id, score FROM users WHERE score > 0');
$statement->outputs[0]->expression->binding->column->name; // id
$statement->where->symbol; // >
$statement->toSql(); // SELECT id, score FROM users WHERE score > 0

SchemaBuilder::build() returns an independent schema snapshot. Binder::bind() returns a bound statement, and Binder::analyze() returns the same structure with diagnostics when names or types cannot be resolved. Binder::replaceExpression() reparses and rebinds an expression edit into a new snapshot. The API tables and SQL examples are in schema.md and binder.md.

Development checks are composer lint, composer test, and composer bench:quick. Run XDEBUG_MODE=off composer fuzz:smoke for a bounded run of each dialect. The fuzz instructions describe the unrestricted grammar property and all-release runs.
