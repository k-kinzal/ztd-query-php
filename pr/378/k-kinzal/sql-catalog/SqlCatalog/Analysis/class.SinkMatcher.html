public function models(Domain $receiver): bool
source§

Whether an extension already models what the receiver is.

An extension that names a class's calls is the model of that class. Walking into that class's own implementation from every call site re-derives the statements it issues at the sites they are already read from, once per caller, which costs a great deal and adds nothing that reading the class itself does not give.
