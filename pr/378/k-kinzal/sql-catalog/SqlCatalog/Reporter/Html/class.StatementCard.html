final class StatementCard
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

One statement, written the way the report shows it.

What the statement is and what the analyzer managed to establish about it are shown as two different things. The kind carries an identity hue because it is a property of the statement; the resolution and the findings carry state hues because they are judgements about the reading. A call that no statement was read from is not dressed up as a statement at all.
