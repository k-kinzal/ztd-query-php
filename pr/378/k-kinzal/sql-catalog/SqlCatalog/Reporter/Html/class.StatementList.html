final class StatementList
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

A listing of statements that a reader can narrow down on the page.

Every listing in the report is the same component: the rows, and above them the facets the rows can be narrowed by — what the statements do, how far the analysis got, and how much attention they need — each showing how many rows it would keep. A facet that every row shares is not offered, since choosing it would change nothing.
