final class ValueDomain
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

What a bound value can be, reported in the form the catalog stores.

A value that resolves statically is reported as the literals it can take, so a parameter typed as a backed enum becomes the union of that enum's values rather than a bare string. A value the analyzer could not follow is reported as its static type and where it came from.
