Laravel experiment case matrix

All cases use the pinned Laravel 13.33.0 runtime. Match means that the bounded prototype agrees with all three Laravel grammars and seeded SQLite on SQL bytes, binding order, and the full query sequence. Unsupported means the prototype abstains; it is not a passing reconstruction. The production analyzer still recovers only the separate raw SQL control.

Both Boolean inputs execute for every case. Each group includes 30 diagnostic patterns followed by two regression cases. These examples do not establish coverage for arbitrary values, models, framework versions or application paths.

PostgreSQL pretend observations for eloquent_create, eloquent_save_new, eloquent_first_or_create and eloquent_update_or_create are incomplete because the generated ID has no returned row. Their query prefixes are recorded but cannot establish a match. SQLite execution completes for all cases.

The reviewed snapshot contains every SQLite query and its bindings, unsupported reasons, and the six cases where pretend differs from seeded execution. Full per-dialect observations are written to results/ and uploaded by CI. expectations.php makes any coverage change an explicit review decision.
