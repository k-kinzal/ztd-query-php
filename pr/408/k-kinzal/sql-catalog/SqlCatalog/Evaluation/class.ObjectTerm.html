final class ObjectTerm
    implements Term
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

An object the analyzer tracked by class.

An enum case carries the case name, which resolves ->value to a literal. A prepared statement carries the identifier of the catalog entry it came from, which is how a later execute() finds the query it binds values to. Modelled builders also carry an allocation identity and immutable state, so aliases observe mutations.
