final class SqlLexer
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Splits SQL into tokens without committing to one dialect's grammar.

Only enough structure is recognised to tell keywords, string bodies, comments and bind parameters apart, which is what reading a statement's kind, its tables and its placeholders needs. Anything unrecognised becomes a symbol.
