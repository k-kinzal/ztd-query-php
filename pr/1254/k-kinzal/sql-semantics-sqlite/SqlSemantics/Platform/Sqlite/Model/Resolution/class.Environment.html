final class Environment
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

What names mean at one position of a statement.

An environment is derived from the clause position and the relation structure: the occurrences visible there, the enclosing query positions, the common tables in scope and the output aliases the position may use. It is a working value of one derivation and is not part of the published model.
