classValueGraph

final class ValueGraph
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Audits that a value graph is deeply immutable and made of the closed value domain only.

Every reachable object must be an enum case or an instance of a final class of the admitted namespaces that uses the Snapshot trait and whose properties are all initialised readonly properties. Properties hold null, booleans, integers, strings, arrays without references, or such objects. Floats, closures, resources and classes of any other origin are rejected, whatever interface they implement.
