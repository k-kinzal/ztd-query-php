enum Parameters
Public API: explicitly declared with @visibility public.

Which parameter markers SQL is read with: the server's own, or those and the named placeholder.

A server has its own markers, such as ? or $1. A named placeholder, :name, is the other common way an application binds a parameter, and a server that has no such marker rejects it. Reading it is a dialect extension: the statement is read as the server would read it once the placeholder is bound.
