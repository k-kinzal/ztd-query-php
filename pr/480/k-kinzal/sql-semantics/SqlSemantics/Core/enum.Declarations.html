enum Declarations
Public API: explicitly declared with @visibility public.

Whether the dependencies a statement is analyzed against declare every table of the database, or only some of them.

With complete declarations, a table name that resolves to nothing is an error: the dependency that would declare it was not given. With partial declarations, the database has tables the dependencies do not describe, and such a name is a reference to an undeclared table, with nothing known of its columns, unless the dependencies dropped that table; every other name is resolved as before.
