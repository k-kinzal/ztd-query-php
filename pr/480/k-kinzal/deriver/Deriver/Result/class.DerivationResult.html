public function definite(): Alternative|null
source§

Selects the one outcome PHP 8.3 produces regardless of inputs, error handlers, and unexplored dependencies. The closed assessment alone does not establish this: a closed result may still carry PHP_WARNING frontiers, exceptional outcomes, or several alternatives.

Returns

Alternative|null The only normal outcome when every observed value is concrete and the result has no frontiers, exceptional outcomes, or project diagnostics; null otherwise
