final class NameRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers identifier tokens and name lists into decoded names.

Rule: SQLITE-NAME-001. Scope: nm, dbnm, fullname, idlist, idlist_opt, collate and the identifier token classes. A name is decoded by SQLITE-IDENTIFIER-DECODE-001 and recorded as an operand leaf; in nm dbnm the first name is the schema when the second is present. Terminates: lists are flattened iteratively. Source: https://sqlite.org/lang_keywords.html, https://sqlite.org/lang_naming.html. Status: Implemented.
