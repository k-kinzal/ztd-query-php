final class TypeNameRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers type names and signed numbers.

Rule: SQLITE-TYPE-NAME-LOWER-001. Scope: typetoken, typename, signed, plus_num, minus_num. A type name is its words in order, each with its quoting, and its numeric arguments with their written signs. Terminates: the word list is flattened iteratively. Source: https://sqlite.org/syntax/type-name.html, https://sqlite.org/syntax/signed-number.html. Status: Implemented.
