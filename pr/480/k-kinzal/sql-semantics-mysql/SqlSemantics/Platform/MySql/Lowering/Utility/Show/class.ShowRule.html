Lowers the SHOW statements of MySQL 8.0 and later: one rule per statement.

Rule: MYSQL-SHOW-LOWERING-001. Scope: every show_*_stmt rule. A rule lowers into the class of its command; the statements about schema objects, stored programs and the server are lowered by MYSQL-SHOW-OBJECT-LOWERING-001, the clauses by MYSQL-SHOW-CLAUSE-LOWERING-001. SLAVE and REPLICA, and MASTER STATUS and BINARY LOG STATUS, are kept as written (Terminology). SHOW PARSE_TREE lowers the statement it wraps through the statement dispatcher. Terminates: every part is a strict subtree. Source: https://dev.mysql.com/doc/refman/8.4/en/show.html. Status: Implemented.
