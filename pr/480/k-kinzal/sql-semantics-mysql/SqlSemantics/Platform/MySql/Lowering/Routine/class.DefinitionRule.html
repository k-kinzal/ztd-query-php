Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Lowers CREATE, ALTER and DROP of stored procedures and functions, CREATE of loadable functions, and DROP of triggers and events.

Rule: MYSQL-ROUTINE-DEFINITION-LOWERING-001. Scope: sp_tail, sf_tail, udf_tail, udf_type, alter_procedure_stmt, alter_function_stmt, drop_procedure_stmt, drop_function_stmt, drop_trigger_stmt, drop_event_stmt, and the alter and drop alternatives of these objects (5.6, 5.7). The symbols of a tail are read by rule name, so one reading serves the layouts of every release. Constructs: CreateProcedure, CreateFunction, CreateLoadableFunction, AlterRoutine, DropProgram. Terminates: every child is a strict subtree. Source: https://dev.mysql.com/doc/refman/8.4/en/create-procedure.html, https://dev.mysql.com/doc/refman/8.4/en/create-function-loadable.html, https://dev.mysql.com/doc/refman/8.4/en/alter-procedure.html, https://dev.mysql.com/doc/refman/8.4/en/drop-procedure.html. Status: Implemented.
