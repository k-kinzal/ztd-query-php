enum PartitionOptionKind: string
Public API: explicitly declared with @visibility public.

The options of a partition or subpartition definition, by the keywords they are written with.

TABLESPACE and ENGINE take a name, NODEGROUP, MAX_ROWS and MIN_ROWS a number, DATA DIRECTORY, INDEX DIRECTORY and COMMENT a string. The optional STORAGE before ENGINE does not change the option. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html#create-table-partitioning.
