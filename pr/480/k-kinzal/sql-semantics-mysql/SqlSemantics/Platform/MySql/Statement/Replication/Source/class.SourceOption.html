final class SourceOption
    implements Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

One option = value of CHANGE REPLICATION SOURCE TO, or one log position of the UNTIL condition of START REPLICA.

Mirrors one field of the server's LEX_SOURCE_INFO. The value is typed by the option (SourceOptionKind::accepts); NULL is the value null, accepted by PRIVILEGE_CHECKS_USER and SOURCE_TLS_CIPHERSUITES. The option is written in the vocabulary of its statement. Source: https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
