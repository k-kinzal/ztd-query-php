The UNTIL clause of START REPLICA: an optional GTID or gap condition first, then log positions, in written order.

The grammar admits a GTID or gap condition only as the first item, so the two parts keep the written order exactly. Which combinations the server accepts is checked when the statement is derived (MYSQL-REPLICA-UNTIL-001). Source: https://dev.mysql.com/doc/refman/8.4/en/start-replica.html.
