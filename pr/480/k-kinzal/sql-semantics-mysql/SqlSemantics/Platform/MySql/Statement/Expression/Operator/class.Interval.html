A temporal interval: INTERVAL quantity unit, the operand of interval arithmetic and of DATE_ADD and DATE_SUB.

An interval is not a value of its own; the expression that holds it derives the quantity. The quantity is enclosed between INTERVAL and the unit, so it may be any expression. Source: https://dev.mysql.com/doc/refman/8.4/en/expressions.html#temporal-intervals.
