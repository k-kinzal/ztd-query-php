The action of ALTER INSTANCE.

Mirrors enum alter_instance_action_enum of the server. The names the grammar reads as identifiers (INNODB, BINLOG, REDO_LOG) are kept as written; the server compares them case-insensitively. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-instance.html.
