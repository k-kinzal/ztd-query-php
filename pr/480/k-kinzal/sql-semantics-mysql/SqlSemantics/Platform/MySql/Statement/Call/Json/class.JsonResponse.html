The response of an ON EMPTY or ON ERROR clause: raise an error, return NULL, or return a default literal.

The holder of the clause derives the default and writes ON EMPTY or ON ERROR. Source: https://dev.mysql.com/doc/refman/8.4/en/json-search-functions.html#function_json-value, https://dev.mysql.com/doc/refman/8.4/en/json-table-functions.html.
