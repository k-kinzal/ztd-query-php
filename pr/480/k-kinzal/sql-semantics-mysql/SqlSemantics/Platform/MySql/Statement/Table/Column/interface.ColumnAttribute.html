interface ColumnAttribute
    extends Node

One attribute of a column definition, such as NOT NULL, DEFAULT, COMMENT or CHECK.

MySQL accepts the attributes in any order and applies them in written order, so a column keeps them as a list. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
