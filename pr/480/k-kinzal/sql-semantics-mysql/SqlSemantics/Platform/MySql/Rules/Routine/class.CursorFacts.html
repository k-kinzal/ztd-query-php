final class CursorFacts
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives the cursor statements OPEN, FETCH and CLOSE.

Rule: MYSQL-PROGRAM-CURSORS-001. The cursor must be declared in an enclosing block (ER_SP_CURSOR_MISMATCH), and every target of FETCH must be a parameter or local variable in scope (ER_SP_UNDECLARED_VAR). Whether the cursor is open, and whether the number of targets equals the number of columns of the cursor query, is checked only when the program runs. Terminates: the lists are finite. Source: https://dev.mysql.com/doc/refman/8.4/en/cursors.html. Status: Implemented.
