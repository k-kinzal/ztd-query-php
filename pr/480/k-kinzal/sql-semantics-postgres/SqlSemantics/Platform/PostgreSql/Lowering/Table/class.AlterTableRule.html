final class AlterTableRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers the statements built on AlterTableStmt and the partition actions.

Rule: PG-ALTER-TABLE-LOWER-001. Scope: AlterTableStmt, alter_table_cmds, partition_cmd, index_partition_cmd. The actions themselves are lowered by AlterCommandRule. A relation written as relation_expr keeps ONLY; a qualified_name never has it. Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-altertable.html. Status: Implemented.
