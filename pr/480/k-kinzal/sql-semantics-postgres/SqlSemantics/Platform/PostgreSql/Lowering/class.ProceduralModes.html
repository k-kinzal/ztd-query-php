Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

The productions the grammar keeps for PL/pgSQL and for parsing a lone type name.

Rule: PG-STATEMENT-002. Scope: the alternatives of parse_toplevel that start with a mode token, PLpgSQL_Expr, PLAssignStmt, plassign_target and plassign_equals. The server enters them by pushing a mode token in front of the text when PL/pgSQL compiles an expression or assignment, or when a type name is parsed on its own; the scanner never produces a mode token from SQL text, so no SQL statement reaches these productions. A tree that contains one was not parsed from SQL text and is rejected as outside the grammar of SQL statements. Source: https://www.postgresql.org/docs/17/plpgsql-implementation.html. Status: Implemented.
