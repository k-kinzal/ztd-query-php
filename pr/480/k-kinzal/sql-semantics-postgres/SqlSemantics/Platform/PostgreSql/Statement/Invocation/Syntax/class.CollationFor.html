COLLATION FOR (value): the name of the collation of a value.

The server calls pg_catalog.pg_collation_for(value). Rule: PG-COLLATION-FOR-001. Facts: text, NULL when no collation is derived for the value. The result column is named pg_collation_for. Source: https://www.postgresql.org/docs/17/functions-info.html#FUNCTIONS-INFO-CATALOG. Status: Implemented.
