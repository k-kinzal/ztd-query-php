A UNIQUE column constraint: no two rows hold the same value in the column.

Mirrors CONSTR_UNIQUE with nulls_not_distinct, options and indexspace. NULLS DISTINCT is the default and is kept when written. Source: https://www.postgresql.org/docs/17/sql-createtable.html.
