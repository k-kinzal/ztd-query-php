A test for NULL: a IS [NOT] NULL, a ISNULL, a NOTNULL.

Mirrors PostgreSQL's NullTest node (IS_NULL, IS_NOT_NULL). For a row value the test applies to every field.

Rule: PG-NULL-TEST-001. Facts: boolean, never NULL. The operand must keep its place before IS (PG-PRECEDENCE-001). Source: https://www.postgresql.org/docs/17/functions-comparison.html. Status: Implemented.
