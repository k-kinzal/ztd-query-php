enum TypeKeyword: string
Public API: explicitly declared with @visibility public.

The keyword spellings of types that take no modifier.

INT and INTEGER are the same type; both spellings exist in the grammar and the one written is kept. JSON is a keyword from PostgreSQL 17 on. Source: https://www.postgresql.org/docs/17/datatype.html#DATATYPE-TABLE.
