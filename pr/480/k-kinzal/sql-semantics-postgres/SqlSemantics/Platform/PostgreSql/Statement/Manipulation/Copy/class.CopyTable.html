Public API: explicitly declared with @visibility public.

COPY between a table and a file, a program or the client.

Mirrors PostgreSQL's CopyStmt with a relation (relation, attlist, is_from, is_program, filename, options, whereClause). The options are those of the old syntax, written one after another, or the generic ones in parentheses; BINARY after COPY and DELIMITERS are old-syntax options too. The facts follow PG-COPY-001. Source: https://www.postgresql.org/docs/17/sql-copy.html. Status: Implemented.
