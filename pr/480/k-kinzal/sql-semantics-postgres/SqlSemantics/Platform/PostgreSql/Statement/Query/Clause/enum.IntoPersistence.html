enum IntoPersistence: string
Public API: explicitly declared with @visibility public.

The kind of table SELECT INTO creates, as written.

TEMP and TEMPORARY are the same request, and LOCAL and GLOBAL change nothing; the spelling is kept because the grammar keeps it. Permanent is the absence of any of these words. Source: https://www.postgresql.org/docs/17/sql-selectinto.html, https://www.postgresql.org/docs/17/sql-createtable.html.
