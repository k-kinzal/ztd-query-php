A key and its value in JSON_OBJECT or JSON_OBJECTAGG.

Mirrors PostgreSQL's JsonPair node. With the VALUE spelling the key is a primary expression; a key that would need parentheses is rejected. Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-JSON-CREATION-TABLE.
