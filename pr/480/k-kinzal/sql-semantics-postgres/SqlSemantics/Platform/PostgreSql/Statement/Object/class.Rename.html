    uses Snapshot
Public API: explicitly declared with @visibility public.

ALTER kind object RENAME [part name] TO new_name: renames an object or one of its columns, constraints or attributes.

Mirrors PostgreSQL's RenameStmt (renameType, relationType, object, subname, newname, behavior, missing_ok). How the object is named depends on the kind (PG-OBJECT-FORM-001). A renamed relation is resolved; renaming a column the declared relation lacks, or to a name it has, is reported. Renaming changes no declaration of the context. Source: https://www.postgresql.org/docs/17/sql-altertable.html, https://www.postgresql.org/docs/17/sql-alterfunction.html.
