final class TableUnique
    implements Constraint
    uses Snapshot
Public API: explicitly declared with @visibility public.

A UNIQUE table constraint: no two rows hold the same values in the key columns.

Mirrors CONSTR_UNIQUE with nulls_not_distinct, keys, including, options, indexspace and the attributes. Each key and included column must be a column of the table (PG-KEY-COLUMNS-001). Source: https://www.postgresql.org/docs/17/sql-createtable.html.
