enum Toggle: string
    implements OptionArgument
Public API: explicitly declared with @visibility public.

The keywords TRUE, FALSE and ON written as an option or parameter value.

The grammar reads these three reserved words where it otherwise reads a word or a string, and passes them on as the texts true, false and on. Source: https://www.postgresql.org/docs/17/sql-set.html.
