enum DefaultObjectKind: string
Public API: explicitly declared with @visibility public.

The kinds of object default privileges are set for; the value of a case is its keyword.

FUNCTIONS and ROUTINES both set the default privileges of functions and procedures; each spelling is kept as written. Source: https://www.postgresql.org/docs/17/sql-alterdefaultprivileges.html.
