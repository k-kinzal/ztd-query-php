An attribute value read as a Boolean, such as hashes of an operator.

defGetBoolean reads an attribute given alone as true, the integers 0 and 1, and the texts true, false, on and off without regard to case, whether written as a word, a keyword or a string. Source: https://www.postgresql.org/docs/17/sql-createoperator.html, defGetBoolean in src/backend/commands/define.c of PostgreSQL 17.
