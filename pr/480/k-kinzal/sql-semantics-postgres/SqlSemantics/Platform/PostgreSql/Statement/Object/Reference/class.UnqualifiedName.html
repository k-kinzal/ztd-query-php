The name of an object that belongs to no schema, such as a schema, an extension, a language, a database or a role.

The grammar writes these objects with a single name; no qualifier can be written. Source: https://www.postgresql.org/docs/17/sql-dropschema.html, https://www.postgresql.org/docs/17/sql-comment.html.
