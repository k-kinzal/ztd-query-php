A character type spelled with keywords, with an optional length.

Rule: PG-TYPE-CHARACTER-001. Without VARYING the type is character, which is one character long when no length is written and unconstrained when it types a constant; with VARYING, or spelled VARCHAR, it is character varying, unlimited without a length. A length is 1 to 10485760. Source: https://www.postgresql.org/docs/17/datatype-character.html. Status: Implemented.
