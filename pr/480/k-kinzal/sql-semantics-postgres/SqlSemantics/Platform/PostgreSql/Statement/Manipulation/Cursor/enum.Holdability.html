enum Holdability: string
Public API: explicitly declared with @visibility public.

Whether a cursor outlives the transaction that created it: WITH HOLD or WITHOUT HOLD.

Mirrors the CURSOR_OPT_HOLD bit of PostgreSQL's DeclareCursorStmt; WITHOUT HOLD is also what a cursor without either clause is. The value is the first keyword. Source: https://www.postgresql.org/docs/17/sql-declare.html.
