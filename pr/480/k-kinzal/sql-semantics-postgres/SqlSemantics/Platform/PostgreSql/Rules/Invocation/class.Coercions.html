final class Coercions
Restricted visibility: declared "@visibility SqlSemantics\Platform\PostgreSql". Code outside that scope must not name this declaration.

The implicit casts between pg_catalog types that function resolution may apply.

Rule: PG-IMPLICIT-CAST-001. The table lists the casts of pg_cast marked implicit among the numeric, string, date/time and bit-string types; a value of type unknown (a string constant or NULL) can be converted to any type. Types are compared without modifiers: a modifier never selects a function. Source: https://www.postgresql.org/docs/17/typeconv-func.html, https://www.postgresql.org/docs/17/sql-createcast.html. Termination: constant work. Status: Implemented.
