ZTD Query PHP

License: MIT PHP Version

This repository is a PHP implementation of Zero Table Dependency (ZTD). It began with an article by M Sugiura (@mkmonaka): ZTD is their idea, we were impressed by it and wanted it in PHP, and we are grateful to the author.

It is also an experiment with AI agents. ZTD is complex, and this repository tests how AI agents can build something like it correctly.
