final class Parser
Public API: explicitly declared with @visibility public.

Reads a Lemon grammar file into a tree that keeps everything the file says.

The file is read as Lemon reads it: %ifdef regions are settled with the names given, the text is split into tokens the way lemon.c splits it, and rules and declarations are accepted and rejected where Lemon accepts and rejects them.
