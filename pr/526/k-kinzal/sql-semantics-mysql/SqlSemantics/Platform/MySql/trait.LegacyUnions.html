trait LegacyUnions
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Composes UNION ALL in the 5.6 and 5.7 query grammars, where a union is a chain hanging off the first SELECT.

A SELECT with its own ORDER BY or LIMIT is parenthesized before a union list is appended, as the server would otherwise read those clauses as the union's. Those releases have no common table expressions.
