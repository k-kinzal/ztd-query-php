enum ParameterSyntax
Public API: explicitly declared with @visibility public.

Which parameter markers a lexer reads as bound parameters.

A server has its own markers, such as ? or $1. A named placeholder, :name, is the other common way to bind a parameter in an application, and a server that has no such marker rejects it. The named syntax reads :name as a parameter where the server itself would not; a server that reads it already is unaffected.
