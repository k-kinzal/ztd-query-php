final class BodyWalker
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Walks a function body, keeping what each variable can hold at each point.

Branches are joined rather than picked between, so a statement assembled in an if is reported as both of the statements it can be. A loop is walked twice and then widened, which turns the familiar $sql .= ' AND …' pattern into one shape covering every number of iterations.
