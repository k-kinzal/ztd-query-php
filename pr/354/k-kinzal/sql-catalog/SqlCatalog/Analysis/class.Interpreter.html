final class Interpreter
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Runs the analysis over one parsed file, body by body.

Every function body is walked on its own, with its parameters standing for whatever a caller may pass. Bodies reached by following a call are walked again with the caller's values, which is what resolves a statement the code assembles across several methods.
