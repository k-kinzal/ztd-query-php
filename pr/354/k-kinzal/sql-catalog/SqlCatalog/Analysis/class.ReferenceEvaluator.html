    Domain $receiver,
    string $owner,
    string $property,
    FunctionScope $scope,

source§

The value behind ->value or ->name on an enum.

A value typed as a backed enum can only ever be one of that enum's cases, so reading its backing value resolves to the union of them. That is what turns a parameter typed Status into the handful of strings the column can hold rather than an opaque string.
