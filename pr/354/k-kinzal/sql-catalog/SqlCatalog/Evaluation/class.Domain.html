final class Domain
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Every value an expression may take, over-approximated.

A domain is a bounded set of alternatives. Keeping the set means a query built from an enum-typed parameter is reported as the handful of statements it can actually be, instead of one statement with a gap. When the set would grow past the bound it is generalized into a single shape that still covers all of it, so the approximation only ever widens.
