final class RecordingReader
Public API: explicitly declared with @visibility public.

Reads a recording of what a program sent to a database.

The recording is a JSON document holding an observations array, each entry naming the statement, the values bound to it and where it came from. That is what a driver wrapper, a query log or a test harness can hand over.
