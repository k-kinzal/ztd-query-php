enum Origin: string
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Where a value the analyzer could not pin down comes from.

The origin drives how a gap in reconstructed SQL is reported: a fragment traced back to a request superglobal is a different finding from one that merely crossed a call the analyzer declined to follow.
