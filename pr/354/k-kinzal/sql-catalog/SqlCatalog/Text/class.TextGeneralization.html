final class TextGeneralization
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Collapses several patterns into the one shape that covers all of them.

Joining branches or iterations of a loop can produce more strings than a catalog should list. Generalization keeps the text the alternatives agree on and replaces the part they disagree on with a single gap, so the reported shape still matches every string the code can build.
