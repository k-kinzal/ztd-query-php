enum Resolution: string
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

How far the analyzer got with a statement, and why it got no further.

A statement that is not pinned down is not simply "unknown". Having followed a value all the way to a request parameter is a different answer from having run out of budget, and both are different from not modelling the dependency at all. Reporting which one it is separates what the program does from what the analyzer managed to establish.
