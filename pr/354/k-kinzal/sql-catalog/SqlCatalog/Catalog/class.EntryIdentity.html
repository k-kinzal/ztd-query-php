The identifier a catalogued statement keeps across runs.

The identifier is built from the file, the enclosing function, the database call and the statement shape, and deliberately not from the line number, so that editing unrelated lines of a file does not renumber its catalog. That is what makes two catalogs comparable across a pull request.

source§

The identifier of a statement issued at the given site.

Two calls in the same function can produce statements the catalog cannot tell apart — two unreached calls, say, whose text is entirely unknown. The occurrence separates them without bringing the line number back in, so they stay distinct and still survive an edit above them.
