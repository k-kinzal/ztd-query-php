final class CodeReader
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads host code as Bison's scanner does: braced code, a prologue, or one unit of either.

Braces nest, the digraphs <% and %> count as braces, and braces inside comments, strings and character literals do not count. A backslash-newline, which C splices away, may fall between the two characters of /*, * /, //, <%, %> and <<, and inside a string or character literal, exactly as scan-gram.l allows.
