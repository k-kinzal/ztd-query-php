final class SymbolListParser
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads the symbol lists that follow %token, %nterm, %type, %start, %left and their kin.

The lists differ in what a string means: after %token it is the alias of the identifier before it, after %left and %type it is a token of its own, and after %token it may also carry a token number.

Passes over a #line directive that falls inside a list, where Bison treats it as whitespace.

A directive followed by anything else ends the list and is kept as a node of its own, so only a directive between two entries is lost.
