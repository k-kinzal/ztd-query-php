final class PostgreSqlSchemaParser
    implements SchemaParserInterface

Reads PostgreSQL CREATE TABLE statements into table schemas.

The statement is parsed with the PostgreSQL grammar, so SERIAL columns, array types, multi-word type names and table constraints are read from the syntax tree rather than from the statement text.
