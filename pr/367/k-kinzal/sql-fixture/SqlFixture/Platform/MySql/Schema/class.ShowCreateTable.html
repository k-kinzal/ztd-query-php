final class ShowCreateTable
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Writes the statement that reads the declaration of one table.

The name is written into the statement and the statement is read back with the grammar of the server, and it is issued only when the grammar read the whole of it as one table's declaration and nothing else: no second statement, no comment and no spacing of its own. A name that is not read that way, a reserved word or a name written with a space in it, is written as one quoted identifier and read back again.
