Reads the name an identifier node spells, without its quotes.

public function decode(Node $ident): ?string
source§

Returns the identifier text, or null when the node holds no token.

The lexer names a word holding anything but plain ASCII a quoted identifier even when it was written without quotes, so what is written decides whether there is a quote to take off.
