classFieldReader

final class FieldReader

Reads the value of one bold field section of a card.

Prose fields are paragraphs; list fields are bullet lists, or "None." for an empty list; labels may also be a paragraph of badge images. Link targets and label badge images are kept so that writing the card back reproduces them.
