final class MarkdownDocument

Reads a definition written as Markdown cards and writes it back in the same form.

The YAML frontmatter holds the version and source; each top-level heading is an item ID followed by badges, a statement, quoted evidence and bold field sections. What the author chose beyond the data model, such as badge images and link targets, is remembered so that formatting reproduces it.
