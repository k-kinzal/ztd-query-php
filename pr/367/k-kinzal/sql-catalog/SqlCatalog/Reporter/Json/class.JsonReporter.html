final class JsonReporter
    implements ReporterInterface
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Writes the catalog as JSON, in an order two runs can be compared in.

Nothing that changes between runs of the same source, such as a timestamp, is written, so the artifact can be committed and its diff read as the change in the SQL an application issues.
