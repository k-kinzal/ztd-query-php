Public API: explicitly declared with @visibility public.

A #line directive: from here on, Bison counts lines from the number given, in the file named.

Bison reads #line at the start of a line anywhere in the file and changes the locations it reports and, through them, the order it numbers symbols in. The directive is kept where it stands: among the declarations, among the rules, or inside a rule.
