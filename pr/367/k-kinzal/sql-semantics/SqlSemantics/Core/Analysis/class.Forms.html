final class Forms

Navigates the symbols of a form to the child values they stand for.

A form lists every symbol of its grammar alternative, fixed words included, while a value keeps children only for the symbols that are rules. Relation rules name symbols, so the child at a symbol has to be found by counting the rule symbols before it.
