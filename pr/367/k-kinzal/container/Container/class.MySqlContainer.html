abstract class MySqlContainer
    extends GenericContainer

Defines a reusable MySQL server with a disposable test database.

Each version extends it and sets only $IMAGE. The server runs on tmpfs and skips loading the time zone tables to start fast; it is ready once PDO can connect as root / root.
