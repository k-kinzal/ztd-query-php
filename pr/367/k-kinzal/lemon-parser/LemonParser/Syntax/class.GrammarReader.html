Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads a whole grammar file, as Lemon's WAITING_FOR_DECL_OR_RULE state does.

A % starts a declaration, a nonterminal starts a rule, and a code block or a [TOKEN] mark attaches to the rule most recently completed, even when declarations come between.
