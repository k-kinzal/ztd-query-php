Checks the option values of VACUUM and the combinations the server refuses.

Rule: PG-VACUUM-OPTIONS-001. PARALLEL takes an integer from 0 to 1024 and must have a value. INDEX_CLEANUP without a value or with auto, compared without regard to case, leaves the choice to the server; any other value must be Boolean. The Boolean options are read by PG-UTILITY-OPTION-VALUE-001; PROCESS_MAIN and PROCESS_TOAST are on unless turned off. The server refuses: BUFFER_USAGE_LIMIT with FULL unless ANALYZE is on; FULL with PARALLEL above 0; a column list without ANALYZE; FULL with DISABLE_PAGE_SKIPPING; FULL with PROCESS_TOAST off; ONLY_DATABASE_STATS with tables, or with any of ANALYZE, FREEZE, FULL, SKIP_LOCKED, DISABLE_PAGE_SKIPPING and SKIP_DATABASE_STATS on. Termination: one pass over the options. Source: https://www.postgresql.org/docs/17/sql-vacuum.html. Status: Implemented.
