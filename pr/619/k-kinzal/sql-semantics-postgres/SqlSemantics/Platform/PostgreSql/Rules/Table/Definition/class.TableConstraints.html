Tells which values are table constraints, and checks the element lists of typed tables and partitions.

Rule: PG-TABLE-CONSTRAINTS-001. A table constraint is one of the ConstraintElem forms: CHECK, UNIQUE, PRIMARY KEY (with columns or USING INDEX), EXCLUDE and FOREIGN KEY. The elements of a typed table or a partition are column options and table constraints. Source: https://www.postgresql.org/docs/17/sql-createtable.html. Status: Implemented.
