enumSpecialSetting

enum SpecialSetting: string
Public API: explicitly declared with @visibility public.

The settings SET writes with keywords of their own.

Each stands for a parameter or a session property: SCHEMA sets search_path, NAMES sets client_encoding, ROLE sets the current role, SESSION AUTHORIZATION the session user, XML OPTION sets xmloption, TRANSACTION SNAPSHOT imports a snapshot, and CATALOG would change the database, which the server refuses. The value is the keyword spelling. Source: https://www.postgresql.org/docs/17/sql-set.html, https://www.postgresql.org/docs/17/sql-set-role.html, https://www.postgresql.org/docs/17/sql-set-session-authorization.html, https://www.postgresql.org/docs/17/sql-set-transaction.html.
