How a type cast is written.

x::t and CAST(x AS t) request the same conversion; the grammar keeps them as different token sequences, and only the operator form takes part in operator precedence. Source: https://www.postgresql.org/docs/17/sql-expressions.html#SQL-SYNTAX-TYPE-CASTS.
