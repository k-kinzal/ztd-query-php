Public API: explicitly declared with @visibility public.

A value passed to an SQL/JSON function, with an optional FORMAT clause.

Mirrors PostgreSQL's JsonValueExpr. Whoever holds it derives it once, through deriveValue(), to read the value's facts. An ENCODING on a value that is not bytea is reported (PG-JSON-CHECKS-001). Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-JSON-CREATION-TABLE.
