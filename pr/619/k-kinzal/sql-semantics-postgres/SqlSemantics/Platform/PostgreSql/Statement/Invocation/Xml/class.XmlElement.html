XMLELEMENT (NAME name [, XMLATTRIBUTES (attributes)] [, content]): an XML element.

Mirrors PostgreSQL's XmlExpr of kind IS_XMLELEMENT. Rule: PG-XMLELEMENT-001. Facts: xml, not NULL. Diagnostics: an unnamed attribute that is not a column reference, and an attribute name used twice (PG-XML-CHECKS-001). The result column is named xmlelement. Source: https://www.postgresql.org/docs/17/functions-xml.html#FUNCTIONS-PRODUCING-XML-XMLELEMENT. Status: Implemented.
