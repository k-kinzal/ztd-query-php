ON CONFLICT [ conflict_target ] DO NOTHING: a row that would violate a unique constraint is not inserted.

Mirrors PostgreSQL's OnConflictClause with ONCONFLICT_NOTHING. Without a target, a conflict with any unique constraint is skipped. Source: https://www.postgresql.org/docs/17/sql-insert.html#SQL-ON-CONFLICT.
