enum JoinKind: string
Public API: explicitly declared with @visibility public.

The kind of a join.

Mirrors PostgreSQL's JoinType for the joins the grammar writes; CROSS JOIN is an inner join without a condition and is kept as its own kind because it is written so. INNER and OUTER are optional words. Source: https://www.postgresql.org/docs/17/queries-table-expressions.html#QUERIES-JOIN.
