enum SpecialParameter: string
Public API: explicitly declared with @visibility public.

What RESET and SHOW name with keywords instead of a parameter name.

TIME ZONE is the parameter timezone, TRANSACTION ISOLATION LEVEL is transaction_isolation, SESSION AUTHORIZATION is session_authorization, and ALL is every parameter. The value is the keyword spelling. Source: https://www.postgresql.org/docs/17/sql-reset.html, https://www.postgresql.org/docs/17/sql-show.html.
