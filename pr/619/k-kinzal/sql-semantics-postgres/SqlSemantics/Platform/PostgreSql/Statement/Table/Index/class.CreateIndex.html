A request to create an index.

Mirrors PostgreSQL's IndexStmt (unique, concurrent, if_not_exists, idxname, relation, accessMethod, indexParams, indexIncludingParams, nulls_not_distinct, options, tableSpace, whereClause). Rule PG-INDEX-001: the indexed table is resolved (PG-TABLE-TARGET-001) and is the relation fact of the statement; the keys, the included columns and the predicate are derived where that table is the only visible relation, the predicate as a condition (PG-TABLE-CONDITION-001). An index declares nothing a query can read. Source: https://www.postgresql.org/docs/17/sql-createindex.html.
