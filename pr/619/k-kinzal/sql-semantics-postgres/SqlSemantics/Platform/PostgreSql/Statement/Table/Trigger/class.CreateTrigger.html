A request to create a trigger.

Mirrors PostgreSQL's CreateTrigStmt without isconstraint (replace, trigname, relation, funcname, args, row, timing, events, whenClause, transitionRels). Rule PG-TRIGGER-001: the table is resolved and is the relation fact of the statement; the WHEN condition of a row trigger sees the table's columns as OLD and NEW, and that of a statement trigger sees no column. FOR [ EACH ] — EACH is optional — and PROCEDURE for FUNCTION are not kept. Source: https://www.postgresql.org/docs/17/sql-createtrigger.html.
