A function, procedure or routine named with or without its argument list.

Mirrors PostgreSQL's ObjectWithArgs for function_with_argtypes. Without an argument list (args_unspecified) the name must identify one routine; an empty list names the routine without arguments. The argument types identify the routine; argument names and output arguments are written but do not take part in the lookup of a function. Source: https://www.postgresql.org/docs/17/sql-dropfunction.html.
