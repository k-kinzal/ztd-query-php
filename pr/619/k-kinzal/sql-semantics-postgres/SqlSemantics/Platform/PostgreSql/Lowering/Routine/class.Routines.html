The entry point of the routine family: functions, procedures, aggregates, operators, operator classes and the generic object commands.

Rule: PG-ROUTINE-001. Every other family reaches the routine rules through these methods: PG-FUNCTION-LOWER-001, PG-ROUTINE-OPTION-LOWER-001, PG-SIGNATURE-LOWER-001, PG-DEFINE-LOWER-001, PG-OPCLASS-LOWER-001, PG-DROP-LOWER-001, PG-COMMENT-LOWER-001, PG-RENAME-LOWER-001, PG-ALTER-OBJECT-LOWER-001 and PG-OBJECT-LOWER-001.
