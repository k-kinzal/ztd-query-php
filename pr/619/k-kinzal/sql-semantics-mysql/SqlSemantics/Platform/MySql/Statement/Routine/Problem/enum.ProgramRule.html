enum ProgramRule: string
Public API: explicitly declared with @visibility public.

The rules of MySQL a grammatical stored program statement can break.

Each case holds the message of the server error it corresponds to; %s stands for the name the problem is about. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.
