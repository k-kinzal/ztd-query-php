final class SystemVariable

    uses Snapshot
Public API: explicitly declared with @visibility public.

A system variable read as a value or named as the target of SET: @@name, @@GLOBAL.name, @@instance.name.

A structured variable is written with the name of its instance or component before the variable name; DEFAULT.name names the instance default. Without a scope the session value is read when the variable has one and the global value otherwise.

Rule: MYSQL-SYSTEM-VARIABLE-001. Facts: the type and the NULL fact are those of the variable in the running server, which no context holds; the fact names the variable as missing session state. Diagnostics: none. Source: https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html, https://dev.mysql.com/doc/refman/8.4/en/structured-system-variables.html. Status: Implemented.
