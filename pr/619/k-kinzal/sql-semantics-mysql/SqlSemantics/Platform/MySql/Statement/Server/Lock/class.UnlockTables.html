UNLOCK {TABLE | TABLES}: a request to release the table locks of the session.

Mirrors SQLCOM_UNLOCK_TABLES. Rule: MYSQL-UNLOCK-TABLES-001. TABLE and TABLES are synonyms; TABLES is written. The statement names no relation and has no facts. Source: https://dev.mysql.com/doc/refman/8.4/en/lock-tables.html. Status: Implemented.
