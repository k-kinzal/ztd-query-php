final class ConditionRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Lowers condition values: error codes, SQLSTATE values, condition names and condition classes.

Rule: MYSQL-CONDITION-LOWERING-001. Scope: sp_cond, sqlstate, opt_value, sp_hcond, sp_hcond_element, sp_hcond_list. The optional word VALUE holds no operand. Constructs: ErrorCode, SqlState, ConditionName, GeneralCondition. Terminates: the list is flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/declare-condition.html, https://dev.mysql.com/doc/refman/8.4/en/declare-handler.html. Status: Implemented.
