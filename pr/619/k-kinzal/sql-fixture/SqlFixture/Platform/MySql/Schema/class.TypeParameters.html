Reads the name, size, sign and permitted values of a column's data type.

Synonyms are named as the server names them: INTEGER is INT, NUMERIC, DEC and FIXED are DECIMAL, LONG VARCHAR is MEDIUMTEXT, and FLOAT(p) is FLOAT up to a precision of 24 and DOUBLE above it.
