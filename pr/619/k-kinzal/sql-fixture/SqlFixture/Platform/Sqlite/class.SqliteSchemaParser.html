final class SqliteSchemaParser
    implements SchemaParserInterface
Public API: explicitly declared with @visibility public.

Reads SQLite CREATE TABLE statements into table schemas.

The statement is analyzed with the grammar and rules of the selected SQLite release, so the declared type names that drive type affinity, the column constraints and the table constraints are read from its typed model rather than from the text, and a statement SQLite would refuse is rejected.
