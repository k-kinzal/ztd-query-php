final class ParseTableBuilder
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Builds the LALR(1) parse table of a grammar.

Each state keeps its shifts, its gotos and the reductions that could not become its default. The default is the reduction with the most lookahead terminals, and a state with one reduction and nothing to shift reduces without looking at all. A state that acts on the wildcard keeps every reduction explicit, as Lemon does, so the wildcard cannot swallow a token the state would rather reduce on. Token classes are spelled out to their members before conflicts are settled, as Lemon does, so a lexer never has to know about them.
