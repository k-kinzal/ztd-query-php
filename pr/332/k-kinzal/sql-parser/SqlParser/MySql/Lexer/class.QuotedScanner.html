Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads MySQL's quoted tokens: strings, quoted identifiers and prefixed literals.

A single-quoted run is a string, and so is a double-quoted one unless ANSI_QUOTES makes it an identifier. Backticks always quote identifiers. A quote right after N, X or B opens a national string, a hexadecimal literal or a bit literal.
