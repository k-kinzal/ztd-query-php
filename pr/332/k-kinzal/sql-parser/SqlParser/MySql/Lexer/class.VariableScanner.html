final class VariableScanner
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads what follows @ in MySQL: a user variable, a host name or a system variable.

After one @ the next word is a host name, so that user@localhost reads as a whole. After @@ the next word is a keyword or identifier naming a system variable, possibly qualified with global. or session..
