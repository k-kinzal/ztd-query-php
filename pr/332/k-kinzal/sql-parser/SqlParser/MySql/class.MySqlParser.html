final class MySqlParser
Public API: explicitly declared with @visibility public.

Parses MySQL statements with the grammar of a chosen server release.

The parse table is built from the sql_yacc.yy of that release and the lexer follows its sql_lex.cc, so the tree names the nonterminals of the official grammar. One statement is parsed at a time, as the server does.
