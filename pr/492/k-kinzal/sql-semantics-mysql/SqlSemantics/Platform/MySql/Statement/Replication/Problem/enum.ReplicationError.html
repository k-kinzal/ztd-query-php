The checks the server's parser applies to the values of replication statements.

Each case names the server error the statement fails with and describes it. The server raises them while it parses, after the grammar has accepted the statement. Source: sql/sql_yacc.yy of MySQL 5.6.51 to 9.1.0 (the actions of TEXT_STRING_sys_nonewline, source_def, replica_until, start_replica_stmt, source_reset_options, filter_wild_db_table_string, dec_num_error and group_replication_password), https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
