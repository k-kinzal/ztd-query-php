enum SetOperator: string
Public API: explicitly declared with @visibility public.

The operator of a set operation.

Each case holds its keyword. INTERSECT binds more tightly than UNION and EXCEPT, which bind equally and associate to the left (MySQL 8.0.31 and later accept INTERSECT and EXCEPT). Source: https://dev.mysql.com/doc/refman/8.4/en/set-operations.html.
