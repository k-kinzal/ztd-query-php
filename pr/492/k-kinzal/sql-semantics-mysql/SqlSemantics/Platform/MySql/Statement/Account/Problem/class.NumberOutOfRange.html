Public API: explicitly declared with @visibility public.

A number that an account statement writes outside the range the server accepts for it.

The server rejects the statement while parsing it: ER_WRONG_VALUE for a PASSWORD EXPIRE INTERVAL outside 1 to 65535 days, a FAILED_LOGIN_ATTEMPTS or PASSWORD_LOCK_TIME above 32767, and a factor number other than 2 or 3; ER_ONLY_INTEGERS_ALLOWED for a decimal or floating number at a position that takes an integer. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html#create-user-password-management, https://dev.mysql.com/doc/refman/8.4/en/alter-user.html#alter-user-multifactor.
