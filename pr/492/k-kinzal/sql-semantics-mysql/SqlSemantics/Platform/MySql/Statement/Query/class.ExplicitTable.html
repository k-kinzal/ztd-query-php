Public API: explicitly declared with @visibility public.

The TABLE statement: every row and column of one table (MySQL 8.0.19 and later).

It is both the query and the occurrence of the table it reads.

Rule: MYSQL-EXPLICIT-TABLE-001. The name resolves like a table reference (MYSQL-TABLE-SHAPES-001); the output fields are the columns of the table in order. Source: https://dev.mysql.com/doc/refman/8.4/en/table.html. Status: Implemented.
