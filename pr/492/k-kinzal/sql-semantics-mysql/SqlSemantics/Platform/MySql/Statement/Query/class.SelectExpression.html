Public API: explicitly declared with @visibility public.

One projected expression of a select list with its optional alias.

MySQL names an item without alias after the text of its expression as the statement writes it (MYSQL-SELECT-ITEM-NAME-001), so such an item keeps the layout of that text (CORE-SPELLING-001): the expression is rendered in the spelling and with the trivia it was written with, and the output name follows from it. An item built without a layout is written, and named, in the canonical rendering of its expression. An aliased item is named by its alias and keeps no layout. Source: https://dev.mysql.com/doc/refman/8.4/en/select.html.
