Public API: explicitly declared with @visibility public.

The head of INSERT and REPLACE: the verb, its modifiers, the table and the optional column list.

Mirrors the server's PT_insert with its is_replace flag: REPLACE deletes a row that duplicates a unique key before it inserts the new one. REPLACE takes no IGNORE and no HIGH_PRIORITY; the written table has no correlation name. The keyword INTO is optional and always written. Source: https://dev.mysql.com/doc/refman/8.4/en/insert.html, https://dev.mysql.com/doc/refman/8.4/en/replace.html.
