Finds out whether the body of a stored function holds a RETURN statement.

Rule: MYSQL-FUNCTION-RETURN-001. The server rejects a stored function whose body holds no RETURN statement at all (ER_SP_NORETURN); whether every path reaches one is found only when the function runs. The search visits the statements nested in blocks, handlers, conditionals and loops with an explicit stack. Terminates: every statement is visited once. Source: https://dev.mysql.com/doc/refman/8.4/en/return.html. Status: Implemented.
