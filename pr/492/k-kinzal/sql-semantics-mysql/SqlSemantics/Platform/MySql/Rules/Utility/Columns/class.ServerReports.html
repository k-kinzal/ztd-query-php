The result columns of the SHOW statements about the server, the session, accounts and diagnostics.

Each report maps the space-separated grammar releases it applies to onto its columns in order, written name:code and separated by |; the code is decoded by MYSQL-SHOW-ROWS-001 (ShowRows), and ? marks a column that can be NULL. The tables were read from the result metadata the servers of the shipped releases (5.6.51, 5.7.44, 8.0.46 for 8.0.44, 8.1.0, 8.2.0, 8.3.0, 8.4.7, 9.0.1, 9.1.0) return for each statement, with a placeholder for a column name the statement computes.
