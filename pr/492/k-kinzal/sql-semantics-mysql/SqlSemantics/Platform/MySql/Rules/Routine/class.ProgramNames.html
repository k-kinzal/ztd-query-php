final class ProgramNames
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Writes the names of stored programs and the labels of their statements.

Rule: MYSQL-PROGRAM-NAMES-001. A program name is written with its database qualifier when it has one; a label before a statement is followed by a colon; a data type is followed by its COLLATE clause when it has one. Terminates: constant work. Source: https://dev.mysql.com/doc/refman/8.4/en/identifier-qualifiers.html, https://dev.mysql.com/doc/refman/8.4/en/statement-labels.html. Status: Implemented.
