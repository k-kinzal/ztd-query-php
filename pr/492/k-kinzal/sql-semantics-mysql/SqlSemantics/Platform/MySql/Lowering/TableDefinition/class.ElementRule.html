Lowers the element list of a table definition and its column elements.

Rule: MYSQL-TABLE-ELEMENT-001. Scope: create_field_list, field_list, field_list_item, table_element_list, table_element, column_def, field_spec. The elements are kept in written order. Constructs: ColumnDefinition, and the elements of MYSQL-KEY-DEFINITION-001. Terminates: lists are flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html. Status: Implemented.
