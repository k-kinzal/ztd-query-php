trait Queries
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Composes MySQL queries: set operations, common table expressions, and the WITH clause of the 8.0 query grammar.

A query given here may be the command of an analyzed statement; its terminator envelope is removed. A composed query is a complete query expression, so it is again a command and a subquery. Releases before 8.0 chain unions as LegacyUnions does and have no common table expressions.
