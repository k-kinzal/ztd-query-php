final class Builder
    extends Composition
    uses Expressions, Queries, Casts
Public API: explicitly declared with @visibility public.

Composes PostgreSQL values under stable names.

A name is written bare only when the release reads it back as the same name: it is quoted when it holds an upper-case letter, which the server would fold, when its characters need it, or when the grammar reads it as a keyword that cannot be a column name. Strings are standard-conforming: a quote is doubled and a backslash is an ordinary character.
