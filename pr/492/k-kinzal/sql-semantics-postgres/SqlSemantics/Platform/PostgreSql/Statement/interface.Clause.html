interfaceClause

packages/sql-semantics-postgres/src/Statement/Clause.php:24
interface Clause
    extends Node
Public API: explicitly declared with @visibility public.

A part of a statement that is not itself an expression, relation or query but may hold some.

Type names, option lists, sort items, window specifications and object signatures are clauses. Whoever holds a clause derives it exactly once, in the environment its expressions are evaluated in, so every expression inside it receives its facts.
