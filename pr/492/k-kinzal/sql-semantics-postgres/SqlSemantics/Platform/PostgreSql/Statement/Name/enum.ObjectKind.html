enumObjectKind

packages/sql-semantics-postgres/src/Statement/Name/ObjectKind.php:19
enum ObjectKind: string
Public API: explicitly declared with @visibility public.

The kind of catalog object a generic object command addresses.

Mirrors PostgreSQL's ObjectType: DROP, COMMENT, SECURITY LABEL, ALTER ... RENAME, OWNER TO, SET SCHEMA, DEPENDS ON EXTENSION, GRANT and ALTER EXTENSION are one node each with an object kind, not one node per kind. Source: https://www.postgresql.org/docs/17/sql-commands.html.
