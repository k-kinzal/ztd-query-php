A request to create a view.

Mirrors PostgreSQL's ViewStmt (view with its persistence, aliases, query, replace, options, withCheckOption). The statement provides one declaration (PG-QUERY-TABLE-001) whose columns keep the NULL facts of the query. A RECURSIVE view is a view over a recursive common table of the same name and column names; the query sees the view as that common table. A view has no storage, so UNLOGGED is an error. A check option after a query that ends with an IS JSON test without a uniqueness clause is rejected: the test would take the WITH (PG-QUERY-TRAILING-001). Source: https://www.postgresql.org/docs/17/sql-createview.html.
