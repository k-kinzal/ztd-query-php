A test of whether a string is in a Unicode normal form: a IS [NOT] [NFC|NFD|NFKC|NFKD] NORMALIZED.

The parser reads it as a call of pg_catalog.is_normalized(a, form); the form defaults to NFC.

Rule: PG-NORMALIZATION-TEST-001. Facts: boolean for a text operand (or a string constant read as text), NULL when the operand can be; any other operand type is reported. The operand must keep its place before IS (PG-PRECEDENCE-001). Source: https://www.postgresql.org/docs/17/functions-string.html#FUNCTIONS-STRING-SQL. Status: Implemented.
