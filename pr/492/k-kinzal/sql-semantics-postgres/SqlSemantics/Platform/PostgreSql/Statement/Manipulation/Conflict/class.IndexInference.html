The conflict target ( index_column_or_expression, ... ) [ WHERE predicate ] that infers the unique indexes ON CONFLICT arbitrates on.

Mirrors PostgreSQL's InferClause with indexElems and whereClause. The elements and the predicate see the target table only. Source: https://www.postgresql.org/docs/17/sql-insert.html#SQL-ON-CONFLICT.
