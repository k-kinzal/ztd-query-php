SET [LOCAL] parameter TO DEFAULT or SET [LOCAL] parameter FROM CURRENT: a parameter set without a written value.

Rule: PG-SET-002. Mirrors PostgreSQL's VariableSetStmt of kind VAR_SET_DEFAULT or VAR_SET_CURRENT. TO DEFAULT and = DEFAULT are the same request. Facts: none. Source: https://www.postgresql.org/docs/17/sql-set.html. Status: Implemented.
