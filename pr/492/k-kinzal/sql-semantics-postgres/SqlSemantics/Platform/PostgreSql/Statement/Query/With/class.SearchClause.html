SEARCH DEPTH FIRST or BREADTH FIRST BY columns SET column: an ordering column added to a recursive query.

Mirrors PostgreSQL's CTESearchClause. The sequence column is appended to the columns of the common table; the BY columns name columns of it. Source: https://www.postgresql.org/docs/17/queries-with.html#QUERIES-WITH-SEARCH.
