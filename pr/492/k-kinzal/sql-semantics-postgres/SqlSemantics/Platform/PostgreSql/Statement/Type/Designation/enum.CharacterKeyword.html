enum CharacterKeyword: string
Public API: explicitly declared with @visibility public.

The keyword spellings of the character types.

Every spelling denotes character, or character varying when VARYING follows or the spelling is VARCHAR; the national spellings are not a different type in PostgreSQL. Source: https://www.postgresql.org/docs/17/datatype-character.html.
