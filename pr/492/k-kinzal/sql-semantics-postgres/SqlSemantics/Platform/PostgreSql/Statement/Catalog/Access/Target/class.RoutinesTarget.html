Functions, procedures or routines named as the objects of a GRANT or REVOKE.

Each is named with or without its argument types. Routines are not declarations a context holds, so the signatures are not resolved; the expressions inside their argument types are derived. Source: https://www.postgresql.org/docs/17/sql-grant.html.
