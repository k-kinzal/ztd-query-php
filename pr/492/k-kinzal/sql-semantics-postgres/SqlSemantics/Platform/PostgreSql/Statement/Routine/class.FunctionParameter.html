    uses Snapshot
Public API: explicitly declared with @visibility public.

One parameter of a routine definition or signature: mode, name, type and default value.

Mirrors PostgreSQL's FunctionParameter node. The name may be written before or after the mode; both orders declare the same parameter and the order is kept so that the statement is written back as it was. Only input parameters take part in calls; output parameters form the result row. Source: https://www.postgresql.org/docs/17/sql-createfunction.html.
