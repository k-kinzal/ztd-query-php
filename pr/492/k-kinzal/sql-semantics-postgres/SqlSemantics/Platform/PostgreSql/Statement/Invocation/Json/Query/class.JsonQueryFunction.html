JSON_EXISTS, JSON_QUERY or JSON_VALUE (PostgreSQL 17): a JSON path applied to a value.

Mirrors PostgreSQL's JsonFuncExpr. JSON_EXISTS takes no RETURNING, wrapper, quotes or ON EMPTY; JSON_VALUE takes no wrapper or quotes. Rule: PG-JSON-QUERY-001. Facts: the RETURNING type, otherwise boolean, jsonb or text; the result may be NULL. Diagnostics: the behaviors and clause combinations the server rejects (PG-JSON-CHECKS-001). The result column is named after the function in lower case. Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-SQLJSON-QUERYING. Status: Implemented.
