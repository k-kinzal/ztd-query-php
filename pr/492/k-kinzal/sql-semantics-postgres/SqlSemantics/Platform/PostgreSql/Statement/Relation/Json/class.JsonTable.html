JSON_TABLE as a FROM item: rows and columns read from a JSON value (PostgreSQL 17).

Mirrors PostgreSQL's JsonTable. The facts follow PG-JSON-TABLE-001. Like a function call, it may refer to the FROM items before it whether or not LATERAL is written; the word is kept as written. Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-SQLJSON-TABLE. Status: Implemented.
