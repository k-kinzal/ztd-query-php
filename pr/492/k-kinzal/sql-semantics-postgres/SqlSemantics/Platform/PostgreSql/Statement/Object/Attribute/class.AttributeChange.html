One changed attribute of ALTER OPERATOR ... SET or ALTER TYPE ... SET.

Mirrors an operator_def_elem: name = NONE and the name written alone (PostgreSQL 17) both give the attribute no value, which removes a function the attribute names; the written form is kept. Otherwise the attribute holds its value as the command reads it. Source: operator_def_elem in src/backend/parser/gram.y of PostgreSQL 17.
