A request to define a domain: a base type with a default, a collation and constraints.

Rule: PG-DOMAIN-001. Mirrors CreateDomainStmt: name, base type and the constraints and collation in the order written; the optional AS is not kept. The constraint expressions see the value being checked as VALUE, of the base type (PG-DOMAIN-VALUE-001); the statement is the relation occurrence that offers it, with an empty row. Constraints a domain cannot have are diagnostics (PG-DOMAIN-CHECK-001). A domain is a type, not a relation, so the statement provides no declaration. Source: https://www.postgresql.org/docs/17/sql-createdomain.html. Status: Implemented.
