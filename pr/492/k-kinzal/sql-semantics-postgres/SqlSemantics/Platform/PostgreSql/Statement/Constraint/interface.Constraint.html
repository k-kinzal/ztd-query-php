A constraint of a column, a table or a domain.

Mirrors PostgreSQL's Constraint node: each implementation is one value of its ConstrType, and its expressions are derived in the environment the owner of the constraint gives. Source: https://www.postgresql.org/docs/17/ddl-constraints.html.
