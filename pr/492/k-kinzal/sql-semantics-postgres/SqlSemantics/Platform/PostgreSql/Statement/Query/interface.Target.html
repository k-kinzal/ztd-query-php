interface Target
    extends Node
Public API: explicitly declared with @visibility public.

One item of a select list or a RETURNING list: an expression with an optional name, or a star.

Mirrors PostgreSQL's ResTarget node. An item contributes one output field, or as many as its star expands to. Source: https://www.postgresql.org/docs/17/sql-select.html#SQL-SELECT-LIST.
