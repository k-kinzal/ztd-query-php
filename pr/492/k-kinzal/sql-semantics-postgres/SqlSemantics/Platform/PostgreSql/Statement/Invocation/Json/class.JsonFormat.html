FORMAT JSON [ENCODING name]: the value is JSON text in an encoding.

Mirrors PostgreSQL's JsonFormat node with format JSON. The encoding name is kept as written; the server compares it without case. Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-JSON-CREATION-TABLE.
