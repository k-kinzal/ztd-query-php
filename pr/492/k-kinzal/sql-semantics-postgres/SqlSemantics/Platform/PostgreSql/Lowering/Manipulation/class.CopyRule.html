final class CopyRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers COPY.

Rule: PG-COPY-LOWER-001. Scope: CopyStmt, copy_from, copy_file_name, copy_delimiter, opt_using, opt_program, opt_binary; the options follow PG-COPY-OPTION-LOWER-001. Constructors: CopyTable, CopyQuery, CopyDirection, CopyStream. USING before DELIMITERS and WITH before the options are noise words. Source: https://www.postgresql.org/docs/17/sql-copy.html. Status: Implemented.
