final class SourceLimits
Public API: explicitly declared with @visibility public.

Deterministic admission limits for captured source before query evaluation starts.

Exceeding a limit rejects opening the project; it never creates a partial declaration world. Runtime source capture remains the caller's responsibility when supplying in-memory strings.
