enum SymbolKind: string
Public API: explicitly declared with @visibility public.

The three spellings a grammar symbol may have.

An identifier names a token or a nonterminal, a character literal such as '+' is a token that stands for itself, and a string such as "end of file" is a token spelled by its alias.
