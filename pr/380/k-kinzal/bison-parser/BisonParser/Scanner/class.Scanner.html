final class Scanner
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Splits a grammar file into the tokens Bison's own scanner produces.

This follows scan-gram.l: an identifier is looked past to see whether a colon or a bracketed name follows, a %name-prefix may be followed by =, a stray comma is whitespace, and everything after the second %% is one epilogue token.
