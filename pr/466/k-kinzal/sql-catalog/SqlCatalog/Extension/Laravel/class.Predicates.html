classPredicates

packages/sql-catalog/src/Extension/Laravel/Predicates.php:22
final class Predicates
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Predicate effects, retaining Laravel's clause and binding order.

A comparison value that is not a literal null is compiled as a bound placeholder, and a list whose contents are unknown as a placeholder list of unknown length. Laravel's null normalization and empty-set constants are reconstructed from literals only, since the null and emptiness guards that usually precede such calls are not evaluated.
