public static function fromServer(string $dialect, string $reported): self
source§

Matches the release closest to the version a server reports.

The release of the same series wins, where the series is every number but the last (8.0 for MySQL 8.0.36, 17 for PostgreSQL 17.2). Otherwise the newest release that is not newer than the server wins, and a server older than every release gets the oldest one.

Parameters

$dialectstringDialect of the server
$reportedstringVersion string of the server, such as `8.0.36-0ubuntu0.22.04.1`

self
