18 * One column of the rows a SHOW, DESCRIBE, EXPLAIN or HELP statement answers, with the metadata the server sends for it.
19 *
20 * A text column is held in the server's system character set, utf8mb3, or in the collation of
21 * the table it is read from, and sent in the character set of the results like any string: its length counts the bytes of its characters
22 * in that set. Every other column is sent in the binary character set with its display length.
23 * The type, flags, decimals and the names of the column, its table and its database are those
24 * the server reports for the statement (verified on a live 8.4 server).

73        if (!$this->text) {

102            Field::MediumBlob, Field::LongBlob, Field::Blob, Field::VarString, Field::String, Field::Geometry => Domain::string($this->length, Collation::binary(), $this->field)->withNullable($nullable),
