39 *
40 * Rule: MYSQL-INSERT-001. The written table is the one visible relation of
41 * the columns, the rows and the assignments; a value may refer to a column

43 * the row). The written columns are the column list, or every column of the
37 * table; they must be distinct. Each row of VALUES has one value per written
38 * column, except an empty row without a column list, which writes the
39 * defaults; rows also agree with each other, an empty row included. A query source is derived where
40 * the table is not visible and must return one column per written column.
44 * table; they must be distinct, and an empty column list stands for every
45 * column. Each row of VALUES has one value per written column, except an
46 * empty row without a column list, which writes the defaults; rows also
47 * agree with each other, an empty row included. A query source whose width
48 * differs from the written columns is the mismatch of its first row. A query source is derived where
49 * the table is not visible and must return one column per written column;
50 * a source that is a VALUES statement, also in parentheses, after WITH or
51 * under ORDER BY and LIMIT, writes every row as VALUES does, each row
52 * checked against the written columns as it is derived
53 * (MYSQL-RESULT-SLOTS-001, verified on a live 8.4 server).
54 * ON DUPLICATE KEY UPDATE assigns columns of the written table; its values
55 * see the written table, the row alias (MYSQL-DML-ROW-ALIAS-001), whose
56 * name may not be the table name, and, for a query source that is one query
57 * block without GROUP BY, the relations of its FROM clause. Generated
58 * columns take only DEFAULT (MYSQL-GENERATED-WRITE-001); a row or a query
59 * whose count does not match is reported for the count only, as the
60 * server stops there. A qualified star
61 * in a 5.x column list is reported as the server's unknown column '*'.
62 * Statements return no rows. Terminates: one pass over finite lists; the
63 * source query is derived once. Source:
64 * https://dev.mysql.com/doc/refman/8.4/en/insert.html,
65 * https://dev.mysql.com/doc/refman/8.4/en/insert-select.html,
66 * https://dev.mysql.com/doc/refman/8.4/en/insert-on-duplicate.html,
