28 * GROUPING() yields a bit per argument and its column can be NULL, as a live 8.4 server reports. The keyword is written against
29 * its parenthesis, and the niladic functions are written with empty
30 * parentheses, which the grammar accepts for every one of them; CURRENT_USER
28 * keeps whether its optional parentheses are written.
31 * keeps whether its optional parentheses are written. MySQL 5.6 warns that OLD_PASSWORD() is
32 * deprecated.
33 * Terminates: the arguments are strict parts.
34 * Source: https://dev.mysql.com/doc/refman/8.4/en/built-in-function-reference.html.
35 * Status: Implemented.
36 *
37 * @visibility public
38 * @example Typing a keyword function
39 *     $query = (new \SqlSemantics\Facade\Semantics(\SqlSemantics\Platform\MySql\Dialect::MySql))->analyze("SELECT LEFT('abc', 2)");
40 *     $query->field(0)->type->descriptor->name() // => 'VARCHAR'
41 * @example Refusing an argument count the grammar does not accept
