interface Operand
    extends Node
Public API: explicitly declared with @visibility public.

A value with type, nullability and resolution facts at its use position.

Some values belong only to a particular statement or argument position. Those values implement this interface without implementing Scalar; their parent names the permitted alternatives explicitly. Scalar is the subset accepted at general expression positions.
