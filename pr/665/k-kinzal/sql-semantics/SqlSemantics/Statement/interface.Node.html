interface Node
Public API: explicitly declared with @visibility public.

A structural value of a statement that is written back as SQL.

A node describes what the SQL requests: an operation, an operand, an input relation. It holds decoded names and exact literals and no binding. The same node instance occurs at most once in a statement.
