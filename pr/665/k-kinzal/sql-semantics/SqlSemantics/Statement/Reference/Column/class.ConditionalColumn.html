final class ConditionalColumn
    implements Resolution
    uses Snapshot
Public API: explicitly declared with @visibility public.

A name whose resolution depends on declarations missing from the context.

The candidates are the places the name can resolve to once the missing inputs are known. A known candidate in a farther scope is not chosen while a nearer scope is incompletely known.
