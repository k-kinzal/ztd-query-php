trait ScalarSemantics
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

The type and reference information of one value occurrence.

Construction supplies this information once, before publishing the statement. It is not an index into an enclosing operation or an execution-time resolver.
