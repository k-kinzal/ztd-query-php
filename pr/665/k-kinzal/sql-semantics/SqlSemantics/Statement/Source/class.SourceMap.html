final class SourceMap
    uses Snapshot
Public API: explicitly declared with @visibility public.

Original input locations for occurrences whose lowering records them.

Coverage is partial: an occurrence constructed directly, or lowered by a rule without source tracking, has no location. Identity distinguishes equal expressions at different positions. Rebinding an existing occurrence can read the input location it already owns.
