final class SourceRanges
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Computes source ranges once per parse node during lowering.

Only integer offsets are cached. Weak keys allow discarded parse trees to be collected, and the cache is never included in a published semantic value.
