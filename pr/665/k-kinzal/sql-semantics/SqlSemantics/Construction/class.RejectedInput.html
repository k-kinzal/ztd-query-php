final class RejectedInput
    extends RuntimeException
Public API: explicitly declared with @visibility public.

An input operand outside a semantic constructor's domain.

Lowering reports the typed problem before constructing a statement. This is distinct from a problem of resolving names against a declaration context. The diagnostic payload contains the typed problem and the integer end of the operand. Neither input SQL nor a parser node is a diagnostic operand.
