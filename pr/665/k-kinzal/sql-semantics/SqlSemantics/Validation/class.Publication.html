final class Publication
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Resolves a constructed statement without passing it through the SQL front end.

Construction checks the value domain and resolves its operands against the declarations. SQL reconstruction is a separate consumer, checked by the round-trip fuzz target. Re-parsing here would make generated-value execution depend on the parser and lowerer that the property is intended to bypass.
