final class Equivalence
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Compares two statement structures operand by operand.

Two structures correspond when they have the same classes, the same scalar values and enum cases, and lists of the same length and order, recursively. Source spans are locations rather than operands: formatting changes their byte offsets, and directly constructed values have no original source. Only properties explicitly typed as Span and the private occurrence bindings are excluded from operand comparison. Exact comparison includes those bindings and inherited private fields. Explicit SQL spelling choices remain comparison operands. A generated name whose quote choice is unspecified corresponds to the concrete choice made by its codec; two explicit choices must agree. Exact comparison also preserves object sharing: equal-looking occurrences or declarations cannot replace references to the same occurrence or declaration. Several roots may be compared together to retain references between them. This is a comparison of actual operands, not of a fingerprint or of text.
