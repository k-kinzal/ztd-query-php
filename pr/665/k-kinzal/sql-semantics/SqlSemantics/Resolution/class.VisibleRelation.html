final class VisibleRelation
    uses Snapshot
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

A relation occurrence as one position of a query sees it: its shape and the names that qualify it.

An occurrence with neither alias nor name, such as the merged columns of a join, is found by unqualified names only.
