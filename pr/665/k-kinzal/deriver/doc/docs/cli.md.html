Command Line

vendor/bin/deliver <query> [options]

The command finds candidate values for one query without executing the selected PHP files or their autoloaders. Run vendor/bin/deliver --help for options.

Example

For a file src/Answer.php containing:

<?php
namespace App;

function answer(): int
{
    return 42;
}

Select its return value:

vendor/bin/deliver 'App\answer#return' --path=src

This reports 42 as an analyzed integer. See reports for output formats and unresolved values.

Options

OptionDescription
-c, --config=FILERead a YAML configuration. Omit to use defaults.
--path=DIRSearch root. Default: working directory. Repeat for multiple roots.
--include=PATTERNRoot-relative include wildcard. Default: **/*.php. Repeat to combine patterns.
--exclude=PATTERNRoot-relative exclude wildcard or directory subtree. Default: none. Repeat to combine patterns.
--php-version=VERSIONTarget PHP major.minor version. Default: 8.3.
--format=FORMATtext or json. Default: text.
-q, --quiet, --ansi, --no-ansiControl terminal output.

CLI options override configuration values. Repeated options replace the whole configured list. Paths supplied on the command line are relative to the working directory.

File selection

By default, the command selects **/*.php under the working directory. Use --path to select the directories containing the code and its dependencies. All selected files must be readable and parseable. Symbolic links are skipped, and no directory is excluded implicitly.

Patterns are relative to each search root. * and ? match within one path component; ** matches across zero or more directories. A file must match an include pattern and no exclude pattern. A directory exclusion also excludes its descendants.

vendor/bin/deliver 'App\answer#return' --path=src --path=lib --include='**/*.php' --exclude='Generated/**'

Quote queries and wildcard patterns so the shell passes them unchanged.

Exit codes

CodeMeaning
0Report written after completed exploration. Partial candidates and empty result collections are valid.
1Exploration interrupted, analysis or reporting failed, or the command invocation was rejected.
2Invalid configuration, query or file selection, including no matching source files.
