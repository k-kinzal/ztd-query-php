final class PathJoin
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Joins excess paths into one path that keeps executing, instead of sealing them.

Paths are joined only when they share their control position, aliases, objects, and handlers, and differ only in plain values. Differing values are widened, so the joined path contains every input path; guards keep their common entries and constraints are dropped.
