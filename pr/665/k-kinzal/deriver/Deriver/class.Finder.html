final class Finder
Public API: explicitly declared with @visibility public.

Finds local file paths without reading or parsing their contents. Patterns match paths relative to each root: * and ? stay within a component. The recursive ** wildcard crosses directories and can match zero directories. Exclusions win. Linked files and directories are skipped. With no roots, searches the current directory; with no includes, selects every regular file. No directories are excluded implicitly.
