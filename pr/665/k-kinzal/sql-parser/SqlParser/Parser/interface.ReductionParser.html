interface ReductionParser
    extends SqlParser
Public API: explicitly declared with @visibility public.

A parser that can report completed grammar reductions while reading input.

Observers see visible productions in reduction order, including productions completed before a later syntax error. Hidden grammar actions produce no node. The observer does not change parsing or the returned lossless tree.
