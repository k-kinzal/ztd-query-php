AggregateIterator @visibility MySqlMemoryGroups the rows of its input and answers one row per group: its first row and its aggregates.
DistinctIterator @visibility MySqlMemoryPasses the first row of each set of rows with equal leading values.
FilterIterator @visibility MySqlMemoryPasses the rows of its input for which the condition is true.
LimitIterator @visibility MySqlMemorySkips the offset rows of its input and passes at most the count of the rest.
LockIterator @visibility MySqlMemoryPasses the rows of a query block that meet its WHERE condition, locking the row of each locked table they hold.
MaterializeIterator @visibility MySqlMemoryReads the rows of a query as a table, computing them when the scan starts.
ProjectIterator @visibility MySqlMemoryComputes the output values of each row of its input.
SortIterator @visibility MySqlMemoryReads the whole input and answers its rows in the order of the sort keys; ties keep input order.
WindowIterator @visibility MySqlMemoryReads the whole input with the arguments of the window functions, sorts it for a window, and answers each row followed by the values of the window functions.
