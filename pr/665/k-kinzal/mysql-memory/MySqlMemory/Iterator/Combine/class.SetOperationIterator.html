final class SetOperationIterator
    implements RowIterator
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Combines the rows of two queries by UNION, INTERSECT or EXCEPT.

Without ALL, the result holds each distinct row once; with ALL, INTERSECT keeps a row as often as both sides hold it and EXCEPT as often as the left side holds it more.
