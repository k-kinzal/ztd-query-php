final class NestedLoopJoinIterator
    implements RowIterator
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Pairs the rows of two inputs, reading the inner input again for each row of the outer one.

For a right join the right input is the outer one; the paired row is always the left columns followed by the right columns.
