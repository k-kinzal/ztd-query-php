final class UpdateOperands
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Prepares retained UPDATE operands through the ordinary expression compiler.

Legacy multiple-table writes bind destinations before preparing the join and append their observed cleanup condition for errors in the latter phase. Single-table legacy writes prepare ordering before assignments; modern writes prepare it after assignment values. No expression is evaluated or rewritten.
