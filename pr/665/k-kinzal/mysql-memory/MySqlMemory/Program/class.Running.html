final class Running
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The statements a session runs, as its stored programs see them: the tables each uses, and the replies a CALL answered before it failed.

A statement of a stored function or a trigger that writes a table a statement invoking it reads or writes is ER_CANT_UPDATE_USED_TABLE_IN_SF_OR_TRG (verified on a live 8.4 server). The result sets a procedure answered come before the error that ends it. Source: https://dev.mysql.com/doc/refman/8.4/en/stored-program-restrictions.html.
