Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Prepares a stored selection from its semantic relations and operands.

An ordinary SQL instruction starts a new diagnostics area on every release. Its input is opened before projections bind; no row-valued projection is converted into a substitute scalar or a reconstructed SQL query.
