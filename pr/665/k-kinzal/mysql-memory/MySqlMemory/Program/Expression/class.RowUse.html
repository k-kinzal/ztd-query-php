final class RowUse
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves a stored row operand when an instruction requires one value.

The program may retain this operand without treating it as a Scalar. Its names and subqueries bind in the current invocation before the width error. No substituted scalar expression or SQL text is needed for preparation.
