Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Prepares a complete retained write, opening its target before value dependencies.

Only the semantic write and the current database state are consulted. Every operand remains in its own row and column scope; no substitute query is made.
