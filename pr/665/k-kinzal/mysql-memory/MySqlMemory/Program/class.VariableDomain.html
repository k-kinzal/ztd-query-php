final class VariableDomain
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The type of a parameter or local variable of a stored program, as declared.

A variable holds a value of its type as a column of that type does, and can be NULL. A string type without a character set takes the collation of the database of the program, and one with a COLLATE clause that collation. Source: https://dev.mysql.com/doc/refman/8.4/en/declare-local-variable.html, https://dev.mysql.com/doc/refman/8.4/en/create-procedure.html.
