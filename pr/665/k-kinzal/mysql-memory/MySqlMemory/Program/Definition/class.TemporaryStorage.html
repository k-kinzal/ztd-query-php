final class TemporaryStorage
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reaches a retained temporary-storage conflict after opening source tables and the database.

Neither existing destinations nor IF NOT EXISTS bypass the conflict. Column and tablespace preparation follow it; an enforced foreign key with a creation query is refused before source preparation. PREPARE and stored routine creation retain the instruction; invocation checks its current dependencies. Observed through SQL on MySQL 8.4.7.
