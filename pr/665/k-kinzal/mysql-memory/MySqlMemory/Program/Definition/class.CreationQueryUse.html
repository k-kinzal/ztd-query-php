final class CreationQueryUse
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves a creation query after its sources and destination have opened.

An existing destination can satisfy IF NOT EXISTS before column preparation; source tables still open first. PREPARE has a separate query-preparation path. No ordinary table declaration with a contradictory read shape is fabricated. Observed through SQL on MySQL 5.7.44 and 8.4.7.
