final class ColumnlessUse
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Invokes a complete columnless creation without fabricating an ordinary declaration.

Legacy releases require columns before opening the schema. MySQL 8.0 and 8.4 can complete IF NOT EXISTS using the catalog; 8.1–8.3 and 9.x check the column condition first. CHECK expression restrictions precede that shortcut. Observed through SQL on MySQL 5.7.44, 8.0.44, 8.4.7 and 9.1.0.
