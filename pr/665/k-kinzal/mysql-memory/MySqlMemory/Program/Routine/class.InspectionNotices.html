final class InspectionNotices
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports retained inspection notices when loading and preparing stored instructions.

A shortened database label warns on definition and first load. A table label that cannot resolve warns again whenever preparation is retried. Only semantic instruction identities and facts cross this boundary. Observed on MySQL 5.6, 5.7, 8.0, 8.4 and 9.1.
