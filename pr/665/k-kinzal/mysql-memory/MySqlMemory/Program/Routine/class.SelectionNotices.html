final class SelectionNotices
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Tracks repeated preparation notices for retained stored selections.

Initial invocation consumes the stored definition's syntax notices. An operand failure causes preparation again on the next invocation. Opening failures keep their relation snapshot; a changed declaration also requests preparation. The cache contains semantic identities, never SQL or parser nodes.
