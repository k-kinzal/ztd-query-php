final class LoadNotices
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports collation, administrative-option and function-name notices when a session first loads a routine definition.

A routine DDL invalidates these session entries; table flushes do not. The definition supplies typed collation occurrences and function names, without reparsing stored display text. Loading a definition with notices replaces preceding conditions from MySQL 5.7 onward; a silent load leaves them intact. In MySQL 5.6 loading OLD_PASSWORD discards preceding conditions without publishing the suppressed load warning; subsequent cached calls retain them. Other load notices accumulate within the statement. Observed with repeated calls, ALTER PROCEDURE and independent connections on MySQL 5.6–9.1.
