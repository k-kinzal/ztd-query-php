final class Wkb
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads and writes a MySQL geometry value: four little-endian SRID bytes followed by two-dimensional WKB.

WKB accepts either byte order independently for each nested geometry. Bounds are checked before reading coordinates or allocating members, including counts and nesting depth. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-data-formats.html.
