A two-dimensional geometry: coordinates for a point or line, rings for a polygon, and members for a collection.

Coordinates retain their order; the spatial reference identifier belongs to the complete value. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-data-formats.html.
