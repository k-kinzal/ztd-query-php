Reads constructor WKB, checking component counts and ring closure.

Nonfinite binary ordinates are retained. MySQL 5.6 accepts trailing bytes and any nonzero byte-order marker as little endian; modern inputs are complete. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-wkb-functions.html.
