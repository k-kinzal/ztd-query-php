final class Geohash
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Encodes interleaved longitude and latitude intervals as base-32 geohashes. Decoding selects the shortest decimal rounding of the cell center that stays inside the cell. Encoding stops when the cell center exactly represents both coordinates, or the requested length is reached. Verified against native SQL. Source: https://dev.mysql.com/doc/refman/8.4/en/spatial-geohash-functions.html.
