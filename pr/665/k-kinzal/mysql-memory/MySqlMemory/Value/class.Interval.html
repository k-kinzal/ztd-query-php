final class Interval
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

An interval of an INTERVAL expression: months and microseconds, read from a quantity of a unit.

A simple unit reads its quantity as a number, rounded to an integer except for SECOND; a compound unit reads the numbers of a string from its largest part, so '1:30' HOUR_MINUTE is one hour and thirty minutes. Source: https://dev.mysql.com/doc/refman/8.4/en/expressions.html#temporal-intervals.
