Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads and writes dates, times and datetimes in the canonical text the emulator holds them in.

A date is YYYY-MM-DD, a datetime YYYY-MM-DD hh:mm:ss and a time [-]hh:mm:ss, each with a point and fractional digits when the domain has decimals. A string is read with any punctuation between the parts, as YYYYMMDDhhmmss digits, or with a two-digit year (70-99 are 1970-1999, 00-69 are 2000-2069); a year of other than two digits is read as written. Fractional seconds beyond six digits round half up at the seventh. Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-literals.html, https://dev.mysql.com/doc/refman/8.4/en/fractional-seconds.html.
