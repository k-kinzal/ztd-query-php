Searches JSON values as JSON_CONTAINS, JSON_OVERLAPS and JSON_SEARCH do.

A candidate is contained in a target when both are scalars that are equal; when the target is an array, and every element of a candidate array, or a candidate that is no array, is contained in some element of the target; or when both are objects and each member of the candidate is contained in the member of the target with its name. Two values overlap when an element of one equals an element of the other, a value that is no array taken as an array of itself; two objects overlap when they have a member of the same name and an equal value. The path of a value is written as the server writes it: $, then [N] for a cell and .name for a member, its name quoted when it is no identifier (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/json-search-functions.html.
