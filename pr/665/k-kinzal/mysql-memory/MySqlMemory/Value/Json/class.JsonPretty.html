Writes a JSON value as JSON_PRETTY() does.

Each element of an array and each member of an object is written on a line of its own, indented by two spaces more than the array or object that holds it, and separated from the next by a comma; the closing bracket or brace is written on a line of its own at the indentation of the opening one. A name is followed by ": ". An empty array is written [] and an empty object {}; a scalar is written as the server writes it anywhere else ({@see JsonNode::text()}), so that a decimal keeps its digits and a temporal or an opaque value is a JSON string (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/json-utility-functions.html#function_json-pretty.
