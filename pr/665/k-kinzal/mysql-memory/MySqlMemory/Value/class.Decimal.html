Exact decimal arithmetic on canonical decimal text.

A decimal is written with an optional minus sign, the integer digits without leading zeros (at least one), and, when the scale is positive, a point and exactly that many digits. Rounding is half away from zero, as the server rounds exact values. Source: https://dev.mysql.com/doc/refman/8.4/en/precision-math-rounding.html.
