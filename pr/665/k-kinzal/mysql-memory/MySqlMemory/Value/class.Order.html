Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Compares and keys values of one domain, as the server sorts, groups and indexes them.

NULL is lower than every value and equal to NULL. Strings follow their collation; numbers their value, so 1.0 and 1.00 are equal. JSON values follow the JSON order ({@see self::json()}).
