final class NumericText
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads the number at the start of a string, as the server reads a string in a numeric context.

Leading whitespace is skipped. The longest prefix that is a number is read; the text is complete when nothing but spaces follows it. An empty string reads as zero and is complete.
