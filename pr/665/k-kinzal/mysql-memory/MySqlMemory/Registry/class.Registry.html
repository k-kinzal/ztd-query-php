final class Registry
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The server-wide objects of the emulated server besides databases and accounts: resource groups, foreign servers, spatial reference systems, tablespaces, the binary log, the prepared XA branches, and the client threads with their user-level locks.

The emulated server runs no replication: the default channel exists unconfigured, with its receiver thread stopped. Its connection repository must be initialized before the applier thread can start. Source: https://dev.mysql.com/doc/refman/8.4/en/replication-channels.html.
