final class EventScheduler
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The event scheduler's daemon identity and current wait, separate from client connections.

ON starts a daemon; OFF or DISABLED removes it. Starting an enabled event wakes the daemon into its next-activation wait. Removing or disabling that event does not immediately wake it (verified through PROCESSLIST on 8.4.7). Event bodies are not executed by this model. Source: https://dev.mysql.com/doc/refman/8.4/en/events-configuration.html, https://dev.mysql.com/doc/refman/8.4/en/event-scheduler-thread-states.html.
