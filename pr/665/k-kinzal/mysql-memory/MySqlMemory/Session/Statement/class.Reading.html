Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Applies initial operand conditions of concrete statements before access and execution.

Preparation and ordinary execution use the same conditions. Replayed and stored statements retain domain checks but do not repeat reading notices. This phase neither reads an SQL buffer nor changes the account or table catalog.
