Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Holds the table of CREATE TABLE ... START TRANSACTION until the transaction commits.

ROLLBACK and disconnect discard the unpublished table. IF NOT EXISTS starts the same restricted transaction without replacing an existing table. Verified on MySQL 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
