final class Statements
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The statements a transaction runs, and the atomicity of each: a statement that fails puts back the rows it changed, as InnoDB rolls back a failed statement.

A statement of a stored function or trigger runs inside the statement that invokes it, and its changes are restored when that statement fails; the statements of a procedure CALL stand on their own. With autocommit on, each statement outside BEGIN is a transaction of its own; with autocommit off, a transaction starts with the first statement, and turning autocommit on commits it. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-autocommit-commit-rollback.html.
