Separates a trailing comment-only query from the preceding terminated statement.

SQL Semantics' lossless splitter attaches trailing trivia to the last statement. The MySQL client protocol instead answers a comment after a terminator as another empty query, while trailing whitespace alone adds no reply. Verified on 5.6.51 and 8.4.7.
