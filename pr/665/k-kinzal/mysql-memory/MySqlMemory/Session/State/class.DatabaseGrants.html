final class DatabaseGrants
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The database privilege value reused by an empty REVOKE in MySQL 8.4 and 9.1.

Public SQL observations on fresh 8.4.7 and 9.1.0 servers show that REVOKE USAGE, or IF EXISTS with only inapplicable dynamic privileges, can copy the last database grant value to an account without a grant at that level. A failed database grant operation leaves TRIGGER as that value. Reconnection and FLUSH TABLES clear it. This state is independent of committed grants and survives statement rollback. No server implementation is used to derive these transitions.
