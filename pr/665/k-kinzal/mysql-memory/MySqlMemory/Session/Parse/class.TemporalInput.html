final class TemporalInput
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Keeps grammar conditions ahead of modern temporal-literal interpretation.

Modern releases finish reading grammar operands before interpreting temporal text. A grammar refusal is left to ordinary semantic analysis so its other conditions are preserved. Otherwise all completed syntax warnings precede the temporal error, including warnings written after that literal. MySQL 5.6 interprets literals during parsing; 5.7 still reports them before contextual collation lookup, but after completed CAST precision checks. Observed on native MySQL 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0.
