final class Clauses
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Finds in the tokens of a statement the clauses MySQL 5.6 and 5.7 refuse while they parse it, and where they refuse them.

Those releases refuse INTO in the query of a view, and a variable or a parameter marker written before it, where they parse INTO; INTO or LIMIT in a union operand but the last at the UNION after it; a variable an INTO or a LIMIT names that no stored program declares where they parse it; and a nested join at its closing parenthesis (verified on live 5.6.51 and 5.7.44 servers). Source: https://dev.mysql.com/doc/refman/5.7/en/union.html, https://dev.mysql.com/doc/refman/5.7/en/create-view.html.
