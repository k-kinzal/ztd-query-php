final class ContinuingRefusal
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Preserves completed grammar conditions when lowering cannot publish an operand.

A continuing input refusal, such as AT LOCAL, still allows later grammar warnings and refusals. Contextual operand failures follow completed grammar conditions. Neither publishes a rejected expression for execution. The input remains confined to this reading boundary; no rejected expression is fabricated to carry its diagnostics into a plan.
