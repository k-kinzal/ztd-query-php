Prepares a refused SHOW filter in its retained inspection scope.

Modern schema inspections require a default database before contextualizing their filters. Filter contextualization precedes opening the inspected target; opening that target precedes resolving nested tables in text execution. Legacy inspections contextualize their filters before selecting a database.
