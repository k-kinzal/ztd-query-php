final class ModernWarnings
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Preserves modern operator and SELECT-modifier warnings before a syntax refusal.

A candidate must have been accepted at its original position by SQL Parser. The versioned warning descriptors belong to SQL Semantics. No fragment is executed. Observed on native MySQL 8.0.44, 8.4.7 and 9.1.0 connections.
