final class ModernWarnings
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Preserves modern operator and SELECT-modifier warnings before a syntax refusal.

Operator candidates must have been accepted at their original position by SQL Parser. Character-set introducers warn when lexed, including as a refused lookahead. The versioned warning descriptors belong to SQL Semantics. No fragment is executed. Observed on native MySQL 8.0.44, 8.4.7 and 9.1.0 connections.
