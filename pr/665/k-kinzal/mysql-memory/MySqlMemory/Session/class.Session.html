final class Session

A client session of the server: its current database, variables, diagnostics area and transaction.

A statement is parsed with the grammar of the release under the session's sql_mode, resolved by SQL Semantics against the tables of the server, and executed by the command of its kind. Statements of one text run in order until one fails.
