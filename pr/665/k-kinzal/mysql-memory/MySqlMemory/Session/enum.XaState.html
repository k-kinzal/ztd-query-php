enum XaState: string
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The state of the XA transaction of a session.

XA START makes the transaction ACTIVE and XA END makes it IDLE; XA PREPARE detaches it from the session, which then has none again. Each case holds the name the server reports the state by. Source: https://dev.mysql.com/doc/refman/8.4/en/xa-states.html.
