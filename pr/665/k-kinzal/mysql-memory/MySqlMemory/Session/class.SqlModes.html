final class SqlModes
Public API: explicitly declared with @visibility public.

The sql_mode of a session: the set of mode names it holds, in the order the server writes them.

A combination mode (ANSI, TRADITIONAL) adds the modes it stands for. Names are read without regard to case; a name the server does not know is refused by the caller. MySQL 5.6 and 5.7 also know NO_AUTO_CREATE_USER and the combination modes of other database systems, in the places 8.0 left unused, and lack TIME_TRUNCATE_FRACTIONAL; their ANSI adds ONLY_FULL_GROUP_BY from 5.7 on (verified on live 5.6.51 and 5.7.44 servers). Source: https://dev.mysql.com/doc/refman/8.4/en/sql-mode.html, https://dev.mysql.com/doc/refman/5.7/en/sql-mode.html.
