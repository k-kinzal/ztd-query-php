final class Variables
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The variables of a session: its user variables, and the session values of the system variables.

A user variable holds a value with the domain of what was assigned; one never assigned is NULL. A connection starts with the session value of each system variable that has both scopes set to its global value, so a later SET GLOBAL does not change it; a variable with a global value only reads the global value. Source: https://dev.mysql.com/doc/refman/8.4/en/user-variables.html, https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html.
