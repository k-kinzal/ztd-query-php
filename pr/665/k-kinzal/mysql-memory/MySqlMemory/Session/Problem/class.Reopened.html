Refuses a statement that names a temporary table more than once (ER_CANT_REOPEN_TABLE).

A statement can open a temporary table once: a self-join, a subquery or a set operation that reads it again fails, naming the first occurrence by its alias, else by its name (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/temporary-table-problems.html.
