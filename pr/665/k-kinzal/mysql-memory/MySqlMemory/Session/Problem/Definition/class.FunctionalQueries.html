final class FunctionalQueries
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Opens functional-index dependencies in their statement ownership order.

References are already resolved by SQL Semantics. CREATE TABLE opens its subquery dependencies before testing target existence; ALTER and CREATE INDEX open their existing target first. Missing key columns and forbidden-subquery diagnostics follow these relation dependencies. Explicit row-width conflicts precede table lookup. Verified through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0 without consulting implementation code.
