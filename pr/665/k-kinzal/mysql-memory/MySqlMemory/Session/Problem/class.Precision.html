final class Precision
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Refuses an excessive CAST precision or an AT TIME ZONE fraction while the statement is read.

SQL Semantics supplies each cast's precision problem: at most 53 bits for FLOAT and 6 digits for temporal fractions. The error is ER_TOO_BIG_PRECISION, named for CAST in each case; the casts are checked in their order, and AT TIME ZONE after them. Source: https://dev.mysql.com/doc/refman/8.4/en/fractional-seconds.html.
