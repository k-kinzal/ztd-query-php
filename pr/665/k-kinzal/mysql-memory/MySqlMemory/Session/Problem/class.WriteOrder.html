final class WriteOrder
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Locates the names of an UPDATE, an INSERT or a DELETE in the order the server resolves them.

An UPDATE resolves WHERE, every assigned column, every value, then ORDER BY; an INSERT resolves its column list or the columns of SET, the rows or the values of SET, then the columns and the values of ON DUPLICATE KEY UPDATE, except that an INSERT ... SELECT resolves the columns of ON DUPLICATE KEY UPDATE before the query (verified on a live 8.4 server). MySQL 5.6 and 5.7 resolve the query of an INSERT ... SELECT before its column list, and 5.6 resolves the first row, or the values of SET, before the columns (verified on live 5.6.51 and 5.7.44 servers).
