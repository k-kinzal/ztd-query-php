Answers the error the server reports for a problem SQL Semantics found in a statement.

Each family of diagnostics, the names a statement reads, the rules of a query, the calls of native functions, the definitions of tables, the writes, the expressions and the server statements, has its own dispatcher. An unmapped semantic diagnostic is an implementation failure, not an SQL refusal that a caller can accept as a result. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.
