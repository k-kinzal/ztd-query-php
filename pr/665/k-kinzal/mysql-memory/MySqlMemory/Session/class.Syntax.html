Earlier refused tokens take precedence over later lexical failures when a parser is supplied. Legacy releases quote a refused comma from the immediately following byte, retaining whitespace and comments. Answers the parse error of a failure to read a statement; an attribute a generated column cannot have is ER_WRONG_USAGE, as the parser of the server refuses it (verified on a live 8.4 server). MySQL 5.6 and 5.7, whose lexer reads the word after WITH to tell WITH ROLLUP and WITH CUBE apart, report an error at WITH from the text after it (verified on live 5.6.51 and 5.7.44 servers).
