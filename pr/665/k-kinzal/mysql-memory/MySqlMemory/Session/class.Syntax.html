Refuses a DATE, TIME or TIMESTAMP literal whose text is no value of its form (ER_WRONG_VALUE).

The parser of the server reads the literal, so the error comes before any name of the statement is resolved. NO_ZERO_DATE and NO_ZERO_IN_DATE refuse zero dates and zero parts. The error quotes the first 128 bytes of the text (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-literals.html.
