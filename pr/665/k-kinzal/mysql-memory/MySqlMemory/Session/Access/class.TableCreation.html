final class TableCreation
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks table-creation state and CREATE TABLE ... START TRANSACTION restrictions.

The legacy default-database check precedes definition diagnostics. Transaction checks follow those diagnostics and precede table and column resolution. Only BINLOG, COMMIT and ROLLBACK may run until the transaction ends. Verified on MySQL 8.4.7. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.

Checks the legacy default database before conditions from later definition clauses.

MySQL 5.6 and 5.7 resolve an unqualified CREATE TABLE or ALTER TABLE target before reading its options and query. Modern releases report those conditions first. Observed on isolated 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0 servers.
