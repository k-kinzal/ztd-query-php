Validates CREATE TABLE ... START TRANSACTION and its restriction on following commands.

These checks follow parse-time diagnostics and precede table and column resolution. Only BINLOG, COMMIT and ROLLBACK may run until the transaction ends. Verified on MySQL 8.4.7. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.
