final class DefaultDatabase
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves an implicit object database before interpreting the object's later clauses.

DELETE targets require a default database even when their FROM tables are qualified. Event names precede body diagnostics, and routine CODE names precede the release-build restriction. Observed on 5.6, 8.0 and 8.4. Only the statement's own names are inspected; stored bodies are deferred.
