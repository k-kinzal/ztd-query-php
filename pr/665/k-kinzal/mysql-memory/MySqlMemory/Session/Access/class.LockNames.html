final class LockNames
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves lock names in their retained order before reading later lock specifications.

A lock mode warns before its table identity, implicit database and duplicate alias are resolved. A failed name prevents warnings from subsequent locks. Semantic notices supply the release-specific messages; no source text is inspected. Observed on native MySQL 5.6.51 and 5.7.44.
