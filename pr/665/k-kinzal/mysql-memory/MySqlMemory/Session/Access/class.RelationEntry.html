final class RelationEntry
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Orders implicit relation databases against system-variable reads and window counts.

Projection operands precede FROM, and filters follow it. Resolved CTE links identify active definitions without opening unused bodies or consulting SQL.
