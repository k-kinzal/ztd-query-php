final class TriggerNotices
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports typed trigger hints when table preparation loads stored definitions. Resource placement follows preparation errors and is reported once per load phase. MySQL 9.1 delays loading until a write; earlier releases also load on reads. Observed through SELECT, UPDATE, trigger DDL and table flush histories.
