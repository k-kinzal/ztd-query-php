Restricted visibility: declared "@visibility MySqlMemory\Hint". Code outside that scope must not name this declaration.

Writes optimizer hints and their names as the server writes them in the warnings about them.

Names are quoted with backticks, or double quotes under ANSI_QUOTES. A table-level hint is written for one table, or for its block when it names none; MRR, NO_MRR, NO_ICP and NO_RANGE_OPTIMIZATION for one index; the other index-level hints with all their indexes. The spacing is the server's own, such as BKA(t ), INDEX(t i, j), JOIN_ORDER( t,u) and NO_SEMIJOIN( FIRSTMATCH); a SET_VAR value is written as a number, as a quoted string, or as nothing for a decimal (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/optimizer-hints.html.
