final class Scheduler
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Lets a statement wait for a row lock while the server goes on serving the other connections.

The listener runs the work of each connection in a fiber it admits here. A statement that must wait suspends its fiber, and the listener resumes it from time to time, when it checks again for the lock. Code that runs outside such a fiber, as a session used in process does, cannot wait: nothing else can run while it would. Source: https://www.php.net/manual/en/language.fibers.php.
