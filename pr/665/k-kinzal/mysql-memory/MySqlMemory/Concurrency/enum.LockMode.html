enum LockMode
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The mode of a row lock: shared, as FOR SHARE takes it, or exclusive, as FOR UPDATE and the writes take it.

Shared locks of different transactions are compatible; an exclusive lock is compatible with no lock of another transaction. A transaction that holds an exclusive lock holds the shared lock too. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-locking.html#innodb-shared-exclusive-locks.
