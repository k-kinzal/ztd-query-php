enum StatementError: int
    implements ErrorCode
    uses CatalogedError
Public API: explicitly declared with @visibility public.

A server error about a statement as a whole: its syntax, forms the server does not support, prepared statements, table locks, XA transactions and EXPLAIN.

The SQLSTATE and message format of each error are those of the server error reference, which resources/errors.php holds. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html. Source: https://dev.mysql.com/doc/refman/8.4/en/sql-statements.html.
