Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A server error about the constraints of a table: generated columns, expression defaults, CHECK constraints and foreign keys.

The SQLSTATE and message format of each error are those of the server error reference, declared alongside this error family. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.
