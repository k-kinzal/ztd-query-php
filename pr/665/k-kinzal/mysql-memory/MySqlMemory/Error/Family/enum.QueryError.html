    implements ErrorCode

A server error about the names and the shape of a query: databases, tables and columns it names, grouping, subqueries, windows, common table expressions and VALUES.

The SQLSTATE and message format of each error are those of the server error reference, which resources/errors.php holds. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html. Source: https://dev.mysql.com/doc/refman/8.4/en/select.html.
