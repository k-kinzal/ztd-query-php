enum ProgramError: int
    implements ErrorCode
    uses CatalogedError
Public API: explicitly declared with @visibility public.

A server error about stored programs: routines, triggers and events, their bodies, and the conditions they declare and signal.

The SQLSTATE and message format of each error are those of the server error reference, which resources/errors.php holds. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html. Source: https://dev.mysql.com/doc/refman/8.4/en/stored-programs-views.html.
