A server error about the partitions of a table: how a table is partitioned, and the rows a partition holds.

The SQLSTATE and message format of each error are those of the server error reference, declared alongside this error family. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html.
