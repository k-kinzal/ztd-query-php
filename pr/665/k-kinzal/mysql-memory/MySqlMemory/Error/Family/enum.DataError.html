enum DataError: int
    implements ErrorCode
    uses CatalogedError
Public API: explicitly declared with @visibility public.

A server error about values: NULL in a NOT NULL column, duplicate keys, truncated or out-of-range values, conversions, collations and JSON.

The SQLSTATE and message format of each error are those of the server error reference, which resources/errors.php holds. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html. Source: https://dev.mysql.com/doc/refman/8.4/en/out-of-range-and-overflow.html.
