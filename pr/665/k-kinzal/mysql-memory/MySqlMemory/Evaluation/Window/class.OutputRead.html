final class OutputRead
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads a window's output slot, preserving its initial state before any row reaches the projection.

Empty row subqueries inspect initial NULL state independently of value evaluation. Value reads retain the original arguments and defaults. Completed windows retain their last computed slot after OFFSET discards every output row. Initial values and warnings are verified through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0.
