final class Bound
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

One boundary of the frame of a window: UNBOUNDED, the current row, or an offset from it.

In a ROWS frame an offset counts rows. In a RANGE frame it is a distance from the value of the single ORDER BY expression of the window: the boundary lies at the value of the current row moved by the offset, toward the rows before it for PRECEDING and after it for FOLLOWING, and a row whose value is NULL has only its peers there. Source: https://dev.mysql.com/doc/refman/8.4/en/window-functions-frames.html.
