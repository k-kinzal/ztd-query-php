final class TemporalDelimiters
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports redundant whitespace retained by runtime temporal conversion.

Modern MySQL reports the first redundant delimiter after the conversion's other warnings. Leading whitespace is reported even when conversion fails; trailing or repeated separators are reported after a clock is recognized. Verified through CAST and time-part functions on MySQL 8.0, 8.4 and 9.1.
