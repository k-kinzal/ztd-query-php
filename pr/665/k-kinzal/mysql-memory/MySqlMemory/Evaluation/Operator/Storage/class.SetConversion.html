final class SetConversion
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Stores a UNION operand in its resolved result field.

Unlike an explicit integer CAST, storage clamps a signedness overflow. Legacy decimal fields can also be narrower than their operand value; storing them saturates without issuing a CAST warning. Conversion warnings produced while reading the original operand are retained. Copying an integer field of the same storage type retains its bits, including a differing signedness; the projection origin supplies this distinction independently of SQL text. Observed through native 5.6 and 5.7 UNION, UNION ALL and derived-table consumers.
