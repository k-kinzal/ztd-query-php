final class Arithmetic
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The arithmetic operators +, -, *, /, DIV and % over two operands.

The operands are read in the kind of the result. A division by zero is NULL with a warning (ER_DIVISION_BY_ZERO), or an error when a write runs under a strict mode with ERROR_FOR_DIVISION_BY_ZERO. An integer result outside the BIGINT range is an error (ER_DATA_OUT_OF_RANGE). Source: https://dev.mysql.com/doc/refman/8.4/en/arithmetic-functions.html.
