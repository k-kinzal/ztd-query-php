final class Logic

Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

AND, OR and XOR in three-valued logic.

AND is 0 when an operand is false, else NULL when one is NULL; OR is 1 when an operand is true, else NULL when one is NULL; XOR is NULL when either is NULL. The right operand is not evaluated when the left one decides. Source: https://dev.mysql.com/doc/refman/8.4/en/logical-operators.html.
