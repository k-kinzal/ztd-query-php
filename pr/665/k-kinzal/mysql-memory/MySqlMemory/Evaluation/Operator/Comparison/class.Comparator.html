final class Comparator
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Compares two values of known domains as the server decides to compare them.

Two strings compare as strings in their aggregated collation, converted into its character set; two integers as integers, a BIT value as the unsigned integer of its bits; a date or time and a string or another temporal value as datetimes; a decimal and a decimal or integer as decimals; anything else as doubles. A JSON value and any value compare as JSON values, the other value made a JSON value from its type: a string is a JSON string, not a JSON text, and a predicate a JSON boolean ({@see JsonNode::compare()}). Source: https://dev.mysql.com/doc/refman/8.4/en/type-conversion.html.
