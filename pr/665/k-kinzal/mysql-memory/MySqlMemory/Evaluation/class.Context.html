What one statement is evaluated in: the session's modes and variables, the clock of the statement, and its diagnostics area.

Every NOW() of a statement reads the same instant, the instant the statement started. A value the server computes once for the statement, such as a constant operand a comparison converts, is kept here the first time it is computed.
