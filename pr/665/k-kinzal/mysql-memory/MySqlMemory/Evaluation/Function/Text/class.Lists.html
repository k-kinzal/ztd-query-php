Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The string functions that pick strings by a number: ELT, MAKE_SET and EXPORT_SET.

The number is read as an integer, an exact value rounded; the bits of MAKE_SET and EXPORT_SET are its 64 bits, from the lowest. ELT answers the string at a position from 1, NULL outside them; MAKE_SET joins with commas the strings of the bits set, skipping NULL ones; EXPORT_SET writes one of two strings for each bit, joined by a separator (a comma by default), for a number of bits that is 64 when it is below 0 or above 64 (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_elt.
