The string functions that change the case of a string: UPPER, LOWER and their synonyms UCASE and LCASE.

Each character maps to one character. A Unicode character set maps by the simple case mapping of the Unicode version of its collation: 9.0 for the _0900_ collations, 5.2 for the _520_ ones, and 3.0 within the Basic Multilingual Plane for the others, which also map U+03F2 to U+03A3; the _turkish_ci collations map i to U+0130 and I to U+0131. A UTF-8 text is mapped in place. Another character set maps the characters whose mappings it holds, latin1 only those of ISO-8859-1. A binary string is unchanged. Source: https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_upper, https://dev.mysql.com/doc/refman/8.4/en/charset-unicode-sets.html.
