final class Soundex
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

SOUNDEX(str): the first letter of a string and the digits of the consonants after it, at least four characters; SOUNDS LIKE compares these codes.

Characters before the first letter are skipped. The first letter is kept, an ASCII one in upper case; after it only the ASCII consonants count, each digit written unless it repeats the last digit written, which neither vowels nor other characters reset, and the code is not cut to four characters. A letter is an ASCII letter, or in utf8mb4 and utf8mb3 any character from U+00C0, in latin1 the letters of cp1252, in a binary string no other byte (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_soundex.
