final class Substrings
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The string functions that take or replace a part of a string: LEFT, RIGHT, SUBSTRING and its synonyms SUBSTR and MID, SUBSTRING_INDEX and INSERT.

Positions and lengths count characters in the character set of the result; a position counts from 1. A result longer than max_allowed_packet is NULL with a warning. Source: https://dev.mysql.com/doc/refman/8.4/en/string-functions.html.
