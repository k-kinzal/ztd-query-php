The date and time functions that read parts of a value: DATE, YEAR, MONTH, DAY, HOUR, MINUTE, SECOND and the others.

An argument that is no valid date or time makes the result NULL with a warning. YEAR, MONTH, DAY and QUARTER take a zero month or day; DAYOFYEAR, DAYOFWEEK and WEEKDAY refuse them. Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html.
