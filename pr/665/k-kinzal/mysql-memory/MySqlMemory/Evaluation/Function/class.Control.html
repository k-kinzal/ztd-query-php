The flow control functions IF, IFNULL, NULLIF and COALESCE, and ISNULL.

The result of IF, IFNULL and COALESCE is in the domain their candidate values aggregate to; NULLIF answers its first argument, or NULL when both are equal. Source: https://dev.mysql.com/doc/refman/8.4/en/flow-control-functions.html.
