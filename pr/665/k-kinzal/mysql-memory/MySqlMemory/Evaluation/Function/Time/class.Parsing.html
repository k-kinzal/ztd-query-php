STR_TO_DATE: a date, time or datetime read from a string by a format.

The format is matched from the start of the string. Whitespace before each part of the string is skipped; other characters of the format must be in the string as written. A number specifier reads up to as many digits as it writes, a one- or two-digit %Y and %y reading as 2000-2069 or 1970-1999; a name specifier reads a whole word and takes the English names in any case; %p needs a twelve-hour specifier, and %% matches nothing. A string that ends before the format is read as far as it goes; text after the format is a warning. A week specifier with a day of the week gives the day of that week, and %j the day of the year. A value that does not match, or a date that does not exist or has zero parts sql_mode refuses, is NULL with ER_WRONG_VALUE_FOR_TYPE; here NO_ZERO_DATE refuses a zero year, month or day (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_str-to-date.
