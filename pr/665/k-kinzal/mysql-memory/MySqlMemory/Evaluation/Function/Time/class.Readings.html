final class Readings
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Reads the arguments of the date and time functions: as a date and time, as a time, or as a number.

A value that is no date or time is NULL with a warning (ER_TRUNCATED_WRONG_VALUE); a date with zero parts the function does not take (Zeros) is NULL with the same warning. Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-type-conversion.html.
