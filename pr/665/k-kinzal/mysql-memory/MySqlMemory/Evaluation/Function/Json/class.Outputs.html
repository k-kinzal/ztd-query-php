Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The JSON utility functions that write a document out or measure it: JSON_PRETTY, JSON_STORAGE_SIZE and JSON_STORAGE_FREE.

Each takes a JSON value or a string holding a JSON text ({@see Jsons::read()}); NULL makes each NULL. JSON_PRETTY writes the document over indented lines ({@see JsonPretty}); JSON_STORAGE_SIZE answers the bytes of its binary form ({@see JsonBinary}); JSON_STORAGE_FREE answers the space a partial update of a JSON column freed in it, which is 0 for every value here, as values are stored whole (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/json-utility-functions.html.
