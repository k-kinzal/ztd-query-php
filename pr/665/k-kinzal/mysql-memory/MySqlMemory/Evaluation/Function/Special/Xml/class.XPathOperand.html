final class XPathOperand
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A value an XPath expression of EXTRACTVALUE computes: a set of nodes, an integer, a double, a string, a truth value or NULL.

The server computes XPath with its own SQL operations, so a value converts as SQL converts it: a node set reads as the texts directly in its nodes, joined by spaces; a string reads as a number with the server's warning; a double keeps the decimals of the literals it was computed from and is written with them, or as the server writes a double when they are not fixed (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/xml-functions.html.
