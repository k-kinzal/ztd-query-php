The XML functions: EXTRACTVALUE and UPDATEXML.

The XPath must be known when the statement is compiled, else the call is refused ("Only

  • constant XPATH queries are supported"); it is read then, so an XPath that does not read fails

the statement even when no row is read. A fragment that does not read is NULL with the warning ER_WRONG_VALUE naming the problem, a warning even where a strict mode makes warnings errors. EXTRACTVALUE answers the texts directly in the nodes the XPath selects, joined by spaces, or the text of the value it computes; UPDATEXML replaces the markup of the one node the XPath selects, answers the fragment unchanged when it selects none or several, and NULL when it computes no node set (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/xml-functions.html.
