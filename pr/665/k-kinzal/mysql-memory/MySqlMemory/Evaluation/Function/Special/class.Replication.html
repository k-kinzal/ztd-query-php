final class Replication
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The GTID functions and the functions that wait for a replica: GTID_SUBSET, GTID_SUBTRACT, WAIT_FOR_EXECUTED_GTID_SET, SOURCE_POS_WAIT, MASTER_POS_WAIT and WAIT_UNTIL_SQL_THREAD_AFTER_GTIDS.

GTID_SUBSET and GTID_SUBTRACT compute on the sets their arguments write (GtidSet); a malformed set is ER_MALFORMED_GTID_SET_SPECIFICATION quoting at most 200 bytes of it. The emulator is neither a source nor a replica, with GTID_MODE OFF, so the waits answer as such a server does: WAIT_FOR_EXECUTED_GTID_SET refuses a NULL set, then a NULL or negative timeout, then GTID_MODE OFF; SOURCE_POS_WAIT answers NULL for a NULL or empty file name, refuses a negative timeout, answers NULL for a named channel and refuses a call without a channel, as no single channel exists (MySQL 8.0 answers NULL); WAIT_UNTIL_SQL_THREAD_AFTER_GTIDS answers NULL, refusing a negative timeout from 5.7 and a NULL set in 8.0; MySQL 5.6 warns of a negative timeout of MASTER_POS_WAIT and answers NULL (verified on live 5.6.51, 5.7.44, 8.0.44, 8.4 and 9.1.0 servers). Source: https://dev.mysql.com/doc/refman/8.4/en/gtid-functions.html, https://dev.mysql.com/doc/refman/8.4/en/replication-functions-synchronization.html.
