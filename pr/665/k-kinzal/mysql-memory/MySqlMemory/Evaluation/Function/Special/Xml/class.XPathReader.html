The tokens of an XPath expression of EXTRACTVALUE and UPDATEXML, read one at a time.

A token is an operator, a string literal in single or double quotes, a number of digits with an optional fraction, a name (prefixed names included), or an axis: a name followed by ::, which must be one of the axes the server knows. An expression that does not read is "XPATH syntax

  • error" quoting the text from the problem on (verified on a live 8.4 server).

Source: https://dev.mysql.com/doc/refman/8.4/en/xml-functions.html.
