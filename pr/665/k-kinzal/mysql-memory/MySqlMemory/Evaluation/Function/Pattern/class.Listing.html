Lists the code points of a set as the ranges of a PCRE class.

A set ICU names by a UnicodeSet pattern is read from ICU a block of code points at a time, by a transliterator whose filter is the complement of the set and which removes what it filters, so that only the members of the block are left. Surrogates, which UTF-8 text cannot hold, and a set without a pattern are tested one code point at a time. Source: https://unicode-org.github.io/icu/userguide/strings/unicodeset.html, https://unicode-org.github.io/icu/userguide/transforms/general/.
