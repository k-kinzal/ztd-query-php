final class Scanner
Restricted visibility: declared "@visibility MySqlMemory\Evaluation\Function\Pattern". Code outside that scope must not name this declaration.

Reads the characters of a regular expression one at a time, and knows where the last one read stands.

A syntax error names the line and the character in that line of the last character read, counting from 1: a carriage return, a line feed that does not follow one, U+0085 and U+2028 begin a new line (verified on a live 8.4 server).
