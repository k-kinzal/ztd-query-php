The performance schema functions FORMAT_BYTES, FORMAT_PICO_TIME, PS_CURRENT_THREAD_ID and PS_THREAD_ID.

FORMAT_BYTES() and FORMAT_PICO_TIME() read their argument as a DOUBLE. A count below the first unit is written as an integer, truncated, right-aligned in 4 (bytes) or 3 (picoseconds) characters; a larger one is divided down to the largest unit it reaches, from KiB to EiB or from ns, us, ms, s, min and h to d, and written with two decimals, or in exponent notation from 100000 of the largest unit on. The thread id of a session is its connection id plus the number of threads a server of the release starts before its first client, as a freshly started server numbers them; a connection id no session has answers NULL (verified on live 8.0.44, 8.4.7 and 9.1.0 servers, whose thread ids also count the threads they started later). Source: https://dev.mysql.com/doc/refman/8.4/en/performance-schema-functions.html.
