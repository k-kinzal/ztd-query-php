final class Properties
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads structural properties of a geometry without computing topological relationships.

Empty collections have no dimension. Geometry type and emptiness in MySQL 5.6 read only a recognized header, whereas newer releases require complete little-endian representations. Coordinate finiteness and polygon closure do not affect these structural properties. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-general-property-functions.html.
