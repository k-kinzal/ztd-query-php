final class Inputs
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Constructs geometry values from WKT or WKB with a reference identifier and axis order.

NULL text short-circuits later operands. Reference validation precedes options and geometry validation. WKB validates its SRID before testing NULL input. Legacy aliases ignore subtype restrictions. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-wkt-functions.html.
