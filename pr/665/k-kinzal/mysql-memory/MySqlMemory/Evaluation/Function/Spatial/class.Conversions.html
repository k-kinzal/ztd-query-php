Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The spatial CAST conversions, preserving coordinates, component order and the source SRID.

A collection converts to a simple geometry only when it contains one appropriate member; conversion to a polygon also checks closure and exterior/interior ring direction. Source: https://dev.mysql.com/doc/refman/8.4/en/cast-functions.html#spatial-cast-functions.
