final class Geohashes
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Evaluates geohash encodings and coordinates after Semantics resolves argument types.

Conversions precede NULL propagation. Modern point decoding validates the numeric SRID before NULL propagation and its catalog entry after it. Geometry encoding uses stored longitude/latitude order. Verified through native SQL. Source: https://dev.mysql.com/doc/refman/8.4/en/spatial-geohash-functions.html.
