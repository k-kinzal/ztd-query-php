Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

POINT and the geometry collection constructors.

POINT converts its coordinates to doubles. The other constructors require GEOMETRY arguments during resolution, before evaluation, and check component types and geometry structure when evaluated. Any evaluated NULL makes the value NULL. Source: https://dev.mysql.com/doc/refman/8.4/en/gis-mysql-specific-functions.html.
