final class EmptyProjection
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Keeps row-subquery output expressions and initialized aggregate state readable without a result row.

Null-safe row comparison can read these expressions after the subquery returns no row. They must remain expressions: each comparison reads them in column order and can stop before a later expression's warning or assignment (verified through SQL on MySQL 8.4).
