final class EmptySet
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Determines whether an empty bounded set still exposes its buffered fields.

MySQL 9.1 invalidates a nonnullable UNION output when at least one operand is a tableless block prepared to return a row directly. HAVING, local row bounds, table references and conditions not resolved to true keep that operand on the buffered path. This distinction is observable even when LIMIT 0 prevents every operand from executing (verified through SQL). MySQL 5.6 retains the initial field state determined by the first UNION operand, independently of later operands and rows discarded by an exhausted OFFSET.
