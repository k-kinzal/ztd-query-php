final class ComparedOutput
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Retains expression and stored-column conversion roles across quantified comparisons.

Ordered quantification reads its inner result as a stored value. Its outer binary literal keeps numeric interpretation only when every projected source is constant. Membership caches the outer value but retains direct inner literal interpretation, including set branches. Verified with native queries; reference identities and projection fields supply all dependencies.
