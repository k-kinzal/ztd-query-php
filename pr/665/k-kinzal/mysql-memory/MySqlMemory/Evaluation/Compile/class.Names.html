final class Names
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Compiles names: columns, select items named by alias or position, parameters and variables.

A column is read at the position its relation occurrence has in the row of the block that holds it; the facts name the occurrence and the column. A name that denotes a variable of the running stored program reads the variable. A column of a stored table is found by its declaration, so invisible columns are found too.

public function default(DefaultOfColumn $node, Scope $scope): Evaluable
source§

Compiles DEFAULT(column): the default of the column.

The default CURRENT_TIMESTAMP reads as NULL, or as the zero value when the column is NOT NULL; an AUTO_INCREMENT column without a default reads as 0, and a default written as an expression is ER_DEFAULT_AS_VAL_GENERATED (verified on a live 8.4 server). In the rows of an INSERT, the column is one of the table written, which the scope holds without reading its rows.
