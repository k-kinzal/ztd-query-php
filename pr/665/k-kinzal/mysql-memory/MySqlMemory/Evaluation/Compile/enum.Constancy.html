enum Constancy: int
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

How long the value of an expression stays the same: for the whole statement, known when it is resolved or only when it runs, or for one row.

A literal, and a function of literals such as DATABASE(), ROW_COUNT() or CONCAT('a', 'b'), is known when the statement is resolved. The account functions (USER() and its synonyms), the clocks of the statement, CONNECTION_ID(), LAST_INSERT_ID(), FOUND_ROWS(), user and system variables the statement does not assign, parameters and an uncorrelated subquery are fixed for the statement but known only when it runs. A column, an aggregate, a window function, an assignment, a correlated subquery and a function such as RAND() or SYSDATE() vary by row. A subquery of one select item without a table or any other clause is the expression it selects, as the server merges it into the enclosing block.
