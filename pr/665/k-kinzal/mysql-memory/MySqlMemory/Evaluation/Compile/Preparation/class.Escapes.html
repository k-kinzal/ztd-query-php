Preserves legacy prepared ESCAPE correlation checks before scalar merging.

DEFAULT(column) is constant after resolution, but MySQL 5.6 and 5.7 refuse a prepared escape subquery that reaches an outer column through DEFAULT. Text execution accepts the merged default. Verified through both protocols.
