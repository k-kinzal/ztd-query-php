final class TimestampLiteral
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Applies the session's calendar modes and time zone to a TIMESTAMP operand.

Displacements are supported from MySQL 8.0.19. Native SQL observations show that carrying rounded fractional seconds discards the displacement before conversion. This operates on decoded literal components, never source SQL.

public static function moment(int $seconds): array{int, int, int, int, int, int}
source§

Keeps year-zero calendar fields which FROM_DAYS deliberately collapses to the zero date.

A displacement can cross the adjacent year boundary. Its out-of-range display is observed on native SQL; explicit zones reject it while SYSTEM has a separate conversion range.
