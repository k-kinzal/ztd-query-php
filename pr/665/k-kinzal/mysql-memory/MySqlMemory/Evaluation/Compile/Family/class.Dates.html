final class Dates
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Compiles date arithmetic: the result is a DATE, DATETIME or TIME for an operand of that kind, else a string.

A DATE moved by a unit smaller than a day becomes a DATETIME. Any other operand gives a string of 29 characters, a date or a datetime as the value reached. Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_date-add.
