final class LegacyPatterns
Restricted visibility: declared "@visibility MySqlMemory\Evaluation". Code outside that scope must not name this declaration.

Preserves legacy temporal LIKE preparation before pattern evaluation.

MySQL 5.x reads constant strings against date operands while preparing LIKE. MySQL 5.6 also refuses particular temporal/text collation combinations before reading the pattern. These decisions use resolved domains and constancy, independently of the original SQL spelling. Verified with constants, columns and both operand orders on 5.6, 5.7 and 8.4.
