final class ScalarRead
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A scalar subquery: the value of its one row, NULL for no row, an error for more than one (ER_SUBQUERY_NO_1_ROW).

A subquery that does not depend on the row is run once for the statement, the first time its value is needed, unless the server reads it as the expression of its one row: a SELECT without a table, an aggregate or HAVING (verified on a live 8.4 server).
