final class Quantified
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

IN, ANY and ALL over a subquery.

ANY (and IN, which is = ANY) is 1 when the comparison holds for a row, else NULL when it is unknown for a row, else 0. ALL is 0 when the comparison fails for a row, else NULL when it is unknown for one, else 1; ALL over no row is 1. NOT IN negates IN. Source: https://dev.mysql.com/doc/refman/8.4/en/any-in-some-subqueries.html.
