final class GroupingFlags
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

GROUPING(): one bit per argument, the first argument the most significant, set when the row rolls up the grouping expression the argument names.

A row WITH ROLLUP holds the number of grouping expressions it rolls up, which are the last ones; the argument naming the grouping expression at position p is rolled up when p is at least the number of grouping expressions less that number. Source: https://dev.mysql.com/doc/refman/8.4/en/miscellaneous-functions.html#function_grouping.
