final class Accumulator
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The fold of one aggregate over the rows of one group.

NULL arguments are skipped, except by JSON_ARRAYAGG and JSON_OBJECTAGG, which keep a NULL value as the JSON null. COUNT counts the rows whose arguments are all not NULL; SUM, AVG, MIN and MAX of no value are NULL; the bit aggregates of no value are their identity. Source: https://dev.mysql.com/doc/refman/8.4/en/aggregate-functions.html.
