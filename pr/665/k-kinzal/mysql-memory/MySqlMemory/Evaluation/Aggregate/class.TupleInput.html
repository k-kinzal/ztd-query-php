final class TupleInput
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Evaluates tuple aggregates at their query block's input phases.

Explicit groups read complete tuples before rejecting NULL rows. An implicit COUNT DISTINCT omits constant fields; an implicit GROUP_CONCAT reads varying fields and sort keys before its deferred constant expressions. Verified through SQL results and user variables on MySQL 8.0, 8.4 and 9.1.
