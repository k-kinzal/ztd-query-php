final class ExactDecimal
    implements Stringable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

An exact intermediate number with separate numeric and text representations.

Numeric consumers read all calculation digits. Text consumers round at the expression's resolved scale. Keeping both with the value also preserves the chosen branch's text scale through IF and CASE without evaluating it again. Source: MySQL 8.4.7 Item_func_numhybrid::val_str and Item_func_if::val_str.
