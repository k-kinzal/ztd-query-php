final class BooleanInput
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads the documented Boolean search operators from the evaluated AGAINST value.

Search-language syntax is runtime data, like a regular expression or JSON path. This reader never receives the SQL statement, its source, or its parser nodes. Source: https://dev.mysql.com/doc/refman/8.0/en/fulltext-boolean.html.
