final class Natural
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Natural-language terms, quoted phrases and the second query-expansion pass.

The input is the evaluated AGAINST value, not SQL or a parser node. Phrase matching applies to InnoDB. MyISAM treats natural-language punctuation as word boundaries. Expansion retains the original query and adds words from matching documents, with MyISAM counting their occurrences and InnoDB adding unique terms. Source: https://dev.mysql.com/doc/refman/8.0/en/fulltext-query-expansion.html.
