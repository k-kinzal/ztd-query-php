final class BufferedRead
    implements Evaluable
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads a buffered result column, including its initialized state before any row is stored.

Empty set operations retain NULL in nullable fields and a zero value in other fields. Reading or discarding rows replaces that state (verified through SQL on MySQL 8.4.7). This state belongs to the result buffer, not to the input expressions of its operands.
