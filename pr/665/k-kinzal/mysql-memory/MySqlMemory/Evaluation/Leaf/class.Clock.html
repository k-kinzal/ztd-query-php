final class Clock

Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The current date or time: the instant the statement started, or the current instant for SYSDATE().

The clocks read the time zone of the session (time_zone); the UTC clocks read UTC. The instant is the timestamp of the session when it is set; SYSDATE() always reads the current instant. Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_now.
