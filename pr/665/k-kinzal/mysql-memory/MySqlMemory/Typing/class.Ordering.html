final class Ordering
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The order of one collation: the comparison and the equality key of its strings.

Untailored Unicode 4.0, 5.2, 9.0 and general_ci use the same weights as WEIGHT_STRING. Other Unicode collations use ICU at their declared strength. Invalid UTF-8 falls back to byte comparison; a multibyte character set other than UTF-8 is read in UTF-8.
