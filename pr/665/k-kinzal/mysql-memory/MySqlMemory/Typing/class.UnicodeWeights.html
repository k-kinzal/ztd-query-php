final class UnicodeWeights
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Untailored Unicode 9.0 primary weights, derived from the public Unicode collation data.

Explicit mappings retain eight collation elements per character. Implicit ideograph weights follow UTS #10 revision 34. Black-box MySQL observations include the unassigned tails of the Hangul and Tangut blocks; their weights follow the same block's arithmetic. Every Unicode scalar was compared with MySQL 8.0.44, 8.4.7 and 9.1.0. Source: https://www.unicode.org/reports/tr10/tr10-34.html#Implicit_Weights. Data: https://www.unicode.org/Public/UCA/9.0.0/allkeys.txt.
