final class Domain
Public API: explicitly declared with @visibility public.

The resolved type of an expression or a column: what the server knows of its values before it reads any.

It is the field type the protocol reports, whether an integer is UNSIGNED, the display length in characters, the number of decimals, the collation of a string, and whether the value can be NULL. The kind says how a value of the domain is held at run time.
