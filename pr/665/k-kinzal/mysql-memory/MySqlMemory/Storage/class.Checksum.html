final class Checksum
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Calculates CHECKSUM TABLE's unsigned sum of the CRC-32 of each record.

The record starts with normalized NULL bits, followed by fields in declaration order. MyISAM packs the high bits of a partial BIT field into the preamble after the column's NULL bit (verified on a live 8.4 server). Virtual generated columns have their NULL bits after stored columns, even when declared earlier. Source: https://github.com/mysql/mysql-server/blob/mysql-8.4.7/sql/sql_table.cc, https://github.com/mysql/mysql-server/blob/mysql-8.4.7/sql/dd_table_share.cc.
