final class ChecksumField
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Encodes the field bytes consumed by CHECKSUM TABLE's row scan.

Integers use little-endian storage, temporal fractions use sortable packed fields, and exact decimals use signed groups of nine digits. Variable strings, BIT, geometry and JSON contribute their value bytes without a length prefix. Source: https://github.com/mysql/mysql-server/blob/mysql-8.4.7/sql/sql_table.cc, https://dev.mysql.com/doc/refman/8.4/en/storage-requirements.html.
