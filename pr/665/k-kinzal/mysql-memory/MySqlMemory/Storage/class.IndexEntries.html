final class IndexEntries
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Expands a stored row into the comparison entries of a composite index.

A multi-valued part contributes one entry per converted JSON element. Duplicate elements inside one row are harmless. SQL NULL and an empty array produce no unique-key conflict with another row. Source: https://dev.mysql.com/doc/refman/8.4/en/create-index.html#create-index-multi-valued.
