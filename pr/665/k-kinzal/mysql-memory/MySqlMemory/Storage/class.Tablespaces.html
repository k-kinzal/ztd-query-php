final class Tablespaces
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Keeps detached InnoDB files separate from table definitions and open handles.

DISCARD retains the definition, removes the stored rows, and makes subsequent scans and writes fail only when they reach a detached partition. A cold open reports its own warning before execution; an impossible predicate need not read storage. Verified on MySQL 5.6.51, 5.7.44 and 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-table-import.html.
