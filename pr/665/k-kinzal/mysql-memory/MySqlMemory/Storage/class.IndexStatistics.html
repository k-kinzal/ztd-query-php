final class IndexStatistics
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A snapshot of row counts and full-key cardinalities collected by index maintenance.

Distinct index scans can compare values before a temporary table hashes them. For small tables, SQL optimizer traces put the grouping crossover near three distinct-key reads per two row reads, including a final key lookup. This records that observed boundary; it does not estimate physical page layouts or large-table sampling.
