What a column stores when an insert names no value for it.

A column has no default (an insert must name a value, or under a non-strict mode stores the implicit default of its type), a constant, an expression evaluated for each row, or the time of the statement. Source: https://dev.mysql.com/doc/refman/8.4/en/data-type-defaults.html.
