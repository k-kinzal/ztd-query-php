final class InstalledCatalog
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The sys routine metadata installed with the MySQL 8.x and 9.x distributions.

The static attributes were observed independently on 8.0.44, 8.4.7 and 9.1.0 and agree. Installation dates are supplied as initial state, defaulting to the instance's creation time. MySQL 5.6 installs no sys schema; 5.7 metadata is not yet included.
