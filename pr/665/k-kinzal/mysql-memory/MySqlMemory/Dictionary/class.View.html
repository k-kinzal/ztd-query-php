final class View
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The immutable stored definition of a view.

Views share the namespace of the tables of their database. Binding against a later catalog produces a separate ViewBinding; analysis never replaces this definition or its declarations. Source: https://dev.mysql.com/doc/refman/8.4/en/create-view.html.
