A view: its query, the columns it declares, and the attributes SHOW CREATE VIEW writes.

Views share the namespace of the tables of their database. The query is kept resolved, with the tables it read when it was resolved; a query whose tables have changed since is resolved again before it is read, in the database that was current when the view was created. Source: https://dev.mysql.com/doc/refman/8.4/en/create-view.html.
