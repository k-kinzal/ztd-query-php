final class Trigger
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A trigger: the table, time and event it fires on, its order among the triggers of the same time and event, and its body.

Trigger names are not case-sensitive and are unique in a database; the body is kept as it was written. Source: https://dev.mysql.com/doc/refman/8.4/en/create-trigger.html.
