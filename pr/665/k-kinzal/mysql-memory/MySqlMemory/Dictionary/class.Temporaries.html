final class Temporaries
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The temporary tables of one session, by database and name.

Only the session that creates a temporary table sees it, and it ends with the session. While it exists it hides a base table of the same name from that session; SHOW TABLES and INFORMATION_SCHEMA list base tables only. Source: https://dev.mysql.com/doc/refman/8.4/en/create-temporary-table.html.
