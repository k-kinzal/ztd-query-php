final class Routine
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A stored procedure or stored function: its signature, characteristics and body as the server stores them.

The parameter list and the body are kept as they were written; the characteristics are kept as values, which SHOW CREATE writes in a fixed order. Routine names are not case-sensitive. Source: https://dev.mysql.com/doc/refman/8.4/en/create-procedure.html.
