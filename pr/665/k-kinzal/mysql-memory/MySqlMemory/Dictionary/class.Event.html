final class Event
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A scheduled event: when it runs, what it does, and what becomes of it after its last run.

The emulator keeps events but never runs them. A one-time event has its time; a recurring one its interval, the time it starts and the time it ends, if any. Event names are not case-sensitive. Source: https://dev.mysql.com/doc/refman/8.4/en/create-event.html.
