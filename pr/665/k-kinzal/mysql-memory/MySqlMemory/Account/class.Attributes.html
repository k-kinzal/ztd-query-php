Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The attributes of an account: a JSON object that ATTRIBUTE merges into and COMMENT sets the comment member of.

ATTRIBUTE merges its object as JSON_MERGE_PATCH() does: a member set to null is removed, an object merges into an object, and any other value replaces the member. A string that is not a JSON object is ER_INVALID_USER_ATTRIBUTE_JSON. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html#create-user-comments-attributes.
