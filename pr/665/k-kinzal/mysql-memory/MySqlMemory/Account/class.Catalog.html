The privileges the server knows: the static privileges in the order it writes them, the levels each fits, and the dynamic privileges it registers.

The dynamic privileges are those a server without plugins or components registers (verified on a live 8.4 server). MySQL 5.6 and 5.7 have neither CREATE ROLE and DROP ROLE nor dynamic privileges (verified on live 5.6.51 and 5.7.44 servers). Source: https://dev.mysql.com/doc/refman/8.4/en/privileges-provided.html, https://dev.mysql.com/doc/refman/5.7/en/privileges-provided.html.
