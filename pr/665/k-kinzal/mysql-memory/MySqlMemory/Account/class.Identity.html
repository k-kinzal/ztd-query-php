Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The name of an account or a role: a user name and a host.

The user name is compared exactly; the host is held in lower case, as the server folds it when it reads an account name, and a name written without a host names the host %. The server writes an account name three ways: quoted as a string ('u'@'h') in the messages of CREATE USER, DROP USER and the like, quoted as identifiers (u@h) in SHOW GRANTS and the messages about roles, and plain (u@h) in a column name. Source: https://dev.mysql.com/doc/refman/8.4/en/account-names.html.
