Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The name of an account or a role: a user name and a host.

The user name is compared exactly; the host is held in lower case, as the server folds it when it reads an account name, and a name written without a host names the host %. The server writes account names as quoted strings in CREATE USER diagnostics, as escaped identifiers in SHOW GRANTS and role-cycle diagnostics, as unescaped backtick labels in authorization and role-membership errors, and plain in column names. Source: https://dev.mysql.com/doc/refman/8.4/en/account-names.html.
