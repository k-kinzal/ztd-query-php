final class Replacement
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves the conflict of a row REPLACE writes with a row of the table.

The existing row is deleted, after its BEFORE DELETE triggers and the foreign keys that reference it, and before its AFTER DELETE triggers, which counts one affected row. A conflict on the last unique key of a table without DELETE triggers updates the existing row in place instead, which counts one affected row when the row is unchanged and two otherwise. Source: https://dev.mysql.com/doc/refman/8.4/en/replace.html.
