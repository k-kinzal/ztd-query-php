final class MultipleChangeCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes UPDATE and DELETE over several tables: the rows of the join that meet WHERE decide the rows of each target table that change.

Each row of a target table changes at most once, however many joined rows it takes part in. Source: https://dev.mysql.com/doc/refman/8.4/en/update.html, https://dev.mysql.com/doc/refman/8.4/en/delete.html.
