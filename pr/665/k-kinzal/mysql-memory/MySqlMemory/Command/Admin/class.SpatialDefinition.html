final class SpatialDefinition
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks the definition of a spatial reference system: an OGC well-known text of a geographic (GEOGCS) or projected (PROJCS) coordinate system.

A node is a keyword, without regard to letter case, followed by its items in brackets or parentheses. A GEOGCS names a datum with its spheroid, a prime meridian, an angular unit and two axes; a PROJCS names a GEOGCS, a projection, its parameters, a linear unit and two axes. AUTHORITY may end the items of any node but an axis, and TOWGS84 may follow the spheroid of a datum (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/create-spatial-reference-system.html, https://dev.mysql.com/doc/refman/8.4/en/spatial-reference-systems.html.
