Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Prepares component assignment values before attempting to load their libraries.

Values are resolved in written order, tested for NULL, then evaluated again for their stored setting value. A failure preserves earlier expression side effects, but component variable lookup waits for loading. Observed through INSTALL COMPONENT on MySQL 8.0, 8.4 and 9.1.
