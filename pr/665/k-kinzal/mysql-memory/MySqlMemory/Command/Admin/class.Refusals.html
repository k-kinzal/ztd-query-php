Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Answers the server errors of the problems SQL Semantics finds while it reads an administrative statement: a tablespace option, a spatial reference system attribute, a resource group priority or thread id, or a replication setting the server refuses as it parses.

Source: https://dev.mysql.com/doc/refman/8.4/en/create-tablespace.html, https://dev.mysql.com/doc/refman/8.4/en/create-spatial-reference-system.html, https://dev.mysql.com/doc/refman/8.4/en/create-resource-group.html, https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
