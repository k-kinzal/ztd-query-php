final class KillCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Evaluates KILL's process identifier and ends the named connection or its active statement.

Identifiers are integers narrowed to 32 bits; NULL is zero. KILL QUERY leaves an idle connection open, while KILL CONNECTION rolls its transaction back. Verified on MySQL 9.1.0. Source: https://dev.mysql.com/doc/refman/8.4/en/kill.html.
