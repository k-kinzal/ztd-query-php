final class UntilExecution
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Validates retained UNTIL log operands when replica startup reaches them.

Receiver configuration precedes these checks when the receiver is requested. Applier-only startup reaches them before repository initialization. Observed through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0.
