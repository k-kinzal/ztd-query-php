final class SourceRepository
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Retains connection settings independently of whether the metadata repository accepts them.

The port and connection retry interval are unsigned modulo 2^32; zero preserves the previous value. TABLE metadata stores signed nonnegative integers. A rejected value survives until a later nonzero assignment or RESET REPLICA ALL. Observed through SQL on 8.0.44, 8.4.7 and 9.1.0, including errors competing with compression and relay settings. Source: https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
