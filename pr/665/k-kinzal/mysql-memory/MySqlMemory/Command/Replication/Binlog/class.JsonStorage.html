Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads binary JSON runtime data into the existing typed JSON value model. Offsets belong to their containing document; small inline integers retain their signedness. Bounds and depth checks reject corrupt or cyclic offsets. Source: https://dev.mysql.com/worklog/task/?id=8132 (public binary format).
