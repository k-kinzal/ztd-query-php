A source table's identity and storage types from a runtime table-map event. Optional metadata does not change the encoded row layout. The destination's catalog supplies signedness and ENUM/SET member names during application. Source: https://dev.mysql.com/doc/dev/mysql-server/latest/page_protocol_replication_binlog_event.html.
