final class SourceSwitches
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks source switch prerequisites against the existing channel configuration.

RESET REPLICA preserves these settings; RESET REPLICA ALL removes them. Observed through SQL on MySQL 5.6.51, 5.7.44, 8.0.44 and 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
