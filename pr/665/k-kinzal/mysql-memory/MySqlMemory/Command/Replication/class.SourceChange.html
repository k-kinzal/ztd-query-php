final class SourceChange
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks replication source settings against the server's GTID mode, accounts and network timeout.

Heartbeat warnings precede validation of GTID and privilege-check settings. Credential and position warnings precede compression validation. Repeated options use their final value. This class validates settings; transporting transactions between servers is not implemented. Verified against MySQL 8.0.44 and 8.4.7 through SQL. Source: https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html.
