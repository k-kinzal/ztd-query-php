final class GenerationMetadata
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Tracks generation-template preparation across destination changes.

Black-box SQL histories distinguish an original preparation from one refreshed against a newly created destination. Dropping that refreshed destination can disconnect the entire native instance. The emulator closes its sessions through its lifecycle API; PHP continues normally. Grouped expressions remain live in the binary protocol. MySQL 5.7 and 9.0 count an extra execution on refresh; 8.0, 8.4 and 9.1 also refresh a removed destination without that extra count. No server implementation is consulted.
