final class PreparedStatement
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A prepared semantic statement with its definition-time name and literal context.

Modern executions reuse the prepared structure and its expression information. Legacy executions bind current parameter and user-variable types. Incompatible modern parameters and changed declarations require explicit repreparation. Source text is only an observable request label. SQL modes and exposed session variables retain their execution-time values. The default database and literal encoding retain their preparation-time interpretation. Observed through SQL PREPARE on MySQL 5.6.51, 5.7.44 and 8.4.7.
