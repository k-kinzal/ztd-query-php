final class PreparedCache
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Invalidates a protocol preparation when a referenced declaration changes.

Ordinary executions consume the active structure. Metadata invalidation selects a typed alternative retained at preparation, under current lexical and client settings in the original database. No SQL text enters refresh. Inactive alternatives do not contribute dependencies to the active cache.
