final class PendingTable
    implements PendingInstruction
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

A prepared table template whose retained condition is checked on execution. The typed refusal is retained without an ordinary semantic Statement or SQL. Engine warnings belong to preparation; database lookup remains per execution. A retained MERGE/query role rejects before table opening or metadata revalidation. Legacy ALTER instructions retain all actions and check destination columns only when invoked. Observed through COM_STMT_PREPARE on MySQL 5.7.44 and 8.4.7.
