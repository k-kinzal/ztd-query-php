final class EventCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes CREATE EVENT and ALTER EVENT.

The schedule is evaluated first: a time that is no datetime is ER_WRONG_VALUE, an interval that is not positive ER_EVENT_INTERVAL_NOT_POSITIVE_OR_TOO_BIG, a unit of microseconds ER_NOT_SUPPORTED_YET, and an end before the start ER_EVENT_ENDS_BEFORE_STARTS. A recurring event starts now unless STARTS says otherwise. A one-time event in the past is dropped at once without ON COMPLETION PRESERVE, and disabled with it; an explicit disabled status needs no disabling note. ALTER refuses an expired replacement without PRESERVE. An event of the same name is ER_EVENT_ALREADY_EXISTS, a note with IF NOT EXISTS; ALTER EVENT of a missing event is ER_EVENT_DOES_NOT_EXIST, found after the note of a DEFINER that does not exist and the database of RENAME TO (verified on live 8.0 and 8.4 servers). The emulator keeps events but never runs them. Source: https://dev.mysql.com/doc/refman/8.4/en/create-event.html, https://dev.mysql.com/doc/refman/8.4/en/alter-event.html.

Ends a one-time event whose time has passed according to the session clock: a created event without ON COMPLETION PRESERVE is dropped, any other one disabled, each with its note unless this statement explicitly disables a preserved event. With the scheduler enabled, modern releases also disable an event without a note when its final time is after the session clock but before the actual clock. A stopped scheduler leaves that definition enabled (verified on live 8.0 and 8.4 servers).
