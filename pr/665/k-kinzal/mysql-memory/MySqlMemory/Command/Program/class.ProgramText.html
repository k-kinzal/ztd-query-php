final class ProgramText
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Supplies display text for stored definitions independently of their executable structure.

A lowered definition can preserve its input spelling. A directly constructed definition has no input location and renders its typed operands instead, without parsing session text. The executable routine and trigger bodies remain the supplied semantic nodes in both cases.
