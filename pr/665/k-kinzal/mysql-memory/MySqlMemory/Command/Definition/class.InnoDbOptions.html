final class InnoDbOptions
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Validates InnoDB table options without creating files or reading native implementation code.

Unsupported row formats and compression algorithms warn before strict-mode rejection. Encryption and file-extension limits report their specific failure followed by the engine failure. Verified by executing DDL on MySQL 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
