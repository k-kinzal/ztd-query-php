final class RefusedDefinitionCommand
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes a CREATE TABLE whose written definition the server executes only to refuse.

The server reports the conditions of such a definition in a fixed order (verified on 8.4.7, 9.1.0, 5.7.44 and 5.6.51): the tables the query and the functional key parts read are opened first (ER_NO_SUCH_TABLE), then the reading-time conditions of the types and collations, then the storage engine; a missing default database follows; from 8.0 the database must exist and an existing table ends the statement (ER_TABLE_EXISTS_ERROR, or a note with IF NOT EXISTS), where 9.0 and later refuse an empty definition before looking at the table; functional key expressions are checked after the table; only then the written problem of the columns and keys is reported. MySQL 5.6 and 5.7 report the written problem before the database and the table exist.

The session's table locks are checked first, as for every definition.
