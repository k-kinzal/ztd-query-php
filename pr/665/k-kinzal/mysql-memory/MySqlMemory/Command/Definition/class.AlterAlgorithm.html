final class AlterAlgorithm
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Determines the row-copying algorithm of an ALTER TABLE after its definition is resolved.

Temporary tables always use COPY. Permanent MyISAM and MEMORY tables copy rows for index storage changes, but keep renames and identical replacements in place. Source: MySQL 8.4.7 sql/sql_table.cc is_inplace_alter_impossible(), fill_alter_inplace_info(), and sql/handler.cc check_if_supported_inplace_alter().

Determines whether the change copies rows and checks its ALGORITHM and LOCK restrictions. Column type or charset changes, ORDER BY, ALGORITHM=COPY, primary-key removal, AUTO_INCREMENT addition and non-strict NOT NULL conversion can require copying. Applies InnoDB's restrictions on virtual-column order and newly indexed virtual slots. Functional indexes use these same slots. Adding an indexed virtual column while dropping another requires COPY; adding one alone needs a shared lock.
