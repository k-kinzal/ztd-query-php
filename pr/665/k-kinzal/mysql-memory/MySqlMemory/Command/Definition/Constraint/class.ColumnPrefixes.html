final class ColumnPrefixes
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves a positive key prefix against the current column's storage domain.

Full-text indexes ignore positive prefixes. Ordinary indexes require a string field; a fixed-capacity string cannot have a longer prefix. Spatial indexes keep their separate engine and geometry diagnostics.
