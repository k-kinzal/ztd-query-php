final class FunctionalKeys
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Compiles functional key parts into internal row slots with no SQL column identity.

The expressions are already resolved by Semantics. Their computed slots let ordinary key comparison enforce uniqueness after inserts and updates. They never enter the table declaration used for name resolution or SELECT stars.
