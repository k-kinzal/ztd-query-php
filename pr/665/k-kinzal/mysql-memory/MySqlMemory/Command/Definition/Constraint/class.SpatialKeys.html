Resolves spatial index structures from the columns SQL Semantics has typed.

Modern geometric indexes use RTREE and require non-null geometric columns. A geometric index cannot be unique or request BTREE or HASH. MEMORY cannot store geometric columns. Verified through SQL on MySQL 5.6 and 8.4.
