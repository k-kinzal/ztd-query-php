final class CallText
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Writes the function calls of an expression of a table definition as the server stores them: the calls, casts and temporal arithmetic.

A function is written in lower case under the name the server keeps for it: SUBSTRING and MID are substr, UCASE upper, LCASE lower, POWER pow, CHARACTER_LENGTH char_length, ISNULL() a null test; DATE(), TIME() and TIMESTAMP() of one argument are casts; DATE_ADD, ADDDATE, DATE_SUB and SUBDATE are additions of an interval; CAST to CHAR names the character set; a JSON path operator is JSON_EXTRACT (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/show-create-table.html.
