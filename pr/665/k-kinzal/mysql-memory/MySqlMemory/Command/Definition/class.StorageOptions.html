final class StorageOptions
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves storage-engine selection and checks the options accepted by the selected engine.

Unknown engines are refused with NO_ENGINE_SUBSTITUTION, otherwise the default engine is substituted with both warnings. Engine attributes require engine support after their JSON has been checked. CREATE directory paths must be absolute; ALTER ignores directory options. Verified on MySQL 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.

Resolves every table and partition engine before opening tables, retaining option order.

Unknown names warn or fail as each option is read. CREATE TABLE then warns if its final table engine requires substitution. A partition's unknown engine has no second warning. A missing current database precedes engine lookup. Verified through SQL on MySQL 8.4.7.
