final class StorageOptions
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves storage-engine selection and checks the options accepted by the selected engine.

Unknown engines are refused with NO_ENGINE_SUBSTITUTION, otherwise the default engine is substituted with both warnings. Engine attributes require engine support after their JSON has been checked. Directory paths must be absolute. Verified on MySQL 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
