final class PartitionNames
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks the names of reached partition definitions, including subpartitions.

Stored instructions retain these names without opening their target table. CREATE checks them before the existing-table shortcut; ALTER opens its target first. Oversized identifiers have already been refused during input handling.
