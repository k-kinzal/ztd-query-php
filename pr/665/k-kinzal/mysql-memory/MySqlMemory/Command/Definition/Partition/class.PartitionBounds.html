final class PartitionBounds
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads the values that bound the partitions of a RANGE or LIST partitioned table.

A RANGE partition is bound by VALUES LESS THAN, strictly above the bound of the partition before it; MAXVALUE bounds only the last one, and NULL none. A LIST partition holds VALUES IN, which no other partition repeats. Without COLUMNS each value is an integer; with COLUMNS a value per column, stored as the column stores it (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/partitioning-range.html, https://dev.mysql.com/doc/refman/8.4/en/partitioning-list.html, https://dev.mysql.com/doc/refman/8.4/en/partitioning-columns.html.
