final class Reorganization
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Replaces a contiguous partition interval and checks its resolved range.

Definition roles are checked against the existing method before partition names. RANGE boundaries retain their total interval, with extension allowed at the last partition. SQL observations cover MySQL 5.6 through 9.1.
