Executes CREATE TABLE: declares the table in its database, with no rows, or with the rows of its query (TableQueries).

The statement commits the open transaction. CREATE TABLE IF NOT EXISTS of an existing table succeeds with a note. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
