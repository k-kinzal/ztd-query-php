public function default(
    list<object> $attributes,
    ColumnDefinition $column,
    CreateTable $create,
): Fill
source§

Answers the default of a column from its attributes.

CURRENT_TIMESTAMP and its synonyms are the time of each statement that stores the default, not of the CREATE TABLE: the default keeps the clock, typed as SQL Semantics resolved it, and evaluates it per row. An expression default, which may read the other columns of the row, is compiled with the table (TableExpressions). Source: https://dev.mysql.com/doc/refman/8.4/en/timestamp-initialization.html.
