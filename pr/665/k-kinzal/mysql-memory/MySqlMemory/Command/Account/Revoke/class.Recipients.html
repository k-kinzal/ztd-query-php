final class Recipients
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Applies a privilege REVOKE to each account occurrence, preserving diagnostic order.

Host warnings precede account processing. Each occurrence may add an error or a warning; the first error is returned after every occurrence has been checked. Dynamic privileges are processed only at the global level and only until the first error. IF EXISTS tolerates missing grants, but does not tolerate missing accounts. The latter report the target-level error in modern releases and ER_NONEXISTING_GRANT in 5.x. Modern global ALL tolerates them. Verified against fresh 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0 servers. Source: https://dev.mysql.com/doc/refman/8.4/en/revoke.html.
