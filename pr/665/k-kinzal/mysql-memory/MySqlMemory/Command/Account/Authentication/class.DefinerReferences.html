Reports stored definer references before modern account existence checks.

Each object family contributes one notice, regardless of its number of definitions. Events precede views, stored routines and triggers. Observed through CREATE USER, CREATE USER IF NOT EXISTS and DROP USER histories on MySQL 5.6, 5.7, 8.0, 8.4 and 9.1; legacy releases have no such notice.
