final class RoleCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes SET ROLE, SET DEFAULT ROLE and ALTER USER … DEFAULT ROLE.

SET ROLE makes roles granted to the account of the session active in the session: its default roles, none, all of them, all except some, or roles it names, each of which must be granted to it directly (ER_ROLE_NOT_GRANTED). SET DEFAULT ROLE commits the open transaction and sets the roles an account activates when it connects: NONE for any account, even one that does not exist; ALL for accounts that exist (ER_UNKNOWN_AUTHID, then ER_FAILED_DEFAULT_ROLES); or named roles, each granted to the account (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/set-role.html, https://dev.mysql.com/doc/refman/8.4/en/set-default-role.html.
