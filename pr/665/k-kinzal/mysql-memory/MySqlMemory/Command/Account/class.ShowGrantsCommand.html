Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes SHOW GRANTS.

The statement writes the GRANT statements of an account (see GrantText), in one text column of 4096 characters named after the account, 1024 in MySQL 5.6 and 5.7 (verified on live 5.6.51 and 5.7.44 servers). Without FOR, or FOR CURRENT_USER, it shows the account of the session with the privileges of its active roles; USING adds the privileges of roles granted to the account, and of the roles granted to them. An account that does not exist is ER_NONEXISTING_GRANT, and a role USING names that is not granted to the account is ER_ROLE_NOT_GRANTED (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/show-grants.html.
