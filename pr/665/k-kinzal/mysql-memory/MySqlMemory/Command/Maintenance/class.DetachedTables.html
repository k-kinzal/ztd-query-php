final class DetachedTables
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports maintenance of InnoDB definitions whose files were discarded.

Failed checks, analysis and repair close the cached handler. A modern failed optimization reopens it, whereas a legacy recreation leaves it closed. Legacy analysis has only the failed status; modern analysis reports each missing file during both statistics reads. Verified on 5.6.51, 5.7.44 and 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/analyze-table.html, https://github.com/mysql/mysql-server/blob/mysql-8.4.7/storage/innobase/handler/ha_innodb.cc.
