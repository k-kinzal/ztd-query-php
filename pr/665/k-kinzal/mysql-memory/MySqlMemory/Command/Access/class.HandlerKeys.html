final class HandlerKeys
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Binds handler key operands before checking whether they can supply a seek value.

Both key values and predicates see the opened table. Column reads are refused after their dependencies resolve; DEFAULT(column) and VALUES(column) are independent of the cursor row. Modern releases also refuse execution-bound session reads. Per-call functions and assignments are not excluded by that restriction. Verified against MySQL 5.7.44 and 8.4.7.
