final class XmlText
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Decodes field bytes in a client XML stream without treating them as SQL. Named entities are decoded once; numeric and unknown entities remain literal. MySQL 8 includes CDATA bytes without entity decoding; 5.6 and 5.7 ignore CDATA. Attribute spacing and fragmented text follow native LOAD XML observations. Source: https://dev.mysql.com/doc/refman/8.4/en/load-xml.html.
