final class SeparatedRecords
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Decodes client file records using the separators held by LOAD DATA. Enclosed fields can contain record delimiters; escaped delimiters are data. The file is runtime input, independent of the SQL parser and source text. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html.
