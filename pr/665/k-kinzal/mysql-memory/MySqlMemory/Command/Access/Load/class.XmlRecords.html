final class XmlRecords
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads LOAD XML records from attributes, child elements and named field elements.

Parent fields remain visible in nested records. A record with no field event repeats the last snapshot, including after an ignored row. Unclosed rows are not emitted. These stream rules also accept fragments and mismatched closing names, as observed on MySQL 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0. Source: https://dev.mysql.com/doc/refman/8.4/en/load-xml.html.
