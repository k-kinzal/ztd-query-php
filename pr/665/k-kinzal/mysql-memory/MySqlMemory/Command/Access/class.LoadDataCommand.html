final class LoadDataCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks LOAD DATA and LOAD XML against an empty server file store and client upload transport.

The server runs with --secure-file-priv=/var/lib/mysql-files/; modern releases default to disabled local loading. Enabled LOCAL DATA consumes client records. Several files and a URL need the bulk algorithm, which this server does not support, and disabled local loading is refused; these are checked while the statement is read. MySQL 8.0 and 8.1 ignore the bulk annotations and follow ordinary file loading, including table, column and secure-file checks (verified through Testcontainers). Then the table and its columns must exist, and a PARTITION clause needs a partitioned table. A file outside the secure directory is refused, and the secure directory holds no files. Every rule was verified on a live 8.4 server. An ENCLOSED BY or ESCAPED BY of more than one byte is refused next, before the table is opened (verified on live 8.0.44, 8.4.7 and 9.1.0 servers). MySQL 5.6 and 5.7 refuse it while they read the statement, before anything else. They check a local load's table and columns before requesting the client file. A wire client can refuse the request itself, sending an empty upload; this exchange preserves its own driver error and leaves the next command usable. Enabled uploads decode DATA or XML records before row writes. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html, https://dev.mysql.com/doc/refman/8.4/en/server-system-variables.html#sysvar_secure_file_priv.
