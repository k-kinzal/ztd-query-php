final class AccountTables
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Checks explicit locks on the grant tables an account operation opens internally.

Modern account changes open every grant table before checking their WRITE locks or looking up identities. Legacy operations open their required subset. Modern SHOW CREATE USER only reads mysql.user; its legacy form, SHOW GRANTS and SET ROLE use the privilege cache. Observed on native MySQL 5.6 through 9.1, including partial and complete grant-table lock lists.
