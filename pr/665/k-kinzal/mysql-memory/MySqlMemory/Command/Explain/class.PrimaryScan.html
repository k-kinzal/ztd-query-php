The clustered primary-index scan of an unrestricted single-table InnoDB UPDATE.

Changing a primary-key column requires a temporary row-identity list. Integer primary keys have fixed key lengths; other key domains and restricted scans retain the general fallback. Verified through EXPLAIN on MySQL 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/explain-output.html.
