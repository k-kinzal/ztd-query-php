Searches installed help data in topic, keyword and category precedence.

A unique topic takes precedence over keywords and categories. Keywords are used only when no topic matches. Otherwise matching categories join the topic list, or a sole category lists its direct topics and children. Verified with independently authored fixtures on native servers; no server implementation is used. Source: https://dev.mysql.com/doc/refman/8.4/en/help.html.
