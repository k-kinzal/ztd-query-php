final class ConstraintText
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Writes the foreign keys and CHECK constraints of a table as SHOW CREATE TABLE writes them.

The foreign keys come first, then the CHECK constraints, each in the order of their names. A foreign key names its referenced table with its database when that is not the database of the table, and its actions but NO ACTION; a CHECK constraint that is not enforced says so in a versioned comment (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/show-create-table.html.
