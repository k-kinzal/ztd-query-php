One column of the rows a SHOW, DESCRIBE, EXPLAIN or HELP statement answers, with the metadata the server sends for it.

A text column is held in the server's system character set, utf8mb3, or in the collation of the table it is read from, and sent in the character set of the results like any string: its length counts the bytes of its characters in that set. Every other column is sent in the binary character set with its display length. The type, flags, decimals and the names of the column, its table and its database are those the server reports for the statement (verified on a live 8.4 server).
