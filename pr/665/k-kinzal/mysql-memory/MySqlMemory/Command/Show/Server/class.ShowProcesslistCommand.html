final class ShowProcesslistCommand
    implements Command
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Executes SHOW [FULL] PROCESSLIST: the sessions connected, by connection id.

The rows are those of INFORMATION_SCHEMA.PROCESSLIST, which MySQL 8.0 and later read with a deprecation warning; the session that runs the statement is in the state init, starting in 5.6 and 5.7. Without FULL the statement of a session is cut to its first 100 characters (verified on live 5.7.44, 8.0.44 and 8.4.7 servers). Source: https://dev.mysql.com/doc/refman/8.4/en/show-processlist.html.
