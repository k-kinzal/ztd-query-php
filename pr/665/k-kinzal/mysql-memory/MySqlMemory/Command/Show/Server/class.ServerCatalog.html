final class ServerCatalog
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The storage engines, plugins, privileges, character set descriptions and collation sort lengths of the emulated server.

Versioned definitions determine engines, plugins and privileges. Character sets and collations reuse the semantic type catalog; sort lengths follow their weighting algorithms. Source: https://dev.mysql.com/doc/refman/8.4/en/storage-engines.html, https://dev.mysql.com/doc/refman/8.4/en/show-plugins.html, https://dev.mysql.com/doc/refman/8.4/en/show-privileges.html.
