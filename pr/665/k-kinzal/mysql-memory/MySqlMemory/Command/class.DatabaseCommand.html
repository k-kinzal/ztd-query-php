Executes CREATE DATABASE, DROP DATABASE and USE.

CREATE DATABASE IF NOT EXISTS of an existing database and DROP DATABASE IF EXISTS of a missing one succeed with a note; DROP DATABASE answers the number of tables it dropped. Source: https://dev.mysql.com/doc/refman/8.4/en/create-database.html.
