final class SortedDistinct
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Types the stored sort columns of DISTINCT after its access path is selected.

An ordered BIT result is stored as an integer when duplicate removal needs a temporary result. An index that covers the result, or a selected non-null unique key that makes duplicate removal unnecessary, retains the BIT field. LIMIT 0 retains the original metadata. Verified through SQL on MySQL 8.4.
