interface AccessPath
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

One step of how a query block computes its rows: what to read and what to do with the rows read.

Paths form a tree, as the access paths of the server do; Iterator\Builder turns each path into the iterator that executes it. A path produces rows of a fixed width.
