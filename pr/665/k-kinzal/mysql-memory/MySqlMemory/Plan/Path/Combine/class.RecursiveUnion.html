final class RecursiveUnion
    implements AccessPath
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Computes a recursive common table expression: its nonrecursive part, then its recursive part over the rows of the last iteration, until an iteration adds no row.

With UNION DISTINCT a row already produced is not added again. More iterations than cte_max_recursion_depth abort the query. Source: https://dev.mysql.com/doc/refman/8.4/en/with.html#common-table-expressions-recursive.
