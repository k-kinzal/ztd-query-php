final class Blocks
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Plans one query block: its FROM, WHERE, grouping, HAVING, windows, select list, DISTINCT, ORDER BY and LIMIT, in the order the server applies them.

The rows of the block's plan hold the select list followed by the sort keys that are not in it. A materialized window function reads a temporary column, so a BLOB or JSON result is flagged as a blob. The base column each output column reads is answered by {@see Origins}.
