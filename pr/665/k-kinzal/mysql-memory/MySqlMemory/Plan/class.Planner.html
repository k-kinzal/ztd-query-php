Plans the queries of a bound statement into access paths: the step of the server that builds the access path tree.

The emulator does not optimize: tables are scanned, joins are nested loops, and grouping, ordering and duplicate removal read their whole input.

public function settled(QueryPlan $operand, list<Domain> $domains): AccessPath
source§

Answers the rows of an operand of a set operation as the temporary table of the operation holds them: each value converted into the type of its column.

A decimal is rescaled even when its resolved type matches: variable reads can retain fewer fractional digits at runtime. Other values whose types match are kept; another is converted into the resolved field, so an integer gains the scale of a decimal column, a date the time of a datetime one, an unsigned integer its digits in a string or decimal one, and a string the character set of its column. Numeric storage saturates instead of applying an explicit CAST's wraparound or overflow diagnostic (verified on live 5.6, 5.7 and 8.4 servers).
