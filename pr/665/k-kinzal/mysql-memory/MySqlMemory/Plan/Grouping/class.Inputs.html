Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Captures aggregate arguments before grouping the input of a window.

With varying grouping keys, windows require stored aggregate inputs. Each argument executes in input order once and every grouping level reads its copy. Constant grouping keys retain the direct per-level argument evaluation. Verified through SQL values and variable effects on MySQL 8.4.
