Plans constant checks and row input for COUNT DISTINCT and GROUP_CONCAT.

Materialized window input has already executed all its fields. Direct grouping evaluates complete tuples; modern implicit aggregation defers table-independent fields. Legacy releases read variable assignments for every tuple.
