final class AggregateOutputs
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Describes grouped aggregate outputs from their resolved types and physical grouping.

Temporary grouping fields differ from streaming expressions. MIN and MAX copy their bound input's missing-default flag; computed parents remain expressions. AVG and variance finalize their grouped state as expressions unless a later stage stores the result. Observed on native MySQL 5.7 and 8.4.
