final class ParentInputs
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Preserves user-variable inputs around buffered windows and sorted output assignments.

A variable read outside aggregate or window arguments is captured before window parents assign their results. Ungrouped outputs independent of windows capture their reads as each row arrives, before its window parents execute. Sorted assignments publish stored values as result rows are emitted, including after LIMIT. Verified through SQL and PDO observations on MySQL 8.0 and 9.1.
