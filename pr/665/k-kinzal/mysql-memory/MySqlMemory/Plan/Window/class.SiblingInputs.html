final class SiblingInputs
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Stores ordinary select expressions alongside the input of a buffered window.

Window arguments and parent reads are captured before ordinary assignments. Grouped rows retain those inputs before window output begins; ROLLUP keeps the previous group's copies. Ordinary bare assignments restore their stored input value as the window consumes each grouped row. MySQL 8.0 also publishes their copied value when a result row is emitted. Later releases read the stored output without that additional assignment. Verified through PDO values, result metadata and subsequent variable reads on MySQL 8.0, 8.4 and 9.1.
