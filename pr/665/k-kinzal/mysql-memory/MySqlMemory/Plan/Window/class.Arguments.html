Separates arguments stored once per input row from expressions read by a window. Assignments and other changing expressions are materialized at the input frontier. MySQL 8.0 subsequently reads a bare assignment through its current input field; 8.4 and 9.1 read its stored value. Verified by assignments inside moving frames.
