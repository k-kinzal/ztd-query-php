final class Collected
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Collects window dependencies while preparing a selection that will refuse a later operand.

Arguments and a directly named window bind at the call. Inline specifications, options and frames follow all ordinary clauses. No rows are evaluated before that preparation completes; the retained refusal prevents this partial plan from executing.
