final class DistinctStorage
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Resolves DISTINCT fields outside windows and publishes their copied assignments.

An unsorted bounded result can emit duplicate-free rows as they arrive. Full results, sorting and SQL_CALC_FOUND_ROWS read stored assignment fields after input effects finish. Constant expressions retain expression metadata. Legacy bounded unsorted queries probe one input row when their expressions do not depend on table columns. Verified through SQL and PDO on MySQL 5.6, 5.7, 8.0, 8.4 and 9.1.

Orders stored grouped duplicate keys before an independent output sort.

Modern numeric DISTINCT results use ordered duplicate storage after grouping, except when the group keys already make them unique. Ordered GROUP_CONCAT results compare their stored strings too; computed string parents, rollup rows and windows keep their own storage order. Verified through SQL on MySQL 8.4.
