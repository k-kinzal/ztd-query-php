Resolves sorting expressions to output fields or additional projected keys.

An alias identifies its block and output position even when ROLLUP has rebuilt the field's type and nullability facts. Reading that position preserves a single evaluation of the selected expression. Verified through PDO on MySQL 8.0, 8.4 and 9.1.
