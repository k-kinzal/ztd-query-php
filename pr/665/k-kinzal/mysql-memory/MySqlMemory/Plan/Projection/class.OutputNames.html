public function name(Field $field, Select|null $select = null): string

Answers the name of an output column.

An item without alias that names a column of a view is named as the view names the column, in any case the statement writes it; so is a column of a view of INFORMATION_SCHEMA of MySQL 8.0 and later (verified on live 5.7.44, 8.0.44 and 8.4.7 servers).
