final class Emission
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Evaluates direct select expressions when their rows pass sorting and bounds.

Sorting ordinary input keys does not evaluate the whole select list. A sorting expression with per-read state requires its projected values first. An implicit aggregate supplies at most one row, so its ORDER BY needs no key evaluation. Verified through SQL and PDO on MySQL 8.0, 8.4 and 9.1.
