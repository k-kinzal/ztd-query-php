final class JoinComparisons
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Retains the hash-key comparison of unindexed string joins in MySQL 8.0 and later.

Rows still execute as nested loops. Hash equality matters independently of performance: under legacy UCA, a space before a trailing ignorable character has a different hash key but compares equal. Unicode 4.0 and 5.2 keys with maximum weight capacity above 1024 bytes use this hash; shorter keys retain their padded weights. Indexed and constant lookups use the comparison directly. Verified through SQL on MySQL 8.0.44 and 9.1.0.
