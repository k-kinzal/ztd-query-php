final class Statements
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The prepared statements of a connection: COM_STMT_PREPARE, COM_STMT_EXECUTE and the commands around them.

A statement is prepared by parsing and resolving it; it is executed with the values bound to its parameter markers, and its rows are sent in the binary protocol. Source: https://dev.mysql.com/doc/dev/mysql-server/latest/page_protocol_command_phase_ps.html.
