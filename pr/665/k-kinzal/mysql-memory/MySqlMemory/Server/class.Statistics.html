final class Statistics
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The COM_STATISTICS text returned by mysqli::stat() and PDO's server-info attribute.

Its Threads field includes the event scheduler daemon, unlike Threads_connected. Its Questions field reads global Queries, including this packet and stored program work. The session Questions counter does not count this request. Uptime observes SET timestamp and the average truncates to three decimal places. Diagnostics and ROW_COUNT remain unchanged. Verified through the public wire interface on 8.0, 8.4 and 9.1. Storage counters retain the same limitations as SHOW STATUS. Source: https://dev.mysql.com/doc/c-api/8.4/en/mysql-stat.html.
