final class Server
Public API: explicitly declared with @visibility public.

A server process clients connect to with PDO or mysqli, as to a MySQL server.

start() runs bin/mysql-memory in a child process that listens on a free local port and holds the databases in its memory; dsn() names it for PDO. The process ends with stop(), or when this object is destroyed.
