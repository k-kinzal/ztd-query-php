Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reports the in-memory transaction system in the InnoDB monitor's sections. Physical files, background workers, buffer pools and redo buffers have zero activity. Transaction sequence, retained history and read views come from the actual instance. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-standard-monitor.html.
