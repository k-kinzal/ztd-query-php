EngineMetrics @visibility MySqlMemoryThe release-specific Performance Schema storage metrics, with no native instrumentation buffers allocated. Names come from pfs_show_status in each release's storage/perfschema/ha_perfschema.cc (pfs_engine_table.cc in 5.6/5.7). These are interface definitions, not captured server state. Counts, byte sizes and memory totals are zero because this implementation materializes its Performance Schema tables on demand rather than allocating the native engine's buffers. Source: https://dev.mysql.com/doc/refman/8.4/en/show-engine.html.
GlobalStatus @visibility MySqlMemoryThe rows of performance_schema.global_status, and of INFORMATION_SCHEMA.GLOBAL_STATUS in MySQL 5.6: the global value of each status variable, as SHOW GLOBAL STATUS lists them.
GlobalVariables @visibility MySqlMemoryThe rows of performance_schema.global_variables, and of INFORMATION_SCHEMA.GLOBAL_VARIABLES in MySQL 5.6: the global value of each system variable, as SHOW GLOBAL VARIABLES lists them.
InnoDbMonitor @visibility MySqlMemoryReports the in-memory transaction system in the InnoDB monitor's sections. Physical files, background workers, buffer pools and redo buffers have zero activity. Transaction sequence, retained history and read views come from the actual instance. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-standard-monitor.html.
PersistedVariables @visibility MySqlMemoryThe settings saved by SET PERSIST and PERSIST_ONLY on this instance.
ReplicationConfiguration @visibility MySqlMemoryConfigured replication connections, including updates retained by a failing CHANGE.
SessionStatus @visibility MySqlMemoryThe rows of performance_schema.session_status, and of INFORMATION_SCHEMA.SESSION_STATUS in MySQL 5.6: the session value of each status variable, as SHOW SESSION STATUS lists them.
SessionVariables @visibility MySqlMemoryThe rows of performance_schema.session_variables, and of INFORMATION_SCHEMA.SESSION_VARIABLES in MySQL 5.6: the session value of each system variable, as SHOW SESSION VARIABLES lists them.
StatusByThread @visibility MySqlMemoryThe rows of performance_schema.status_by_thread: the session value of each status variable that has one, for each session connected.
StatusDefinitions @visibility MySqlMemoryStatus-variable declarations grouped by scope, initial value, visibility and supported releases. Runtime counters are computed by StatusVariables; these definitions contain no captured counters. Source: https://dev.mysql.com/doc/refman/8.4/en/server-status-variables.html.
StatusOrder @visibility MySqlMemoryThe server registration order of SHOW STATUS names that do not follow alphabetical order.
StatusVariables @visibility MySqlMemoryThe status variables of a release, defined by their release, with the values the emulated server shows.
UserVariablesByThread @visibility MySqlMemoryUser variables belonging to each connected session, preserving their first name spelling and binary values.
Variables @visibility MySqlMemoryThe rows the variables and status tables of the Performance Schema share: a name and a value, as SHOW VARIABLES and SHOW STATUS list them.
VariablesByThread @visibility MySqlMemoryThe rows of performance_schema.variables_by_thread: the session value of each system variable that has one, for each session connected.
