final class EngineMetrics
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The release-specific Performance Schema storage metrics, with no native instrumentation buffers allocated. Names come from pfs_show_status in each release's storage/perfschema/ha_perfschema.cc (pfs_engine_table.cc in 5.6/5.7). These are interface definitions, not captured server state. Counts, byte sizes and memory totals are zero because this implementation materializes its Performance Schema tables on demand rather than allocating the native engine's buffers. Source: https://dev.mysql.com/doc/refman/8.4/en/show-engine.html.
