The rows of INFORMATION_SCHEMA.SCHEMATA: one for each database, with its default character set and collation.

MySQL 8.4 and 9.1 list the databases by name, 8.0 in the order they were created, the system databases first; 5.6 and 5.7 list INFORMATION_SCHEMA first, then the others by name (verified on live 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0 servers). No database has an SQL path, and none is encrypted by default. Source: https://dev.mysql.com/doc/refman/8.4/en/information-schema-schemata-table.html.
