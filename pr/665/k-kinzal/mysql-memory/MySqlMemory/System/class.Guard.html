Refuses the statements that would create, change or lock a table of the system databases.

INFORMATION_SCHEMA holds views the server computes: creating, changing, dropping or locking a table in it, or writing one, is denied for the database (ER_DBACCESS_DENIED_ERROR). The other system schemas require command- and table-specific mutation semantics. An unimplemented mutation fails internally instead of inventing a privilege denial or an ER_NOT_SUPPORTED_YET result that could match the native server by accident. Source: https://dev.mysql.com/doc/refman/8.4/en/information-schema-introduction.html, https://dev.mysql.com/doc/refman/8.4/en/performance-schema-table-characteristics.html.
