The rows of mysql.tables_priv: one for each table an account holds privileges on, by host, database, user and table.

Table_priv lists the privileges on the table, GRANT for GRANT OPTION; Column_priv those held on any of its columns. Source: https://dev.mysql.com/doc/refman/8.4/en/grant-tables.html.
