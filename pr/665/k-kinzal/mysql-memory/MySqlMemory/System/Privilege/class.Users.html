Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

The rows of mysql.user: one for each account and role, by host and user, with its global privileges, TLS requirements, limits, authentication and password policy.

A role is an account created locked with an expired password. The user attributes hold the metadata ATTRIBUTE and COMMENT set and the failed-login tracking, under metadata and Password_locking. The emulator does not record when a password changed, which it reports as the time the server started. MySQL 5.6 keeps the string of a mysql_native_password account in its Password column, and its authentication_string empty (verified on a live 5.6.51 server). Source: https://dev.mysql.com/doc/refman/8.4/en/grant-tables.html.
