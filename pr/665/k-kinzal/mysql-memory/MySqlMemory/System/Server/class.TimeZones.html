The rows of mysql.time_zone and mysql.time_zone_name: the named time zones the server knows, numbered as mysql_tzinfo_to_sql numbers them.

The zones are those of the tz database PHP carries, each also under posix/ and, counting leap seconds, under right/, and posixrules. They are numbered in the order of their names as the zoneinfo directory lists them: the zones, then posix/, posixrules and right/ (verified on a live 8.4.7 server, whose tables were loaded from the same tz database); mysql.time_zone_name lists them by name, in its case-insensitive collation. The emulator keeps no transition table: the rules of a zone come from PHP. Source: https://dev.mysql.com/doc/refman/8.4/en/time-zone-support.html.
