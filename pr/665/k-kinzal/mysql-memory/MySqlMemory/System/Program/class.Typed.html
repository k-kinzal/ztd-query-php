The type of a parameter or of the value a stored function returns, as ROUTINES and PARAMETERS list it.

The type is described as INFORMATION_SCHEMA.COLUMNS describes the type of a column: its name, lengths, precision and scale, fractional digits, character set and collation, and the type written in full as DTD_IDENTIFIER. A string declared without a character set has that of the database of the routine. Source: https://dev.mysql.com/doc/refman/8.4/en/information-schema-parameters-table.html.
