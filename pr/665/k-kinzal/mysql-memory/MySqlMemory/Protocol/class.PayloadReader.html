final class PayloadReader
Restricted visibility: declared "@visibility MySqlMemory". Code outside that scope must not name this declaration.

Reads the fields of one packet payload of the MySQL client/server protocol from the start.

Integers are little-endian; a length-encoded integer starts with one byte below 0xFB, or with 0xFC, 0xFD or 0xFE followed by two, three or eight bytes. Reading past the end raises MalformedPacket. Source: https://dev.mysql.com/doc/dev/mysql-server/latest/page_protocol_basic_data_types.html.
