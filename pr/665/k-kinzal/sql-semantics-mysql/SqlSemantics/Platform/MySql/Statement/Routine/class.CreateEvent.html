CREATE EVENT: a statement the event scheduler runs once or repeatedly.

The statement is structured as a request: it declares nothing to a context. The facts follow MYSQL-EVENT-001. Source: https://dev.mysql.com/doc/refman/8.4/en/create-event.html.
