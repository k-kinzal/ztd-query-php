final class NonGroupedColumn
    implements Diagnostic
    uses Snapshot
Public API: explicitly declared with @visibility public.

A column a grouped or DISTINCT query reads that its groups do not determine, a problem under the sql_mode ONLY_FULL_GROUP_BY.

The server refuses the query only when the session runs with ONLY_FULL_GROUP_BY, the default mode; without it the query reads the column of an arbitrary row of each group. The column is named database.table.column after the name the query reads the table by.
