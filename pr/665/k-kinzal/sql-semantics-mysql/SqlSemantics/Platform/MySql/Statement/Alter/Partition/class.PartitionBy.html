PARTITION BY … in ALTER TABLE: a request to partition or repartition the table.

Mirrors PT_alter_table_partition_by. The partitioning is derived in the scope of the changed table (MYSQL-PARTITIONING-001). Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table-partition-operations.html.
