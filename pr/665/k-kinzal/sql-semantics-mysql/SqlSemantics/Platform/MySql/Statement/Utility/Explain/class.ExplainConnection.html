EXPLAIN FOR CONNECTION: the plan of the statement another connection is running (MySQL 5.7 and later).

Rule: MYSQL-EXPLAIN-CONNECTION-001. The connection is a thread number as SHOW PROCESSLIST reports it; the statement it runs is not part of the request. The options and the rows of the report follow MYSQL-EXPLAIN-ROWS-001. Terminates: no nested statement. Source: https://dev.mysql.com/doc/refman/8.4/en/explain-for-connection.html. Status: Implemented.
