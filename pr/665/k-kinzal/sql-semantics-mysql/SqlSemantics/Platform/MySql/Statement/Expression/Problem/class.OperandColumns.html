final class OperandColumns

    uses Snapshot
Public API: explicitly declared with @visibility public.

An operand with a number of columns its position does not take (ER_OPERAND_COLUMNS, error 1241).

A single value is one column; a row constructor or a subquery of several columns is a row. The server rejects a row where a single value is required and rows of different widths in one comparison. Source: https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html, https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html#error_er_operand_columns.
