final class DeferredCast
    implements DeferredOperand
    uses ScalarSemantics, Occurrence
Public API: explicitly declared with @visibility public.

A stored cast around an expression whose preparation is deferred until invocation.

The target, request form and ARRAY clause retain their semantic roles. Definition-time cast conditions are derived even in unreachable branches. This value never implements Scalar.
