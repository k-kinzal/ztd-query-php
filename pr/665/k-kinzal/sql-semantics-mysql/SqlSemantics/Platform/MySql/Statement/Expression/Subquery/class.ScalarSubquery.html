A subquery used as a value: (SELECT …), a scalar or row subquery (Item_singlerow_subselect).

The subquery sees the enclosing positions as its outer scope.

Rule: MYSQL-SCALAR-SUBQUERY-001. Facts: MYSQL-SUBQUERY-ROWS-001; a a one-column subquery has that column's type and is NULL when no row is returned. Explicit multi-column output uses RowSubquery instead. Wildcard output remains a declaration-dependent width constraint. A tableless, unfiltered row subquery retains its columns' combined NULL attribute, subject to the release's LIMIT rule. MySQL 5.6 instead reports a nonnullable attribute for tableless unfiltered rows and tableless UNION rows, independently of NULL values in their columns. A reducible one-expression query instead publishes that bound expression as its replacement and retains its type and NULL attribute (MYSQL-SCALAR-REDUCTION-001). Terminates: the query is a strict part. Source: https://dev.mysql.com/doc/refman/8.4/en/scalar-subqueries.html, https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html. Status: Implemented.
