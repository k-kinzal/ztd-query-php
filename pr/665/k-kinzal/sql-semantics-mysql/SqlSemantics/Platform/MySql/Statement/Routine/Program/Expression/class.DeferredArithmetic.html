final class DeferredArithmetic
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored arithmetic operation containing a row-valued scalar use.

The instruction is a valid stored definition even though reaching this computation raises an operand-width condition after binding its dependencies. Scalar-only arithmetic uses Arithmetic; this class never implements Scalar.
