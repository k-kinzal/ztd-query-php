final class Text
    implements Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

A string at a position that is not an expression: a comment, a file name, a password, a separator, a member of an ENUM.

It is written as a quoted string or, where the grammar allows it, as a hexadecimal or bit literal that stands for a string. The value is the decoded bytes of a quoted string, or the digits of the other two forms. It is an operand of the statement that holds it and has no type fact of its own. Source: https://dev.mysql.com/doc/refman/8.4/en/string-literals.html, https://dev.mysql.com/doc/refman/8.4/en/hexadecimal-literals.html.
