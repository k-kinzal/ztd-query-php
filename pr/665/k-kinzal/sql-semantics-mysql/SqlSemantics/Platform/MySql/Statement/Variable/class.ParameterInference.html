final class ParameterInference
Public API: explicitly declared with @visibility public.

The initial marker domains of a prepared statement, derived from semantic facts.

Arithmetic and comparison markers inherit their sibling's domain, widening integers to BIGINT. CASE and control-function result branches supply the other branch types. Arithmetic against NULL needs DOUBLE. CAST records that its argument is fixed against automatic repreparation. Other positions retain their supplied preparation domain. Consumers retain these domains between executions and supply them as parameter settings when resolving again.

This rule inspects neither source text nor parser nodes. Source: https://dev.mysql.com/doc/refman/8.4/en/prepare.html.
