final class DeferredGrantAs
    implements ProgramStatement, PrivilegeChange
    uses Snapshot
Public API: explicitly declared with @visibility public.

A program-only GRANT whose non-global AS condition is raised when reached.

MySQL accepts the definition, permits an unreachable instruction, and raises error 3835 on invocation before resolving the accounts or target objects. The grant operands and AS clause are retained as values; no input SQL is kept. Observed through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0.
