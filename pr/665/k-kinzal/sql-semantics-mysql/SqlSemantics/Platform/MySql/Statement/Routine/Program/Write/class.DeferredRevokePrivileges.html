final class DeferredRevokePrivileges
    implements ProgramStatement, PrivilegeChange
    uses Snapshot
Public API: explicitly declared with @visibility public.

A complete stored REVOKE whose routine target has a wildcard level.

The definition retains every privilege and recipient without binding them. Invocation resolves the current database and account spelling before the target condition. Global ALL uses this role only in legacy MySQL; modern SQL instead gives it an ordinary global-revocation interpretation.
