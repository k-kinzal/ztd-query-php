final class RoutineColumnPrivilege
    implements Diagnostic
    uses Snapshot
Public API: explicitly declared with @visibility public.

A completed GRANT applies a column privilege to a routine kind.

Modern servers refuse this when the grant is read, including inside routines. Legacy servers first refuse a routine kind without an object privilege level. The position identifies the completed operand, not retained input text.
