Public API: explicitly declared with @visibility public.

The privilege, target and account operands shared by immediate and stored GRANT.

A request is not a standalone statement. Its scope may instead describe a stored instruction whose condition is raised only when control reaches it. The statement and program-member constructors enforce those distinct roles.
