enum BinlogOption: string
Public API: explicitly declared with @visibility public.

The two written forms that suppress binary logging of a maintenance request.

Absence is represented by null on the owning statement. Both alternatives suppress logging while retaining the keyword requested by the caller. Source: https://dev.mysql.com/doc/refman/8.4/en/analyze-table.html, https://dev.mysql.com/doc/refman/8.4/en/flush.html.
