CONVERT TO CHARACTER SET name | DEFAULT [COLLATE name]: a request to convert every character column and the table default.

Mirrors PT_alter_table_convert_to_charset. DEFAULT means the character set selected by the session variable character_set_database. CHARACTER SET and CHARSET are synonyms; CHARACTER SET is written. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html#alter-table-character-set.
