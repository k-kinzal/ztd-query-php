GRANT role, … TO account, … [WITH ADMIN OPTION] (8.0+): a request to grant roles.

The nonempty role list accepts only GrantedRole operands. Static and column privileges are refused by input lowering before publication. Anonymous account operands and explicit self-grants remain in the request with a typed intrinsic condition. CURRENT_USER remains a session-dependent reference. Source: https://dev.mysql.com/doc/refman/8.4/en/grant.html#grant-roles. Status: Implemented.
