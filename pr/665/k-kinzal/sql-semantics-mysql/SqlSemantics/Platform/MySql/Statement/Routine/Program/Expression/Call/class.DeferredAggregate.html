final class DeferredAggregate
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

An aggregate invocation retaining a non-scalar argument until preparation.

No ordinary aggregate or fabricated scalar is needed to retain this call. All arguments, quantifiers and the optional window keep their semantic roles.
