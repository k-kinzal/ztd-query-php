final class DeferredWeightString
    implements DeferredOperand
    uses ScalarSemantics, Occurrence
Public API: explicitly declared with @visibility public.

A WEIGHT_STRING template retaining a non-scalar subject and every typed option.

An unused definition or unexecuted stored instruction keeps its dependencies. The subject remains outside Scalar; a reached use must prepare its operands. No reconstructed SQL, parser node or substitute scalar is retained.
