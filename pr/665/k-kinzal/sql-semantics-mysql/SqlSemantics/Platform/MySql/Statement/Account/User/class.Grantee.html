final class Grantee
    implements Node

Public API: explicitly declared with @visibility public.

An account receiving a grant, with the optional authentication of legacy GRANT.

GRANT cannot hold ALTER USER password management, additional factors or USER(). Keeping this operand separate makes those fields unavailable in a grant structure. An existing UserSpecification can be converted only when it satisfies the same invariant. Source: https://dev.mysql.com/doc/refman/5.7/en/grant.html.
