enum NoticePhase: string
Public API: explicitly declared with @visibility public.

The stage of interpreting an input at which an ordered condition is raised.

A debug parse-tree inspection reads grammar operands but does not contextualize the inspected statement. Resolution notices belong to their semantic operands; earlier relation or column failures can prevent those operands from resolving. This records the origin of a diagnostic, not whether a statement can execute. Observed with SHOW PARSE_TREE on MySQL 8.4.7 and 9.1.0.
