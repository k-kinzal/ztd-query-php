final class ArrayPart
    implements KeyPart, Operand
    uses ScalarSemantics, Occurrence
Public API: explicitly declared with @visibility public.

A multi-valued index part: one JSON document expression and its element type.

This value is an index part, not a scalar expression. Each converted array element contributes an index entry for the same stored row. The operand is resolved against the indexed table, while the element target belongs to the key definition. Written ordering is retained for definition diagnostics, including declarations whose IF NOT EXISTS branch leaves a table intact. Source: https://dev.mysql.com/doc/refman/8.4/en/create-index.html#create-index-multi-valued.
