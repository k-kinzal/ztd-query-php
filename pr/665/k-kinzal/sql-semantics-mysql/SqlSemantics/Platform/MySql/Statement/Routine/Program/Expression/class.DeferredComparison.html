final class DeferredComparison
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A comparison containing a computation whose scalar use is deferred until invocation.

The instruction is a valid stored definition even though reaching this computation raises an operand-width condition after binding its dependencies. Ordinary scalar and compatible-row comparisons use Comparison.
