ADD [COLUMN] (element, …): a request to add several columns, and in 8.0 also keys and constraints, at the end of the table.

Mirrors PT_alter_table_add_columns. The expressions of the elements are derived in the scope of the changed table. The word COLUMN is optional and always written. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html#alter-table-add-drop-column.
