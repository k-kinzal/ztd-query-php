The identifier of an XA transaction: gtrid [, bqual [, formatID]].

Mirrors XID. The global transaction identifier and the branch qualifier are strings of at most 64 bytes each, written as quoted strings or as hexadecimal or bit literals; the format identifier is an unsigned number and defaults to 1. A longer part is a syntax error of the server and cannot be constructed; a format identifier above 2^63-1 is a syntax error from MySQL 5.7 on and is refused when a statement holding it is derived for such a release (MYSQL-SERVER-MAGNITUDE-001). Source: https://dev.mysql.com/doc/refman/8.4/en/xa-statements.html.
