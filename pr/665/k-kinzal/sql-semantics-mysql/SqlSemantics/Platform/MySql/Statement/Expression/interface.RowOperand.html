interface RowOperand
    extends Operand
Public API: explicitly declared with @visibility public.

A row-valued operand with its own role, separate from Scalar.

Ordinary scalar positions do not accept this interface. A comparison or a membership predicate explicitly admits it alongside scalar expressions. Stored program conditions, initializers, CASE operands and return values can retain a row; their scalar-use condition is checked when the instruction is reached. Source: https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html.
