final class DeferredInsertSet
    implements ProgramStatement
    uses Occurrence
Public API: explicitly declared with @visibility public.

A stored INSERT or REPLACE SET retaining a non-scalar assignment and its context.

Every target, assignment and duplicate-key operand remains available when the instruction is reached. This template is neither an ordinary Statement nor a replacement VALUES statement.
