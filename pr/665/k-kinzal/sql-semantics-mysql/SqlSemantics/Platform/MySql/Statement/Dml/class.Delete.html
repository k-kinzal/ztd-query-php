DELETE from one table, with WHERE, ORDER BY and LIMIT.

The facts follow MYSQL-DELETE-001. The hints of the comment written right after DELETE are kept with the statement. Source: https://dev.mysql.com/doc/refman/8.4/en/delete.html.
