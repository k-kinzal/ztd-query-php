SHOW EVENTS: the scheduled events of a database.

Rule: MYSQL-SHOW-EVENTS-001. The columns are those of the layout of MYSQL-SHOW-ROWS-001 for the release; the database written after FROM or IN only selects the rows. The rows and the WHERE condition are derived by MYSQL-SHOW-FACTS-001. Terminates: a fixed layout. Source: https://dev.mysql.com/doc/refman/8.4/en/show-events.html. Status: Implemented.
