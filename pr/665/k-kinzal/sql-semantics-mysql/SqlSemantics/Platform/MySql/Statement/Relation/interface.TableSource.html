interface TableSource
    extends Relation
Public API: explicitly declared with @visibility public.

A MySQL table reference or composition of table references used as query input.

Other relations, such as SHOW result columns, a trigger row or a routine's parameters, have relation facts but are not table-reference operands. The special FROM DUAL form is accepted separately by SELECT.
