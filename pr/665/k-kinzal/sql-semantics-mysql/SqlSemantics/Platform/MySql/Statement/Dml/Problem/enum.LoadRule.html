enum LoadRule: string
Public API: explicitly declared with @visibility public.

Mutually incompatible LOAD options, independent of files and target tables.

The order of these refusals is observed on native MySQL 8.4.7 and 9.1.0. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html.
