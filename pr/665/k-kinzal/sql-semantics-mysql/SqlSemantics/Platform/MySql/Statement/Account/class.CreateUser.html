CREATE USER [IF NOT EXISTS] account [auth], … [DEFAULT ROLE …] [REQUIRE …] [WITH limits] [options] [ATTRIBUTE|COMMENT '…']: a request to create accounts.

Mirrors SQLCOM_CREATE_USER (LEX users_list, default_roles, ssl_type, mqh, alter_password, alter_user_attribute). Rule: MYSQL-CREATE-USER-001. The accounts, their authentication methods and every clause are kept in source order; passwords keep their exact values. The problems of the clauses are reported by MYSQL-ACCOUNT-CHECKS-001. An account is not a relation: the statement provides no declaration. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html. Status: Implemented.
