Public API: explicitly declared with @visibility public.

ALGORITHM [=] DEFAULT | name: the algorithm the server must use for a table change.

The grammar reads the algorithm as an identifier; the server accepts INPLACE and COPY, INSTANT from 8.0 on, and the word DEFAULT spelled as an identifier in 5.6 and 5.7, compared without regard to case. Any other name is the diagnostic UnknownAlterChoice (MYSQL-ALTER-CHOICES-001). The name is kept as written; the keyword DEFAULT is the absent name. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html#alter-table-performance.
