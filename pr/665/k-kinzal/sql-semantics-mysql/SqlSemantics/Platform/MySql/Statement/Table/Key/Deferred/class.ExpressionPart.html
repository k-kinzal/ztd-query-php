final class ExpressionPart
    implements KeyPart
    uses Snapshot
Public API: explicitly declared with @visibility public.

An index definition retaining an operand that cannot be an ordinary functional key.

Target lookup and index constraints precede operand preparation. In particular, CREATE TABLE IF NOT EXISTS can leave this definition unused. The operand stays distinct from an ordinary functional key. Subqueries, variables, parameter markers, nondeterministic calls and grouped expressions need this role, as does a bare column reference, which belongs in a column key. No source SQL or parser node is retained.
