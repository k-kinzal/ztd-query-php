[DEFAULT] ENCRYPTION [=] {'Y' | 'N'}: the default encryption of the database's tables (MySQL 8.0.16 and later).

DEFAULT before the option and the optional equals sign are retained. The value is a two-case setting. A noncanonical decoded operand may be retained for rendering; construction checks that it denotes exactly the same setting. It is a literal value, without input SQL or parser nodes. Source: https://dev.mysql.com/doc/refman/8.4/en/create-database.html.
