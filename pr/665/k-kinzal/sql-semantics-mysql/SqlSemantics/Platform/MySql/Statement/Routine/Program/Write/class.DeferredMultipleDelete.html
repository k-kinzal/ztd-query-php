final class DeferredMultipleDelete
    implements ProgramStatement
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored deletion retaining an intrinsically read-only target and all its dependencies.

An unvisited instruction opens no tables. Reaching it resolves its input before reporting the target role; the ordinary MultipleDelete type excludes this role.
