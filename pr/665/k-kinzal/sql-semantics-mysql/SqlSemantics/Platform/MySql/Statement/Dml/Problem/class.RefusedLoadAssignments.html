final class RefusedLoadAssignments
    implements Diagnostic, Node
    uses Snapshot
Public API: explicitly declared with @visibility public.

A complete LOAD request with an intrinsic input or SET assignment constraint.

This diagnostic retains input and assignment roles without publishing an ordinary statement. Database and file-entry conditions can precede the intrinsic assignment constraint. It retains no SQL text or parser tree.
