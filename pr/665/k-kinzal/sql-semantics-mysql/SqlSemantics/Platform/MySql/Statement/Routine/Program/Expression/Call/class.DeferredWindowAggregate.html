final class DeferredWindowAggregate
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A retained aggregate invocation with a fixed modifier or window constraint.

The arguments, modifiers and sole OVER clause are retained directly. This value is not a Scalar and does not assign aggregate ownership to its enclosing query while deriving a deferred preparation condition.
