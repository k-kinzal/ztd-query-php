INSERT or REPLACE of rows written in a VALUES clause, with the optional row alias and ON DUPLICATE KEY UPDATE.

Rule: MYSQL-INSERT-ROWS-001. The facts follow MYSQL-INSERT-001 with the rows of VALUES as the source; VALUE is a synonym of VALUES. Source: https://dev.mysql.com/doc/refman/8.4/en/insert.html. Status: Implemented.
