final class ParseFailure
    implements Warning
    uses Snapshot
Public API: explicitly declared with @visibility public.

The ordered place of a problem found while reading or contextualizing a statement.

Rule: MYSQL-PARSE-FAILURE-001. The server looks up the collation of COLLATE and refuses CAST ... AT LOCAL when it parses the construct: it records the error and parses on, so the warnings of the constructs it parses after it follow the error, and every such error of the statement is recorded. A cast to an array of a type no multi-valued index takes, and a cast to TIME or DATETIME with a precision above 6, stop the parse in 8.4 and 9.1: no construct after it raises a warning. In 8.0 those cast errors are recorded and parsing continues. Role-list input errors continue even beyond the enclosing stored-program statement; the endsProgramStatement flag distinguishes that continuation. The problem is reported as a diagnostic too; this notice keeps its order among the warnings. Terminates: no recursion. Source: https://dev.mysql.com/doc/refman/8.4/en/show-warnings.html. Status: Implemented.
