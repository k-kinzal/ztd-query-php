CREATE SERVER name FOREIGN DATA WRAPPER wrapper OPTIONS (option, …): a request to define a server for the FEDERATED engine.

Mirrors SQLCOM_CREATE_SERVER with Server_options. Rule: MYSQL-CREATE-SERVER-001. The name and the wrapper are written as identifiers or strings; the server compares server names case-insensitively. The options are kept in written order. The statement declares no relation. Source: https://dev.mysql.com/doc/refman/8.4/en/create-server.html. Status: Implemented.
