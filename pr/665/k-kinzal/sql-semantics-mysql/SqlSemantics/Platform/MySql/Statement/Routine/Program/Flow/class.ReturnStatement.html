RETURN: ends a stored function and returns the value of an expression.

The facts follow MYSQL-PROGRAM-FLOW-001. Source: https://dev.mysql.com/doc/refman/8.4/en/return.html.

A stored row operand is retained until this instruction is reached. It cannot supply a scalar result, but an unreachable instruction does not evaluate it.
