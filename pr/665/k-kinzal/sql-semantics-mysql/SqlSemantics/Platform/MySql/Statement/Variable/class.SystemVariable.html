Public API: explicitly declared with @visibility public.

A system variable read as a value: @@name, @@GLOBAL.name, @@instance.name.

A structured variable is written with the name of its instance or component before the variable name; DEFAULT.name names the instance default. Without a scope the session value is read when the variable has one and the global value otherwise.

Rule: MYSQL-SYSTEM-VARIABLE-001. Facts: the type and the NULL fact are those of the variable in the running server, which no context holds; the fact names the variable as missing session state; a parameter of a named key cache has the type of the variable of the default key cache, as every parameter is an integer. Diagnostics: a variable read with an instance name that is neither a key cache variable nor a variable the release knows by that full name is unknown, named with its instance (verified on a live 8.4 server); MySQL 5.6 and 5.7 read the name after the instance as the variable, unknown by that name or, when they know it, not structured (verified on live 5.6.51 and 5.7.44 servers). Source: https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html, https://dev.mysql.com/doc/refman/8.4/en/structured-system-variables.html. Status: Implemented.
