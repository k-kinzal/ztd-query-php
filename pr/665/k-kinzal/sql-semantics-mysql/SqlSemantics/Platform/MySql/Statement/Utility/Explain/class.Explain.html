EXPLAIN (DESCRIBE, DESC) with a statement: the execution plan of a SELECT, TABLE, VALUES, INSERT, REPLACE, UPDATE or DELETE.

Rule: MYSQL-EXPLAIN-001. The explained statement is inspected, not run: every part of it is derived as usual, so its name resolutions and diagnostics are facts of the operation, but the rows it would return are discarded. FOR DATABASE (8.2 and later) explains it as if that database were the current one: it is derived with that database searched for unqualified names. ANALYZE (8.0.18 and later) runs the statement and reports the measured plan. The rows of the report follow MYSQL-EXPLAIN-ROWS-001. Terminates: the explained statement is a strict subtree. Source: https://dev.mysql.com/doc/refman/8.4/en/explain.html. Status: Implemented.
