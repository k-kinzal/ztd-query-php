final class UserVariable
    implements Scalar
    uses Snapshot
Public API: explicitly declared with @visibility public.

A user-defined variable read as a value: @name.

Variable names are compared without regard to letter case; the name is kept as written.

Rule: MYSQL-USER-VARIABLE-001. Facts: the type and the NULL fact are those of the value the session last assigned, which no context holds; the fact names the variable as missing session state. Diagnostics: none. Source: https://dev.mysql.com/doc/refman/8.4/en/user-variables.html. Status: Implemented.
