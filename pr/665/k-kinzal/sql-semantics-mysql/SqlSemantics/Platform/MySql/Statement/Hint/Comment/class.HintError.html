final class HintError

Public API: explicitly declared with @visibility public.

The problem a hint comment stops at: why, and where in the statement text.

The server reports the problem as warning 1064, "<failure> near '<text>'

  • at line <n>", where the text is the statement from the offset on, cut to

80 bytes, or only the end of the comment when the problem is that the comment ends, and the line is the line of the offset (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/optimizer-hints.html#optimizer-hints-syntax.
