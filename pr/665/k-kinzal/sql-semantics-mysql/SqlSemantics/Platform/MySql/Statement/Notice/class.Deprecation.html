final class Deprecation
    implements CodedWarning
    uses Snapshot
Public API: explicitly declared with @visibility public.

The warning the server raises for a deprecated or converted construct while it reads a statement.

Rule: MYSQL-DEPRECATION-001. Syntax warnings precede name resolution, while contextualization and resolution notices are reported only when their stage reaches the construct. A statement that fails keeps the preceding notices. Each construct warns once per occurrence and preparation, in the releases that deprecate it (Deprecated::warnedIn()). Terminates: no recursion. Source: https://dev.mysql.com/doc/refman/8.4/en/show-warnings.html. Status: Implemented.
