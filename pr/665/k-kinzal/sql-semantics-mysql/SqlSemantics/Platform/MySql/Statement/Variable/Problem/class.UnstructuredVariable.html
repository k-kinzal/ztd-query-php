final class UnstructuredVariable
    implements Diagnostic
    uses Snapshot
Public API: explicitly declared with @visibility public.

A system variable written with an instance name that is not a structured variable (ER_VARIABLE_IS_NOT_STRUCT, error 1272), which MySQL 5.6 and 5.7 report for @@instance.name.

Those releases read the name after the instance as the variable, so a variable they know without being a component of a key cache is refused, and one they do not know is unknown by that name (verified on live 5.6.51 and 5.7.44 servers). Source: https://dev.mysql.com/doc/refman/5.7/en/structured-system-variables.html.
