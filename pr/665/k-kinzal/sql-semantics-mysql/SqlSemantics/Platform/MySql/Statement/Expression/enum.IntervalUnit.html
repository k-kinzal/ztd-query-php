enumIntervalUnit

packages/sql-semantics-mysql/src/Statement/Expression/IntervalUnit.php:18
enum IntervalUnit: string
Public API: explicitly declared with @visibility public.

The unit of a temporal interval, as written after an INTERVAL quantity and in the functions that take a unit.

Each case holds the unit keyword. The SQL_TSI_ spellings of the simple units are the same keywords to the server. Source: https://dev.mysql.com/doc/refman/8.4/en/expressions.html#temporal-intervals.
