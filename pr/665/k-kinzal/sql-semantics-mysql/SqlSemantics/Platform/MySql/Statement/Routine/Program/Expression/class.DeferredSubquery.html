final class DeferredSubquery
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored value or existence use of a query with an intrinsic read-column constraint.

The complete query remains available for invocation-time dependency checks. It cannot supply an ordinary Scalar, but an unreached stored instruction may retain it. Empty or inconsistent written rows, INSERT-only defaults and a tableless star differ from a catalog-dependent wildcard width.
