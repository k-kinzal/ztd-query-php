final class DeferredBody
    implements Query
    uses Snapshot
Public API: explicitly declared with @visibility public.

A query template whose retained operands are checked when a read reaches it.

CTE definitions are not themselves read statements. An unused definition can retain a row where a scalar would be required on reference. QueryRoot excludes this template from reached read positions, while retaining unused definitions. No source SQL, parser node or substitute scalar is kept.
