final class DeferredTimeZone
    implements DeferredOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored time-zone conversion with an incompatible or deferred operand role.

The original typed operand is retained for preparation when its instruction is reached. This value is not a Scalar and cannot be embedded in an ordinary query as if its intrinsic operand constraint were satisfied.
