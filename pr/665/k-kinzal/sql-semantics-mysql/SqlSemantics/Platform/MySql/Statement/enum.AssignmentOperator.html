enum AssignmentOperator: string
Public API: explicitly declared with @visibility public.

The written operator of a variable, column or option assignment.

Both signs assign the same value. Optional option assignments use null when no sign is written; the operator never contains input SQL. Source: https://dev.mysql.com/doc/refman/8.4/en/assignment-operators.html.
