One assignment column = value of SET, ON DUPLICATE KEY UPDATE, UPDATE or LOAD DATA.

The statement that holds the assignment resolves the column among the tables it writes and derives the value; = and := are one operator here. Source: https://dev.mysql.com/doc/refman/8.4/en/update.html.
