The condition information items SIGNAL and RESIGNAL set and GET DIAGNOSTICS reads.

Each case holds its keyword. RETURNED_SQLSTATE is read only: SIGNAL sets it through the condition value. Source: https://dev.mysql.com/doc/refman/8.4/en/diagnostics-area.html#diagnostics-area-information-items.
