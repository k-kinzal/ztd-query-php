interface LiteralExpression
    extends Literal, Scalar
Public API: explicitly declared with @visibility public.

A literal that is also an ordinary expression, without a separate unary sign.

This role is accepted by SIGNAL information items. A signed literal is restricted to constant positions; an arithmetic sign in an expression is a Unary node and is not a literal expression.
