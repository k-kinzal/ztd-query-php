final class RowSubquery
    implements RowOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A subquery whose explicit output contains several columns.

It can participate in row comparisons, but cannot occupy a scalar position. Its output width is fixed by structure; wildcard queries remain dependent scalar subqueries until their declaration context supplies their width.
