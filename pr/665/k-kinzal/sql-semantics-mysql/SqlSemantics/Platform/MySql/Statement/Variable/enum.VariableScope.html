enum VariableScope: string
Public API: explicitly declared with @visibility public.

The scope a system variable is read from or assigned in.

LOCAL is a synonym of SESSION. PERSIST and PERSIST_ONLY are scopes of SET only. Source: https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html, https://dev.mysql.com/doc/refman/8.4/en/set-variable.html.
