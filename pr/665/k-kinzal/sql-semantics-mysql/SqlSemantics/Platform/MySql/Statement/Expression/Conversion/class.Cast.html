final class Cast
    implements Scalar
    uses ScalarSemantics, Occurrence
Public API: explicitly declared with @visibility public.

A cast of a value to a type: CAST(expr AS type [ARRAY]) or CONVERT(expr, type) (Item_typecast_*).

CAST, typed CONVERT and AT LOCAL retain their written request forms. ARRAY (MySQL 8.0.17 and later) casts a JSON array for a multi-valued index.

Rule: MYSQL-CAST-001. Facts: MYSQL-CAST-RESULT-001; a cast to an array is a JSON value. Unsupported element types, AT LOCAL and invalid target bounds remain complete requests with ordered SQL conditions. Invalid conversions have an Invalid type fact instead of an invented result domain. The operand takes a single value. Terminates: the operand is a strict part. Source: https://dev.mysql.com/doc/refman/8.4/en/cast-functions.html#function_cast, https://dev.mysql.com/doc/refman/8.4/en/cast-functions.html#function_convert. Status: Implemented.
