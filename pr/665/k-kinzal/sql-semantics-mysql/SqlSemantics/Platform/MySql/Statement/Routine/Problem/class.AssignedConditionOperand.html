An assignment in a SIGNAL item or GET DIAGNOSTICS condition-number position.

MySQL 5.6 and 5.7 parse the complete assignment before refusing this role. Earlier grammar conditions in the assigned expression still take precedence. Source: https://github.com/mysql/mysql-server/blob/mysql-5.7.44/sql/sql_yacc.yy.
