final class DeferredAssignment
    implements Node
    uses Occurrence
Public API: explicitly declared with @visibility public.

A stored SET item whose assigned operand requires invocation-time preparation.

Its target remains a named local/system variable, an explicit system target, or a user variable. It is not an ordinary SetItem accepting a scalar value.
