SHOW TRIGGERS: the triggers of a database.

Rule: MYSQL-SHOW-TRIGGERS-001. FULL is accepted and returns the same columns. The rows and the WHERE condition are derived by MYSQL-SHOW-FACTS-001 from the layout of MYSQL-SHOW-ROWS-001. Terminates: a fixed layout. Source: https://dev.mysql.com/doc/refman/8.4/en/show-triggers.html. Status: Implemented.
