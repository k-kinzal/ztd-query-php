The character sets and collations of every MySQL release, read from the catalogs generated from the servers.

Names are kept in their 8.0 spelling: the utf8 of 5.6 and 5.7 is utf8mb3. Each character set and collation is created once, from the newest release that has it, so two lookups of the same name answer the same object.
