final class ConflictingUpdate
    implements Diagnostic, Node
    uses Occurrence
Public API: explicitly declared with @visibility public.

The complete input of an UPDATE with an intrinsically conflicting table namespace.

This diagnostic is neither an ordinary statement nor a stored instruction. MySQL rejects the collision when defining a routine, including an unreached branch. Retained sources still determine earlier database conditions.
