final class DropIndex
    implements Statement
    uses Snapshot
Public API: explicitly declared with @visibility public.

DROP INDEX name ON t [ALGORITHM = …] [LOCK = …]: a request to remove an index of a table.

Mirrors PT_drop_index_stmt. Rule: MYSQL-DROP-INDEX-001. The table resolves by MYSQL-CHANGE-TARGET-001 and its resolution is the relation fact of the statement node; PRIMARY names the primary key. A declaration context holds no indexes, so the index name is kept unresolved. The ALGORITHM and LOCK options are kept in the order written. The statement changes no declaration and provides none. Source: https://dev.mysql.com/doc/refman/8.4/en/drop-index.html. Status: Implemented.
