interface Explainable
    extends Statement
Public API: explicitly declared with @visibility public.

A query or data manipulation statement whose plan EXPLAIN can inspect.

SELECT, TABLE, VALUES, INSERT, REPLACE, UPDATE and DELETE have this role. It describes a statement position, independently of whether the named objects exist, whether privileges permit access, or whether execution succeeds. Source: https://dev.mysql.com/doc/refman/8.4/en/explain.html.
