final class GeneratedColumn
    implements ColumnSpecification
    uses Occurrence
Public API: explicitly declared with @visibility public.

The specification of a generated column: its values are computed from an expression (MySQL 5.7 and later).

Rule: MYSQL-GENERATED-COLUMN-001. The expression sees the columns of the table (MYSQL-DEFINITION-SCOPE-001). Without VIRTUAL or STORED the column is VIRTUAL; the storage is kept as written (null when absent). The words GENERATED ALWAYS are optional and change nothing. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table-generated-columns.html. Status: Implemented.
