DEALLOCATE PREPARE (or its synonym DROP PREPARE): releases a prepared statement.

Rule: MYSQL-DEALLOCATE-001. The prepared statement is a session object; the statement derives nothing and returns no rows. Terminates: no child. Source: https://dev.mysql.com/doc/refman/8.4/en/deallocate-prepare.html. Status: Implemented.
