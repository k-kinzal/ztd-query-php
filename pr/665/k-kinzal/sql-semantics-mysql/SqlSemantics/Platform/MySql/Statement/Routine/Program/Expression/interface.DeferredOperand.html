interface DeferredOperand
    extends Operand
Public API: explicitly declared with @visibility public.

A stored computation whose intrinsic operand constraint is checked on invocation.

This domain belongs to program instructions, not general Scalar positions. Its operands retain their own semantic roles and resolve in the invocation's scope. An unreachable instruction does not evaluate or prepare this value.
