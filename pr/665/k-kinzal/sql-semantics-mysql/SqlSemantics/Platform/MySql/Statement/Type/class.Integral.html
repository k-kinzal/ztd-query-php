An integer type with its optional display width and its attributes in the order written.

INT, INTEGER and INT4 are one keyword to the server, as are the other numbered spellings; the kind names the type they denote. Source: https://dev.mysql.com/doc/refman/8.4/en/integer-types.html, https://dev.mysql.com/doc/refman/8.4/en/numeric-type-attributes.html.
