enum Deprecated: string
Public API: explicitly declared with @visibility public.

A construct the server reads but warns about while it reads the statement: deprecated syntax, and syntax it converts.

Each case holds the error number and the text of its warning. Release 5.6 warns only that DELAYED is deprecated, and 5.7 that it is converted and that the query cache modifiers, PROCEDURE ANALYSE, a direction in GROUP BY and a name after a leading dot are deprecated. Release 5.6 also warns about OLD_PASSWORD(), and 5.7 about DES_ENCRYPT(), DES_DECRYPT() and ENCRYPT(), and both about the system variables they deprecate, each read or assignment of one naming it (see DeprecatedVariables), and, as 8.0 does, about LOW_PRIORITY WRITE in LOCK TABLES; 5.6 also warns about ALTER IGNORE TABLE (verified on live 5.6.51, 5.7.44 and 8.0.44 servers). MySQL 8.0 and later warn about MASTER_POS_WAIT() and WAIT_UNTIL_SQL_THREAD_AFTER_GTIDS() (verified on live 8.0.44 and 8.4 servers). Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html#error_er_warn_deprecated_syntax.
