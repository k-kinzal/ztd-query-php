The query of CREATE TABLE ... SELECT, with the handling of rows that duplicate a unique key.

The rows of the query fill the new table. IGNORE discards a row that duplicates a unique key value, REPLACE replaces the old row; without either such a row is an error. The word AS before the query is optional and is retained separately from the query. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table-select.html.
