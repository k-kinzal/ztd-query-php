final class DeferredWindowSpec
    implements WindowSpecification
    uses Snapshot
Public API: explicitly declared with @visibility public.

A complete window whose partitioning, ordering or frame retains a non-scalar operand.

Named definitions and inactive common tables retain this specification without preparing its expressions. A reached window checks every item in written order.
