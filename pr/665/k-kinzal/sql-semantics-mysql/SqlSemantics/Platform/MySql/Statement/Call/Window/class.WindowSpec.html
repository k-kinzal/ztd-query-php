final class WindowSpec
    implements WindowSpecification
    uses Occurrence
Public API: explicitly declared with @visibility public.

A parenthesized window specification: an optional window it refines, a partitioning, an ordering and a frame.

Rule: MYSQL-WINDOW-SPEC-001. The expressions are derived at the position of the window. The base window is a window of the WINDOW clause, which the query family resolves. A GROUPS frame and an EXCLUDE clause are accepted by the grammar and rejected by the server (ER_NOT_SUPPORTED_YET). Terminates: the parts are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/window-functions-usage.html, https://dev.mysql.com/doc/refman/8.4/en/window-functions-named-windows.html. Status: Implemented.
