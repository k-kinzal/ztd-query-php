enum NullTreatment: string
Public API: explicitly declared with @visibility public.

Whether a value window function skips NULL values, as written after its arguments.

Each case holds the keywords. RESPECT NULLS is the default; the server does not support IGNORE NULLS. Source: https://dev.mysql.com/doc/refman/8.4/en/window-function-descriptions.html.
