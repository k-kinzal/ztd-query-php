final class Logical

    uses Snapshot
Public API: explicitly declared with @visibility public.

A logical AND, OR or XOR of two operands, in the order written (Item_cond_and, Item_cond_or, Item_func_xor).

The operators associate to the left; AND binds tighter than XOR, XOR tighter than OR (MYSQL-PRECEDENCE-001). An operand that would be read differently without a grouping is rejected.

Rule: MYSQL-LOGICAL-001. Facts: the result is 1, 0 or NULL, an integer; it can be NULL when an operand can. Both operands take a single value. The symbols || and && are deprecated synonyms of OR and AND; reading one raises its warning after the left operand (MYSQL-DEPRECATION-001). Terminates: the operands are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/logical-operators.html. Status: Implemented.
