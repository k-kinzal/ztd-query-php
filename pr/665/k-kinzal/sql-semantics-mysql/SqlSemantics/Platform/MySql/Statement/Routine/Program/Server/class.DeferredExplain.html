final class DeferredExplain
    implements ProgramStatement

Public API: explicitly declared with @visibility public.

A complete stored explanation whose operands require invocation-time preparation.

Reaching this instruction prepares the explained statement before its output target. MySQL 8.1–8.3 also defers invalid target names until invocation. This is a program instruction, never a standalone Statement.
