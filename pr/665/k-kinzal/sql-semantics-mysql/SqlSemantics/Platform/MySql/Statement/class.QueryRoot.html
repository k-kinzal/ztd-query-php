final class QueryRoot
    implements Explainable, Selection
    uses Snapshot
Public API: explicitly declared with @visibility public.

A query submitted as a statement, separately from a query used as an operand.

Query bodies also occur in subqueries and INSERT sources, whose grammar positions admit different forms. Only this wrapper implements the statement role. Its checks concern that grammatical position, not execution eligibility.
