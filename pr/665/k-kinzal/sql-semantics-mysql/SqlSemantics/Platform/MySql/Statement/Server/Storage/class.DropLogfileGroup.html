DROP LOGFILE GROUP name [option …]: a request to remove an NDB log file group.

Mirrors PT_drop_logfile_group and the DROP_LOGFILE_GROUP command of st_alter_tablespace in MySQL 5.x. Rule: MYSQL-DROP-LOGFILE-GROUP-001. The options are checked, kept and written in order by MYSQL-STORAGE-OPTIONS-001. A log file group is no relation, so the statement neither declares nor resolves one. Source: https://dev.mysql.com/doc/refman/8.4/en/drop-logfile-group.html. Status: Implemented.
