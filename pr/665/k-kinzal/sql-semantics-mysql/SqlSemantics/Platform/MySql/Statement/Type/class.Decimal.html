The exact fixed-point type DECIMAL with its optional precision and scale.

DEC, NUMERIC and FIXED are synonyms of DECIMAL. A precision without a scale is written DECIMAL(M). Source: https://dev.mysql.com/doc/refman/8.4/en/fixed-point-types.html.
