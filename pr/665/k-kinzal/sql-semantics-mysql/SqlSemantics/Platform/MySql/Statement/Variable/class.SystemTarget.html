final class SystemTarget
    implements Operand
    uses Snapshot
Public API: explicitly declared with @visibility public.

The system variable assigned by SET or an INSTALL COMPONENT setting.

This operand is not a value expression. PERSIST and PERSIST_ONLY select assignment scopes only. The enclosing assignment resolves writability, scope and structured names in the release's diagnostic order; deriving the target never reads the variable or emits a read deprecation warning. Source: https://dev.mysql.com/doc/refman/8.4/en/set-variable.html.
