final class FunctionCall
    implements Scalar
    uses Snapshot
Public API: explicitly declared with @visibility public.

A call written as name(...) or db.name(...): a native function reached by name, a loadable function or a stored function.

The server mirrors this as PTI_function_call_generic_ident_sys and PTI_function_call_generic_2d. Only the unqualified form takes argument aliases. The facts follow MYSQL-ROUTINE-CALL-001. The name is written against its parenthesis, because a name followed by a space is a column unless IGNORE_SPACE is set. Source: https://dev.mysql.com/doc/refman/8.4/en/function-resolution.html. Status: Implemented.
