A fractional seconds precision above 6 for a cast (ER_TOO_BIG_PRECISION, error 1426).

The server refuses it while it parses the cast, and parses no further. Source: https://dev.mysql.com/doc/mysql-errors/8.4/en/server-error-reference.html#error_er_too_big_precision.
