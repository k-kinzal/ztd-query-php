A call of JSON_OBJECTAGG(key, value): a JSON object of the key and value pairs of a group.

Rule: MYSQL-JSON-OBJECTAGG-001. Each operand takes its own ALL. The result is JSON; it is NULL for a group without rows. A NULL key is the error ER_JSON_DOCUMENT_NULL_KEY at run time. Terminates: the operands and the window are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/aggregate-functions.html#function_json-objectagg. Status: Implemented.
