CREATE TRIGGER: a statement that runs for each row an INSERT, UPDATE or DELETE changes in a table.

The statement is structured as a request: it declares nothing to a context. The facts follow MYSQL-TRIGGER-001. Source: https://dev.mysql.com/doc/refman/8.4/en/create-trigger.html.
