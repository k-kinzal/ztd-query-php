final class LegacyDatabaseName
    implements Node
    uses Occurrence
Public API: explicitly declared with @visibility public.

A legacy database directory identity, before MySQL's filename encoding.

The suffix is decoded name data. The fixed #mysql50# marker is supplied by this role, so an upgrade cannot accidentally name an ordinary database. A directory component is nonempty, at most 64 characters, has no separator, period or NUL, and does not end with ASCII whitespace. Its UTF-8 directory component fits 183 bytes so the complete marked identity fits 192 bytes. Observed through MySQL 5.6.51 and 5.7.44 database upgrade statements.
