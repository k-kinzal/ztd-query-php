GET DIAGNOSTICS: copies statement or condition information of a diagnostics area into variables.

The statement is valid on its own and inside a stored program; it returns no rows. The facts follow MYSQL-PROGRAM-CONDITIONS-001. Source: https://dev.mysql.com/doc/refman/8.4/en/get-diagnostics.html.
