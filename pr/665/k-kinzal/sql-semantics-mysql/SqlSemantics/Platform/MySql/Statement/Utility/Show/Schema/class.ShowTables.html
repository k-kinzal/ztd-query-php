SHOW TABLES: the tables and views of a database.

Rule: MYSQL-SHOW-TABLES-001. One column named Tables_in_db after the database written or the current one, Tables_in_db (pattern) with LIKE; FULL adds Table_type. EXTENDED, from MySQL 8.0 on, also lists hidden tables and adds no column. When neither the statement nor the context names the database, the column name depends on the current database of the session and the shape is open. The rows and the WHERE condition are derived by MYSQL-SHOW-FACTS-001. Terminates: a fixed layout. Source: https://dev.mysql.com/doc/refman/8.4/en/show-tables.html. Status: Implemented.
