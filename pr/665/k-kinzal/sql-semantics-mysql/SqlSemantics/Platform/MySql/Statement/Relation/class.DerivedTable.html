Public API: explicitly declared with @visibility public.

A derived table: [LATERAL] (query) [AS] alias [(columns)].

The query is the one inside the parentheses the syntax requires.

Rule: MYSQL-DERIVED-TABLE-001. From MySQL 8.0 the query sees the enclosing queries and, when LATERAL is written, the tables to its left in the same FROM clause (MYSQL-FROM-SCOPE-001). The columns are those of the query, renamed by the column list (MYSQL-DERIVED-SHAPES-001). The correlation name is mandatory; an empty quoted alias remains a valid name. Source: https://dev.mysql.com/doc/refman/8.4/en/derived-tables.html, https://dev.mysql.com/doc/refman/8.4/en/lateral-derived-tables.html. Status: Implemented.
