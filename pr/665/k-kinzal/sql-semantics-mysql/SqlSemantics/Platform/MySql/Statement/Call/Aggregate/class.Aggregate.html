A call of an aggregate function with one argument, COUNT(*), or COUNT(DISTINCT ...) with several arguments.

Rule: MYSQL-AGGREGATE-001. The server builds the Item_sum classes. DISTINCT counts each distinct value once; ALL, written before the argument, is the default. With OVER the call is a window function (MySQL 8.0 and later). The result follows MYSQL-AGGREGATE-RESULT-001. Terminates: the arguments and the window are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/aggregate-functions.html. Status: Implemented.
