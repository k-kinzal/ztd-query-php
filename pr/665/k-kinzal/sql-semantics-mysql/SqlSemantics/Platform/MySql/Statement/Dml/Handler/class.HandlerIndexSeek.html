HANDLER ... READ index op (value, ...): reads rows of an open handler from the first index key that compares as asked.

The values are compared with the leading columns of the index. The facts follow MYSQL-HANDLER-READ-001. Source: https://dev.mysql.com/doc/refman/8.4/en/handler.html.
