Public API: explicitly declared with @visibility public.

One column of a table definition: its name and its specification.

Rule: MYSQL-COLUMN-DEFINITION-001. MySQL 5.x lets a table and database qualify the name, which the server requires to name the table of the statement; the qualifier is kept as written. The expressions inside the specification are derived at the position of the table definition (MYSQL-DEFINITION-SCOPE-001). Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html, https://dev.mysql.com/doc/refman/5.7/en/identifier-qualifiers.html. Status: Implemented.
