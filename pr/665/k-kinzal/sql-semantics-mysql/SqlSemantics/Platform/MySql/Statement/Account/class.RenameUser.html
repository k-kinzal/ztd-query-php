final class RenameUser
    implements Statement
    uses Snapshot
Public API: explicitly declared with @visibility public.

RENAME USER old TO new, …: a request to rename accounts, applied pair by pair in order.

Mirrors SQLCOM_RENAME_USER. Rule: MYSQL-RENAME-USER-001. Accounts are not declared in a context, so the statement has no resolution facts. Construction excludes contradictory ordered identities, considering fixed and following CURRENT_USER interpretations without resolving an account catalog. Complete contradictory input remains available as DeferredRenameUser in stored code. Source: https://dev.mysql.com/doc/refman/8.4/en/rename-user.html. Status: Implemented.
