    extends SqlStatement
    implements Statement, AnalyzedStatement

Public API: explicitly declared with @visibility public.

RENAME USER old TO new, …: a request to rename accounts, applied pair by pair in order.

Mirrors SQLCOM_RENAME_USER. Rule: MYSQL-RENAME-USER-001. Accounts are not declared in a context, so the statement has no resolution facts. Construction preserves every ordered pair, including contradictory identity requirements. The derived problem describes that intrinsic condition without executing it: catalog lookup, implicit commit and partial legacy effects belong to execution. Source: https://dev.mysql.com/doc/refman/8.4/en/rename-user.html. Status: Implemented.
