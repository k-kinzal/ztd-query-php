An unsigned number literal, kept as its exact text.

Rule: MYSQL-NUMBER-LITERAL-001. Facts: an integer that fits a signed 64-bit integer is BIGINT, one that fits only unsigned is BIGINT UNSIGNED; an exact number with a decimal point or beyond the 64-bit range is DECIMAL; a number with an exponent is DOUBLE; never NULL. Precision: the type family is exact; precision and scale of a DECIMAL literal are not derived. Diagnostics: none. Terminates: constant work. Source: https://dev.mysql.com/doc/refman/8.4/en/number-literals.html, https://dev.mysql.com/doc/refman/8.4/en/precision-math-numbers.html. Status: Implemented.
