final class DeferredQuery
    implements ProgramStatement
    uses Occurrence
Public API: explicitly declared with @visibility public.

A stored query whose fixed read constraint is checked when it is reached.

It retains the complete query but is neither an ordinary Statement nor a Scalar. A skipped instruction or unopened cursor does not prepare its rows. Lexical recursive-reference restrictions still apply to the enclosing program declaration; anchor and output-column restrictions wait for invocation.
