final class DeferredQuery
    implements ProgramStatement
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored query whose fixed column constraint is checked when it is reached.

It retains the complete query but is neither an ordinary Statement nor a Scalar. A skipped instruction or unopened cursor does not prepare its rows.
