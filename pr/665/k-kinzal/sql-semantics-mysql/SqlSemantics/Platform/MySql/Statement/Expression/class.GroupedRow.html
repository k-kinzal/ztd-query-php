final class GroupedRow
    implements RowOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

Grouping around a row operand, retaining its row-valued role.

Parentheses and ODBC braces both preserve the row. An optional escape kind distinguishes braces without converting the row into a scalar.

Grouping never turns a row into a scalar. The enclosed row supplies the comparison fields and their derived facts.
