final class DeferredCreateTable
    implements ProgramStatement
    uses Occurrence
Public API: explicitly declared with @visibility public.

A stored CREATE TABLE whose written definition the server executes only when the routine runs.

The server reads a routine body with its grammar and checks what it checks while reading: the types, the options and the collations of the definition. Whether the written columns and keys form a table it can create is decided when the instruction is reached; CREATE PROCEDURE accepts a body that creates a table with two columns of one name (verified on 8.4.7 and 5.7.44). This is a program instruction, never a standalone Statement; the executable statement is CreateTable, whose constructor refuses such a definition.
