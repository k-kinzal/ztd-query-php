final class DropProgram
    implements Statement
    uses Snapshot
Public API: explicitly declared with @visibility public.

DROP PROCEDURE, DROP FUNCTION, DROP TRIGGER or DROP EVENT.

Rule: MYSQL-DROP-PROGRAM-001. The statement is structured as a request only: it changes no context and derives nothing. DROP FUNCTION with an unqualified name drops a stored function of the current database or, when there is none, a loadable function of that name; which one is not decided here. Source: https://dev.mysql.com/doc/refman/8.4/en/drop-procedure.html, https://dev.mysql.com/doc/refman/8.4/en/drop-function-loadable.html, https://dev.mysql.com/doc/refman/8.4/en/drop-trigger.html, https://dev.mysql.com/doc/refman/8.4/en/drop-event.html. Status: Implemented.
