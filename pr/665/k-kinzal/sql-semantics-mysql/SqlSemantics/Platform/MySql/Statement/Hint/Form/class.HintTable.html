final class HintTable
    uses Snapshot
Public API: explicitly declared with @visibility public.

A table an optimizer hint names: its name or alias, and the query block it is in when the hint writes one (t@qb).

The name is matched against the table names and aliases of the query block as written, and cannot be qualified with a database. Source: https://dev.mysql.com/doc/refman/8.4/en/optimizer-hints.html.
