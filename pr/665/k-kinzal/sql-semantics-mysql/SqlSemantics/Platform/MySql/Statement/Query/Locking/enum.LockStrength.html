enum LockStrength
Public API: explicitly declared with @visibility public.

The lock a locking read takes: FOR UPDATE, FOR SHARE, or the older LOCK IN SHARE MODE.

LOCK IN SHARE MODE takes a shared lock like FOR SHARE but accepts no table list and no NOWAIT or SKIP LOCKED. Source: https://dev.mysql.com/doc/refman/8.4/en/innodb-locking-reads.html.
