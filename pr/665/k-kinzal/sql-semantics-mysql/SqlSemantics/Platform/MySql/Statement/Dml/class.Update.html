final class Update
    implements Explainable
    uses Snapshot
Public API: explicitly declared with @visibility public.

UPDATE of one table or of several tables, with SET assignments, WHERE, ORDER BY and LIMIT.

Mirrors the server's PT_update: the statement is a multiple-table UPDATE when its table references hold more than one table. The facts follow MYSQL-UPDATE-001. Ordinary values exclude read-only destinations and multi-table ORDER BY/LIMIT clauses; stored instructions retain these conditions in DeferredUpdate until invocation. The hints of the comment written right after UPDATE are kept with the statement. Source: https://dev.mysql.com/doc/refman/8.4/en/update.html.
