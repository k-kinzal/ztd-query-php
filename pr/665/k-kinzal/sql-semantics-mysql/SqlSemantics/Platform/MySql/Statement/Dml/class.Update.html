final class Update
    extends SqlStatement
    implements Explainable, AnalyzedStatement
    uses Occurrence
Public API: explicitly declared with @visibility public.

UPDATE of one table or of several tables, with SET assignments, WHERE, ORDER BY and LIMIT.

Mirrors the server's PT_update: the statement is a multiple-table UPDATE when its table references hold more than one table. The facts follow MYSQL-UPDATE-001. Read-only destinations, non-scalar operands and incompatible multi-table clauses remain on the complete request. Preparation and execution determine the reached condition. The hints of the comment written right after UPDATE are kept with the statement. Source: https://dev.mysql.com/doc/refman/8.4/en/update.html.
