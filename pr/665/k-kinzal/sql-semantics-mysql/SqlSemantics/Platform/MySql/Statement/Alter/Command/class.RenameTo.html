RENAME [TO | AS] new: a request to rename the table, possibly into another database.

Mirrors PT_alter_table_rename. A new name the context declares is the diagnostic TableExists, unless it is the name of the changed table itself. TO, AS, = and no word are the same request; TO is written. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html#alter-table-rename.
