final class SystemTables
    uses Snapshot
Public API: explicitly declared with @visibility public.

The tables of the system databases of one release, read from the catalog generated from a server of the release.

The information_schema, mysql and performance_schema databases hold them. A statement that reads one is bound against its declaration, which this catalog supplies with the type each column has when it is read. The name of information_schema and the names of its tables are compared without regard to case, whatever lower_case_table_names says; the names of the other system databases and of their tables follow the setting. Source: https://dev.mysql.com/doc/refman/8.4/en/information-schema-introduction.html, https://dev.mysql.com/doc/refman/8.4/en/identifier-case-sensitivity.html.
