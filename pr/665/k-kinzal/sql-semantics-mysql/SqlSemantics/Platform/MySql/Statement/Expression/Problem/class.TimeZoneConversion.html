final class TimeZoneConversion
    implements Diagnostic

Public API: explicitly declared with @visibility public.

An AT TIME ZONE conversion whose resolved operand or zone is unsuitable.

The conversion owns the condition. Its operand is resolved first, so a missing column inside it precedes this condition, while a later expression does not. A dependent operand is not rejected until its type is available. Observed through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0.
