The target namespace of a multiple-table DELETE and its input occurrences.

Every target can name an input occurrence. Database selection and instance name comparison are resolved later, while an intrinsically absent or repeated name is excluded here. Constructing this operand does not require unrelated predicates, hints or statement options.
