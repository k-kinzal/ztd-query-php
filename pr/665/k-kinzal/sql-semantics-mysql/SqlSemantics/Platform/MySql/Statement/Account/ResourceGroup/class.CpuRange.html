One CPU number or range n-m of the VCPU option of a resource group.

Mirrors resourcegroups::Range. Which CPUs exist is a property of the machine the server runs on, which a declaration context does not hold. Source: https://dev.mysql.com/doc/refman/8.4/en/create-resource-group.html.
