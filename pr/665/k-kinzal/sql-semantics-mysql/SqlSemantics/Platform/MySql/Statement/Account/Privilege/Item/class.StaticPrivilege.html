A privilege the server defines statically, such as SELECT (a, b) or CREATE ROUTINE, with its column list.

Mirrors PT_static_privilege. Only SELECT, INSERT, UPDATE and REFERENCES take a column list; the columns are kept as written. Source: https://dev.mysql.com/doc/refman/8.4/en/grant.html#grant-column-privileges.
