Public API: explicitly declared with @visibility public.

A window function or window specification that uses a part of the syntax the server does not support.

Window refusals retain the semantic value that owns the diagnostic, so a consumer can defer it until window planning without recovering input SQL or guessing which call or frame produced it.

Source: https://dev.mysql.com/doc/refman/8.4/en/window-function-restrictions.html.
