A MySQL error code as a condition value.

The grammar reads the code as an unsigned number (rule ulong_num of sql_yacc.yy): the leading decimal digits of a decimal or floating number (1e2 is 1, 0.5 is 0), or the digits of a hexadecimal literal; a value beyond the range of the conversion is its largest value. The code 0 is rejected (ER_WRONG_VALUE), and the server keeps the code as a 32-bit error number. Source: https://dev.mysql.com/doc/refman/8.4/en/declare-condition.html, https://github.com/mysql/mysql-server/blob/mysql-8.0.44/sql/sql_yacc.yy (rules sp_cond, ulong_num).
