final class DormantCall
    implements DeferredOperand

Public API: explicitly declared with @visibility public.

A native-call spelling retained in an uncontextualized clause or CTE definition.

This is not a Scalar or an invocable stored expression. Statement constructor checks restrict it to unused definitions and clauses of INSERT/REPLACE VALUES sources. No SQL text or parser node is retained.
