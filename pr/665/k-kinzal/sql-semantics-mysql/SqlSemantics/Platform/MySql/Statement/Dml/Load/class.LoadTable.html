LOAD DATA and LOAD XML: reads rows from a file into a table.

Mirrors the server's PT_load_table with its sql_exchange. The facts follow MYSQL-LOAD-001. A clause written twice in the field or line options is kept twice. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html, https://dev.mysql.com/doc/refman/8.4/en/load-xml.html.
