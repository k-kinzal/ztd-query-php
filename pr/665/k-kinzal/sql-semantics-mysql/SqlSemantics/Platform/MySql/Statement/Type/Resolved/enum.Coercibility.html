enum Coercibility: int
Public API: explicitly declared with @visibility public.

How strongly the collation of a string holds against the collation of another string it meets.

The lower value wins; two different collations of the same value conflict. Source: https://dev.mysql.com/doc/refman/8.4/en/charset-collation-coercibility.html.
