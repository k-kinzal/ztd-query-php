final class DeferredInsertRows
    implements ProgramStatement
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored INSERT or REPLACE retaining every value, target and duplicate-key clause.

At least one value has a non-scalar preparation condition. The ordinary write domain remains InsertRows; a skipped stored instruction never prepares this template. Its target and every operand bind together when it is reached.
