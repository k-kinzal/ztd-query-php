final class ExplicitIndexOrder
    implements Diagnostic
    uses Snapshot
Public API: explicitly declared with @visibility public.

A modern input requests ordering from an index that cannot order key parts.

The target and incompatible direction survive without an ordinary modern index, parser tree or original SQL. No later operand is needed to diagnose this intrinsic input condition, including in an unreachable stored branch.
