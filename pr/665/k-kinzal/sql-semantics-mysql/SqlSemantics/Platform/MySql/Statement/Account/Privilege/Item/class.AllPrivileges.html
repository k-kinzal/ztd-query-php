ALL [PRIVILEGES]: every privilege of the level the grant names, except GRANT OPTION and, globally, PROXY.

It is written alone in the privilege list. PRIVILEGES is an optional word. Source: https://dev.mysql.com/doc/refman/8.4/en/privileges-provided.html#priv_all.
