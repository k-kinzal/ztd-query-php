One branch of IF or CASE: an expression, THEN, and the statements that run when the branch is chosen.

In IF and in a searched CASE the expression is a search condition; in a simple CASE it is the value compared with the operand of the CASE. Source: https://dev.mysql.com/doc/refman/8.4/en/if.html, https://dev.mysql.com/doc/refman/8.4/en/case.html.

Row operands remain stored program values. Their scalar-use condition is checked when control reaches this instruction, after binding its operands. They do not become ordinary Scalar expressions.
