final class DeferredSubqueryPredicate
    implements DeferredOperand
    uses ScalarSemantics, Occurrence
Public API: explicitly declared with @visibility public.

Stored subquery membership or quantification with a deferred operand constraint.

Both the compared operand and the complete query remain structured. The ordinary scalar predicate types reject this contradictory fixed shape.
