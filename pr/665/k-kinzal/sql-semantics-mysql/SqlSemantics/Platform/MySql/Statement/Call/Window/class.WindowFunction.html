final class WindowFunction
    implements Scalar
    uses Snapshot
Public API: explicitly declared with @visibility public.

A call of a function that is only a window function: ranking, distribution, and the value functions LEAD, LAG, FIRST_VALUE, LAST_VALUE and NTH_VALUE.

Rule: MYSQL-WINDOW-FUNCTION-001. The window is required. The count of NTILE and the offset of LEAD and LAG are an integer, a parameter marker, a user variable or a routine variable (stable_integer); the row number of NTH_VALUE is a primary expression. The result follows MYSQL-WINDOW-RESULT-001. Terminates: the arguments and the window are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/window-function-descriptions.html. Status: Implemented.
