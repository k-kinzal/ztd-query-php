final class DeferredGeneratedColumn
    implements ColumnSpecification
    uses Snapshot
Public API: explicitly declared with @visibility public.

A complete generation declaration with operands retained until invocation.

Stored definitions retain this column template until their table instruction is invoked. Ordinary CREATE TABLE and ALTER TABLE values exclude this role. Aggregates and window calls retain their invocation-time role across releases. MySQL 5.7 prepared compound expressions can retain markers whose bound values become constants in the created table. A bare marker has no such declaration role.
