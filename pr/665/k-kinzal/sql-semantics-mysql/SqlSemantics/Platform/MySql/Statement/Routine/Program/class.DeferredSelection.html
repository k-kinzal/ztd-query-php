final class DeferredSelection
    implements ProgramStatement
    uses Snapshot
Public API: explicitly declared with @visibility public.

A stored SELECT of items and an optional input/filter needing deferred preparation.

A definition can retain row-valued projections and predicates. Its relation and all operand names bind when control reaches the instruction. This program member is distinct from an ordinary Query and preserves no source text.
