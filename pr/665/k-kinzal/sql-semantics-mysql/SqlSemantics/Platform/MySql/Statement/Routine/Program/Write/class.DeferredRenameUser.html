final class DeferredRenameUser
    implements ProgramStatement

Public API: explicitly declared with @visibility public.

A stored account rename list retaining contradictory identity requirements.

The complete ordered pairs remain available to the account consumer, including partial legacy effects and current-account references. An unreached branch does not apply them. Ordinary RenameUser values exclude this contradiction.
