final class Row
    implements RowOperand
    uses Snapshot
Public API: explicitly declared with @visibility public.

A row constructor: (expr, expr …) or ROW(expr, expr …) (Item_row).

The keyword ROW is optional and does not change the row. Its explicit spelling is retained by the keyword operand.

Rule: MYSQL-ROW-001. Facts: a row of as many columns as elements; it can be NULL when an element can. Comparisons and IN explicitly accept rows. Stored program operand positions may retain them until a reached instruction applies MYSQL-OPERAND-COLUMNS-001. Ordinary scalar positions require Scalar and cannot accept a row. Terminates: the elements are strict parts. Source: https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html. Status: Implemented.
