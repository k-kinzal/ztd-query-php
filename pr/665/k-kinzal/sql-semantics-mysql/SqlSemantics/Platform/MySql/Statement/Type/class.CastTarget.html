Public API: explicitly declared with @visibility public.

The target type of CAST, CONVERT and JSON_VALUE ... RETURNING: a closed set of kinds with length, scale and character set.

SIGNED INTEGER is SIGNED and UNSIGNED INTEGER is UNSIGNED; DOUBLE PRECISION is DOUBLE. The server keeps one cast type value with a target kind, and so does this class. Source: https://dev.mysql.com/doc/refman/8.4/en/cast-functions.html#function_cast.
