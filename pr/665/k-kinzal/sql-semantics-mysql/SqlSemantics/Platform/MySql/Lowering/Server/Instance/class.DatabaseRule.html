final class DatabaseRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Lowering\Server". Code outside that scope must not name this declaration.

Lowers CREATE, ALTER and DROP DATABASE.

Rule: MYSQL-DATABASE-001. Scope: the DATABASE alternatives of create, alter and drop (alter and drop in 5.6 and 5.7), alter_database_stmt, drop_database_stmt, opt_create_database_options, create_database_options, create_database_option, alter_database_options, alter_database_option, default_encryption. The character set and collation go through the leaf character set rules; DEFAULT before an option and its equals sign are retained. Constructs: CreateDatabase, AlterDatabase, UpgradeDatabaseName, DropDatabase and the DatabaseOption classes. Terminates: the option lists are flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/create-database.html, https://dev.mysql.com/doc/refman/8.4/en/alter-database.html, https://dev.mysql.com/doc/refman/8.4/en/drop-database.html. Status: Implemented.
