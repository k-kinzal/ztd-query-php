Resolves handler conditions as their list completes, before reading the handler body.

Empty declaration lists open lexical scopes; completed blocks close them. Only typed condition declarations and already handled values survive between reductions. Ordinary block rules supply name resolution and duplicate identity. No input tree or text escapes this transient lowering helper.
