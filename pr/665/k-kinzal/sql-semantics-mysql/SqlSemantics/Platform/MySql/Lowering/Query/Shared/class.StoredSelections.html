final class StoredSelections
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Reads stored item/input/filter selections without changing the scalar query domain.

The complete clause frontier is inspected before any operand is lowered. Other query forms remain with their ordinary query rules; no clause is dropped or replaced when this instruction form does not represent the input.
