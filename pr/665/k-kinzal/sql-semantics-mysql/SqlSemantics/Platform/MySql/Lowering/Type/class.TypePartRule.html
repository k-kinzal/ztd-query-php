final class TypePartRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Lowers the parts a data type is written with: lengths, precisions, numeric attributes and character set attributes.

Rule: MYSQL-TYPE-PART-001. Scope: field_length, opt_field_length, precision, opt_precision, float_options, standard_float_options, type_datetime_precision, field_options, field_opt_list, field_option, opt_binary, opt_bin_mod, opt_charset_with_opt_binary, ascii, unicode. A length keeps its exact text; numeric attributes keep their written order; a character set attribute keeps the place of BINARY. Constructs: NumericModifier, CharsetAttribute. Terminates: the attribute list is flattened iteratively; every other child is a strict subtree. Source: https://dev.mysql.com/doc/refman/8.4/en/data-types.html. Status: Implemented.
