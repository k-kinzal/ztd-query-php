final class SyntaxWarnings
Public API: explicitly declared with @visibility public.

Interprets notices of completed expressions before a later input refusal.

BINARY and assignment expressions warn after their operand has been read. A missing operand therefore produces no notice. The temporary parser nodes are consumed during the call; only warning descriptors and offsets escape. Source: https://dev.mysql.com/doc/refman/8.4/en/show-warnings.html.
