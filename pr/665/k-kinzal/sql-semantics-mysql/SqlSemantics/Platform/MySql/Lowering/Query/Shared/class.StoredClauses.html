Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Reads stored sort clauses without converting deferred operands into scalars.

Ordinary integer items still denote output ordinals and ordinary clauses retain their existing structure. Deferred items preserve complete operands.
