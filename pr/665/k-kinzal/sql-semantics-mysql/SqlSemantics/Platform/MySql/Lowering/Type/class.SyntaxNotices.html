final class SyntaxNotices
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Interprets completed numeric and character-type attributes before later malformed input.

The attribute is lowered to its ordinary typed value. Full derivation and prefix lowering then use the same ordered warning rule. Unknown charset names can abort before the enclosing attribute completes.
