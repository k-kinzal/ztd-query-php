Lowers user-defined variables, system variables and their scopes.

Rule: MYSQL-VARIABLE-001. Scope: variable, variable_aux, opt_var_ident_type (5.6, 5.7); rvalue_system_or_user_variable, rvalue_system_variable, opt_rvalue_system_variable_type, in_expression_user_variable_assignment, lvalue_variable, opt_set_var_ident_type (8.0 and later). @name is a user variable, @name := expr an assignment, @@[scope.][instance.]name a system variable. LOCAL is the scope SESSION; DEFAULT.name names the instance default. Constructs: UserVariable, VariableAssignment, SystemVariable, VariableScope. Terminates: every child is a strict subtree. Source: https://dev.mysql.com/doc/refman/8.4/en/user-variables.html, https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html. Status: Implemented.
