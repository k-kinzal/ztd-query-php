Lowers the SHOW statements of MySQL 5.6 and 5.7: show: SHOW show_param.

Rule: MYSQL-SHOW-LEGACY-LOWERING-001. Scope: show, show_param, show_engine_param. Each show_param production is the same command as the 8.0 rule of the same words and lowers into the same class; the MySQL 5.6 and 5.7 spellings of a production differ only in the clause rules they use (wild_and_where or opt_wild_or_where, opt_limit_clause_init or opt_limit_clause, where_clause or opt_where_clause), which MYSQL-SHOW-CLAUSE-LOWERING-001 lowers alike. The statements about schema objects and the server are lowered by MYSQL-SHOW-LEGACY-OBJECT-LOWERING-001. Terminates: every part is a strict subtree. Source: https://dev.mysql.com/doc/refman/5.7/en/show.html. Status: Implemented.
