final class RetainedTails
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Lowering\Query". Code outside that scope must not name this declaration.

Assigns legacy SELECT tails without discarding retained projection or filter operands.

The final unparenthesized block gives its ordering and limit to the complete UNION. Parenthesized operands keep their own clauses. Earlier blocks retain the MySQL 5.6 LIMIT role and exclude that role on later releases.
