final class SyntaxRoles
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Interprets role-list input failures without publishing a role statement.

Recipient names are checked first. Role operands then report their problems in list order, continuing through later program statements. Only decoded diagnostic operands and byte positions escape; no parser tree is retained. Observed on MySQL 8.0.44, 8.4.7 and 9.1.0 through SQL.
