final class ClientEntry
Public API: explicitly declared with @visibility public.

Rejects grammar entries that cannot denote a client statement.

MySQL 5.6 and 5.7 refuse a leading PARTITION before inspecting its body. The refusal retains only its typed reason and the keyword's end offset. MySQL 5.7 refuses PARSE_GCOL_EXPR after its operands complete, retaining the keyword offset separately from that completion boundary. Observed on native 5.6.51 and 5.7.44 servers.

Identifies a legacy client entry inside an unfinished stored program.

A fixed valid partition body lets the parser identify the keyword's production despite a malformed original body. Only partition_entry is refused; the same keyword in a table clause keeps its ordinary meaning. The probe is never lowered, retained or executed.
