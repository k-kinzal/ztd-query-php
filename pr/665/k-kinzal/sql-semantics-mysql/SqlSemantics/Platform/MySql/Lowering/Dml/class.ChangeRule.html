final class ChangeRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Lowering". Code outside that scope must not name this declaration.

Lowers UPDATE and DELETE of every release.

Rule: MYSQL-CHANGE-LOWERING-001. Scope: update, delete, single_multi, table_wild_list, table_wild_one, delete_limit_clause (5.6); update_stmt, delete_stmt; opt_low_priority, opt_delete_options, opt_delete_option. An UPDATE is Update; a DELETE with one table after FROM is Delete; the two multiple-table spellings are MultipleDelete with their form. Clauses are lowered by the query family. Terminates: the parts are strict subtrees; option lists are flattened by MYSQL-DML-LIST-001. Source: https://dev.mysql.com/doc/refman/8.4/en/update.html, https://dev.mysql.com/doc/refman/8.4/en/delete.html, https://dev.mysql.com/doc/refman/5.6/en/delete.html. Status: Implemented.
