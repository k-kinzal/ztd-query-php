Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Interprets MySQL 5.6 native-call signature refusals at grammar completion.

No SQL or syntax node escapes. Argument aliases and counts are read without resolving argument values, preserving notices before an unfinished statement. Source: https://dev.mysql.com/doc/refman/8.4/en/function-resolution.html.
