final class InputTokens
Public API: explicitly declared with @visibility public.

Reads the tokenizable prefix before the first lexical failure.

An eager lexer may first report a later invalid byte. Each retry removes that suffix until the remaining prefix can be inspected. No source text or token is retained in a semantic structure.
