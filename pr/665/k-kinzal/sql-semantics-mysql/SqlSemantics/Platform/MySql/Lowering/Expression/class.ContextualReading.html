final class ContextualReading
Public API: explicitly declared with @visibility public.

Decodes temporal and system-variable leaves in their contextualization order.

Only typed values and input ranges escape. MySQL 5.6 reads these leaves in written order; later releases visit TRIM's subject and TIMESTAMPADD's date before the other operand. Grammar diagnostics remain a separate earlier phase.
