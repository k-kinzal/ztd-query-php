final class InputPrefix
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves completed condition and declaration operands before a rejected program value.

Prefix blocks contain only constructor-accepted operands. Existing program rules resolve condition scopes and declaration conflicts; binding failures that belong to later preparation do not displace the input rejection. Temporary parse nodes and frames never enter a published operation.
