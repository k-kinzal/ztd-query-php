final class SyntaxTableNames
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Refuses table-identity operands while preserving aliases with empty names. Table identities and open handler references use this rule. In particular, a multiple-DELETE target can name an empty alias through table_ident_opt_wild.
