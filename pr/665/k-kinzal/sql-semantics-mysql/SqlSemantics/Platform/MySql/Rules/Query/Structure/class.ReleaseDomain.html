Intersects release-specific interpretations retained in one semantic graph.

An ignored empty EXPLAIN destination means no assignment only in 8.2–8.3. An illegal destination survives routine definition only in 8.1–8.3. These meanings cannot coexist with later-only operands such as VECTOR. This checks language composition, independently of execution and catalog availability.
