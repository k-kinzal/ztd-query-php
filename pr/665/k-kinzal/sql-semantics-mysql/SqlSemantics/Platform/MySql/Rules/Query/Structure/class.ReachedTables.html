final class ReachedTables
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Defines the modifier domain of the common table expressions a statement reads.

The server prepares a common table expression when the statement references it, by its exact name, directly or through another common table expression it reads, and refuses HIGH_PRIORITY, SQL_BUFFER_RESULT, SQL_CALC_FOUND_ROWS and SQL_CACHE (ER_CANT_USE_OPTION_HERE) and ALL with DISTINCT (ER_WRONG_USAGE) in its blocks before any table is opened; a definition nobody references is read and left alone. Verified on MySQL 8.4.7: WITH c AS (SELECT HIGH_PRIORITY 1) SELECT * FROM c, missing_t -> 1234, WITH c AS (SELECT HIGH_PRIORITY 1) SELECT 2 and ... SELECT * FROM C are accepted, WITH c AS (SELECT HIGH_PRIORITY 1), d AS (SELECT * FROM c) SELECT * FROM d -> 1234, also in DELETE, UPDATE, INSERT ... WITH and inside a stored program body.
