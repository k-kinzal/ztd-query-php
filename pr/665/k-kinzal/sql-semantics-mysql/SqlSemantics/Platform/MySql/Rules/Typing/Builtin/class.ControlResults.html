public function branches(Invocation $call, list<int> $positions): list<Domain>
source§

Infers absent user-variable operands from the other result branches.

Explicitly initialized variables retain their recorded type. Each absent occurrence is inferred independently from the first other resolved branch, including a literal NULL; this does not create a session entry. The remaining branches take part only in the final aggregation of result types. Verified through SQL on MySQL 8.0.44, 8.4.7 and 9.1.0.
