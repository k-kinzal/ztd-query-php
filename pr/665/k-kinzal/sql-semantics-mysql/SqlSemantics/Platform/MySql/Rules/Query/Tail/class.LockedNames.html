final class LockedNames
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks the tables a locking clause names against the block it locks, independently of any context.

A bare OF name names a table of the FROM clause of the block by its correlation name or, when it has none, its table name, byte for byte (FROM t AS \T\ FOR UPDATE OF t is refused, OF T is accepted); a name no table carries is refused once the statement is read, before any table is opened (ER_UNRESOLVED_TABLE_LOCK), in every position and in a stored program body. A derived or JSON table named by OF, or a table two OF lists name, is locked twice (ER_DUPLICATE_TABLE_LOCK). A name qualified by a database is resolved with the tables (FROM t FOR UPDATE OF test.t opens test.t), so it stays with LockedTables, as do the clauses without OF, whose tables depend on which names are common table expressions, and the HIGH_PRIORITY lock of a query's first block. MySQL 5.6 and 5.7 name no tables in a locking clause. Verified on MySQL 8.4.7.
