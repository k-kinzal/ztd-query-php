final class GeneralWeights
Public API: explicitly declared with @visibility public.

The general_ci identity used by stored-program parameter names.

The mapping was sampled through WEIGHT_STRING for every valid BMP code point and compared on MySQL 5.6.51 and 8.4.7, without reading server implementation code. Case and accent variants can therefore denote the same parameter. Source: https://dev.mysql.com/doc/refman/8.4/en/charset-collation-effect.html.
