Derives replication vocabulary notices from retained semantic operands.

These notices belong to the statement's meaning even when a later condition prevents execution. MySQL 8.0 through 8.3 warn about each legacy occurrence; consumers need neither original input nor keyword inspection. Source: https://dev.mysql.com/doc/refman/8.0/en/replication-statements.html.
