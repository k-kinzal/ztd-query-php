final class TimeZoneOperands
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Distinguishes intrinsic literal roles in AT TIME ZONE from catalog-dependent operands.

A TIMESTAMP literal is accepted although its output field is DATETIME. Other non-null literals cannot denote a TIMESTAMP input. Parentheses retain that role. MIN/MAX preserve an argument's field family, not the special TIMESTAMP literal role. Unresolved names still require their resolved facts. Numeric and JSON aggregates, EXTRACT and GET_FORMAT cannot produce TIMESTAMP. TIMESTAMPADD produces date/time fields, not TIMESTAMP. A direct parameter is refused during native PREPARE, before any bound value can change its role. Verified through standalone and stored SQL on MySQL 8.0, 8.4 and 9.1.
