final class OutputFields
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves output storage independently of the logical types of parent expressions.

Strings computed over aggregates retain expression metadata until DISTINCT stores them. A parent of a grouped window remains computed after its window; ROLLUP keeps that parent outside DISTINCT storage too. Streaming GROUP_CONCAT retains its direct metadata until DISTINCT or a window stores it. Other bare aggregates use grouped fields unless implicit aggregation, constant grouping or direct ROLLUP emits them. Verified through SQL metadata on MySQL 8.4.

public function deferred(Select $select, ?Scalar $expression, ?Facts $facts = null): bool
source§

Tells whether an aggregate parent is computed after duplicate removal at a window stage. With varying group keys, aggregate parents are not DISTINCT keys; bare calls are. Without ROLLUP, parents of GROUP_CONCAT and JSON aggregates are deferred too. Constant ROLLUP groups store their parent outputs and compare them as keys. If no nonconstant keys remain, all input rows reach the deferred expressions. Verified through SQL on MySQL 8.4.
