final class OutputFields
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves output storage independently of the logical types of parent expressions.

Strings computed over aggregates retain expression metadata until DISTINCT stores them. A parent of a grouped window remains computed after its window; ROLLUP keeps that parent outside DISTINCT storage too. Bare aggregates use grouped fields unless direct ROLLUP emits them. Verified through SQL metadata on MySQL 8.4.
