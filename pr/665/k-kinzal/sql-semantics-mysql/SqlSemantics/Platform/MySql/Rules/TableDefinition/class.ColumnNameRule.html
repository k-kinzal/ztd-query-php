Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Tells which names MySQL accepts as the name of a table or view column.

Rule: MYSQL-COLUMN-NAME-001. A column name is not empty, does not end in a space character, and has at most 64 characters; the server reads the name up to its first NUL byte (check_column_name). Source: sql/table.cc of each release, https://dev.mysql.com/doc/refman/8.4/en/identifier-length.html, https://dev.mysql.com/doc/refman/8.4/en/identifiers.html. Status: Implemented.
