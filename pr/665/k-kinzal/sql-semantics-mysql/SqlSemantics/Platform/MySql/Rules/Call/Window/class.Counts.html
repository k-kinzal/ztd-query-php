final class Counts
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Constrains literal window counts without evaluating database or session state.

NTILE and NTH_VALUE require positive signed 64-bit integers. LEAD and LAG also admit zero. Parameters, variables and computations retain their own resolution and evaluation responsibilities. Native SQL observations cover these literal boundaries on MySQL 8.0.44, 8.4.7 and 9.1.0.
