final class QuantifiedAttributes
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Retains quantified-subquery NULL attributes independently of runtime truth. A fixed nonnullable projection can acquire an empty-input NULL attribute; nullable outputs and predicates with runtime effects retain the outer attribute. Verified using legacy and modern result metadata and populated query histories.
