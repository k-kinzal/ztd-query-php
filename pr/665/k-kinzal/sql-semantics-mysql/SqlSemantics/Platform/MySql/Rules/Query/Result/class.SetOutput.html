final class SetOutput
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves the externally returned fields of a set statement separately from its materialized query fields. MySQL 5.7 streams an unordered UNION ALL and reports strings as VARCHAR with unfixed decimals. A scalar or derived-table consumer instead reads the temporary column. Original operand facts retain the bounds before storage allocation and byte conversion. Verified with Testcontainers MySQL 5.7 through GROUP_CONCAT, nested unions and scalar consumers.
