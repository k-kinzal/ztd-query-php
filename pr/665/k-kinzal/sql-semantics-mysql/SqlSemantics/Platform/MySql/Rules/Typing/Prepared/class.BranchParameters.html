final class BranchParameters
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives modern prepared marker types from the other result branches. Integer branches provide BIGINT; text branches retain the preparation VARCHAR capacity in their collation. An all-NULL sibling set provides binary VARCHAR. Observed through prepared queries on MySQL 8.0, 8.4 and 9.1.
