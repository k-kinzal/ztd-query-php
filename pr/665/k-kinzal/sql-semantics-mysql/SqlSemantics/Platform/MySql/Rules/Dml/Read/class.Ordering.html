final class Ordering
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Identifies output positions in writes that have no select list.

Parentheses and unary plus preserve a bare integer's positional role. Other numeric expressions are ordinary ordering values. Catalog and row changes cannot give DELETE or UPDATE an output position to which an integer binds.
