final class CollationLookup
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves an expression collation in the release's preparation order.

MySQL 5.6 and 5.7 prepare the operand before looking up the collation and defer that lookup inside stored definitions. Later releases resolve a nonempty name while parsing, before operand preparation. Definition-level character set and collation names have their own rules.
