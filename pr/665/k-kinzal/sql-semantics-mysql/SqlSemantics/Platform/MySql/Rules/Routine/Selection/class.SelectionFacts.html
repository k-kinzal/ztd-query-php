final class SelectionFacts
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Binds a stored selection's complete clauses while retaining preparation conditions.

The ordinary projections establish aliases before grouping, HAVING and ordering. A deferred projection retains an invalid output slot and derives its operand without manufacturing a scalar expression. The program instruction retains its original operand and clause roles.
