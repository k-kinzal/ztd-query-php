final class RelationQualifiers
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Tells whether a qualifier of a column or a star names a visible relation.

Rule: MYSQL-RELATION-QUALIFIER-001. A qualifier names a relation by its alias when it has one, else by its table name. A database the qualifier writes must be the database of the table or view the relation reads, the current one when its name writes none, even under an alias; any database names a derived table, a common table expression and a table function. Database names compare as table names do. A context that names no current database (MYSQL-CURRENT-DATABASE-001) admits any database for an unqualified table. Verified on a live 8.4 server. Terminates: one comparison per relation. Source: https://dev.mysql.com/doc/refman/8.4/en/identifier-qualifiers.html. Status: Implemented.
