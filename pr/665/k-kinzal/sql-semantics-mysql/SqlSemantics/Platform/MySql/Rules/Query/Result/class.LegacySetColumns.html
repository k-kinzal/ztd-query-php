final class LegacySetColumns
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Settles legacy set fields in operand order, retaining column-reference facts.

Black-box 5.6.51 and 5.7.44 observations distinguish a leading expression's bound from later numeric storage bounds. A later computed DOUBLE contributes 53 characters to a text result; a referenced DOUBLE contributes its field width. FLOAT with a following BIGINT stays FLOAT, while the reverse order promotes to DOUBLE. No input SQL or parser structure is needed.
