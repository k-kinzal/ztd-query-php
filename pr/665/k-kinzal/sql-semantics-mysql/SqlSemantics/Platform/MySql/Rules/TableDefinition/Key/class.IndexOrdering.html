final class IndexOrdering
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Identifies index directions whose ignored interpretation belongs to MySQL 5.x.

MySQL 8.0 and later refuse explicit directions on FULLTEXT, SPATIAL and HASH indexes before opening referenced tables. Both 5.6 and 5.7 accept them. The release constraint composes with other retained operands, including modern functional keys, without resolving a table or choosing an execution engine. Verified through native SQL on 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0.
