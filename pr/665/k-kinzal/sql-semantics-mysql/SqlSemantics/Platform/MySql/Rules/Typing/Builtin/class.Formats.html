Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Rules\Typing". Code outside that scope must not name this declaration.

Resolves the results of the functions that take a format string: DATE_FORMAT, TIME_FORMAT and FROM_UNIXTIME write one, STR_TO_DATE reads one.

A format written as a string literal is read: each specifier counts as long as the longest text it writes, every other byte as one character; an empty format writes nothing. Any other format makes the result ten times as long as the format written as text. STR_TO_DATE gives a DATE, a TIME or a DATETIME by the specifiers of a literal format, with microseconds for %f, and a DATETIME(6) for a format that is no literal (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_date-format.
