final class TableIdentity
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Excludes empty table identities independently of whether the table exists.

The absent database qualifier denotes the session database. An explicit empty qualifier does not. Empty correlation names remain valid and never pass through this table-identity rule. Native servers reject these table names even in unexecuted procedure branches. Source: https://dev.mysql.com/doc/refman/8.4/en/identifiers.html.
