final class BodyAssignments
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves the autocommit assignment restriction in function and trigger bodies.

A routine parameter or block variable can shadow the unqualified name. Explicit @@ targets always denote the system variable. Password assignments carry the same body restriction. No values or database state are evaluated. Observed through SQL on MySQL 5.7.44 and 8.4.7.
