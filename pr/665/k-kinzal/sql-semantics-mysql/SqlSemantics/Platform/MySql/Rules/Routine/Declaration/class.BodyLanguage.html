final class BodyLanguage
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Relates a routine's effective language to its body representation.

SQL is the default. The last LANGUAGE characteristic wins, including an identifier spelling SQL in any letter case. SQL bodies contain instructions; external bodies contain opaque code. Observed on MySQL 8.1 through 9.1.
