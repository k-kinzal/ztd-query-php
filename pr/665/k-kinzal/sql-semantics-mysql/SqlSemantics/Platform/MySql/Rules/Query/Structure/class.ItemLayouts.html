Checks a projected expression's observable spelling at construction.

A layout spells the same tokens in the same grammatical roles under its declared language profile. It cannot replace an operand, introduce syntax through trivia, or hide several tokens in one slot. Parsing is local to validation: no SQL string, parser tree or parser object survives in the item. Naming and lexical correspondence are model invariants, independent of an execution engine, schema or runtime state.
