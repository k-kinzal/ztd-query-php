final class ColumnCollations
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Compares the character set a column type names with the collation its COLLATE attribute names.

Rule: MYSQL-COLUMN-COLLATIONS-001. A column written with both CHARACTER SET and COLLATE names a collation of that character set; the server refuses another pairing while reading the definition, even inside a stored program body (ER_COLLATION_CHARSET_MISMATCH; verified on 5.6.51, 5.7.44 and 8.4.7). A type without a named character set, or a COLLATE without a name, is compared later against the table or database default. Terminates: one pass over the attributes. Source: https://dev.mysql.com/doc/refman/8.4/en/charset-column.html. Status: Implemented.
