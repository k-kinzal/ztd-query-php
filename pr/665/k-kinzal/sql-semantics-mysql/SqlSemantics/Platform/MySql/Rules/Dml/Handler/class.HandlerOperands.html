Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Constrains HANDLER expressions independently of open handles and tables.

Subqueries have no interpretation in this command, even in an unselected branch. Stored functions are also excluded independently of routine existence. Source: https://dev.mysql.com/doc/refman/8.4/en/handler.html, https://dev.mysql.com/doc/refman/8.4/en/stored-program-restrictions.html.
