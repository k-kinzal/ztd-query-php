final class DateResults
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Rules\Typing". Code outside that scope must not name this declaration.

Resolves the results of date functions: DATE is a date, YEAR a year, each other part of a date or time a BIGINT as wide as its digits and a sign.

A function that gives a TIME or DATETIME keeps the fractional digits of its arguments (Seconds); the formatting functions are typed by their format (Formats); DAYNAME and MONTHNAME are as long as the longest name of the lc_time_names locale. MySQL 5.6 and 5.7 give several results other lengths, and YEAR is a BIGINT before 8.4 (verified on live 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0 servers).

Source: https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html.
