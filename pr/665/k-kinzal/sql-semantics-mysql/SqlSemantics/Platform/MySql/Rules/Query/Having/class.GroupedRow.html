Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

The entry of a HAVING environment that hands the select list and the GROUP BY columns to the names written there.

Rule: MYSQL-HAVING-REFERENCE-001 (see ResultReferences). The entry travels as a visible occurrence with neither alias nor name and without any column, so no column lookup, qualifier or star can reach it; only HavingScope and ResultReferences recognise it, by its class. It is a working value of one derivation and never part of a statement. Source: https://dev.mysql.com/doc/refman/8.4/en/select.html. Status: Implemented.
