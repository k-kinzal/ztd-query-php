final class Syntax
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks the intrinsic JSON document grammar of engine attributes.

A document contains one value and nests at most 100 arrays or objects. Errors identify a decoded operand byte, independently of SQL text or database state. The empty attribute is handled by Attribute, outside the JSON grammar. Observed through the MySQL 8.4.7 SQL interface. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html.
