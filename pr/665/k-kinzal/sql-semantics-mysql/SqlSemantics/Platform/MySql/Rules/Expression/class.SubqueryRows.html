Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives the value of a subquery used as an expression and the NULL fact of a test against its rows.

Rule: MYSQL-SUBQUERY-ROWS-001. A subquery used as a value yields the value of its one column, without the display width of the column, or a row of its columns, and NULL when it returns no row. An unreduced string scalar has no fixed fractional digits, including a column whose own metadata reports zero. A temporal expression reported as a string is read as text and retains its reported decimals, independently of the original evaluation kind. A direct GROUP_CONCAT result retains its fractional metadata (zero in MySQL 5.6 and 5.7, verified through SQL). A subquery with an unexpandable star depends on the inputs it misses. A membership or quantified test is NULL when the operand or a column of the subquery can be NULL. Multi-column membership is reported nullable even for constant non-NULL rows, as observed through PDO. A subquery whose columns are not known leaves that dependent. The width of the operand must equal the number of columns (MYSQL-OPERAND-COLUMNS-001). LIMIT is refused on the tested query blocks, including set branches, independently of limits inside derived tables or CTEs. Terminates: limit checks recurse only into strict query children. Source: https://dev.mysql.com/doc/refman/8.4/en/scalar-subqueries.html, https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html, https://dev.mysql.com/doc/refman/8.4/en/any-in-some-subqueries.html. Status: Implemented.
