final class DatabaseOptions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves names in database options before a database is opened or changed.

Only diagnostics and their ordered notices are produced; database state is untouched. Source: https://dev.mysql.com/doc/refman/8.4/en/charset-database.html.
