final class Generations
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Refuses query graphs whose features require disjoint grammar generations.

Rule: MYSQL-QUERY-GENERATIONS-001. PROCEDURE ANALYSE, SQL_CACHE and the legacy trailing-clause forms end before 8.0. WITH, VALUES, TABLE, window specifications, JSON_TABLE, QUALIFY, INTERSECT and EXCEPT start in 8.x or later. A graph containing both sets cannot belong to any supported release. This is a constructor invariant; it does not decide whether a statement executes or whether a particular release accepts every feature. Source: https://dev.mysql.com/doc/refman/8.4/en/mysql-nutshell.html, https://dev.mysql.com/doc/refman/8.0/en/with.html, https://dev.mysql.com/doc/refman/8.4/en/set-operations.html. Status: Implemented.
