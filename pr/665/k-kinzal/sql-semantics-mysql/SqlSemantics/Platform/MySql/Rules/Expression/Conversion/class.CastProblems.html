FLOAT accepts at most 53 bits and reports an overflowing request as a signed 32-bit integer. Temporal fractions accept at most 6 digits. Verified on MySQL 8.4.7.

public function array(CastTarget $target): ?string
source§

Answers the form the server refuses while it parses a cast to an array, or null when the type is one a multi-valued index takes.

A multi-valued index takes no character set, no BLOB, and none of JSON, the floating-point types, YEAR and the spatial types; the parse stops there, in any statement. A cast to another type is refused outside a functional index when the expression is resolved (ARRAY_OUTSIDE_INDEX), which these facts do not tell (verified on a live 8.4 server).
