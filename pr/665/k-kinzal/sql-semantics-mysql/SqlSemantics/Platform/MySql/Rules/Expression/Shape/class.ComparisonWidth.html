Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Retains the early condition of differently sized written row comparisons.

MySQL 5.7 and modern releases check the outer widths during contextualization of a completed statement. MySQL 5.6, nested row shapes, scalar/row pairs and subquery widths wait for preparation. Verified through ordinary SQL and stored definitions against all five release families.
