Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks generated-expression roles before ordinary scalar preparation.

Full-text search has a forbidden generation role before its search operand. Other child expressions complete before their enclosing function or query. A forbidden call inside a subquery therefore precedes that subquery's role refusal. This visits semantic operands only, independently of catalog state.
