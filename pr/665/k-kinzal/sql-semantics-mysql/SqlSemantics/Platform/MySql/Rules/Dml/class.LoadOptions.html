final class LoadOptions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Interprets LOAD option compatibility independently of table and file state.

MySQL 8.0 and 8.1 ignore bulk annotations. From 8.2, bulk loading excludes XML, column lists, assignments, LOCAL, nonempty LINES STARTING BY and IGNORE, in that order. The last STARTING BY option replaces earlier ones. A positive COUNT requires bulk loading; zero is the omitted-count interpretation in 8.2 and 8.3 and a syntax refusal from 8.4. Observed through Testcontainers. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html.
