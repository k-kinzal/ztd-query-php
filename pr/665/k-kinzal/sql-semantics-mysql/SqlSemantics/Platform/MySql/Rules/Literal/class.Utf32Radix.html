final class Utf32Radix
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Validates introduced UTF-32 hexadecimal and bit values after leading-unit padding.

Legacy releases allow surrogate code points; modern releases reject them. Quoted text has a different conversion rule and is not checked here. Native observations: MySQL 5.6.51, 5.7.44, 8.0.44, 8.4.7 and 9.1.0.
