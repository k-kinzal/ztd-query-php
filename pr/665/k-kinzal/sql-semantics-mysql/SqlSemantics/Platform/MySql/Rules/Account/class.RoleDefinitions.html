final class RoleDefinitions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Identifies role definitions that no account catalog can satisfy.

Conditional definitions can skip existing anonymous or repeated accounts. Unconditional definitions require distinct, nonanonymous account identities. User names compare exactly after trimming; host names compare without case, and an omitted host denotes %. Observed on MySQL 8.0, 8.4 and 9.1.
