final class TimeZoneFacts
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Uses existing type rules to identify results that cannot supply a TIMESTAMP field.

Catalog declarations, routine signatures and parameter bindings are absent. Unresolved facts remain unresolved. A rejection requires a non-TIMESTAMP result in every supported release with AT TIME ZONE; diagnostics and execution eligibility are not consulted. Coarse DATETIME families remain undecided because they can include a TIMESTAMP field.
