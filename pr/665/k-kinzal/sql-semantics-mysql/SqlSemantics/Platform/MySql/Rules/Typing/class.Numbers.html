final class Numbers
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves the types of arithmetic.

An operand takes part as an integer, a decimal or a double: a temporal value with fractional seconds is a decimal and one without is an integer, a string is a double. Integer arithmetic yields a BIGINT as wide as its operands allow; when an operand is a decimal or the operator divides, the result is a DECIMAL whose precision and scale follow from the operands, a division adding div_precision_increment digits to the scale of its dividend; any double makes the result a DOUBLE. An integer product has the digits of both operands, at most 65. Source: https://dev.mysql.com/doc/refman/8.4/en/arithmetic-functions.html, https://dev.mysql.com/doc/refman/8.4/en/precision-math-expressions.html.

public function quotient(Domain $left, Domain $right): Domain
source§

Resolves an integer division (DIV): a BIGINT as long as its dividend written without its fraction.

A temporal dividend counts its width, unless remainders count it by its length as MySQL 5.6 and 5.7 do. A divisor that is not an integer adds one character; the result is unsigned when either operand is. The result width is bounded by 22 characters (21 unsigned) from MySQL 8.0; a floating-point operand takes that full bound. MySQL 5.6 and 5.7 retain the dividend width, add nothing for the divisor, and cap every result at 21. Verified through PDO and Testcontainers.
