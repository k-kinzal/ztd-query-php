final class PathSyntax
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Interprets JSON path operands, with the byte boundaries exposed by MySQL.

It reads decoded operand values and never reads SQL source or a parser tree. Source: https://dev.mysql.com/doc/refman/8.4/en/json.html.
