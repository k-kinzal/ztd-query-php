final class AccountChecks
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives the diagnostics of the account clauses of CREATE USER, ALTER USER and GRANT.

Rule: MYSQL-ACCOUNT-CHECKS-001. A REQUIRE clause that names a property twice is RepeatedTlsAttribute (ER_DUP_ARGUMENT). PASSWORD EXPIRE INTERVAL takes 1 to 65535 days, FAILED_LOGIN_ATTEMPTS and PASSWORD_LOCK_TIME 0 to 32767, every other number of an option any integer (MYSQL-ACCOUNT-NUMBER-001). An ATTRIBUTE string that is not a JSON object is InvalidUserAttribute; the JSON text is read with the JSON grammar of RFC 8259, which the server also implements. A factor change names factors 2 or 3, two changes name different factors, and two ADDs add 2 before 3 (InvalidFactorPair). No type facts: the clauses hold no expressions. Terminates: one pass over each list. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html, https://dev.mysql.com/doc/refman/8.4/en/alter-user.html. Status: Implemented.
