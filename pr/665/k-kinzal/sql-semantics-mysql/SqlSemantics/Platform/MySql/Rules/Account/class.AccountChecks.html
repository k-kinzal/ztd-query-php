final class AccountChecks
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives the attribute diagnostic of CREATE USER and ALTER USER.

Rule: MYSQL-ACCOUNT-CHECKS-001. A REQUIRE clause that names a property twice is refused before construction. Numeric options retain their values; their integer-token and range conditions are derived here. An ATTRIBUTE string that is not a JSON object is InvalidUserAttribute; the JSON text is read with the JSON grammar of RFC 8259, which the server also implements. The clause holds no expressions and contributes no type facts. Terminates: one bounded JSON decode. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html, https://dev.mysql.com/doc/refman/8.4/en/alter-user.html. Status: Implemented.
