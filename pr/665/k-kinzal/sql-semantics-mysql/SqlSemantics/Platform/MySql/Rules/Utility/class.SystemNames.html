final class SystemNames
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Shared name rules for a system-variable read and an assignment target.

Rule: MYSQL-SYSTEM-NAMES-001. MySQL 5.x resolves the name after an instance independently; later releases resolve the whole component name. Key-cache parameters are structured in every release. Assignment and read occurrences keep distinct diagnostics. Rendering writes the same qualified name for both roles. Source: https://dev.mysql.com/doc/refman/8.4/en/structured-system-variables.html. Status: Implemented.
