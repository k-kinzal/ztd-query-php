final class QueryColumns
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Column positions determined by query values without catalog declarations.

Null for the whole list means that its width depends on a relation declaration. A null member has a fixed position but a session-dependent output name. Common tables are evaluated in lexical order; a recursive reference uses the anchor's columns instead of recursively expanding its own definition.
