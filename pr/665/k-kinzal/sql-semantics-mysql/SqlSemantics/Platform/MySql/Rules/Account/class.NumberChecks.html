Checks the numbers of account statements against the ranges the server's grammar actions enforce.

Rule: MYSQL-ACCOUNT-NUMBER-001. A numeral is an integer when it is written with digits only or as a hexadecimal literal; its value is computed exactly in decimal digits, without a PHP integer or float. A decimal or floating number at an integer position (real_ulong_num through dec_num_error) is NumberOutOfRange with ER_ONLY_INTEGERS_ALLOWED; an integer outside the range of its option is NumberOutOfRange with ER_WRONG_VALUE. Precision: exact. Terminates: one pass over the digits. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html#create-user-password-management, https://dev.mysql.com/doc/refman/8.4/en/number-literals.html. Status: Implemented.
