final class TransactionStatements
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Identifies DDL instructions excluded from function and trigger bodies.

Temporary CREATE/DROP TABLE remain legal body instructions. Storage DDL, permanent table DDL, database DDL and account DDL are refused even in an unreachable branch. SET DEFAULT ROLE and INSTALL COMPONENT do not have this declaration restriction. Observed through SQL on MySQL 5.7, 8.0, 8.4 and 9.1.
