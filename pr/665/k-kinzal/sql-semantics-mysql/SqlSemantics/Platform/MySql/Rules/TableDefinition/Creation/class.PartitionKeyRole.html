final class PartitionKeyRole
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks whether a completely written declaration can supply implicit KEY columns.

This is a relation between definition operands, independent of destination existence. Conditional creation may skip it, so a missing key is retained by a complete creation instruction instead of an ordinary table declaration.
