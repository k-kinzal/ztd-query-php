final class MergeDependencies
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Keeps assignments and dependent selected subqueries behind a materialization boundary.

Scalar wrappers eliminated by the release's reduction rules are inspected as their selected expression. An independent subquery can remain in a merged projection; a retained subquery reading an outer column cannot. Verified through SQL and EXPLAIN on MySQL 8.4, with legacy correlated-column metadata from Testcontainers. Source: https://dev.mysql.com/doc/refman/8.4/en/derived-table-optimization.html.
