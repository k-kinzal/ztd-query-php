final class NamedConstant
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves NAME_CONST's literal argument restrictions before execution.

Its name accepts literal constants. Its value accepts a literal, optionally negated or collated once. Bare boolean values are accepted in MySQL 5.x and refused in modern releases; MySQL 9.1 also accepts a negated or collated boolean value. A NULL name is reserved syntax; other invalid argument forms have error 1210. Source: https://dev.mysql.com/doc/refman/8.4/en/miscellaneous-functions.html#function_name-const.
