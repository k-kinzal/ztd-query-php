final class PartitionExpressions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves a partition expression and records restrictions checked before the table is opened.

Variables, clocks, stored calls and functions that read or change session or external state are rejected at this stage. Other restrictions on the permitted partition functions are checked after table resolution; even a constant or VERSION() reaches that later stage. Source: https://dev.mysql.com/doc/refman/8.4/en/partitioning-limitations.html. Verified with ALTER TABLE of an absent table on MySQL 8.4.7.
