source§

Answers the first definition condition, the instruction it is found at, and whether reading stops there.

Declaration-input conditions precede completed-body restrictions. The server finds most conditions while parsing the instruction; the body-wide restrictions of functions and triggers and a missing RETURN are found once the whole body is read.
