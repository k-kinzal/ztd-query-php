final class BodyConditions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives definition-time conditions without discarding a complete instruction body.

The same typed operands are checked for parsed and directly constructed declarations. Input sources order and format notices but never supply missing SQL meaning. Source: https://dev.mysql.com/doc/refman/8.4/en/stored-program-restrictions.html.
