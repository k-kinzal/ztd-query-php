final class GeohashResults
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Rules\Typing". Code outside that scope must not name this declaration.

Resolves geohash result domains and argument type constraints before evaluation.

Binary strings are geometry payloads, not geohash text. Lengths and reference identifiers accept integers and character strings, but not real or decimal domains, even when their runtime value is NULL. Verified on MySQL 5.7 and 8.4. Source: https://dev.mysql.com/doc/refman/8.4/en/spatial-geohash-functions.html.
