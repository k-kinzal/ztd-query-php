final class TableDefinitionText
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Writes a CREATE TABLE definition, for the executable statement and for its stored form alike.

Rule: MYSQL-TABLE-DEFINITION-TEXT-001. The header, the element list in parentheses when there is one, the options with their written commas, the partitioning and the query follow in that order; the 5.x enclosed form writes the partitioning inside the parenthesis that opens the query. Terminates: one pass over the operands. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html. Status: Implemented.
