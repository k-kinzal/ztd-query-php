final class ParameterInference
Public API: explicitly declared with @visibility public.

The initial marker domains of a prepared statement, derived from semantic facts.

Arithmetic and comparison markers inherit their sibling's domain, widening integers to BIGINT and decimals to DECIMAL(65,30). An unresolved arithmetic subtree receives its enclosing numeric context before falling back to DOUBLE; integer division defaults to BIGINT. CASE and control-function result branches supply the other branch types. A NULL sibling supplies binary VARCHAR; binding a numeric value can then trigger automatic repreparation. CAST records that its argument is fixed against automatic repreparation. Other positions retain their supplied preparation domain. Consumers retain these domains between executions and supply them as parameter settings when resolving again.

This rule inspects neither source text nor parser nodes. Source: https://dev.mysql.com/doc/refman/8.4/en/prepare.html.
