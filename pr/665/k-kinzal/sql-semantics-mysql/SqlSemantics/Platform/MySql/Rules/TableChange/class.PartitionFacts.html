Derives the partitioning of a table for the statement that holds it.

Rule: MYSQL-PARTITION-FACTS-001. The entry the table definition family calls for CREATE TABLE … PARTITION BY: the partitioning functions and columns are derived in the scope of the partitioned table, the partition values as constants (MYSQL-PARTITIONING-001).
