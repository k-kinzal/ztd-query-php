final class ReadColumns
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Intrinsic column constraints of a query used for reading.

Query bodies are also templates for unused CTEs and stored instructions, and VALUES can supply INSERT defaults. These constraints belong to their read positions, independently of a catalog or execution eligibility judgement.
