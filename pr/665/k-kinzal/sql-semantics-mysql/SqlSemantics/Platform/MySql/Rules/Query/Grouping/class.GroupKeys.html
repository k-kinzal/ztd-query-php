final class GroupKeys
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Distinguishes an implicit or constant group from groups partitioned by input rows.

Constant keys do not require stored aggregate result fields. ROLLUP still adds levels, but only varying keys defer aggregate parents beyond a window's DISTINCT. Column aliases use their resolved targets; calls with per-read effects and variables assigned by the statement remain varying. Verified through SQL and PDO on MySQL 8.4.
