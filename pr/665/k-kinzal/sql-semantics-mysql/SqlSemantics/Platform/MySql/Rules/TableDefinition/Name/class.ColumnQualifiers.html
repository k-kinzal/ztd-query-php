final class ColumnQualifiers
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Relates legacy definition-name qualifiers to the table being defined or changed.

Different written table names, or different explicit database names, cannot identify one definition target. Case-only differences remain conditional on the context's name comparison. An omitted target database is resolved from that context; it is not an intrinsic contradiction. Native MySQL 5.6 and 5.7 reject mismatches even in unexecuted stored-program branches. Source: https://dev.mysql.com/doc/refman/5.7/en/identifier-qualifiers.html.
