final class ReturnCollation
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Distinguishes implicit return collations from complete character-set declarations.

A non-national character return with BINARY alone has no resolved return collation on any supported release. National types become defined on MySQL 8. Legacy character returns also refuse BINARY with a named character set; ASCII uses its fixed collation. ENUM and SET retain their own binary attribute semantics and do not share the character-type refusal.

Resolves the return collation from its declaration and the definition's database default. ENUM and SET ignore BINARY alone in a return declaration; a named set with the binary attribute retains its ordering from MySQL 8. Legacy named character sets ignore that mark.
