Derives the facts of LOAD DATA and LOAD XML.

Rule: MYSQL-LOAD-001. The table is resolved like the table of INSERT (MYSQL-DML-TARGET-001) and is the one visible relation of the column list and of the SET assignments. Input user variables introduce string reads before SET expressions are resolved. Existing entries retain their assignment collation during preparation from 5.7; absent entries and 5.6 use the file charset. A SET value may refer to columns and user variables; the value DEFAULT is the default of its column. The file is read by the server or the client and is not examined. The statement returns no rows. Terminates: one pass over the finite lists. Source: https://dev.mysql.com/doc/refman/8.4/en/load-data.html, https://dev.mysql.com/doc/refman/8.4/en/load-xml.html. Status: Implemented.

public function variables(LoadTable $load, Derivation $derivation): void
source§

Resolves file-input variables before the SET expressions that read them. These occurrences read strings even if an entry previously held a number. Their prepared collation is the preceding assignment collation for existing entries and the file charset for new entries. Loading a record updates the runtime entry separately. MySQL 5.6 resolves all these reads in the file charset. This derivation does not assign a session value.
