Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

The shared domain of column, index, table and tablespace engine attributes.

An empty quoted string resets the attribute. Every nonempty string denotes a complete JSON value with finite numbers and at most 100 container levels. These conditions are published on the complete definition, including unreachable program instructions, independently of storage state. Observed on MySQL 8.4.7.
