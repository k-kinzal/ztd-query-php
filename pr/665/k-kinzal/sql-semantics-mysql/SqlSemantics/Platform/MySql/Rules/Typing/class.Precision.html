Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Reads the resolved types of operands from their type facts.

An operand has a resolved type when its fact is a domain, or NULL itself. An expression resolves precisely only when every operand does; otherwise its fact keeps the class of its type.
