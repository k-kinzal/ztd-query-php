final class SetEncoding
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Resolves explicitly named SET encodings before preparing assignment values.

Unknown names stop grammar interpretation, including inside an unexecuted stored instruction. A collation of another character set than the named one is refused while reading, in every release and inside stored program bodies (ER_COLLATION_CHARSET_MISMATCH); SetNames refuses such a pair as an invariant. DEFAULT and client-variable assignments retain their session-dependent checks. Observed on MySQL 5.6.51, 5.7.44 and 8.4.7. Source: https://dev.mysql.com/doc/refman/8.4/en/set-names.html.
