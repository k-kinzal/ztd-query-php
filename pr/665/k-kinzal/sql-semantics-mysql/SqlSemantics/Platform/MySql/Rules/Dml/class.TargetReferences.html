final class TargetReferences
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks whether DELETE targets can name occurrences in the input relation.

An alias hides the table name and cannot be database-qualified. For an unaliased table, an omitted database and case comparison remain session or instance constraints. Only a name with no possible occurrence is rejected. Nested query tables never enter the containing statement's target namespace.
