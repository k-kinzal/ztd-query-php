final class Structure
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Identifies UPDATE contradictions independent of catalog and session state.

A derived, JSON or local common table cannot be an update destination. Joined input can still supply values while assignments target physical tables. Unknown columns and ambiguous names remain resolution dependencies. Stored instructions retain these complete operands until invocation.
