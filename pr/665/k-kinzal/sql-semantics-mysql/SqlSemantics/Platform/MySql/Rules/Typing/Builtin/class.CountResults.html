final class CountResults
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql\Rules\Typing". Code outside that scope must not name this declaration.

Resolves the results of functions that count or locate: a BIGINT of the display length each reports.

GROUPING() is a BIGINT of 21 digits, verified on a live 8.4 server. BIT_COUNT() is a BIGINT of 21 digits (of 2 in MySQL 5.6 and 5.7, verified on a live 5.7.44 server), INTERVAL() a BIGINT of 2 and CRC32() an unsigned BIGINT of 10 (verified on a live 8.4 server). Source: https://dev.mysql.com/doc/refman/8.4/en/string-functions.html, https://dev.mysql.com/doc/refman/8.4/en/miscellaneous-functions.html#function_grouping, https://dev.mysql.com/doc/refman/8.4/en/mathematical-functions.html.
