final class ChannelName
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

The decoded name domain shared by every FOR CHANNEL operand.

Channel names are quoted text whose NUL-terminated name contains no LF. Empty names identify the default channel. Input lowering reports a typed refusal before publishing a statement. Source: https://dev.mysql.com/doc/refman/8.4/en/replication-channels.html.
