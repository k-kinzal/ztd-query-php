final class AccountNames
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

The user-character and host-byte domains of account operands.

MySQL 5.6 accepts 16 user characters and 60 host bytes; 5.7 accepts 32 and 60; modern releases accept 32 and 255. An explicit host in 5.6 makes both original operands subject to the limit before trimming. Other forms check trimmed operands. Host names cannot contain an at sign. Observed through account and DEFINER statements on isolated native servers.
