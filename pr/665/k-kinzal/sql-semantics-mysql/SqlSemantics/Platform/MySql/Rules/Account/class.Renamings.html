final class Renamings
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Checks the consistency of the account identities in an ordered rename list.

Each pair requires its source identity and excludes its destination identity. Earlier pairs establish the identities available to later pairs. CURRENT_USER can alias any written identity or a distinct one; its original account need not still exist. Both fixed legacy identity and following modern identity are considered. A list is contradictory only if neither interpretation admits consistent account identities. This does not resolve an account catalog.
