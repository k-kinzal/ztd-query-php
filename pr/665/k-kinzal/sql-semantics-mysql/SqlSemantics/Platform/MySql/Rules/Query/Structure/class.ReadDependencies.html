final class ReadDependencies
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Follows lexical CTE dependencies without consulting a catalog or execution state.

A definition sees earlier definitions and its enclosing scope; RECURSIVE also exposes its own name. Only references reached from the body activate a CTE.
