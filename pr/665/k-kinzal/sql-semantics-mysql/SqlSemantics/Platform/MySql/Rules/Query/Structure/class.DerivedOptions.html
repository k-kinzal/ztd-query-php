final class DerivedOptions
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Defines the modifier domain of the query blocks forming a derived table.

HIGH_PRIORITY, SQL_BUFFER_RESULT, SQL_CALC_FOUND_ROWS and legacy SQL_CACHE cannot occur in these blocks, including later set operands and uncalled stored definitions. Nested expressions and CTE declarations have their own query boundaries. Verified through SQL on MySQL 5.6, 5.7, 8.0 and 8.4.
