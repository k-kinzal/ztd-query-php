final class QueryColumns
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Infers declarations for computed CREATE TABLE ... SELECT fields from resolved types.

These are semantic column values, independent of SQL spelling and session quote modes. Direct input columns can instead retain their declared defaults and types. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table-select.html.
