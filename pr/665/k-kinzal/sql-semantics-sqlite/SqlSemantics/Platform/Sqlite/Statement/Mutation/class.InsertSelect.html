An INSERT of the rows a query returns.

Rule: SQLITE-INSERT-SELECT-001. The facts follow SQLITE-INSERT-001 with the query as the source of the rows. A bare VALUES clause is not this statement but an insert of written rows. Source: https://sqlite.org/lang_insert.html. Status: Implemented.
