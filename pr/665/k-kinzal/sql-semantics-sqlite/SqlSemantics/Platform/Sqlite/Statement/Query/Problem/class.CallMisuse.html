Public API: explicitly declared with @visibility public.

A call of a built-in function with a clause its kind of function does not take.

A window-only function needs OVER, a scalar function takes neither OVER nor FILTER nor an argument ordering, a window takes no DISTINCT, and a DISTINCT aggregate takes exactly one argument.
