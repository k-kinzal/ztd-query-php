final class MutationTarget
    implements NamedRelation
    uses Snapshot
Public API: explicitly declared with @visibility public.

The table a data change statement writes to, with its optional correlation name and index choice.

Rule: SQLITE-MUTATION-TARGET-001. The name denotes a declared relation found along the schema search path; a common table of that name is never the target. The shape follows SQLITE-TABLE-SHAPE-001. Source: https://sqlite.org/lang_insert.html, https://sqlite.org/lang_update.html, https://sqlite.org/lang_delete.html. Status: Implemented.
