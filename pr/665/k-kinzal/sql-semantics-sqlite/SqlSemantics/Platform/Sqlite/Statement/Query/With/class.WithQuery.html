A query with its own WITH clause.

Rule: SQLITE-WITH-QUERY-001. The common tables are bound by SQLITE-COMMON-TABLE-001 and are visible in the body and in every query nested in it. The output is that of the body. Source: https://sqlite.org/lang_with.html. Status: Implemented.
