interface ColumnConstraint
    extends Node
Public API: explicitly declared with @visibility public.

One clause written after the name and type of a column, in written order.

The closed set is: a constraint name, a default, NULL, NOT NULL, PRIMARY KEY, UNIQUE, CHECK, a REFERENCES clause, a DEFERRABLE clause, a collation and a generated column expression. Source: https://sqlite.org/syntax/column-constraint.html.
