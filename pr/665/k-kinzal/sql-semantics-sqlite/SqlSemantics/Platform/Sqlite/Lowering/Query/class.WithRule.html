Lowers WITH clauses.

Rule: SQLITE-WITH-LOWER-001. Scope: with, wqlist, wqitem, wqas, withnm. The common table expressions keep their written order, column lists and materialization hints. Terminates: the list is flattened iteratively. Source: https://sqlite.org/lang_with.html. Status: Implemented.
