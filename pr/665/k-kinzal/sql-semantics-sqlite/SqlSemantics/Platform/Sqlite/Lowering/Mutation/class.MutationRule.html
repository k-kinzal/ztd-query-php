final class MutationRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers INSERT, UPDATE and DELETE.

Rule: SQLITE-MUTATION-LOWER-001. Scope: the cmd productions of DELETE, UPDATE and INSERT; insert_cmd, xfullname, setlist, where_opt_ret, returning. An INSERT whose source is a bare VALUES clause is an insert of written rows, any other source an insert of a query, DEFAULT VALUES an insert of defaults. Assignments keep their written order and whether the column is written as a parenthesised list. Terminates: the assignment list is walked along its spine in a loop. Source: https://sqlite.org/lang_insert.html, https://sqlite.org/lang_update.html, https://sqlite.org/lang_delete.html. Status: Implemented.
