final class TransactionRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers transaction control commands.

Rule: SQLITE-TRANSACTION-LOWER-001. Scope: the cmd productions of BEGIN, COMMIT, END, ROLLBACK, SAVEPOINT and RELEASE, with transtype, trans_opt and savepoint_opt. Constructors: Begin, Commit, Rollback, RollbackTo, Savepoint, Release. The behavior word and every name are kept; the keywords COMMIT and END, a bare TRANSACTION and the SAVEPOINT before a savepoint name are declared noise. No fact is derived and no diagnostic is emitted. Terminates: every production has a fixed number of children. Source: https://sqlite.org/lang_transaction.html, https://sqlite.org/lang_savepoint.html. Status: Implemented.
