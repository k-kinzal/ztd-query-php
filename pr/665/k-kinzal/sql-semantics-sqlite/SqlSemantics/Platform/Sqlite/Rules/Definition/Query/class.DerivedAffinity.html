final class DerivedAffinity
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

The affinity SQLite derives for a result expression; a working value of one derivation.

SQLite keeps two states besides the five affinities: no affinity at all (SQLITE_AFF_NONE, the affinity of a literal or an operator), and the flexible numeric affinity (SQLITE_AFF_FLEXNUM) a CAST gets in a compound query, which counts as numeric but never equals the affinity of a type name. An affinity is not determined when it depends on a declaration the context lacks or on a name that did not resolve.
