final class SortScopes
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Derives ORDER BY and GROUP BY terms in the environment SQLite resolves each of them in.

Rule: SQLITE-SORT-SCOPE-001. An integer constant denotes the result column at that position (SQLITE-OUTPUT-ORDINAL-001). In ORDER BY, a term that is one unqualified word, possibly in parentheses or under COLLATE, and equals a result column alias denotes that result column before any input column of the same name. Every other term is an expression over the input columns, in which a result column alias is used when no input column has the name, and is a single value (SQLITE-ROW-VALUE-USE-001). Terminates: one pass over the terms. Source: https://sqlite.org/lang_select.html#the_order_by_clause. Status: Implemented.
