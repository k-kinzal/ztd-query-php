final class ArrayConstructor
    implements Scalar, OutputNaming
    uses Snapshot
Public API: explicitly declared with @visibility public.

An array built from values: ARRAY[a, b], ARRAY[[a, b], [c, d]].

Mirrors PostgreSQL's A_ArrayExpr node.

Rule: PG-ARRAY-CONSTRUCTOR-001. Facts: an array of the common type of the values (PG-UNIFICATION-001; unknown-typed values give text); values that are arrays, and sub-arrays, make a multidimensional array of the same type; an empty array has no element type of its own, which a cast supplies; the array is never NULL. An unaliased result column is named array. Source: https://www.postgresql.org/docs/17/sql-expressions.html#SQL-SYNTAX-ARRAY-CONSTRUCTORS. Status: Implemented.
