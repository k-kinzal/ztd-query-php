XMLROOT (value, VERSION {version | NO VALUE} [, STANDALONE {YES | NO | NO VALUE}]): an XML value with a new root declaration.

Mirrors PostgreSQL's XmlExpr of kind IS_XMLROOT. Rule: PG-XMLROOT-001. Facts: xml; NULL exactly when the value is. The result column is named xmlroot. Source: https://www.postgresql.org/docs/17/functions-xml.html#FUNCTIONS-PRODUCING-XML-XMLROOT. Status: Implemented.
