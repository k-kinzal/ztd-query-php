What a foreign key does when a referenced row changes.

Mirrors the FKCONSTR_ACTION_* codes. NO ACTION is the default and is kept when written. Source: https://www.postgresql.org/docs/17/sql-createtable.html#SQL-CREATETABLE-PARMS-REFERENCES.
