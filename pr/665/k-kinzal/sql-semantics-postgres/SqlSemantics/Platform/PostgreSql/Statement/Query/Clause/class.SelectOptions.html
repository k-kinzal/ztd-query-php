Public API: explicitly declared with @visibility public.

The ORDER BY, LIMIT, OFFSET, FETCH and locking clauses written after a query body.

Mirrors the sortClause, limitOffset, limitCount, limitOption and lockingClause that PostgreSQL attaches to a SelectStmt. The locking clauses may be written before or after the limit; the order is kept. FOR READ ONLY requests no lock. An integer constant in ORDER BY is an output position and must be given as one. Source: https://www.postgresql.org/docs/17/sql-select.html.
