interface SchemaElement
    extends Statement
Public API: explicitly declared with @visibility public.

A statement that CREATE SCHEMA may contain: CREATE TABLE, CREATE INDEX, CREATE SEQUENCE, CREATE TRIGGER or CREATE VIEW.

Inside CREATE SCHEMA, an unqualified object (or the unqualified table of CREATE INDEX and CREATE TRIGGER) belongs to the schema being created; a different written schema is an error the containing statement reports. Source: https://www.postgresql.org/docs/17/sql-createschema.html.
