interface RoleOption
    extends Node
Public API: explicitly declared with @visibility public.

One option of CREATE ROLE or ALTER ROLE.

Mirrors the DefElem the grammar builds for CreateOptRoleElem and AlterOptRoleElem. Several spellings fill the same option of the server (LOGIN and NOLOGIN both fill canlogin), and an option filled twice is rejected, so every option tells which one it fills. Source: https://www.postgresql.org/docs/17/sql-createrole.html.
