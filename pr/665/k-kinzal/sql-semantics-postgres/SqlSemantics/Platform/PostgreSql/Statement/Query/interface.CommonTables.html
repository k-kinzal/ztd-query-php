interface CommonTables
    extends Node
Public API: explicitly declared with @visibility public.

A WITH clause: the common table expressions a query or a data-modifying statement can refer to.

Mirrors PostgreSQL's WithClause node. The statement that holds the clause derives it once and evaluates its own parts in the environment the clause answers, where the common tables are visible. Source: https://www.postgresql.org/docs/17/queries-with.html.
