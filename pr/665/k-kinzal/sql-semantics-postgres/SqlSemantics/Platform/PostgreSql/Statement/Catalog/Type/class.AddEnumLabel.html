A request to add a label to an enum type: ALTER TYPE name ADD VALUE [ IF NOT EXISTS ] 'label' [ BEFORE | AFTER 'label' ].

Rule: PG-TYPE-ENUM-002. Mirrors AlterEnumStmt with newVal, newValNeighbor, newValIsAfter and skipIfNewValExists. A label longer than 63 bytes is a diagnostic. Source: https://www.postgresql.org/docs/17/sql-altertype.html. Status: Implemented.
