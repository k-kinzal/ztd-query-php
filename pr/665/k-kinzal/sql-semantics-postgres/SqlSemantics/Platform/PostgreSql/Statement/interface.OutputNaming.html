interface OutputNaming
Public API: explicitly declared with @visibility public.

An expression that gives a result column its name when the column has no alias.

PostgreSQL names an unaliased result column after the expression: a column reference after its column, a function call after the function, a cast after its type, and so on; every other expression is named ?column?. Source: https://www.postgresql.org/docs/17/sql-select.html#SQL-SELECT-LIST.
