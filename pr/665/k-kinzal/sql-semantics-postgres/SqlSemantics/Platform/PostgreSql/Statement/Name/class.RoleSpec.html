Public API: explicitly declared with @visibility public.

A role named directly, or designated as PUBLIC, CURRENT_ROLE, CURRENT_USER or SESSION_USER.

Mirrors PostgreSQL's RoleSpec node. The word public designates every role whether or not it is quoted, and none is reserved, so neither can be the name of a named role. Source: https://www.postgresql.org/docs/17/sql-grant.html, https://www.postgresql.org/docs/17/sql-createrole.html.
