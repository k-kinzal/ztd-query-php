A request to empty tables.

Mirrors PostgreSQL's TruncateStmt (relations, restart_seqs, behavior). Each table is resolved (PG- TABLE-TARGET-001) and is the relation fact of its reference; a view, a materialized view or a sequence is not a table (truncate_check_rel; PG-RELATION-KIND-001), and a foreign table depends on its wrapper. The optional TABLE word is not kept; CONTINUE IDENTITY is the default and is kept when written. Source: https://www.postgresql.org/docs/17/sql-truncate.html.
