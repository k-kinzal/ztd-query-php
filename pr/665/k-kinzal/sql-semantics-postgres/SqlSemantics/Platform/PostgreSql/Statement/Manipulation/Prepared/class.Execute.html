EXECUTE: a run of a prepared statement with values for its parameters.

Mirrors PostgreSQL's ExecuteStmt (name, params). Rule: PG-EXECUTE-001. The values are derived in the empty environment. The prepared statement is session state, so the rows returned are an open shape that depends on it. Source: https://www.postgresql.org/docs/17/sql-execute.html. Status: Implemented.
