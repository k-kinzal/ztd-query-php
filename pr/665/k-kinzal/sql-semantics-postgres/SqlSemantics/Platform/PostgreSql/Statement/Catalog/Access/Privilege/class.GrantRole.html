A request to make roles members of other roles.

Rule: PG-GRANT-ROLE-001. Mirrors GrantRoleStmt with is_grant: the granted roles, the member roles, the membership options of WITH and GRANTED BY. The grammar reads the granted roles as a privilege list, so a granted role may carry a column list or be spelled with a privilege keyword; a column list is reported, as are an option name the server does not recognize and PUBLIC as a granted role, member or grantor (PG-MEMBERSHIP-CHECK-001). Source: https://www.postgresql.org/docs/17/sql-grant.html#SQL-GRANT-DESCRIPTION-ROLES. Status: Implemented.
