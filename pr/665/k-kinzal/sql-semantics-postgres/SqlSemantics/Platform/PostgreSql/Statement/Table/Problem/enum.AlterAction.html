enum AlterAction: string
Public API: explicitly declared with @visibility public.

An ALTER TABLE action as the server names it when the relation kind does not accept it.

Mirrors alter_table_type_to_string in tablecmds.c, which names SET ( attribute options ) and the SET options of an identity column alike.
