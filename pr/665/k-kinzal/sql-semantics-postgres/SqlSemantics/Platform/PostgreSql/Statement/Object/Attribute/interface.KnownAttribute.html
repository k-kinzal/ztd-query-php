interface KnownAttribute
Public API: explicitly declared with @visibility public.

An attribute name a command recognizes, with the way the command reads its value.

Each command compares the attribute names with the names it knows, respecting case; an unquoted name is folded to lower case first. Each command has its own set: the cases of the enum for that command. Source: https://www.postgresql.org/docs/17/sql-createoperator.html, DefineOperator in src/backend/commands/operatorcmds.c of PostgreSQL 17.
