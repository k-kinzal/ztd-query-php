Public API: explicitly declared with @visibility public.

One named option of a definition or storage-parameter list: name, name = value or namespace.name = value.

Mirrors PostgreSQL's DefElem node as def_elem and reloption_elem write it. An option without a value is the option given alone, which most commands read as true. Source: https://www.postgresql.org/docs/17/sql-createtable.html#SQL-CREATETABLE-STORAGE-PARAMETERS.
