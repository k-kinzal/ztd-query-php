Spells a decoded PostgreSQL name so that it decodes to the same name at its position.

Rule: PG-NAME-CODEC-001. A name is written without quotes only when it is a lower-case word of ASCII letters, digits, _ and $ that does not start with a digit or $, and the grammar reads that word as a name at the position: a keyword must belong to a category the position accepts. Anything else is written between double quotes with each quote doubled, which the server reads literally. The empty name, a name containing a zero byte and a name longer than the server stores cannot be spelled and are rejected. Source: https://www.postgresql.org/docs/17/sql-syntax-lexical.html#SQL-SYNTAX-IDENTIFIERS. Status: Implemented.
