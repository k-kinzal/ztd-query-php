final class Spelling
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Writes the spellings several PostgreSQL structure values share.

Rule: PG-SPELLING-001. A string constant is written between single quotes with each quote doubled, which reads back as the same value under standard_conforming_strings = on. A dotted name writes its first part where the grammar reads a ColId and every later part where it reads a ColLabel. Source: https://www.postgresql.org/docs/17/sql-syntax-lexical.html. Status: Implemented.
