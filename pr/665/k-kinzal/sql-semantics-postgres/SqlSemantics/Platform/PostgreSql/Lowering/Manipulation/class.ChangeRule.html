final class ChangeRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers UPDATE and DELETE, and the clauses the data-modifying statements share.

Rule: PG-CHANGE-LOWER-001. Scope: UpdateStmt, DeleteStmt, using_clause, set_clause_list, set_clause, set_target, set_target_list, relation_expr_opt_alias, where_or_current_clause, returning_clause, cursor_name. Constructors: Update, Delete, TargetTable, Assignment, RowAssignment, ColumnTarget, CurrentOf. The AS before a correlation name is optional. Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-update.html, https://www.postgresql.org/docs/17/sql-delete.html. Status: Implemented.
