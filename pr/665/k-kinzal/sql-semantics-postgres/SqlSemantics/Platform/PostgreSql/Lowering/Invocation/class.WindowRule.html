final class WindowRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\PostgreSql\Lowering". Code outside that scope must not name this declaration.

Lowers OVER clauses and window specifications.

Rule: PG-WINDOW-LOWERING-001. Scope: over_clause, window_specification, opt_existing_window_name, opt_partition_clause, opt_frame_clause, frame_extent, frame_bound, opt_window_exclusion_clause. Constructors: WindowSpecification, WindowFrame, FrameBound. EXCLUDE NO OTHERS states the default and is noise (see InvocationNoise). The frames the grammar's action rejects (a start at UNBOUNDED FOLLOWING, an end at UNBOUNDED PRECEDING, a frame that ends before it starts) raise an AnalysisException with the server's message. Termination: the partition list is flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-expressions.html#SYNTAX-WINDOW-FUNCTIONS. Status: Implemented.
