final class MaintenanceRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers TRUNCATE, extended statistics and CREATE ASSERTION.

Rule: PG-TABLE-MAINTENANCE-LOWER-001. Scope: TruncateStmt, opt_restart_seqs, CreateStatsStmt, stats_params, stats_param, AlterStatsStmt, CreateAssertionStmt. The optional TABLE of TRUNCATE is noise (LeafNoise opt_table). Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-truncate.html, https://www.postgresql.org/docs/17/sql-createstatistics.html. Status: Implemented.
