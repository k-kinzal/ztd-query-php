final class RenameRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers ALTER ... RENAME.

Rule: PG-RENAME-LOWER-001. Scope: RenameStmt. Constructor: Rename, as PostgreSQL builds one RenameStmt for every kind; the object part is read by PG-OBJECT-LOWER-001. COLUMN before a renamed column is a noise word. ALTER GROUP, ROLE and USER rename a role and keep their keyword. Source: https://www.postgresql.org/docs/17/sql-altertable.html, https://www.postgresql.org/docs/17/sql-alterrole.html. Status: Implemented.
