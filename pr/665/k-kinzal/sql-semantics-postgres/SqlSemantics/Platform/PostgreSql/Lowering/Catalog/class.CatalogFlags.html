Lowers the optional keywords of the catalog family.

Rule: PG-CATALOG-FLAG-001. Scope: opt_if_exists, opt_if_not_exists, opt_trusted. A flag is whether its keywords are written; each is significant. Source: https://www.postgresql.org/docs/17/sql-dropcast.html, https://www.postgresql.org/docs/17/sql-altertype.html, https://www.postgresql.org/docs/17/sql-createlanguage.html. Status: Implemented.
