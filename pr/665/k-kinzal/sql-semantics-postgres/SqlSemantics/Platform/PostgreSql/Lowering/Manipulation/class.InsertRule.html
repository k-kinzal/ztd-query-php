final class InsertRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers INSERT.

Rule: PG-INSERT-LOWER-001. Scope: InsertStmt, insert_target, insert_rest, override_kind, insert_column_list, insert_column_item, opt_on_conflict, opt_conf_expr. Constructors: InsertRows when the query is VALUES alone, in parentheses or none (the grammar keeps no node for them), InsertSelect for any other query, InsertDefaults for DEFAULT VALUES; TargetTable, ColumnTarget, Overriding, ConflictDoNothing, ConflictDoUpdate, IndexInference, ConstraintInference. Termination: lists are flattened iteratively; parentheses around VALUES are unwrapped one per level. Source: https://www.postgresql.org/docs/17/sql-insert.html. Status: Implemented.
