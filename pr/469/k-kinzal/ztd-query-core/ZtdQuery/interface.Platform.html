interface Platform
Public API: explicitly declared with @visibility public.

Database semantics used by the core executor and driver adapters.

Implementations provide dialect services, never sessions or execution policy. Reusing a platform must not share virtual rows, schema, or rewrite state: each createRewriter() call binds a new pipeline to the supplied state.
