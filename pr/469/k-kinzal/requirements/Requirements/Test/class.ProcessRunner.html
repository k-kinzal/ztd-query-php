final class ProcessRunner
Public API: explicitly declared with @visibility public.

Runs a runner command that writes JUnit XML and reads the verdict from its reports.

The arguments are appended to the configured command without a shell, the reports are written to a fresh temporary directory and removed afterwards. A process that cannot start or exceeds its timeout becomes an "error" result.
