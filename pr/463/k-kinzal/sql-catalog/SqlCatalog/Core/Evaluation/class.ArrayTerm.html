An array literal the analyzer reconstructed element by element.

Bound parameters reach the database as an array, so keeping element order and keys is what lets the catalog line placeholders up with the values they take.

public function anyValue(Origin $origin, ?string $expression = null): ?Domain
source§

Whatever one element can be, or null when the array holds none.

The union of every element covers the value whichever key selects it, which is what turns self::TABLES[$kind] with an unknown $kind into one statement per table instead of a gap. An array known only in part may hold elements the walk never saw, so the union keeps a gap for them.
