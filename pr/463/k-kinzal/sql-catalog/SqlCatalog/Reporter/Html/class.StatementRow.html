One statement as a row of a listing.

A row is a doc-ui listing row. A listing is for scanning, so a row shows the statement itself first — the SQL in doc-ui's multiline code block — and then where it is issued, with every place it names linked to the page for it. What the analyzer thinks of the statement is shown only when it is not the ordinary case: a resolved statement with nothing reported carries no state chips at all, so the ones that do stand out.
