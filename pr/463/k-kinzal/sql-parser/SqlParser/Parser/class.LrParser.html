final class LrParser
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Drives a parse table over a token stream and builds the syntax tree.

This is the shift-reduce loop every LALR(1) parser runs. A shift pushes the token; a reduce pops the symbols of a rule and pushes a node for its nonterminal, unless the rule stands in for a mid-rule action, which leaves no node. Accepting yields the node of the grammar's start symbol, which takes over the trivia of the end marker the augmented start rule ends with, so the text after the last token of the stream belongs to the tree too.
