final class PdoFetchMode

The fetch mode a caller set on a statement, remembered with its arguments.

ZTD prepares a statement again every time it is executed, and a statement prepared again is back on the connection's default mode. Remembering what was asked for is what lets the mode be set again before the rows are read.
