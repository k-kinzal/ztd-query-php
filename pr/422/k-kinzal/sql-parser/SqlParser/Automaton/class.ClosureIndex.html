What the closure of an item set adds, precomputed per nonterminal.

Closing an item set adds every rule of every nonterminal reachable from a nonterminal after a dot. Those additions depend only on the nonterminal, so they are computed once: the items that begin with each symbol, and the empty rules, which complete immediately.
