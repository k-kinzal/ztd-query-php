13 * Writes the catalog as JSON, in an order two runs can be compared in.
14 *

16 * is written, so the artifact can be committed and its diff read as the change
17 * in the SQL an application issues.
18 *

21 * @phpstan-type FindingNode array{rule: string, severity: string, message: string}

23 * @phpstan-type StatementNode array{id: string, kind: string, sql: string, exact: bool, resolution: string, searchClosed: bool, correlated: bool, tables: list<string>, site: SiteNode, through: list<string>, placeholders: list<PlaceholderNode>, findings: list<FindingNode>}
