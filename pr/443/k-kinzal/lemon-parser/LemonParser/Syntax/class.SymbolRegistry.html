final class SymbolRegistry
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Remembers what Lemon's symbol table would know while the file is read.

Lemon rejects a second precedence, type, fallback or wildcard for a symbol and a token class named after a symbol already seen; this keeps enough to raise the same errors in the same places.
