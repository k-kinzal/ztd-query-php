Finds every call that is written the way a database call is written.

Reading a statement and finding the call that carries it are separate jobs. A call whose statement cannot be reconstructed is still a place the program talks to a database, and a call nothing could be read from is a gap in the analysis rather than an absence in the program. This pass answers the second question on its own, so neither can be lost to a failure of the first.
