Walks a path back over what one statement assigns.

An assignment to a name the path needs becomes a step, and the names its right-hand side reads are needed instead. An assignment that replaces its target settles the name; one that only adds to it, like .= or $a[] =, keeps the name needed so the walk goes on to find what it added to.
