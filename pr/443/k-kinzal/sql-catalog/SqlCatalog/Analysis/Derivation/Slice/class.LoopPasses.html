final class LoopPasses
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Walks back through a loop one pass at a time.

A loop that builds part of a statement produces a different statement for every number of times it runs, so each number of passes is its own path: the statement as it is before the loop, after one pass, after two, up to the budget's limit. When a path could still have gone round again at the limit, it is marked as cut short, because the statements listed are not all of the ones the loop can produce. A foreach over an array written out in full runs exactly as many times as the array has elements, and only that number is taken.
