final class SymbolTable
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Numbers every symbol of a grammar, terminals first.

Terminal identifiers run from zero, with the end marker at zero, and the nonterminals continue after the last terminal. The automaton and the parse table refer to symbols by these numbers only.
