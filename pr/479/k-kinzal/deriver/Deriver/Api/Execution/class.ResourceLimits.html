final class ResourceLimits
Public API: explicitly declared with @visibility public.

Runtime protections independent of reproducible structural query budgets.

Memory is additional allocated PHP memory since the query starts; source capture and indexing precede this limit. A zero duration disables the optional wall-clock limit. Resource interruptions are explicit frontiers and are not stored in the result cache.
