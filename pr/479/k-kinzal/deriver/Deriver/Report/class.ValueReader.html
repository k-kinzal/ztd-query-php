final class ValueReader
Public API: explicitly declared with @visibility public.

Reconstructs shared immutable terms from a version 1 report's value graph.

Redacted records become confidential opaque terms; their missing payload is never mistaken for a known null. This reader validates value records and references. Validate the complete report against the packaged schema when consuming other fields.
