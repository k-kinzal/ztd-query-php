final class Semantics
Public API: explicitly declared with @visibility public.

Structures every statement of a selected SQL language into independent values.

This entry point needs no schema or database connection. Statements are read as the server reads them: with the grammar of one release, under the session settings given as the mode, and with the parameter markers of the selected syntax.
