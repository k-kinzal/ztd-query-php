Reads the declared table state that statements are analyzed against.

Schema describes state as declarations spell it; Semantics describes SQL operations. A statement that changes state, such as ALTER TABLE, or whose resulting columns need query evaluation, such as CREATE TABLE AS SELECT, is a statement model of Semantics, and this reader does not evaluate it.
