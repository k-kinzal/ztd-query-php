Regex-based parser for PostgreSQL CREATE TABLE statements.

  • Schema-qualified names (e.g., public.users)
  • PostgreSQL-specific types (UUID, JSONB, BYTEA, INET, TIMESTAMPTZ, etc.)
  • Array types (INT[], TEXT[])
  • CONSTRAINT syntax
