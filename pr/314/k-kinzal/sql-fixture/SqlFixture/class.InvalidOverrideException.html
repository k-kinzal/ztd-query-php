final class InvalidOverrideException
    extends InvalidArgumentException

An override that the table cannot accept.

Overrides are the one route by which a generated row can stop matching the schema it came from. The type mappers never produce null for a NOT NULL column, or a value of the wrong shape; a caller can do both, and used to, silently.
