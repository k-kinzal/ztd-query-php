public function evaluateOperands(
    Expr $node,
    Environment $environment,
    FunctionScope $scope,
): void
source§

Evaluates whatever an expression is written over, for what those evaluations find.

A statement can sit anywhere an expression can, including in an operand the analyzer has no use for the value of. $enabled && $pdo->query(…) issues a query whatever $enabled turns out to be, so finding the call must not depend on the analyzer caring about the expression around it. Every call written inside an operand is evaluated even when the value of the expression holding it is discarded.
