final class Contributions
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

The models, providers, domains, intrinsics and state slots contributed to one session. This is the input of the registration stage. It is not part of the public API: callers configure a session with Configuration, and the library and its tests contribute models through this class.
