class DatabaseFixtureProvider
    extends Base
Public API: explicitly declared with @visibility public.

Faker provider that generates fixtures from database tables via PDO.

Automatically detects the database driver (MySQL, PostgreSQL, SQLite) and the release of the server, and uses the appropriate schema fetcher and type mapper.
