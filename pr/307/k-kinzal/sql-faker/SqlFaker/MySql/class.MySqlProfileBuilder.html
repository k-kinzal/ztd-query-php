final class MySqlProfileBuilder

Builds a MySQL lexical profile from the server's own lexer source.

The three files it reads are the keyword table, the scanner and the character state header, and where the last of those lives moved twice across the supported releases — so the profile is bound to one exact version and records the hash of every file it was built from.
