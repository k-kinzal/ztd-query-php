final class LexicalWitnessShape

Reads one terminal witness out of the checked-in catalog.

A witness is a lexing example: the SQL to feed the server's own lexer, the tokens it must produce, and the coverage units the example accounts for. The generator writes them in two spellings — a compact list and a keyed map — so the compact one is expanded here and everything downstream sees the keyed form only.
