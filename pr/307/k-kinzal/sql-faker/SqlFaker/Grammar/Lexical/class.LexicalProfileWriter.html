final class LexicalProfileWriter

Writes a generated profile and its grammar to the files they are read from.

A profile and the AST it was built against describe one release together, so publishing one without the other would leave the package generating against a grammar its lexer does not match. Both are staged beside their destination and renamed into place, which is the only way to replace two files without a window where one has moved and the other has not.
