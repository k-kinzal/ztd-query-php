interface LexicalGrammar
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Realizes parser terminals as SQL text and verifies the resulting token stream.

Every dialect writes its terminals differently, but all of them owe the same guarantee: text written from a terminal sequence must read back as that same sequence through the dialect's own lexer. An implementation that only wrote text would let a generator drift away from the server it claims to target.
