final class MySqlProvider
    extends Base
Public API: explicitly declared with @visibility public.

Faker Provider for generating syntactically valid MySQL SQL statements.

This provider uses MySQL's official Bison grammar (sql_yacc.yy) to generate SQL that is syntactically valid. Note that generated SQL may not be semantically valid (tables/columns may not exist).

Supported MySQL versions:

    • mysql-5.6.51
    • mysql-5.7.44
    • mysql-8.0.44
    • mysql-8.1.0
    • mysql-8.2.0
    • mysql-8.3.0
    • mysql-8.4.7 (default)
    • mysql-9.0.1
    • mysql-9.1.0

maxDepth selects shortest productions once the depth is reached; it is not a SQL length limit. Generated statements may include whitespace and SQL comments. Optional clauses may be empty. Seed the supplied Faker generator to reproduce a run within the same package version.
