Writes one PostgreSQL parser terminal as the SQL text that produces it.

There are two ways to write a terminal and they are not interchangeable. The catalogued way replays SQL that the server's own lexer was observed to turn into the terminal, which is what makes generated statements trustworthy. The synthetic way constructs text from the terminal's name, which reaches terminals no catalog witnesses but only promises to be plausible — so it is off unless a caller asks for it.
