The SQL that shows each SQLite terminal being lexed.

A compiled profile is only as good as the examples it was built from: each one is a piece of SQL, the tokens SQLite reads it as, and the character classes reading it went through. They are written out rather than derived, because the whole point of them is to be independent of the code that consumes them.
