9/**
10 * Reports that a grammar could not derive a statement.
11 *
12 * A rule with no alternatives, an alternative no lexer can realize, a reference
13 * to a rule the grammar does not define, or a derivation that runs past its
14 * depth limit are all properties of the grammar being generated from, not of
15 * the generator. Callers that generate from grammars they did not author are
16 * expected to handle this.
17 *
18 * The three dialect generators hit the same failures, so the wording lives here
19 * rather than being repeated at each throw site.
20 *
21 * @visibility public
22 * @example Catch this failure as a runtime exception
23 *     $failure = new \SqlFaker\Grammar\GenerationException('SQL generation failed');
24 *     $failure instanceof \RuntimeException // => true
25 *     $failure->getMessage() // => 'SQL generation failed'
26 */
