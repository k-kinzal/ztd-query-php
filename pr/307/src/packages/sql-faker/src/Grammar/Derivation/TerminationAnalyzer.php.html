12 * Answers what it still costs to finish a rule or a production.
13 *
14 * A derivation has to stop, and to stop it has to know which way out is
15 * shortest. Two measures of "shortest" matter: how many tokens will be
16 * written, which decides how long the SQL gets, and how many rules will be
17 * expanded, which decides whether the walk fits in its step budget. Both are
18 * asked of the same grammar, so both are answered here.
19 *
20 * @visibility root
21 */

31     */
32    public function __construct(Grammar $grammar, ?callable $terminalSupported = null)
33    {

35            ? Closure::fromCallable($terminalSupported)
36            : static fn (string $terminal): bool => true;
37        $this->lengths = new TerminationCost($grammar, $supported, 1, 0);
38        $this->steps = new TerminationCost($grammar, $supported, 0, 1);
