Extracts the keyword table from SQLite's tool/mkkeywordhash.c.

Each keyword names the features it belongs to, and a build leaves out a keyword none of whose features are compiled in. The features follow the same SQLITE_OMIT_* and SQLITE_ENABLE_* names the grammar's own conditionals use, so one list of defines decides both.
