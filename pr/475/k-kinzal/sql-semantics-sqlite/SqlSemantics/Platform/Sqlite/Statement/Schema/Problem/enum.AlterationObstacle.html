enum AlterationObstacle: string
Public API: explicitly declared with @visibility public.

The reasons SQLite refuses to add or drop a column.

Only the reasons that follow from the statement and the declared columns are modeled; those that need the constraints and indexes of the existing table are not part of a declaration context. Source: https://sqlite.org/lang_altertable.html.
