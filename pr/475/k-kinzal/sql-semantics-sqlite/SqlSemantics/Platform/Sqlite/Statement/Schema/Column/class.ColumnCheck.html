Public API: explicitly declared with @visibility public.

A CHECK column constraint.

Rule: SQLITE-COLUMN-CHECK-001. The expression is evaluated for each written row and may refer to any column of the table and to its row identifier, not only to the column it is written after. It is derived at a position whose only visible relation is the table being defined. A bound parameter or a subquery in it is a diagnostic (SQLITE-DEFINITION-LIMITS-001). Source: https://sqlite.org/lang_createtable.html#check_constraints. Status: Implemented.
