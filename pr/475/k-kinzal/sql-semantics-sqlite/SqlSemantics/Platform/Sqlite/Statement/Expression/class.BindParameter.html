A bind parameter: a placeholder for a value supplied when the statement runs.

Rule: SQLITE-PARAMETER-001. The parameter is identified by its prefix and its label: no label for an anonymous ?, digits for ?NNN, a name for the other prefixes. Its type and NULL fact depend on the bound value. Source: https://sqlite.org/lang_expr.html#parameters. Status: Implemented.
