Public API: explicitly declared with @visibility public.

One occurrence of a named table, view or common table as query input.

Rule: SQLITE-TABLE-INPUT-001. The shape and the resolution of the name follow SQLITE-TABLE-SHAPE-001. An index choice restricts how SQLite may read the table and changes no row. Source: https://sqlite.org/lang_select.html#the_from_clause, https://sqlite.org/lang_indexedby.html. Status: Implemented.
