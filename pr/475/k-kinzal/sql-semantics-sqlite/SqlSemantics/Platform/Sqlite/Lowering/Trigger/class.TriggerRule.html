final class TriggerRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers trigger definitions.

Rule: SQLITE-TRIGGER-LOWER-001. Scope: trigger_decl, trigger_time, trigger_event, foreach_clause, when_clause, trigger_cmd_list, trigger_cmd, trnm, tridxby. The statements of the program keep their written order and are lowered into the same statement classes as outside a trigger. Terminates: the program is flattened iteratively. Source: https://sqlite.org/lang_createtrigger.html. Status: Implemented.
