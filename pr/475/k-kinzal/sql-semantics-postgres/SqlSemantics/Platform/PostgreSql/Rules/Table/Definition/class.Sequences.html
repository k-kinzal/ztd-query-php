Derives CREATE SEQUENCE and the options of a sequence.

Rule: PG-SEQUENCE-001. A sequence is a relation that can be read: "the

  • sequence's last_value, log_cnt and is_called" are its columns (bigint,

bigint, boolean), never NULL, with the system columns. A temporary sequence with an unqualified name belongs to pg_temp; inside CREATE SCHEMA an unqualified sequence belongs to that schema. SEQUENCE NAME is accepted only for the sequence of an identity column and is reported in CREATE and ALTER SEQUENCE ("invalid sequence option SEQUENCE NAME"). Source: https://www.postgresql.org/docs/17/sql-createsequence.html. Status: Implemented.
