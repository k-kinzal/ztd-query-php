Derives CREATE VIEW.

Rule: PG-VIEW-001. The query is derived at the top level; for a RECURSIVE view the view name is bound in it as a recursive common table with the written column names ("CREATE RECURSIVE VIEW name (columns) AS SELECT

  • ...; is equivalent to CREATE VIEW name AS WITH RECURSIVE name (columns) AS
  • (SELECT ...) SELECT columns FROM name;"). The view is declared by

PG-QUERY-TABLE-001 with the NULL facts of the query and without system columns. UNLOGGED is reported: views have no storage. Source: https://www.postgresql.org/docs/17/sql-createview.html. Status: Implemented.
