A number with an optional minus sign, written where the grammar reads NumericOnly instead of an expression.

Sequence options, storage parameters and configuration values take such numbers. A written plus sign changes nothing and is not kept. The grammar makes an integer node of a negated integer constant, and a float node of a negated numeric constant whose text is the constant's text after a minus sign (doNegateFloat); commands that read the value as text receive that. Source: https://www.postgresql.org/docs/17/sql-createsequence.html, NumericOnly and SignedIconst in src/backend/parser/gram.y of PostgreSQL 17.
