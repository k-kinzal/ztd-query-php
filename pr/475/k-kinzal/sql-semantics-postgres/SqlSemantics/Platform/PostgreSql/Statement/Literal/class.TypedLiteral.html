A constant of a stated type, written type 'string'.

DATE '2024-01-01', INTERVAL '1' DAY, N'text' and float8 '1.5' are typed constants: the string is converted by the input routine of the type. The raw parser reads the form as a cast of the string to the type.

Rule: PG-TYPED-CONSTANT-001. Facts: the type the type name denotes, where bit and character without a length are unconstrained; never NULL; an unaliased result column is named after the catalog name of the type. Source: https://www.postgresql.org/docs/17/sql-syntax-lexical.html#SQL-SYNTAX-CONSTANTS-GENERIC. Status: Implemented.
