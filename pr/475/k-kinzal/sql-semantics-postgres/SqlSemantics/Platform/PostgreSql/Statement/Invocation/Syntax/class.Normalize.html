NORMALIZE (value [, form]): a string converted to a Unicode normal form.

The server calls pg_catalog.normalize(value[, 'form']); without a form the function's default NFC applies, but the form written is kept. Rule: PG-NORMALIZE-001. Facts: those of the call (PG-CALL-RESULT-001, the form passed as a text constant). The result column is named normalize. Source: https://www.postgresql.org/docs/17/functions-string.html. Status: Implemented.
