interface PublicationMember
    extends Node
Public API: explicitly declared with @visibility public.

One item of the object list of CREATE or ALTER PUBLICATION: a table, or the tables of a schema.

An item may omit its introducing keywords (TABLE or TABLES IN SCHEMA); it then continues the kind of the item before it. The server reads the list that way while parsing and rejects a list that starts without keywords. Source: https://www.postgresql.org/docs/17/sql-createpublication.html.
