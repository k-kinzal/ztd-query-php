enum MergeMatch
Public API: explicitly declared with @visibility public.

Which rows a WHEN clause of MERGE applies to.

Mirrors PostgreSQL's MergeMatchKind: MERGE_WHEN_MATCHED (a target row joined with a source row), MERGE_WHEN_NOT_MATCHED_BY_SOURCE (a target row without source row, PostgreSQL 17) and MERGE_WHEN_NOT_MATCHED_BY_TARGET (a source row without target row, written NOT MATCHED or, in PostgreSQL 17, NOT MATCHED BY TARGET). Source: https://www.postgresql.org/docs/17/sql-merge.html.
