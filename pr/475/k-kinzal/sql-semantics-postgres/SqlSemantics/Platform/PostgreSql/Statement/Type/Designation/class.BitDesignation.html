The type spelled BIT or BIT VARYING, with an optional length.

Rule: PG-TYPE-BIT-001. BIT without a length is bit(1) as a type and unconstrained when it types a constant; BIT VARYING without a length is unlimited. Facts: PG-TYPE-MODIFIER-001. Source: https://www.postgresql.org/docs/17/datatype-bit.html. Status: Implemented.
