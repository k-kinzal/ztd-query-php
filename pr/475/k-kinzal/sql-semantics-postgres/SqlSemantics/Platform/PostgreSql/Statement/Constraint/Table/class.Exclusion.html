final class Exclusion
    implements Constraint
    uses Snapshot
Public API: explicitly declared with @visibility public.

An EXCLUDE table constraint: no two rows satisfy all the operators of the elements together.

Mirrors CONSTR_EXCLUSION with access_method, exclusions, including, options, indexspace, where_clause and the attributes. The keys and the predicate are derived where the columns of the table are visible. Source: https://www.postgresql.org/docs/17/sql-createtable.html#SQL-CREATETABLE-EXCLUDE.
