The kind of a grouping set written in GROUP BY.

Mirrors PostgreSQL's GroupingSetKind without SIMPLE, which the server only creates internally: a plain grouping expression is kept as the expression itself. Source: https://www.postgresql.org/docs/17/queries-table-expressions.html#QUERIES-GROUPING-SETS.
