final class CreateAsRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers the statements that define a relation by a query: CREATE TABLE AS, CREATE VIEW, CREATE MATERIALIZED VIEW, and REFRESH.

Rule: PG-CREATE-AS-LOWER-001. Scope: CreateAsStmt, create_as_target, opt_with_data, CreateMatViewStmt, create_mv_target, OptNoLog, RefreshMatViewStmt, ViewStmt, opt_check_option, and the CREATE TABLE ... AS EXECUTE forms of ExecuteStmt. Termination: no recursion of its own. Source: https://www.postgresql.org/docs/17/sql-createtableas.html, https://www.postgresql.org/docs/17/sql-createview.html. Status: Implemented.
