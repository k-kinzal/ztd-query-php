public function call(
    State $state,
    list<Term> $values,
    list<Location> $references,
    string $reason,
    bool $shared = true,
): void
source§

Invalidates values reachable from unknown calls and escaped references. With $shared, exposed globals and statics also become unknown, as when the analysis of a path is cut off. An unavailable callee does not share: it is unrelated to globals and statics it was not given through its receiver, arguments or references, so they keep their values.

Parameters

$stateStateMutable execution path
$valueslist<Term>Receivers, arguments, and escaped callbacks
$referenceslist<Location>Potential reference arguments
$reasonstringRoot cause
$sharedboolWhether exposed globals and statics are also invalidated
