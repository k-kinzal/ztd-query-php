final class FromScope
Restricted visibility: declared "@visibility SqlSemantics\Platform\MySql". Code outside that scope must not name this declaration.

Derives the terms of a FROM clause and the relations they make visible to names.

Rule: MYSQL-FROM-SCOPE-001. A table reference, a derived table and a JSON table are each one visible relation under their correlation name, or a table reference under its table name when it has none, together with the INVISIBLE columns a name finds (MYSQL-TABLE-SHAPES-001); DUAL makes none visible. A non-lateral derived table sees the enclosing queries only; a LATERAL derived table and the document of JSON_TABLE also see the tables to their left: the earlier members of the comma list and, inside a join, the left operand. A join combines its operands by MYSQL-JOIN-COLUMNS-001 and derives its ON condition where exactly its two operands are visible, before NULL extension. Parentheses, braces and comma lists group terms and change no name. Terminates: comma lists are walked in a loop; recursion follows the strictly smaller operands. Source: https://dev.mysql.com/doc/refman/8.4/en/join.html, https://dev.mysql.com/doc/refman/8.4/en/lateral-derived-tables.html, https://dev.mysql.com/doc/refman/8.4/en/json-table-functions.html. Status: Implemented.
