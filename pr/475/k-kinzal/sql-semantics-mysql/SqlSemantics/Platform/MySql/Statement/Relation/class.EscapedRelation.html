The ODBC escape { word table_reference } of the 5.x grammars, where any identifier takes the place of OJ.

Rule: MYSQL-ODBC-JOIN-001. The server ignores the word; the braces group the reference like parentheses and change no name. Source: https://dev.mysql.com/doc/refman/5.7/en/join.html. Status: Implemented.
