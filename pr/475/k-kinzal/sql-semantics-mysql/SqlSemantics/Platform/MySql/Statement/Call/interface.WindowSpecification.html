interface WindowSpecification
    extends Node
Public API: explicitly declared with @visibility public.

A window specification: an optional existing window name, partitioning, ordering and frame.

It is written after OVER and in the WINDOW clause. The function-like expression family provides the structure; the query family holds it in named windows and derives it there with deriveWindow(). Source: https://dev.mysql.com/doc/refman/8.4/en/window-functions-usage.html.
