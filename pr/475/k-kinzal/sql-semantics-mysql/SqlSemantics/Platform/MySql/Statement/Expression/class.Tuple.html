The type of a row of several values: a row constructor or a subquery of several columns (ROW_RESULT).

Only the number of columns is part of the type: comparisons, IN and row subqueries require rows of equal width. Source: https://dev.mysql.com/doc/refman/8.4/en/row-subqueries.html.
