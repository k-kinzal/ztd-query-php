A size option: INITIAL_SIZE [=] size, MAX_SIZE [=] size, FILE_BLOCK_SIZE [=] size, ….

The size is a number of bytes or a word with a K, M or G multiplier. The equals sign is optional and not written. Source: https://dev.mysql.com/doc/refman/8.4/en/create-tablespace.html.
