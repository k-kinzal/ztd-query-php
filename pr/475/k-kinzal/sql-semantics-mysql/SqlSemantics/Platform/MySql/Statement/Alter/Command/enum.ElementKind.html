enum ElementKind: string
Public API: explicitly declared with @visibility public.

The kinds of table elements ALTER TABLE drops, renames or alters by name.

Mirrors Alter_drop::drop_type: a column, the primary key, a foreign key, an index (KEY and INDEX are synonyms), a check constraint, and a constraint of any kind (8.0.19 and later). Each case holds the keywords it is written with. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html.
