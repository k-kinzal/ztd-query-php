interface Partitioning
    extends Node

The partitioning of a table: PARTITION BY with its function, columns, counts and partition definitions.

CREATE TABLE and ALTER TABLE hold it. The statement that holds it derives it in the scope of the table it partitions. Source: https://dev.mysql.com/doc/refman/8.4/en/partitioning.html.
