The LIKE clause of a SHOW: the rows whose name matches a pattern.

The pattern is matched with the rules of the LIKE operator against the column the statement names its rows by (the first column, or the variable name of SHOW VARIABLES and SHOW STATUS); % and _ are wildcards. Source: https://dev.mysql.com/doc/refman/8.4/en/extended-show.html.
