A column default written as a literal, NULL or the current timestamp function, without parentheses.

A literal default is the value itself; CURRENT_TIMESTAMP (and its synonyms) is the only function MySQL accepts without parentheses, for TIMESTAMP and DATETIME columns. Source: https://dev.mysql.com/doc/refman/8.4/en/data-type-defaults.html.
