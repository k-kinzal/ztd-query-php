An ENUM or SET type with its permitted values in declaration order and its character set attribute.

The order of the values is their index order and is part of the type. Source: https://dev.mysql.com/doc/refman/8.4/en/enum.html, https://dev.mysql.com/doc/refman/8.4/en/set.html.
