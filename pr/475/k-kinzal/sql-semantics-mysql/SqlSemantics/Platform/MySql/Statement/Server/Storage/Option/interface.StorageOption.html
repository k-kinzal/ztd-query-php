interface StorageOption

Public API: explicitly declared with @visibility public.

An option of a tablespace, undo tablespace or log file group statement.

Mirrors PT_alter_tablespace_option_base and its subclasses (MySQL 8.0) and the fields of st_alter_tablespace (MySQL 5.x). Each statement accepts the options its grammar rule lists. Source: https://dev.mysql.com/doc/refman/8.4/en/create-tablespace.html.
