Lowers values and assignments: the expression lists of rows and the SET lists.

Rule: MYSQL-DML-VALUES-001. Scope: opt_values, values, expr_or_default, update_list, update_elem, insert_update_list, insert_update_elem, ident_eq_list, ident_eq_value. A value is an expression or the keyword DEFAULT (DefaultRequest); an assignment is a column and a value (Assignment), with = and := as one operator. Terminates: lists are flattened by MYSQL-DML-LIST-001, expressions are strict subtrees. Source: https://dev.mysql.com/doc/refman/8.4/en/insert.html, https://dev.mysql.com/doc/refman/8.4/en/update.html. Status: Implemented.
