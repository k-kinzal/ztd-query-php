Lowers REFERENCES clauses.

Rule: MYSQL-REFERENCES-LOWERING-001. Scope: references, opt_references, opt_ref_list, ref_list, reference_list, opt_match_clause, opt_on_update_delete, delete_option. The referential actions are kept in written order. Constructs: References, ReferentialAction. Terminates: lists are flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table-foreign-keys.html. Status: Implemented.
