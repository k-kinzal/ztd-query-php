final class BisonGrammarReader
Public API: explicitly declared with @visibility public.

Turns a Bison grammar file into the grammar the automaton is built from.

The file is read with bison-parser; this class keeps what the automaton needs. %token names terminals, %left, %right, %nonassoc and %precedence rank them, %start and %expect are recorded, and every alternative becomes a rule. A mid-rule action becomes a hidden $@n nonterminal deriving the empty string, numbered before the rule it appears in, exactly as Bison numbers it. Character literals and strings on a right-hand side are terminals named by their value.
