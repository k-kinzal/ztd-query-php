final class Rule
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

One production of a grammar, numbered in the order it was declared.

Rule zero is always the augmented start rule. A hidden rule is one the reader synthesised for a mid-rule action; it derives the empty string and is left out of the syntax tree.
