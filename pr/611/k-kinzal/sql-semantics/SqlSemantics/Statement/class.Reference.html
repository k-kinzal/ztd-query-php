A table name written in a statement and what it resolves to.

The value is the name as written, so it can be found and rewritten in the statement by identity. A grammar that writes a qualified name as separate values of one form, as SQLite's FROM writes a schema and a table, has no single value for it: the values are all of them, in writing order, and the value is the first. The name parts are decoded, in writing order, the schema before the table when the name is qualified.
