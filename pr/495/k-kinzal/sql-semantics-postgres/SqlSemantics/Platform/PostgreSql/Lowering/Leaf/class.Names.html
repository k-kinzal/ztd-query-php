final class Names
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers identifiers and the name forms built from them.

Rule: PG-NAME-001. Scope: ColId, ColLabel, BareColLabel, type_function_name, NonReservedWord, name, attr_name, param_name, columnElem, generic_option_name, name_list, opt_name_list, columnList, opt_column_list, qualified_name, qualified_name_list, any_name, any_name_list, attrs, func_name, opt_single_name, opt_qualified_name, opt_collate, opt_collate_clause. Constructors: Name, QualifiedName, DottedName. An identifier is decoded by PG-IDENT-001, a keyword by PG-KEYWORD-NAME-001. A relation name and a function name written with an indirection accept field selections only and a relation name at most three parts; the server rejects anything else while parsing, so it is SQL outside the grammar. Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-syntax-lexical.html#SQL-SYNTAX-IDENTIFIERS. Status: Implemented.
