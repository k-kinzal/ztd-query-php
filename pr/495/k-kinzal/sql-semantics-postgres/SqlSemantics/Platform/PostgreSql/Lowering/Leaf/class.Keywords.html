Reads a keyword used as a name.

Rule: PG-KEYWORD-NAME-001. Scope: unreserved_keyword, col_name_keyword, type_func_name_keyword, reserved_keyword and bare_label_keyword. The name is the keyword folded to lower case, exactly as an unquoted identifier is folded. Source: https://www.postgresql.org/docs/17/sql-keywords-appendix.html. Status: Implemented.
