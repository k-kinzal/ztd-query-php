enum RoutineAttribute: string
    implements RoutineOption
Public API: explicitly declared with @visibility public.

A routine option written as keywords only: null-input behavior, volatility, security, leakproofness or WINDOW.

CALLED ON NULL INPUT, RETURNS NULL ON NULL INPUT and STRICT set the same attribute; the last two mean the same and are kept apart because they are written differently. EXTERNAL SECURITY ... is SECURITY ... with an optional noise word. WINDOW is accepted by CREATE only. Source: https://www.postgresql.org/docs/17/sql-createfunction.html.
