name type EXISTS [PATH path] [ON ERROR]: a JSON_TABLE column that tells whether the path yields an item.

Mirrors PostgreSQL's JsonTableColumn of type JTC_EXISTS. A column named nested is written quoted: before a type named path gram.y reads the word as the NESTED PATH of a nested column (NESTED has a lower precedence than PATH). Source: https://www.postgresql.org/docs/17/functions-json.html#FUNCTIONS-SQLJSON-TABLE.
