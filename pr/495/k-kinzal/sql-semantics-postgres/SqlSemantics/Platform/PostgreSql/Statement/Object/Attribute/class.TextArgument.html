Public API: explicitly declared with @visibility public.

An attribute value read as text, such as the initial condition of an aggregate or the locale of a collation.

defGetString accepts every value: a string as written, a word or a type name as its names joined by dots, a keyword in lower case, an operator, or a number as written. The text is opaque to the command; an initial condition, for example, is later read by the input function of the state type. Source: https://www.postgresql.org/docs/17/sql-createaggregate.html, defGetString in src/backend/commands/define.c of PostgreSQL 17.
