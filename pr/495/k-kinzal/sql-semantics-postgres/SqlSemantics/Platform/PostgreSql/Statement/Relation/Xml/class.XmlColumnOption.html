One option of an XMLTABLE column: its path, its default, or whether it can be NULL.

Mirrors the DefElem options PostgreSQL's grammar builds for xmltable_column_option_el. Source: https://www.postgresql.org/docs/17/functions-xml.html#FUNCTIONS-XML-PROCESSING-XMLTABLE.
