enum RoleWord: string
Public API: explicitly declared with @visibility public.

The keyword ALTER ... RENAME names a role with: ROLE, USER or GROUP.

The three spellings rename the same kind of object; the word is kept so that the statement is written back as it was. Source: https://www.postgresql.org/docs/17/sql-alterrole.html, https://www.postgresql.org/docs/17/sql-altergroup.html.
