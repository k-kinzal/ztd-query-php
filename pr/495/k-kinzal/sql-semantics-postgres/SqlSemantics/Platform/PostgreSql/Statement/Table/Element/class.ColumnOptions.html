Public API: explicitly declared with @visibility public.

Constraints added to a column a typed table or a partition takes from its type or parent.

Mirrors the ColumnDef without a type that columnOptions builds. The optional WITH OPTIONS words change nothing ("column_name [ WITH OPTIONS ]

  • [ column_constraint [ ... ] ]") and are not kept.

Source: https://www.postgresql.org/docs/17/sql-createtable.html.
