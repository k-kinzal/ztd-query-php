final class AlterTable
    implements Statement, Relation
    uses Snapshot
Public API: explicitly declared with @visibility public.

A request to change a table, an index, a sequence, a view, a materialized view or a foreign table.

Mirrors PostgreSQL's AlterTableStmt (relation, cmds, objtype, missing_ok). The relation is resolved (PG-TABLE-TARGET-001) and is the relation fact of the statement; the actions are derived against it (PG-ALTER-TABLE-001). The statement changes no declaration. ONLY is written only for tables and foreign tables; a partition action stands alone. Source: https://www.postgresql.org/docs/17/sql-altertable.html.
