NOTIFY channel [, payload]: a request to send a notification to the listeners of a channel.

Rule: PG-NOTIFY-001. Mirrors PostgreSQL's NotifyStmt (conditionname, payload). The statement also occurs as an action of a rule. Facts: none; a channel is not part of a declaration context. Diagnostic: a payload of 8000 bytes or more, the limit of the default configuration (a block size of 8192 bytes), counted in UTF-8. Source: https://www.postgresql.org/docs/17/sql-notify.html. Status: Implemented.
