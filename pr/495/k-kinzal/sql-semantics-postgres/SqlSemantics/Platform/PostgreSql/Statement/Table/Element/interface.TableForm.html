Where the columns of a new table come from: a column list, a composite type, or a partitioned parent.

The three forms of CREATE TABLE: tableElts with inhRelations, ofTypename, or partbound with one parent in inhRelations. Source: https://www.postgresql.org/docs/17/sql-createtable.html.
