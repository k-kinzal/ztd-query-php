A column written by name as the key of an index, a partition key or extended statistics.

Mirrors the name of PostgreSQL's IndexElem, PartitionElem and StatsElem. The name is resolved as a column of the indexed relation, which is the only relation visible there. Source: https://www.postgresql.org/docs/17/sql-createindex.html.
