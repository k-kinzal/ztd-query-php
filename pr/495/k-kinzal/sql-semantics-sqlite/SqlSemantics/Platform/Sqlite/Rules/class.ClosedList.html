Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Narrows a constructor argument to an ordered list whose items are of one of several admitted classes.

PHP does not check array element types, so every list a constructor accepts passes through here whatever its PHPDoc promises; a list of one class goes through the core check instead.
