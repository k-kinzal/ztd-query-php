Lowers conflict resolution clauses.

Rule: SQLITE-CONFLICT-LOWER-001. Scope: resolvetype, raisetype, onconf, orconf. Each names one of the five conflict resolution algorithms; an empty clause names none. Source: https://sqlite.org/lang_conflict.html. Status: Implemented.
