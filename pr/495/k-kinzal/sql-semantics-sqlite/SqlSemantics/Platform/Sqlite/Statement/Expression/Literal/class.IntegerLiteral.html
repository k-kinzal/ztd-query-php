final class IntegerLiteral

    uses Snapshot
Public API: explicitly declared with @visibility public.

A decimal integer literal, kept as its exact digits.

Digit separators are not part of the value and are not kept.

Rule: SQLITE-INTEGER-LITERAL-001. A literal that fits a signed 64-bit integer has storage class INTEGER; a larger one is read as REAL. Source: https://sqlite.org/lang_expr.html#literal_values_constants_. Status: Implemented.
