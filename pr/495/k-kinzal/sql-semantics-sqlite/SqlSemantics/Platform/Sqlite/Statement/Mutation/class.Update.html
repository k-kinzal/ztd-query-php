final class Update
    implements Statement, Selection
    uses Snapshot
Public API: explicitly declared with @visibility public.

An UPDATE of columns of the rows of a table that satisfy a predicate, optionally joined to further input.

Rule: SQLITE-UPDATE-001. The assigned values and the predicate see the written table and the relations of the FROM clause, which are derived by SQLITE-FROM-SCOPE-001; an assigned generated column is reported (SQLITE-GENERATED-WRITE-001); the rest follows SQLITE-MUTATION-SCOPE-001. Source: https://sqlite.org/lang_update.html. Status: Implemented.
