The LIMIT clause: the largest number of rows to return and the number of rows to skip first.

SQLite has two spellings for a limit with an offset, LIMIT count OFFSET offset and LIMIT offset, count; the model keeps which one is written. Source: https://sqlite.org/lang_select.html#the_limit_clause.
