A PRIMARY KEY table constraint.

Rule: SQLITE-TABLE-PRIMARY-KEY-001. The grammar writes the key terms as ordering terms, so any expression parses; SQLite accepts column names only, each optionally with a collation and a sort order ("expressions prohibited

  • in PRIMARY KEY and UNIQUE constraints"). A column name is an identifier, a

double-quoted word or a string literal (LiteralColumn; a plain string literal term is refused at construction, SQLITE-KEY-TERM-001). Each term is derived where the columns and the row identifier of the table are visible. Unlike the column constraint, a single-column key of declared type INTEGER is the row identifier whatever sort order is written. AUTOINCREMENT is written inside the parentheses after the last term. Source: https://sqlite.org/lang_createtable.html#the_primary_key, https://sqlite.org/lang_createtable.html#rowid. Status: Implemented.
