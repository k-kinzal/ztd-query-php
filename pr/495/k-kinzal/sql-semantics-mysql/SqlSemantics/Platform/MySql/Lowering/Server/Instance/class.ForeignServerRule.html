Lowers CREATE, ALTER and DROP SERVER.

Rule: MYSQL-FOREIGN-SERVER-001. Scope: the SERVER alternatives of create, alter and drop (alter and drop in 5.6 and 5.7), server_def (5.6), alter_server_stmt, drop_server_stmt, server_options_list, server_option. Constructs: CreateServer, AlterServer, DropServer, ServerOption. Terminates: the option list is flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/create-server.html, https://dev.mysql.com/doc/refman/8.4/en/alter-server.html, https://dev.mysql.com/doc/refman/8.4/en/drop-server.html.
