The entry rules of the server family: the methods other families and the statement dispatcher call.

Rule: MYSQL-SERVER-ENTRY-001. Scope: transactions, XA, locks, table maintenance, key caches, FLUSH, KILL, plugins and components, databases, foreign servers, spatial reference systems, tablespaces, undo tablespaces, log file groups, ALTER INSTANCE, CLONE, SHUTDOWN and RESTART. The method names, parameters and return types are fixed by the family plan; each delegates to the rule class of its area (MYSQL-SERVER-STATEMENT-001). Source: https://dev.mysql.com/doc/refman/8.4/en/sql-server-administration-statements.html. Status: Implemented.
