enum DropBehavior: string
Public API: explicitly declared with @visibility public.

The RESTRICT or CASCADE keyword of a DROP statement or of ALTER TABLE ... DROP COLUMN.

MySQL accepts both keywords and they do nothing; the keyword is kept as written because it is part of the request. Source: https://dev.mysql.com/doc/refman/8.4/en/drop-table.html.
