Public API: explicitly declared with @visibility public.

One password management or account locking option of CREATE USER or ALTER USER, with its number when it takes one.

The number is kept as written. Several options may be written; for one field the last option written wins in the server, so the list keeps every option in source order. Source: https://dev.mysql.com/doc/refman/8.4/en/create-user.html#create-user-password-management.
