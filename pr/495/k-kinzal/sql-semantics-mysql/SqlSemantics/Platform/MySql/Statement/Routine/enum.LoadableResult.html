The return type of a loadable function: STRING, REAL, DECIMAL or INTEGER.

Each case holds the keyword the statement is written with; INT and INTEGER are one keyword of the lexer. Source: https://dev.mysql.com/doc/refman/8.4/en/create-function-loadable.html.
