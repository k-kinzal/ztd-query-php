final class PostgreSqlParser
    implements SqlParser
Public API: explicitly declared with @visibility public.

Parses PostgreSQL statements with the grammar of a chosen server release.

The parse table is built from the gram.y of that release and the lexer follows its scan.l, so the tree names the nonterminals of the official grammar. Several statements separated by semicolons parse as one tree.
