public static function prepare(
    list<string> $files,
    DeriverConfig|null $configuration = null,
): self
source§

Captures and parses the selected files without executing application code. Builds reverse indexes for calls, property writes, closure owners and script globals. Function, method and closure bodies are compiled on demand and reused by later queries. The returned instance keeps these contents even if the files later change or disappear.

Parameters

$fileslist<string>Local paths, for example the result of Finder::files()
$configurationDeriverConfig|nullIndependent language and evaluation settings; null selects the defaults

Returns

self

Throws

CollectorException If a selected file cannot be collected
ParserException If a selected source cannot be parsed
ResolutionException If a selected source cannot be resolved
InvalidInputException If declarations are incomplete or declarations or evaluator registrations conflict

public function derive(string $query): CandidateCollection

Answers a selector against the prepared sources with fresh evaluation state. Each result owns its evidence; the deriver does not retain query results.

Parameters

$querystringCallable or source-position selector

Returns

CandidateCollection Candidates and their self-contained evidence
