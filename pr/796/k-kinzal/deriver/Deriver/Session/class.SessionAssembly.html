final class SessionAssembly
Restricted visibility: declared "@visibility namespace". Code outside that scope must not name this declaration.

Runs the project stages once, in order, and holds their artifacts for the lifetime of a session: provider expansion, model registration, snapshot identity, declaration scanning, and the candidate definition index. No stage is run anywhere else, and no artifact changes after assembly.
