final class Scopes
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Walks a statement with the common table expressions visible at each value.

A form that writes a WITH clause makes the clause's expressions visible in every other value of the form. Inside the clause, the body of each expression sees the expressions of the clause the database allows, which differ between a plain and a recursive clause; a name it cannot see is resolved outside the clause. A value at a target position of the relation rules, a table a DML statement writes to where the database never reads it as an expression, sees no expression at all.
