final class Condition
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Evaluates the expression after %if, %ifdef or %ifndef.

Lemon reads the expression left to right with no precedence: a name is true when it is defined, ! negates the next term, parentheses group, and || and && stop as soon as the answer is known.
