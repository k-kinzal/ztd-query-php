final class RhsItem
Public API: explicitly declared with @visibility public.

One position on the right-hand side of a rule.

Usually one symbol, but Lemon lets several terminals share a position, written A|B|C; the position then matches any of them. An alias in parentheses names the value of the position in the rule's code.
