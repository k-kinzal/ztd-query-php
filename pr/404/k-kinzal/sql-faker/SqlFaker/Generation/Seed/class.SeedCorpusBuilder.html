final class SeedCorpusBuilder

Synthesizes byte inputs that together select every production reachable from a root, one target at a time.

Every seed decodes under the same contract: the plan starts at the root, requires output, and carries no other constraint, so any fuzz target compiling its input that way replays the corpus unchanged.
