final class TypeName
Public API: explicitly declared with @visibility public.

A type the binder knows only by its declared name: a user-defined, domain, or unmodeled type.

The name parts are decoded like identifiers. Modifiers written after such a name are not interpreted; the typed declaration a column keeps still has them.
