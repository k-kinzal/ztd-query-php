final class Scope
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Where in the program a statement is issued, read out of the enclosing function's name.

The catalog writes the enclosing function as Class::method, function or {main}. The report needs the pieces: the namespace to group by, the class to write a page for, and the member to head a section with. Reading them once here is what keeps every page addressing the same code the same way.
