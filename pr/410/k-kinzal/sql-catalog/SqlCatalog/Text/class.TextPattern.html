final class TextPattern
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

A string the analyzer knows in part: resolved runs of text with gaps between them.

A pattern with no gaps is an exact string. One with gaps describes the shape of every string the expression can produce, which is what the catalog reports when a query is assembled from values that are not statically known.
