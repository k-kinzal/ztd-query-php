A VALUES clause: a query whose rows are written out.

Rule: SQLITE-VALUES-001. The values see the enclosing queries and no relation of their own. The result has the width of the first row; a row of another width is reported. SQLite names the result columns column1, column2, and so on. The type of a column is the choice over its values and it can be NULL when one of its values can. Source: https://sqlite.org/lang_select.html#the_values_clause. Status: Implemented.
