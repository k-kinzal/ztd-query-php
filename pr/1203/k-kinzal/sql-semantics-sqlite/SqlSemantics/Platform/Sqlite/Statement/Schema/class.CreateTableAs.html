A request to create a table from the result of a query and fill it with the rows.

Rule: SQLITE-CREATE-TABLE-AS-001. The query is derived as a root query. The statement provides one table declaration whose columns come from the output fields of the query (SQLITE-QUERY-COLUMNS-001); the table has a rowid and no constraints. When the query shape is open or a column name is not determined, the declaration lists the leading determined columns and is marked incomplete. The statement returns no rows. A TEMP table belongs to the temp schema. Source: https://sqlite.org/lang_createtable.html#create_table_as_select_statements. Status: Implemented.
