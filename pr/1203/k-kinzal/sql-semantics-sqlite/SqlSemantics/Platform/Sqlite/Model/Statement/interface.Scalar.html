interface Scalar
    extends Node
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

A scalar expression: an operation over operands that yields one value per evaluation.

Its type, NULL fact and name resolution are not stored on the node; the operation that contains the node derives and owns them.
