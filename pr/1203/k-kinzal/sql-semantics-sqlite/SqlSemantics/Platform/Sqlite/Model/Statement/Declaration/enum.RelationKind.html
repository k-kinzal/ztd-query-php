enum RelationKind
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

What kind of relation a declaration is.

Statements such as SHOW CREATE TABLE or DROP VIEW behave differently for a base table and a view; the declaration states which one it is.
