Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

A relation declaration supplied to an analysis context: a table or a view with its columns.

The object is the identity of the declaration. Two equal-looking tables are two declarations. A context reports a conflict when both claim the same namespace.
