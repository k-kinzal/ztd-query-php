enum UnaryOperator: string
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

The prefix operators of the simple_expr level: +, -, ~ and the tight logical negation !.

Under HIGH_NOT_PRECEDENCE the keyword NOT is the tight negation and is written !. Each case holds the written operator. Source: https://dev.mysql.com/doc/refman/8.4/en/operator-precedence.html, https://dev.mysql.com/doc/refman/8.4/en/sql-mode.html#sqlmode_high_not_precedence.
