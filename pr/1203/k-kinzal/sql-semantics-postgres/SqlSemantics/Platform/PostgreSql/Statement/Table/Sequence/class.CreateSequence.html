A request to create a sequence.

Mirrors PostgreSQL's CreateSeqStmt (sequence with its persistence, options, if_not_exists). A sequence is a relation: the statement provides its declaration (PG-SEQUENCE-001) with the columns last_value and log_cnt (bigint) and is_called (boolean), never NULL, and the system columns. Source: https://www.postgresql.org/docs/17/sql-createsequence.html.
