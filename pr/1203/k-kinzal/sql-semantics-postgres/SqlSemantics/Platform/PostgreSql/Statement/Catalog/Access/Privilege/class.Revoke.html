A request to revoke privileges on objects, or only the right to grant them, from roles.

Rule: PG-REVOKE-001. Mirrors GrantStmt without is_grant: the privileges (an empty list is ALL PRIVILEGES), the objects, the roles, GRANT OPTION FOR, GRANTED BY and CASCADE or RESTRICT as written. The objects and privileges are derived and checked as for GRANT. Source: https://www.postgresql.org/docs/17/sql-revoke.html. Status: Implemented.
