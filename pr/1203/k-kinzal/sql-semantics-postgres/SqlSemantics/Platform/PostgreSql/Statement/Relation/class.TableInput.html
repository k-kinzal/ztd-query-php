One occurrence of a named table, view or common table as query input.

Mirrors PostgreSQL's RangeVar with its Alias and an optional RangeTableSample. The facts follow PG-TABLE-SHAPE-001. Source: https://www.postgresql.org/docs/17/sql-select.html#SQL-FROM. Status: Implemented.
