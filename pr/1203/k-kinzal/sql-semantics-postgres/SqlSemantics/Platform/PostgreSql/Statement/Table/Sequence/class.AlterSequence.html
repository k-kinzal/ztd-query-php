A request to change the options of a sequence.

Mirrors PostgreSQL's AlterSeqStmt (sequence, options, missing_ok). The sequence is resolved (PG- TABLE-TARGET-001) and is the relation fact of the statement; the statement changes no declaration. A relation declared as another kind is reported: "t" is not a sequence in PostgreSQL 16, cannot open relation "t" in PostgreSQL 17 (PG-RELATION-KIND-001). Source: https://www.postgresql.org/docs/17/sql-altersequence.html.
