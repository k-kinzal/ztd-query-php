final class Facts
    uses Snapshot
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Every context-dependent fact an operation derived, keyed by the statement node it is about.

Facts are established when the operation is constructed and never filled in later. A node of another operation has no fact here.
