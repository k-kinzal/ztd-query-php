Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

A fixed language profile together with an immutable snapshot of relation declarations.

The context states what is known: the declarations, whether they enumerate every relation, and how names are compared. The same declaration object given twice is kept once; different objects with the same name are kept as a conflict. Nothing replaces a declaration, and no statement changes a context. Routines, data types and session variables are not declared in a version 1 context; facts that need them name them as missing inputs.
