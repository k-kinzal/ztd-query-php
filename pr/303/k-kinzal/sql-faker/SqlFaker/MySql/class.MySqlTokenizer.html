final class MySqlTokenizer
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads MySQL text back into the parser tokens the server would produce.

This is the inverse of realization and the reason realization can be trusted: SQL written from a terminal sequence is read back here, and the two sequences must agree. It follows the server's own rules — a word before an open parenthesis may be a function name, a run of digits widens from NUM through LONG_NUM by magnitude, WITH ROLLUP is one token — because a tokenizer that merely looked plausible would agree with a generator that was equally wrong.
