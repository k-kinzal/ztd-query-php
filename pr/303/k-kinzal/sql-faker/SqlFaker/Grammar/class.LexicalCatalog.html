final class LexicalCatalog

The checked-in terminal catalog derived from an upstream lexer source.

The catalog records, for each terminal the grammar can produce, SQL that the server's own lexer turns into that terminal. It is generated from an upstream lexer and committed, so it is read rather than trusted: a catalog that cannot be shown to describe a whole lexer is refused at construction rather than producing wrong answers later.
