final class SqliteTerminalRealizer
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Writes one SQLite parser terminal as the SQL text that produces it.

There are two ways to write a terminal and they are not interchangeable. The catalogued way replays SQL that SQLite's own lexer was observed to turn into the terminal, which is what makes generated statements trustworthy. The synthetic way constructs text from the terminal's name, which reaches terminals no catalog witnesses but only promises to be plausible — so it is off unless a caller asks for it.

public const STRICT_TABLE_OPTION = 'STRICT_TABLE_OPTION'
source§

The table option that makes a table reject values of the wrong type.

SQLite's grammar spells this as an ordinary identifier, so the generator needs a terminal of its own to ask for it deliberately rather than hoping an identifier happens to come out as the word STRICT.
