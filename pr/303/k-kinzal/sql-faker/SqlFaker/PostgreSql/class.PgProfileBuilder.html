final class PgProfileBuilder

Builds a PostgreSQL lexical profile from the server's own lexer source.

PostgreSQL splits what one release calls a keyword across a keyword list and a scanner, and its parser frontend rewrites some tokens by looking ahead, so the profile records both and is bound to one exact version.
