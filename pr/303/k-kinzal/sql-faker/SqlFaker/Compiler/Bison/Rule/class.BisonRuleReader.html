final class BisonRuleReader
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads the rules section of a Bison grammar.

A rule is an identifier followed by a colon, and nothing else in the section looks like that. Anything that does not is skipped one token at a time rather than aborting the section, because MySQL's grammar carries constructs this parser has no model for and losing the rules after one of them would be worse than losing the construct itself.
