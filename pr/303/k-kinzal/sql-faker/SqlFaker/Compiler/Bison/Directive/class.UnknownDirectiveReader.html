final class UnknownDirectiveReader
    implements BisonDirectiveReader
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Reads any directive no other reader knows.

Bison keeps adding directives and MySQL's grammar uses several this parser has no model for. Skipping them would silently drop content and leave the stream pointing into the middle of a declaration, so the arguments are consumed to the boundary and kept as text: the declaration survives the round trip even though nothing understands it.
