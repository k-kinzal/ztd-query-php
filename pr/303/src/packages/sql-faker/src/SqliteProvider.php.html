15/**
16 * Faker Provider for generating syntactically valid SQLite SQL statements.
17 *
18 * This provider uses SQLite's official Lemon grammar (parse.y) to generate
19 * SQL that is syntactically valid. Note that generated SQL may not be semantically
20 * valid (tables/columns may not exist).
21 *
22 * maxDepth selects shortest productions once the depth is reached; it is not a SQL length limit.
23 * The basic pipeline resolves lexical spaces without inserting comments. Optional clauses may be empty.
24 * Seed the supplied Faker generator to reproduce a run within the same package version.
25 *
26 * @visibility public
27 *
28 * @example Register the provider with Faker
29 *     $faker = \Faker\Factory::create();
30 *     $faker->addProvider(new \SqlFaker\SqliteProvider($faker));
31 *     $faker->integerLiteral(min: 42, max: 42) // => '42'
32 */

17/**
18 * Faker Provider for generating syntactically valid SQLite SQL statements.
19 *
20 * This provider uses SQLite's official Lemon grammar (parse.y) to generate
21 * SQL that is syntactically valid. Note that generated SQL may not be semantically
22 * valid (tables/columns may not exist).
23 *
24 * maxDepth selects shortest productions once the depth is reached; it is not a SQL length limit.
25 * The basic pipeline resolves lexical spaces without inserting comments. Optional clauses may be empty.
26 * Seed the supplied Faker generator to reproduce a run within the same package version.
27 *
28 * @visibility public
29 *
30 * @example Register the provider with Faker
31 *     $faker = \Faker\Factory::create();
32 *     $faker->addProvider(new \SqlFaker\SqliteProvider($faker));
33 *     $faker->integerLiteral(min: 42, max: 42) // => '42'
34 */
