11/**
12 * Executes generated SQL against PostgreSQL and reports unexpected rejections.
12 * Sends only Parse and Sync to PostgreSQL; generated SQL is never executed.
13 *
14 * PostgreSQL defers preparation, so PDO::prepare() accepts syntax the server
15 * would still refuse. The statement therefore has to be executed, and each run
16 * is wrapped in a savepoint so a rejected statement does not poison the
17 * surrounding transaction. A fuzz run has no schema, so the grammar
18 * legitimately produces statements that reference missing objects; those
19 * SQLSTATEs are tolerated. Any other rejection means the grammar emitted
20 * something PostgreSQL cannot parse, which is a finding and surfaces as an
21 * Error for php-fuzzer to record.
