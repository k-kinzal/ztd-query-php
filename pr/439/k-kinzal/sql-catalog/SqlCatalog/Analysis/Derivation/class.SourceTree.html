final class SourceTree
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Where a node sits in the source: which statement list holds it, and which file.

Walking back from a call means walking back through the statement lists it is nested in, so every statement has to be able to say which list it sits in and at what position. A statement inside a body says so through its parent; a statement at the top of a file has no parent, and is found here instead.
