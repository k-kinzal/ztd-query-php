The table function JSON_TABLE(document, path COLUMNS (...)) [AS] alias.

Rule: MYSQL-JSON-TABLE-001. The document expression sees the enclosing queries and the tables to its left in the same FROM clause (MYSQL-FROM-SCOPE-001). The columns are the slots the column definitions contribute, nested paths flattened in order. A table function without alias is reported. Source: https://dev.mysql.com/doc/refman/8.4/en/json-table-functions.html. Status: Implemented.
