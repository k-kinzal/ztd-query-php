Public API: explicitly declared with @visibility public.

One index hint of a table reference: USE|FORCE|IGNORE INDEX [FOR scope] (indexes).

USE accepts an empty list, which asks for no index; FORCE and IGNORE name at least one index. The names are not checked against declarations: the analysis context holds no indexes. Source: https://dev.mysql.com/doc/refman/8.4/en/index-hints.html.
