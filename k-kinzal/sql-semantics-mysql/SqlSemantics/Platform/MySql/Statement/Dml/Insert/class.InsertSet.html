INSERT or REPLACE of one row written as SET assignments, with the optional row alias and ON DUPLICATE KEY UPDATE.

Rule: MYSQL-INSERT-SET-001. The facts follow MYSQL-INSERT-001; the assigned columns are the written columns and must be distinct. Source: https://dev.mysql.com/doc/refman/8.4/en/insert.html. Status: Implemented.
