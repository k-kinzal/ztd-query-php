enum OptionalWords
Public API: explicitly declared with @visibility public.

Whether optional words that do not change the meaning are written, such as the empty parentheses after CURDATE or the ROW before a row constructor.

Both forms mean the same. The form is kept because MySQL names an unaliased select list expression after its text, so SELECT CURDATE and SELECT CURDATE() return differently named columns. Source: https://dev.mysql.com/doc/refman/8.4/en/select.html, https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html.
