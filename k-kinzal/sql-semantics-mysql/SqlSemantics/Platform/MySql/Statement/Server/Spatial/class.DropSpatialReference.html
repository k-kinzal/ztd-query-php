DROP SPATIAL REFERENCE SYSTEM [IF EXISTS] srid: a request to remove a spatial reference system (MySQL 8.0 and later).

Mirrors PT_drop_srs (Sql_cmd_drop_srs). Rule: MYSQL-DROP-SRS-001. An identifier of 0 or above 2^32-1 is a diagnostic (MYSQL-SRS-CHECK-001). Source: https://dev.mysql.com/doc/refman/8.4/en/drop-spatial-reference-system.html. Status: Implemented.
