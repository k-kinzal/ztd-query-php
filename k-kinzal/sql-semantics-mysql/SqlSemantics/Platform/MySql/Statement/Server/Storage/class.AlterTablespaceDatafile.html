Public API: explicitly declared with @visibility public.

ALTER TABLESPACE name {ADD | DROP | CHANGE} DATAFILE 'file' [option …]: a request to add, remove or resize a data file of a tablespace.

Mirrors PT_alter_tablespace_add_datafile, PT_alter_tablespace_drop_datafile and the ALTER_TABLESPACE commands of st_alter_tablespace in MySQL 5.x. Rule: MYSQL-ALTER-TABLESPACE-DATAFILE-001. ADD and DROP are NDB requests; CHANGE (MySQL 5.x) takes size options only and at least one. The options are checked, kept and written in order by MYSQL-STORAGE-OPTIONS-001. A tablespace is no relation, so the statement neither declares nor resolves one. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-tablespace.html. Status: Implemented.
