enumSourceOptionKind

packages/sql-semantics-mysql/src/Statement/Replication/Source/SourceOptionKind.php:28
enum SourceOptionKind: string
Public API: explicitly declared with @visibility public.

The options of CHANGE REPLICATION SOURCE TO and CHANGE MASTER TO: the fields of the server's LEX_SOURCE_INFO.

Each case holds the keyword of the current vocabulary. An option whose name begins with SOURCE_ (or GET_SOURCE_) is written MASTER_ (or GET_MASTER_) in the legacy vocabulary; the other options have one name. The log file and position options also form the UNTIL condition of START REPLICA. Source: https://dev.mysql.com/doc/refman/8.4/en/change-replication-source-to.html, https://dev.mysql.com/doc/refman/5.7/en/change-master-to.html.
