enum EscapeRule
Public API: explicitly declared with @visibility public.

How a backslash inside a quoted string is read: as an escape character or as itself.

The session mode NO_BACKSLASH_ESCAPES decides it, and the language profile fixes that mode. A string value holds the rule it is spelled under, because the same bytes are spelled differently under each rule; a value built for the other rule than the profile of its operation is refused when the operation is constructed. Source: https://dev.mysql.com/doc/refman/8.4/en/sql-mode.html#sqlmode_no_backslash_escapes.
