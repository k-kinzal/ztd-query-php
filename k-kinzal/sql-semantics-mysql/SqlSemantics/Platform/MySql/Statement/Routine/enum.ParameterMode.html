enum ParameterMode: string

The direction of a procedure parameter: IN, OUT or INOUT.

Each case holds its keyword. A parameter written without a keyword is an IN parameter; the model keeps whether the keyword is written. Source: https://dev.mysql.com/doc/refman/8.4/en/create-procedure.html.
