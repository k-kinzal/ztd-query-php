RESIGNAL: passes on, or changes and passes on, the condition a handler is handling.

The statement is valid on its own and inside a stored program, where a condition name and the names in the item values are resolved in the scope of the statement. The facts follow MYSQL-PROGRAM-CONDITIONS-001. Source: https://dev.mysql.com/doc/refman/8.4/en/resignal.html.
