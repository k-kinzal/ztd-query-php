ALTER USER [IF EXISTS] account n FACTOR {INITIATE REGISTRATION | FINISH REGISTRATION SET CHALLENGE_RESPONSE AS '…' | UNREGISTER} (8.0.27+).

Mirrors the registration flags of LEX_MFA. Rule: MYSQL-ALTER-REGISTRATION-001. The challenge response is an operand with its exact value. A factor number other than 2 or 3 is reported (MYSQL-ACCOUNT-NUMBER-001). Source: https://dev.mysql.com/doc/refman/8.4/en/alter-user.html#alter-user-registration. Status: Implemented.
