PARTITION name [VALUES …] [options] [(subpartitions)]: one partition of a partitioned table.

Mirrors PT_part_definition. RANGE and LIST partitions state their values; KEY and HASH partitions state none. An empty subpartition list means none is written. Source: https://dev.mysql.com/doc/refman/8.4/en/create-table.html#create-table-partitioning.
