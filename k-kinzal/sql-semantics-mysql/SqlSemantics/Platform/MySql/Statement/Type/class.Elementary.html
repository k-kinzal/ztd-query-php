Public API: explicitly declared with @visibility public.

A type written as one keyword: BOOL, SERIAL, JSON, and BIT or VECTOR with an optional length.

BOOLEAN is BOOL; both request TINYINT(1). SERIAL requests BIGINT UNSIGNED NOT NULL AUTO_INCREMENT UNIQUE. The request is kept as written; the expansion is a rule of the statement that declares a column. Source: https://dev.mysql.com/doc/refman/8.4/en/numeric-type-syntax.html, https://dev.mysql.com/doc/refman/8.4/en/json.html, https://dev.mysql.com/doc/refman/9.1/en/vector.html.
