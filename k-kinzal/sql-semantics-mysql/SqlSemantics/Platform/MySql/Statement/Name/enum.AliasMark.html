enum AliasMark
Public API: explicitly declared with @visibility public.

What is written between an operand and its alias: AS, nothing, or in MySQL 5.6 and 5.7 = before a table alias.

The three forms give the same alias. The form is kept because MySQL names an unaliased select list expression after its text, and an alias written inside that expression, in a subquery for example, is part of the text. Source: https://dev.mysql.com/doc/refman/8.4/en/select.html, sql/sql_yacc.yy of MySQL 5.7 (table_alias).
