The WHERE clause of a SHOW: the rows of the statement for which a condition holds.

The condition sees the result columns of the statement and nothing else: a column name resolves to a column of the rows SHOW returns. Source: https://dev.mysql.com/doc/refman/8.4/en/extended-show.html.
