enum ShowListing: string
Public API: explicitly declared with @visibility public.

The FULL and EXTENDED keywords of SHOW TABLES and SHOW COLUMNS.

FULL adds columns (the table type; the collation, privileges and comment of a column). EXTENDED, from MySQL 8.0 on, also lists the hidden tables and columns the server uses internally. Each case holds its keywords. Source: https://dev.mysql.com/doc/refman/8.4/en/show-tables.html, https://dev.mysql.com/doc/refman/8.4/en/show-columns.html.
