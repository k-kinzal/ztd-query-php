The entry rules of the table change family: the methods other families and the statement dispatcher call.

Rule: MYSQL-TABLE-CHANGE-ENTRY-001. Scope: ALTER TABLE, partitioning, DROP TABLE and INDEX, RENAME TABLE and TRUNCATE. The method names, parameters and return types are fixed by the family plan; each delegates to the rule classes of this family (MYSQL-TABLE-CHANGE-STATEMENT-001, MYSQL-ALTER-STATEMENT-001, MYSQL-PARTITION-CLAUSE-001, MYSQL-ALTER-MODIFIER-001, MYSQL-ALTER-STANDALONE-001). Terminates: delegates once. Source: https://dev.mysql.com/doc/refman/8.4/en/alter-table.html. Status: Implemented.
