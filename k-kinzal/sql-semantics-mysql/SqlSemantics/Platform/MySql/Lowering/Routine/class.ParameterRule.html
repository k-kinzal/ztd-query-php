Lowers the parameter lists of stored routines and the data types of parameters, variables and return values.

Rule: MYSQL-ROUTINE-PARAMETER-LOWERING-001. Scope: sp_fdparam_list, sp_fdparams, sp_fdparam, sp_pdparam_list, sp_pdparams, sp_pdparam, sp_opt_inout, type_with_opt_collate. The type comes from the type rules, the collation from the leaf rules. Constructs: ParameterList, Parameter. Terminates: the lists are flattened iteratively. Source: https://dev.mysql.com/doc/refman/8.4/en/create-procedure.html. Status: Implemented.
