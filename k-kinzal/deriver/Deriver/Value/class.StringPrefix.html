final class StringPrefix
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

Retains the bytes every string of a widened set starts with.

A widened string is represented as concat(constant prefix, abstract string). Its prefix only shrinks as more strings are joined, so repeated widening terminates.
