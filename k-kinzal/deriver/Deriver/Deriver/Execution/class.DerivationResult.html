public function definite(): Alternative|null

Selects a single concrete outcome from the explicit execution API. The closed assessment alone does not establish this: a closed result may still carry PHP_WARNING frontiers, exceptional outcomes, or several alternatives.

Returns

Alternative|null The only normal outcome when every observed value is concrete and the result has no frontiers, exceptional outcomes, or source diagnostics; null otherwise
