final class ColumnSet
Restricted visibility: declared "@visibility SqlSemantics\Platform\PostgreSql\Rules\Table". Code outside that scope must not name this declaration.

Collects the columns of a table declaration while a definition is read; lives for one derivation.

Rule: PG-TABLE-DECLARATION-001 (work area). Columns keep the order they are added in; an inherited column of a name already present is merged into it (the column is NOT NULL when either is, and generated when either is); a column added under a name already present is not added again. Once closed, the set takes no more columns: the declaration is complete only up to that point. Status: Implemented.
