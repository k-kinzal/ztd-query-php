enumAggregateAttribute

packages/sql-semantics-postgres/src/Statement/Object/Attribute/Known/AggregateAttribute.php:27
enum AggregateAttribute: string
    implements KnownAttribute
Public API: explicitly declared with @visibility public.

An attribute CREATE AGGREGATE recognizes.

DefineAggregate reads the support functions (sfunc, finalfunc, combinefunc, serialfunc, deserialfunc, msfunc, minvfunc, mfinalfunc) as routine names, sortop as an operator, basetype, stype and mstype as type names, sspace and msspace as integers, the initial conditions as text, parallel and the modify attributes as fixed words and the rest as Booleans. sfunc1, stype1 and initcond1 are obsolete spellings of sfunc, stype and initcond. Any other attribute draws a warning and is ignored. Source: https://www.postgresql.org/docs/17/sql-createaggregate.html, DefineAggregate in src/backend/commands/aggregatecmds.c of PostgreSQL 17.
