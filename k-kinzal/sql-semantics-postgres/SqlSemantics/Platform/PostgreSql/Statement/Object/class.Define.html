Public API: explicitly declared with @visibility public.

CREATE kind name [arguments] ( definition ): defines an aggregate, operator, base or shell type, text search object or collation.

Mirrors PostgreSQL's DefineStmt (kind, oldstyle, defnames, args, definition, if_not_exists, replace). The definition is the list of attributes in written order, each read the way the command for the kind reads it (DefineAggregate, DefineOperator, DefineType, DefineCollation or the text search commands): the function of an operator is a routine name, its argument types are types. An aggregate is written with its argument list, or in the old style without one, where every attribute has a value and its name is an identifier. CREATE TYPE name alone defines a shell type. Source: https://www.postgresql.org/docs/17/sql-createaggregate.html, https://www.postgresql.org/docs/17/sql-createoperator.html, https://www.postgresql.org/docs/17/sql-createtype.html, https://www.postgresql.org/docs/17/sql-createtsdictionary.html, https://www.postgresql.org/docs/17/sql-createcollation.html.
