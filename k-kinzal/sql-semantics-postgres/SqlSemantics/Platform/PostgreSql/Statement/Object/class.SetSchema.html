ALTER kind object SET SCHEMA schema: moves an object to another schema.

Mirrors PostgreSQL's AlterObjectSchemaStmt. A moved relation is resolved; the move changes no declaration of the context. Source: https://www.postgresql.org/docs/17/sql-altertable.html, https://www.postgresql.org/docs/17/sql-alterfunction.html.
