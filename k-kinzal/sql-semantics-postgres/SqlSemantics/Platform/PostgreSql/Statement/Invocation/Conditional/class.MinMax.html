Public API: explicitly declared with @visibility public.

GREATEST (values) or LEAST (values).

Mirrors PostgreSQL's MinMaxExpr. Rule: PG-MINMAX-001. Facts: the common type of the values (Rules\Expression\Unification); NULL values are ignored, so the NULL rule is PG-COALESCING-NULL-001. The result column is named greatest or least. Source: https://www.postgresql.org/docs/17/functions-conditional.html#FUNCTIONS-GREATEST-LEAST. Status: Implemented.
