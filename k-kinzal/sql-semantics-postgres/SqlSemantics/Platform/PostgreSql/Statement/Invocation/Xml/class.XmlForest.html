XMLFOREST (values): a sequence of XML elements, one per value.

Mirrors PostgreSQL's XmlExpr of kind IS_XMLFOREST. Rule: PG-XMLFOREST-001. Facts: xml; NULL values are omitted (PG-COALESCING-NULL-001). Diagnostics: an unnamed value that is not a column reference (PG-XML-CHECKS-001). The result column is named xmlforest. Source: https://www.postgresql.org/docs/17/functions-xml.html#FUNCTIONS-PRODUCING-XML-XMLFOREST. Status: Implemented.
