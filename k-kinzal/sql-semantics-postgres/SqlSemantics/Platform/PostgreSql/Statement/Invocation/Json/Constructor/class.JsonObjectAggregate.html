JSON_OBJECTAGG (key : value [NULL | ABSENT ON NULL] [WITH | WITHOUT UNIQUE] [RETURNING type]) with FILTER and OVER.

Mirrors PostgreSQL's JsonObjectAgg with its JsonAggConstructor. Rule: PG-JSON-OBJECTAGG-001. Facts: the pair, the filter and the window are derived at the position; the RETURNING type, otherwise json; NULL over no row. The result column is named json_objectagg. Source: https://www.postgresql.org/docs/17/functions-aggregate.html. Status: Implemented.
