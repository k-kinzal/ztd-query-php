The parenthesized parameter list of a routine definition.

In an SQL-standard body the input parameters are visible as one row: a name that is no column of the statement's own relations denotes the parameter of that name, and routine_name.parameter qualifies it. The list is therefore a relation whose row shape holds one slot per input parameter, named when the parameter is named; a parameter can be NULL. Source: https://www.postgresql.org/docs/17/xfunc-sql.html#XFUNC-SQL-FUNCTION-ARGUMENTS.
