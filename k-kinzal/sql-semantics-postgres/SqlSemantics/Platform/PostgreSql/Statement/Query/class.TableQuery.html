    implements Statement, Query, Selection, OutputNaming
    uses Snapshot
Public API: explicitly declared with @visibility public.

TABLE name: every row and column of one table, the same as SELECT * FROM name.

Rule: PG-TABLE-QUERY-001. The table is one FROM item without alias; the output is every column of it, and the ORDER BY, LIMIT and locking clauses written after it see its columns as a selection would. Source: https://www.postgresql.org/docs/17/sql-select.html#SQL-TABLE. Status: Implemented.
