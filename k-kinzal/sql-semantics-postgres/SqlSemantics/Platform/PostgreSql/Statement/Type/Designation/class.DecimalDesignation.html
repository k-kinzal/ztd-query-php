The type spelled NUMERIC, DECIMAL or DEC, with optional precision and scale.

Rule: PG-TYPE-DECIMAL-001. The grammar reads the modifiers as expressions; the type takes one or two integer constants. Facts: PG-TYPE-MODIFIER-001. Source: https://www.postgresql.org/docs/17/datatype-numeric.html#DATATYPE-NUMERIC-DECIMAL. Status: Implemented.
