A request to add a constraint to a domain: ALTER DOMAIN name ADD constraint [ NOT VALID ].

Rule: PG-DOMAIN-002. Mirrors AlterDomainStmt subtype 'C'. Release 16 writes a table constraint, release 17 a domain constraint (DomainCheck, DomainNotNull). The constraint sees VALUE, whose type depends on the undeclared domain (PG-DOMAIN-VALUE-001); kinds a domain cannot have are diagnostics (PG-DOMAIN-CHECK-001). Source: https://www.postgresql.org/docs/17/sql-alterdomain.html. Status: Implemented.
