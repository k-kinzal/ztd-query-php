The grouping operation GROUPING(a, b, …): a bit mask telling which arguments the current grouping set leaves out.

Mirrors PostgreSQL's GroupingFunc node.

Rule: PG-GROUPING-001. Facts: integer, never NULL; an unaliased result column is named grouping. Whether each argument matches a grouping expression is decided by the query that groups. Source: https://www.postgresql.org/docs/17/functions-aggregate.html#FUNCTIONS-GROUPING-TABLE. Status: Implemented.
