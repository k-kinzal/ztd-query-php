enum ConstraintAttribute: string
    implements Clause
Public API: explicitly declared with @visibility public.

A property written after a constraint: whether it can be deferred, when it is checked, and whether it is validated or inherited.

Mirrors the CONSTR_ATTR_* values of PostgreSQL's Constraint node and the CAS_* bits of ConstraintAttributeSpec. NOT DEFERRABLE and INITIALLY IMMEDIATE are the defaults; a written default is kept as written. Source: https://www.postgresql.org/docs/17/sql-createtable.html.
