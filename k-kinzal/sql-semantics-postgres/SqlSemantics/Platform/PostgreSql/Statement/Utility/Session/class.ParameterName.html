Public API: explicitly declared with @visibility public.

The name of a configuration parameter, such as search_path or plpgsql.variable_conflict.

Mirrors the name of PostgreSQL's VariableSetStmt: the dotted parts in order. A parameter of an extension is written with the extension's prefix. Parameter names are compared without regard to case by the server, and an unquoted name is folded to lower case when it is read. Source: https://www.postgresql.org/docs/17/sql-set.html, https://www.postgresql.org/docs/17/runtime-config-custom.html.
