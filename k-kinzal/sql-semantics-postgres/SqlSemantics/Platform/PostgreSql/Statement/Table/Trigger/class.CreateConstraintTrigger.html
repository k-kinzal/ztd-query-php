A request to create a constraint trigger: an AFTER ROW trigger whose firing can be deferred.

Mirrors PostgreSQL's CreateTrigStmt with isconstraint (constrrel, deferrable, initdeferred). The table and the referenced table are resolved; the WHEN condition sees the table's columns as OLD and NEW (PG-TRIGGER-001). Source: https://www.postgresql.org/docs/17/sql-createtrigger.html.
