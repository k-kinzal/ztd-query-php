enumCursorOption

enum CursorOption: string
Public API: explicitly declared with @visibility public.

An option written between the cursor name and CURSOR: BINARY, ASENSITIVE, INSENSITIVE, SCROLL or NO SCROLL.

Mirrors the CURSOR_OPT_* bits of PostgreSQL's DeclareCursorStmt. Every cursor of PostgreSQL is insensitive, so ASENSITIVE and INSENSITIVE change nothing but cannot be combined; SCROLL and NO SCROLL cannot be combined either. The value is the keyword sequence. Source: https://www.postgresql.org/docs/17/sql-declare.html.
