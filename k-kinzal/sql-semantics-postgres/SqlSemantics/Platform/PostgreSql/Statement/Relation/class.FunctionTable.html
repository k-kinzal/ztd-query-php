Public API: explicitly declared with @visibility public.

A function call, or ROWS FROM of several, used as a FROM item.

Mirrors PostgreSQL's RangeFunction. The facts follow PG-FUNCTION-TABLE-001. A function call may refer to the FROM items before it whether or not LATERAL is written; the word is kept as written. Column definitions are written after the alias for one function outside ROWS FROM, and per function inside it. Source: https://www.postgresql.org/docs/17/queries-table-expressions.html#QUERIES-TABLEFUNCTIONS. Status: Implemented.
