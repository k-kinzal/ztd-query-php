final class AlterCommandRule
Restricted visibility: declared "@visibility SqlSemantics". Code outside that scope must not name this declaration.

Lowers the actions of ALTER TABLE.

Rule: PG-ALTER-COMMAND-LOWER-001. Scope: alter_table_cmd, alter_column_default, alter_using, replica_identity, alter_identity_column_option_list, alter_identity_column_option, set_statistics_value, set_access_method_name. The optional COLUMN words are noise (LeafNoise opt_column, TableNoise ADD COLUMN), and so is SET DATA before TYPE (LeafNoise). Termination: lists are flattened iteratively. Source: https://www.postgresql.org/docs/17/sql-altertable.html. Status: Implemented.
