final class SelectRule
Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers query productions into selections, VALUES clauses, compound queries and queries with common tables.

Rule: SQLITE-SELECT-LOWER-001. Scope: select, selectnowith, multiselect_op, oneselect, groupby_opt, having_opt, limit_opt. The arms of a compound query keep their written order; the ORDER BY and LIMIT written after its last arm become those of the compound query. In ORDER BY and GROUP BY an integer constant becomes a result column position (SQLITE-ORDINAL-001). Terminates: the arm list is flattened iteratively; every other child is a strict subtree. Source: https://sqlite.org/lang_select.html. Status: Implemented.
