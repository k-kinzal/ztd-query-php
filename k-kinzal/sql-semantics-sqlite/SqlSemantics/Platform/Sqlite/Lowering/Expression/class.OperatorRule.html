Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

Lowers the binary and prefix operator productions.

Rule: SQLITE-EXPR-OPERATOR-001. Scope: the expr productions of the binary operators, the IS family and the prefix operators. The operator is kept by its spelling and the operands in written order; the structure the parser chose is the structure built. Terminates: every operand is a strict subtree. Source: https://sqlite.org/lang_expr.html#operators_and_parse_affecting_attributes. Status: Implemented.
