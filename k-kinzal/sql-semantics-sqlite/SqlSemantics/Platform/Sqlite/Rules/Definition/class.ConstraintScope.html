Restricted visibility: declared "@visibility SqlSemantics\Platform\Sqlite". Code outside that scope must not name this declaration.

What the expressions and column names inside a table definition can refer to.

Rule: SQLITE-DEFINITION-SCOPE-001. A CHECK constraint, a key term and an index expression see the columns of the table being defined or changed and its row identifier. The expression of a generated column sees the columns but "may not directly reference the ROWID". A DEFAULT value must be constant and sees no column at all, so a column name in it is a missing column. A column list of a constraint names declared columns only. The scope is a working value of one derivation. Source: https://sqlite.org/lang_createtable.html, https://sqlite.org/gencol.html. Status: Implemented.
