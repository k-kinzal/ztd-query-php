A DEFERRABLE or NOT DEFERRABLE clause of a foreign key.

Rule: SQLITE-FK-DEFERRABLE-001. A foreign key is checked at the end of the transaction only when the clause is DEFERRABLE INITIALLY DEFERRED; every other form, NOT DEFERRABLE INITIALLY DEFERRED included, is checked at the end of each statement. Written as a column constraint, the clause applies to the foreign key defined last before it in the table definition and has no effect when there is none. Source: https://sqlite.org/foreignkeys.html#fk_deferred. Status: Implemented.
