interface TableConstraint

Public API: explicitly declared with @visibility public.

One clause of the constraint list written after the columns of a table definition.

The closed set is: a constraint name, PRIMARY KEY, UNIQUE, CHECK and FOREIGN KEY. Source: https://sqlite.org/syntax/table-constraint.html.
