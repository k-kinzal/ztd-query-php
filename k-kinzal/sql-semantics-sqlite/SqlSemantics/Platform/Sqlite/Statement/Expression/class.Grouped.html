Public API: explicitly declared with @visibility public.

An expression written in parentheses.

The grouping fixes the evaluation structure of its operand and is kept as written; rendering never adds or removes a grouping.

Rule: SQLITE-GROUPED-001. The type and the NULL fact are those of the operand. The name resolution stays with the operand, the node that is the name use; rules that look through groupings read it there. Source: https://sqlite.org/lang_expr.html. Status: Implemented.
