The declared type of a SQLite column: its text as SQLite reports it and the affinity SQLite derives from it.

Rule: SQLITE-COLUMN-AFFINITY-001. A declared type that is one of the standard names ANY, BLOB, INT, INTEGER, REAL and TEXT, compared without regard to ASCII case, is reported in upper case. The affinity follows the five ordered substring rules of the manual, applied to the declared text without regard to ASCII case; a column without a declared type has BLOB affinity. A column of an ordinary table can hold a value of any storage class. A column of a STRICT table holds only the storage class its standard type names (INT and INTEGER: INTEGER; REAL: REAL, with integers converted; TEXT; BLOB) or NULL, and a STRICT column of type ANY holds any value unchanged, which is BLOB affinity. Source: https://sqlite.org/datatype3.html#determination_of_column_affinity, https://sqlite.org/stricttables.html. Status: Implemented.
