final class StatementPart
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

One piece of a catalogued statement: a run of text that is known, or a gap.

A statement the analyzer could not pin down is not a string with a marker in it. It is a shape, and the gaps in that shape are claims about the analysis: this much is the statement, and this much is a value that would be spliced into it. Reporting the two apart is what lets a reader see which is which instead of reading {$} as something the program writes.
