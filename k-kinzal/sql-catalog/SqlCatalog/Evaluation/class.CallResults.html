final class CallResults
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

What following a call produced, remembered for the next caller that leads there.

Following the same function with the same arguments reaches the same statements and returns the same value, however many callers lead there. Reading it once is what keeps a file whose functions call each other heavily from being walked over and over.
