interface Term
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

One alternative an expression may evaluate to.

The hierarchy is sealed. A term is a resolved scalar (LiteralTerm), a string with gaps (PatternTerm), an array (ArrayTerm), an object (ObjectTerm), or a value known only by its type (OpaqueTerm).
