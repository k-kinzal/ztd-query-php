Which hue each fact about a statement is written in.

What a statement does and what the analyzer managed to establish about it are two different things, and the report keeps them apart by hue. The kind carries an identity hue because it is a property of the statement; the resolution and the findings carry state hues because they are judgements about the reading. A search the analyzer left open is the common case in a real application, so it is written quietly, and the loud hues are kept for what is rare and worth a look: input from outside the program, and a finding of some severity.
