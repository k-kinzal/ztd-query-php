final class TableReader

Reads the tables a statement names.

The names let a catalog be grouped and filtered by table, and are what a fixture generator needs in order to build rows for the statement. A name the analyzer knows only part of — a prefix read from configuration and a suffix written in the source — is still a name to group by, and is reported with the unknown part marked. A name nothing is known of is not guessed at.
