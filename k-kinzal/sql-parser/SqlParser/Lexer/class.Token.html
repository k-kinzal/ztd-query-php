final class Token
Public API: explicitly declared with @visibility public.

One terminal as the lexer read it from the SQL text.

A token carries the whitespace and comments written before it, so a run of tokens spells the text it was read from, byte for byte. The end marker and other tokens a lexer synthesises have no text and stand at the offset where the lexer produced them, which is how the trivia before them still has an owner.
