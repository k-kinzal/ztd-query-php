enum Associativity
Restricted visibility: declared "@visibility root". Code outside that scope must not name this declaration.

How a shift/reduce conflict between equally ranked operators is settled.

A grammar declares operators in ranked groups. When a shift and a reduce carry the same rank, the group's associativity decides: left-associative operators reduce, right-associative ones shift, non-associative ones make the token an error, and a bare rank leaves the conflict unresolved.
