final class LexicalProfileSource

Loads the checked-in lexical profile for one dialect and version.

A profile is generated from the server's own lexer and committed as a PHP file, so it is loaded rather than trusted: a file that names a different dialect or version than the one asked for describes a different server, and generating against it would produce SQL that only looks right.
